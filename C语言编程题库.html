Q-001

两个整数的和、差、积、商与余数

基础 03-顺序结构与输入输出

题目：输入两个整数 a、b（b 不为 0），分行输出它们的和、差、积、整除商、余数。

要求：用 %d 输出；除法用整数除法（7/2 得 3）。

输入示例

▸ 程序输出
7 2

输出示例

▸ 程序输出
sum=9
diff=5
prod=14
quot=3
rem=1
参考答案
// in: 7 2
#include <stdio.h>
int main(void) {
    int a, b;
    scanf("%d%d", &a, &b);
    printf("sum=%d\n",  a + b);
    printf("diff=%d\n", a - b);
    printf("prod=%d\n", a * b);
    printf("quot=%d\n", a / b);     /* 整数除法：7/2 = 3，小数部分被丢掉 */
    printf("rem=%d\n",  a % b);     /* % 只能用于整数 */
    return 0;
}
▸ 程序输出
sum=9
diff=5
prod=14
quot=3
rem=1
⚠ 易错：把 a + b 写成 a + b 却忘了换行 \n，五行会挤在一起——格式分直接丢光。 ⚠ 易错：% 对浮点数用是编译错误（7.0 % 2 不合法）。
Q-002

三位整数的数位拆解

基础 03-顺序结构与输入输出

题目：输入一个三位正整数，输出它的百位、十位、个位数字之和，以及逆序后的整数。

输入示例

▸ 程序输出
123

输出示例

▸ 程序输出
sum=6
rev=321
参考答案
// in: 123
#include <stdio.h>
int main(void) {
    int n, a, b, c;
    scanf("%d", &n);
    a = n / 100;          /* 百位：123/100 = 1 */
    b = n / 10 % 10;      /* 十位：先 12 再 %10 = 2 */
    c = n % 10;           /* 个位：123%10 = 3 */
    printf("sum=%d\n", a + b + c);
    printf("rev=%d\n", c * 100 + b * 10 + a);
    return 0;
}
▸ 程序输出
sum=6
rev=321
💡 任意位数的通用拆位写法（循环）：while (n > 0) { d = n % 10; n /= 10; }，每次取到最后一位。 ⚠ 易错：把十位写成 n / 10（得到 12，不是 2）——必须再 % 10。
Q-003

字符与 ASCII 码互查

基础 03-顺序结构与输入输出

题目：输入一个大写字母，输出它本身、它的 ASCII 码值、以及对应的小写字母。

输入示例

▸ 程序输出
A

输出示例

▸ 程序输出
ch=A code=65 lower=a
参考答案
// in: A
#include <stdio.h>
int main(void) {
    char ch;
    scanf("%c", &ch);                 /* %c 读单个字符，前面不要加空格 */
    printf("ch=%c code=%d lower=%c\n", ch, ch, ch + 32);
    return 0;
}
▸ 程序输出
ch=A code=65 lower=a
💡 记忆：'A'=65，'a'=97，差 32。小写转大写就是 ch - 32。 ⚠ 易错：char 型参与运算时按 ASCII 码当整数算；ch + 32 的结果是 int，用 %c 打印会自动当字符输出。 ⚠ 易错：scanf("%c", &ch) 会读到空格和回车。如果前面刚读过数字，要在 %c 前加一个空格写成 scanf(" %c", &ch) 来跳过空白。
Q-004

交换两个变量的值（三种写法）

基础 03-顺序结构与输入输出

题目：输入两个整数，交换后输出。

输入示例

▸ 程序输出
3 8

输出示例

▸ 程序输出
8 3
参考答案
// in: 3 8
#include <stdio.h>
int main(void) {
    int a, b, t;
    scanf("%d%d", &a, &b);
    /* 写法一：用临时变量（考试首选，最不容易错） */
    t = a; a = b; b = t;
    printf("%d %d\n", a, b);
    return 0;
}
▸ 程序输出
8 3

另外两种写法（了解即可，考试推荐写法一）：

/* 写法二：加减法 —— 缺点：a+b 可能整数溢出 */
a = a + b; b = a - b; a = a - b;

/* 写法三：异或法 —— 缺点：可读性差，且 a、b 相同时结果为 0 */
a = a ^ b; b = a ^ b; a = a ^ b;
⚠ 易错：顺序不能写反。a = b; b = a; 两句话下来两个变量都变成原来的 b —— 这是最经典的错误，因为第一句就把 a 的原值覆盖了。
Q-005

秒数换算成时分秒

基础 03-顺序结构与输入输出

题目：输入一个整数秒数（0 ≤ n < 86400），输出对应的 时:分:秒。

输入示例

▸ 程序输出
3725

输出示例

▸ 程序输出
1:2:5
参考答案
// in: 3725
#include <stdio.h>
int main(void) {
    int n, h, m, s;
    scanf("%d", &n);
    h = n / 3600;          /* 1 小时 */
    m = n % 3600 / 60;     /* 剩 125 秒 -> 2 分 */
    s = n % 60;            /* 剩 5 秒 */
    printf("%d:%d:%d\n", h, m, s);
    return 0;
}
▸ 程序输出
1:2:5
💡 套路：大单位用整除、小单位用取余。凡是「换算」类题目都是这个模式： 高位 = n / 进制; n = n % 进制; 反复做下去（这就是进制转换的雏形）。 ⚠ 易错：m = n % 3600 / 60 里，% 和 / 优先级相同、从左往右算，所以先取余再除是对的；写成 n / 60 % 60 也对，但要能讲清为什么。
Q-006

三个数的平均值（保留两位小数）

基础 03-顺序结构与输入输出

题目：输入三个实数，输出它们的平均值，保留两位小数。

输入示例

▸ 程序输出
1 2 4

输出示例

▸ 程序输出
avg=2.33
参考答案
// in: 1 2 4
#include <stdio.h>
int main(void) {
    double a, b, c;
    scanf("%lf%lf%lf", &a, &b, &c);     /* double 用 %lf 读入 */
    printf("avg=%.2f\n", (a + b + c) / 3.0);
    return 0;
}
▸ 程序输出
avg=2.33
⚠ 易错（最高频的丢分点）：
  • double 读入必须用 %lf，输出可以用 %f；
  • float 读入也用 %f。读入 double 写成 %f 会读出垃圾值。
  • 除数写成 3 会做整数除法吗？不会—— (a+b+c) 已经是 double，3 会自动转成 3.0。但如果三个数都是 int，sum / 3 就真的丢掉小数了，必须写 / 3.0。
Q-007

大小写互换

基础 03-顺序结构与输入输出04-选择结构

题目：输入一个字符，若是大写字母输出其小写，若是小写字母输出其大写，其他字符原样输出。

输入示例

▸ 程序输出
G

输出示例

▸ 程序输出
g
参考答案
// in: G
#include <stdio.h>
int main(void) {
    char ch;
    scanf("%c", &ch);
    if (ch >= 'A' && ch <= 'Z')       ch = ch + 32;   /* 大写 -> 小写 */
    else if (ch >= 'a' && ch <= 'z')  ch = ch - 32;   /* 小写 -> 大写 */
    printf("%c\n", ch);
    return 0;
}
▸ 程序输出
g
💡 判断「是不是字母」必须用两个条件加 &&：ch >= 'A' && ch <= 'Z'。 ⚠ 易错：写成 'A' <= ch <= 'Z' —— 这是数学写法！C 里先算 'A' <= ch 得到 0 或 1，再拿 0/1 和 'Z' 比，永远为真，逻辑全废。这个错误 2025 年真题考过。
Q-008

整数各位数字之和（任意位数）

拔高 05-循环结构

题目：输入一个非负整数（可能很大，最多 9 位），输出它各位数字之和。

输入示例

▸ 程序输出
98765

输出示例

▸ 程序输出
sum=35
参考答案
// in: 98765
#include <stdio.h>
int main(void) {
    int n, d, s = 0;
    scanf("%d", &n);
    if (n == 0) { printf("sum=0\n"); return 0; }   /* 0 要单独处理，否则 while 一次都不进 */
    while (n > 0) {
        d = n % 10;      /* 取最后一位 */
        s += d;
        n /= 10;         /* 丢掉最后一位 */
    }
    printf("sum=%d\n", s);
    return 0;
}
▸ 程序输出
sum=35
💡 这是「拆位」的标准循环模板，后面判回文数、水仙花数、数字逆序全用它。 ⚠ 易错：忘记处理 n = 0。此时 while (n > 0) 一次都不执行，输出 sum=0 恰好正确——但如果你写的是「先 do 后判断」，就要小心了。真正会错的是「求位数」类题目（0 应该是 1 位数）。
Q-009

温度换算表

拔高 03-顺序结构与输入输出05-循环结构

题目：输出摄氏温度 0、20、40、…、100 度对应的华氏温度，每行一个，格式 C=20 F=68.0。公式 F = C × 9 / 5 + 32。

输出示例

▸ 程序输出
C=0 F=32.0
C=20 F=68.0
...
C=100 F=212.0
参考答案
#include <stdio.h>
int main(void) {
    int c;
    for (c = 0; c <= 100; c += 20)
        printf("C=%d F=%.1f\n", c, c * 9.0 / 5.0 + 32.0);
    return 0;
}
▸ 程序输出
C=0 F=32.0
C=20 F=68.0
C=40 F=104.0
C=60 F=140.0
C=80 F=176.0
C=100 F=212.0
⚠ 易错（本题的核心陷阱）：写成 c * 9 / 5 + 32 —— c 是 int，c*9/5 全程整数运算，C=20 时 20*9/5 = 36 没问题，但 C=60 时 60*9/5 = 108 也对…… 危险在别处：只要出现除不尽就会丢小数，例如 C=10 时 90/5=18 仍然整除。所以本题两种写法结果相同。 但换成 F = C * 9 / 5.0 + 32 或 9.0/5.0 才永远安全。规则：只要结果要小数，至少让一个操作数是浮点。
Q-010

一元二次方程求根（含判别式分支）

拔高 04-选择结构

题目：输入 a、b、c（a ≠ 0），求 ax² + bx + c = 0 的根，按判别式分三种情况输出：

  • d > 0：两个不等实根，输出 x1=_.2f x2=_.2f（x1 ≥ x2）
  • d == 0：输出 x1=x2=_.2f
  • d < 0：输出 no real root

输入示例

▸ 程序输出
1 -5 6

输出示例

▸ 程序输出
x1=3.00 x2=2.00
参考答案
// in: 1 -5 6
#include <stdio.h>
#include <math.h>
int main(void) {
    double a, b, c, d, x1, x2;
    scanf("%lf%lf%lf", &a, &b, &c);
    d = b * b - 4 * a * c;
    if (d > 0) {
        x1 = (-b + sqrt(d)) / (2 * a);
        x2 = (-b - sqrt(d)) / (2 * a);
        if (x1 < x2) { double t = x1; x1 = x2; x2 = t; }   /* 保证 x1 大 */
        printf("x1=%.2f x2=%.2f\n", x1, x2);
    } else if (d == 0) {
        printf("x1=x2=%.2f\n", -b / (2 * a));
    } else {
        printf("no real root\n");
    }
    return 0;
}
▸ 程序输出
x1=3.00 x2=2.00
💡 关键三点：
  1. sqrt 需要 #include <math.h>，且参数必须是 double（传 int 会隐式转换，但建议显式写 sqrt((double)d)）；
  2. 浮点数不要用 == 比大小的理想做法是 fabs(d) < 1e-6，但考试里判 d == 0 通常给的是整除的情况，可以直接比——如果题目给的数据除不尽，就必须用 fabs(d) < 1e-6；
  3. 输出前先排序，保证 x1 ≥ x2，题目要求的顺序不能反。
⚠ 易错：(-b + sqrt(d)) / (2 * a) 里，/ 必须除 (2*a) 而不是 2*a —— 其实 2*a 也对（乘除同级左结合），但写成 2a 就是编译错误，而且写成 -b + sqrt(d) / 2 * a 就完全错了（优先级变了）。
Q-011

字节重排（位运算）

拔高 02-运算符与表达式（位运算）

题目：输入一个 32 位无符号整数 x，把它低 8 位和高 8 位互换，其余位不变，输出结果的十进制值。

提示：x & 0xFF 取低 8 位；(x >> 24) & 0xFF 取高 8 位；用 << 把它们搬到对面；用 & 0x00FFFF00 保留中间位。

输入示例

▸ 程序输出
305419896

输出示例

▸ 程序输出
2016695826

提示：305419896 就是 0x12345678。低字节是 0x78、高字节是 0x12，互换后应得 0x78345612。

参考答案
// in: 305419896
#include <stdio.h>
int main(void) {
    unsigned int x, lo, hi, mid, r;
    scanf("%u", &x);                       /* 无符号用 %u */
    lo  = x & 0xFF;                        /* 低 8 位 */
    hi  = (x >> 24) & 0xFF;                /* 高 8 位 */
    mid = x & 0x00FFFF00;                  /* 中间 16 位原样保留 */
    r = mid | (lo << 24) | hi;             /* 低搬到高，高搬到低 */
    printf("%u\n", r);
    return 0;
}
▸ 程序输出
2016695826
💡 本题是位运算的通用模板：& 掩码 取位、| 置位、^ 翻转、<< >> 移位。
  • 0xFF = 低 8 位全是 1；
  • 移位时要注意符号（无符号是逻辑移位；有符号的 int 右移补什么由实现决定）；
  • 本题 0x12345678 → lo=0x78、hi=0x12、mid=0x00345600，合起来 0x78345612 = 2016695826。
⚠ 易错：用 int 而不是 unsigned int。若 lo 的最高位是 1（比如输入 0xF2345678），lo << 24 会溢进符号位变成负数，输出就成了负数——考试里必须写 unsigned 或先强转。

Q-017

最大公约数与最小公倍数

基础 05-循环结构

题目：输入两个正整数 a、b，输出它们的最大公约数和最小公倍数。

输入示例

▸ 程序输出
12 18

输出示例

▸ 程序输出
gcd=6 lcm=36
参考答案
// in: 12 18
#include <stdio.h>
int main(void) {
    int a, b, x, y, t;
    scanf("%d%d", &a, &b);
    x = a; y = b;
    while (y != 0) {          /* 辗转相除法（欧几里得算法） */
        t = x % y;
        x = y;
        y = t;
    }
    printf("gcd=%d lcm=%d\n", x, a / x * b);   /* 先除后乘，防溢出 */
    return 0;
}
▸ 程序输出

💡 记住这个循环的形状：while (y != 0) { t = x % y; x = y; y = t; }，结束后 x 就是最大公约数。 💡 最小公倍数 = a * b / gcd。写成 a / gcd * b 更好：先除后乘能避免 a*b 溢出。 ⚠ 易错：用完 a、b 就丢了。上面必须先把 a、b 备份到 x、y（或者在算 lcm 时用原来的 a）——如果直接用 a、b 做辗转相除，循环结束时它们都变了，lcm 就算错。

  • "abc" vs "abd"：前两字符相同，第三字符 'c'(99) - 'd'(100) = -1 < 0 → s1 < s2；
  • ⚠ 注意 strcmp 比较的是字符的 ASCII 码，所以大写字母全部小于小写字母（"Z" < "a"）。
  • 拼接结果是 abcabd（"abc" 后面接上 "abd"），不是覆盖。
⚠ 易错：s1 必须开得足够长（本题 200）才能装下 s1 + s2。真题第 23 题就是考这个——char s1[100] 拼接后可能溢出。 ⚠ 易错：比较时用 if (s1 > s2) —— 这是比较两个数组的首地址（永远是错的，且不同编译器结果不同）！字符串比较必须逐个字符比。
Q-040

字符串逆序输出（指针版）

基础 08-指针

题目：输入一个不含空格的字符串，用指针把字符串原地逆置后输出（不许用数组下标 s[i]）。

输入示例

▸ 程序输出
program

输出示例

▸ 程序输出
margorp
参考答案
// in: program
#include <stdio.h>
#include <string.h>
int main(void) {
    char s[100], *p, *q, t;
    scanf("%s", s);
    p = s;                        /* p 指向第一个字符 */
    q = s + strlen(s) - 1;        /* q 指向最后一个字符（'\0' 前一个） */
    while (p < q) {
        t = *p; *p = *q; *q = t;  /* 交换两端 */
        p++; q--;                 /* 向中间靠拢 */
    }
    printf("%s\n", s);
    return 0;
}
▸ 程序输出
margorp
💡 双指针法：一个从头、一个从尾，向中间走，相遇即停。
  • q = s + strlen(s) - 1 是关键：strlen 返回字符个数，因为下标从 0 开始，末字符位置是 len - 1；
  • 循环条件 p < q（不是 p != q）—— 偶数长度时两个指针会交错而不相遇，用 != 会死循环！
⚠ 易错：q = s + strlen(s) 少减 1 → 从 '\0' 开始交换，把结束标记换到前面，输出直接变成空串。 ⚠ 易错：循环写成 p != q → 长度为偶数时死循环（比如 "abcd"：p 走到 b、q 走到 c，再走一步 p>q 但永不相等）。 ⚠ 易错：本题用了 strlen 需要 #include <string.h>；漏了头文件在 C99 下是隐式声明警告，某些编译器直接报错。

题目：编写函数 int isPrime(int n)，是素数返回 1，否则返回 0。在 main 里输出 2~m 之间所有素数（m 由输入给出），用空格分隔。

▸ 程序输出

// in: 20
#include <stdio.h>

int isPrime(int n) {
    int i;
    if (n < 2) return 0;              /* 0 和 1 都不是素数，边界单独处理 */
    for (i = 2; i * i <= n; i++)
        if (n % i == 0) return 0;     /* 找到因子立刻返回 0 */
    return 1;
}

int main(void) {
    int m, i, cnt = 0;
    scanf("%d", &m);
    for (i = 2; i <= m; i++) {
        if (isPrime(i)) {
            if (cnt) printf(" ");
            printf("%d", i);
            cnt++;
        }
    }
    printf("\n");
    return 0;
}
▸ 程序输出
2 3 5 7 11 13 17 19
💡 函数的提前返回：找到因子就 return 0，不用 break + flag——函数里比循环里干净得多。这就是「拆函数」的价值。 ⚠ 易错：忘了 if (n < 2) return 0; → isPrime(1) 会返回 1（循环一次都不进，直接走到 return 1）。任何「判断类」函数都要先想边界。

输入示例

▸ 程序输出

// in: <<<
5
60 70 80 90 100
// >>>
#include <stdio.h>

double average(int a[], int n) {      /* 数组作参数：a[] 里不用写长度 */
    int i, s = 0;
    for (i = 0; i < n; i++) s += a[i];
    return (double)s / n;             /* 强转，避免整数除法 */
}

int main(void) {
    int n, i, a[100], cnt = 0;
    double avg;
    scanf("%d", &n);
    for (i = 0; i < n; i++) scanf("%d", &a[i]);
    avg = average(a, n);              /* 传数组名 = 传首地址，不用写 a[] */
    for (i = 0; i < n; i++)
        if (a[i] > avg) cnt++;
    printf("avg=%.2f\n", avg);
    printf("above=%d\n", cnt);
    return 0;
}
▸ 程序输出

above=2
💡 数组作参数的三条铁律：
  1. 形参写 int a[] 或 int *a 都行，本质都是指针；
  2. 长度必须另用一个参数传（int n）——函数里 sizeof(a) 得到的是指针大小（8），不是数组长度！
  3. 调用时写 average(a, n)，数组名后面不加方括号。
⚠ 易错：函数里写 int len = sizeof(a) / sizeof(a[0]); —— 在函数内部 a 已退化成指针，算出来永远是 2（64 位下 8/4）。这是最经典的陷阱。 ⚠ 易错：函数里改 a[i] 会真的改到原数组（因为传的是地址），这和普通变量「改副本不影响原值」正好相反。

汉诺塔

拔高 07-函数

题目：用递归输出汉诺塔的移动步骤。输入盘子数 n（1 ≤ n ≤ 4），把 n 个盘子从 A 柱移到 C 柱，借助 B 柱。每行输出一步，格式 A->C。最后输出总步数。

2

// in: 2
#include <stdio.h>

int steps = 0;                         /* 全局变量累计步数 */

void hanoi(int n, char from, char to, char via) {
    if (n == 1) {                      /* 出口：只剩一个盘子，直接搬 */
        printf("%c->%c\n", from, to);
        steps++;
        return;
    }
    hanoi(n - 1, from, via, to);       /* 把上面 n-1 个搬到中转柱 */
    printf("%c->%c\n", from, to);       /* 搬最大的那个 */
    steps++;
    hanoi(n - 1, via, to, from);       /* 再把 n-1 个从转柱搬到目标柱 */
}

int main(void) {
    int n;
    scanf("%d", &n);
    hanoi(n, 'A', 'C', 'B');
    printf("steps=%d\n", steps);
    return 0;
}

A->C
B->C
steps=3
💡 汉诺塔是「递归思想」的最佳范例：把「搬 n 个」拆成「搬 n-1 个 + 搬 1 个 + 搬 n-1 个」。参数顺序 from, to, via 是核心，写之前先在纸上把三个角色标清楚。 💡 步数公式：2ⁿ - 1（n=2 是 3，n=3 是 7，n=4 是 15）。可以用它自检输出对不对。 ⚠ 易错：hanoi(n-1, from, via, to) 和 hanoi(n-1, via, to, from) 两个调用的参数顺序不一样，抄错一个结果就全乱。 ⚠ 易错：steps 用全局变量最省事；如果放在 main 里想传给递归函数，必须用指针（int *steps），否则函数里加的是副本（见 Q-044）。

#include <stdio.h>

void swap(int *x, int *y) {        /* 形参是指针：接收地址 */
    int t = *x;
    *x = *y;                       /* 通过指针直接改调用处的变量 */
    *y = t;
}

int main(void) {
    int a, b;
    scanf("%d%d", &a, &b);
    swap(&a, &b);                  /* 传地址，不是传值 */
    printf("a=%d b=%d\n", a, b);
    return 0;
}

💡 对照记忆：
  • void swap(int x, int y) —— 换的是副本，外面没变（Q-044）；
  • void swap(int *x, int *y) —— 换的是外面那个变量，真的换了。
⚠ 易错：调用时忘写 &：swap(a, b) → 编译警告（传 int 给 int*），运行多半崩溃。这是指针题第一号错误。 ⚠ 易错：函数里写成 *x = *y; *y = *x; 想省掉临时变量 —— 两句话之后 x 和 y 都变成原来的 *y（第一句已经把 *x 覆盖了）。跟数组交换一样，必须用临时变量。

用指针遍历数组

基础 08-指针

题目：读入 n 个整数存入数组，只用指针（不许用 a[i]）求它们的和与最大值。

输入示例

▸ 程序输出
5
3 9 2 7 5

输出示例

▸ 程序输出

参考答案
// in: <<<
5
3 9 2 7 5
// >>>
#include <stdio.h>

int main(void) {
    int n, i, a[100], *p, sum = 0, max;
    scanf("%d", &n);
    for (i = 0; i < n; i++) scanf("%d", &a[i]);

    p = a;                     /* 数组名就是首元素地址，等价于 p = &a[0] */
    max = *p;                  /* 用第一个元素初始化最值 */
    for (i = 0; i < n; i++) {
        sum += *(p + i);       /* *(p+i) 完全等价于 a[i] */
        if (*(p + i) > max) max = *(p + i);
    }
    printf("sum=%d max=%d\n", sum, max);
    return 0;
}
▸ 程序输出

💡 核心等价关系：a[i] ≡ *(a + i) ≡ *(p + i)（当 p = a 时）。
  • p + i 不是「地址加 i 个字节」，而是往后跳 i 个 int（4×i 字节）；
  • 所以 *(p + 1) 就是第二个元素，不是「首字节之后的第 1 个字节」。
⚠ 易错：数组名不能被赋值、不能自增：a = p;、a++; 都是编译错误（数组名是常量地址）。能自增的只有指针变量 p++。 ⚠ 易错：*p + 1 和 *(p + 1) 完全不同——前者是「第一个元素的值加 1」，后者是「第二个元素」。括号位置决定一切。

#include <stdio.h>

void stat(int a[], int n, int *pmax, int *pmin, double *pavg) {
    int i, s = 0, mx = a[0], mn = a[0];
    for (i = 0; i < n; i++) {
        s += a[i];
        if (a[i] > mx) mx = a[i];
        if (a[i] < mn) mn = a[i];
    }
    *pmax = mx;              /* 把结果写进调用处的变量里 */
    *pmin = mn;
    *pavg = (double)s / n;
}

int main(void) {
    int n, i, a[100], mx, mn;
    double avg;
    scanf("%d", &n);
    for (i = 0; i < n; i++) scanf("%d", &a[i]);
    stat(a, n, &mx, &mn, &avg);      /* 传地址，让函数把结果写回来 */
    printf("max=%d min=%d avg=%.2f\n", mx, mn, avg);
    return 0;

Q-066

带参与不带参的宏定义

基础 10-预处理与文件

题目：用宏定义实现：① #define PI 3.14159；② #define MAX(a, b) ((a) > (b) ? (a) : (b))。main 里读入半径 r 和两个整数 x、y，输出圆周长（保留 4 位小数）和 x、y 中的较大者。

输入示例

输出示例

▸ 程序输出

参考答案
// in: <<<
2 7 3
// >>>
#include <stdio.h>
#define PI 3.14159
#define MAX(a, b) ((a) > (b) ? (a) : (b))     /* 每个参数和整体都加括号 */

int main(void) {
    double r;
    int x, y;
    scanf("%lf %d %d", &r, &x, &y);
    printf("c=%.4f\n", 2 * PI * r);

}

max=7

  3. 行尾不加分号。

基础 10-预处理与文件

题目：把 1~5 写入文件 num.txt（每行一个），然后重新打开读取，输出读到的所有数字之和。

▸ 程序输出

#include <stdio.h>

int main(void) {
    FILE *fp;
    int i, x, sum = 0;

    fp = fopen("num.txt", "w");            /* "w" 写模式：文件不存在会新建，存在则清空 */

    fclose(fp);                            /* 写完必须关，否则缓冲区可能没落盘 */

    if (fp == NULL) { printf("open failed\n"); return 1; }
    while (fscanf(fp, "%d", &x) == 1)      /* 读到 1 个数据就继续 */

    fclose(fp);

    return 0;
}

"r"只读失败，返回 NULL
"w"只写新建；存在则清空
"a"追加新建；存在则在末尾接着写
"r+"读写失败

Q-071

位运算：判断 2 的幂与求平均值（不用除法）

拔高 02-运算符与表达式

题目：读入两个非负整数 n、a、b（分三行）： ① 判断 n 是否为 2 的幂（是输出 yes，否则 no）； ② 用移位求 a 和 b 的平均值（向下取整）输出。

输入示例

▸ 程序输出
8 6 11

输出示例

▸ 程序输出
yes
avg=8

8
6
11
// >>>
#include <stdio.h>

int main(void) {
    unsigned int n;
    int a, b;
    scanf("%u %d %d", &n, &a, &b);

    if (n != 0 && (n & (n - 1)) == 0) printf("yes\n");   /* 2 的幂：只有一位是 1 */
    else printf("no\n");

    printf("avg=%d\n", (a + b) >> 1);                    /* 右移 1 位 = 除以 2 */
    return 0;
}
▸ 程序输出
yes

💡 n & (n-1) 是位运算的经典技巧：2 的幂（1,2,4,8...）在二进制里只有一位是 1，减 1 之后那一位变 0、后面全变 1，两者相与必然为 0。
  • 8 = 1000，7 = 0111，1000 & 0111 = 0 → 是 2 的幂；
  • 6 = 0110，5 = 0101，0110 & 0101 = 0100 ≠ 0 → 不是。
⚠ 易错：忘了 n != 0 判断 —— 0 & (0-1) 里的 0-1 在无符号里会变成最大值，结果不是 0，侥幸正确；但如果用有符号 int，0 & -1 = 0，会误判 0 是 2 的幂。所以必须显式排除 0。 ⚠ 易错：avg = (a + b) / 2 和 (a + b) >> 1 对正数结果相同，但 >> 对负数是向下取整（-3 >> 1 = -2，而 -3 / 2 = -1）。题目说非负整数才敢这么写。

    scanf("%s", s1);
    scanf("%s", s2);

    printf("len1=%d len2=%d\n", (int)strlen(s1), (int)strlen(s2));

    if (strcmp(s1, s2) > 0) printf("bigger=%s\n", s1);
    else printf("bigger=%s\n", s2);

    strcat(s1, s2);             /* 把 s2 接到 s1 后面，结果存在 s1 */
    printf("cat=%s\n", s1);
    return 0;
}

bigger=abd

函数作用返回值
strlen(s)求长度（不含 '\0'）字符个数
strcpy(d, s)复制d
strcat(d, s)拼接d
strcmp(a, b)比较负数/0/正数
⚠ 易错：strcat(s1, s2) 的结果在 s1 里，s2 不变。方向不能反。 ⚠ 易错：s1 必须开得足够大。真题程序填空第 23 题就是这个考点：char s1[100] 拼接后可能溢出。 ⚠ 易错：strcmp 返回的是差值，不是固定的 ±1。判断相等写 strcmp(a,b) == 0，不能写 strcmp(a,b) == 1。

程序填空：补全字符串处理

真题 06-数组

题目：2025 山西卷程序填空题第 23 题。 下面的程序把 s2 的内容连接到 s1 后面（不用 strcat），请补全两处横线。

#include <stdio.h>
int main() {
    char s1[100], s2[100];
    int i = 0, j = 0;
    gets(s1);
    gets(s2);
    while (__________) i++;          /* 空① */

}

▸ 程序输出

world

输出示例

▸ 程序输出

// in: <<<
hello
world
// >>>
#include <stdio.h>

int main(void) {
    char s1[100], s2[100];
    int i = 0, j = 0;
    scanf("%s", s1);              /* 原题用 gets；这里改用更安全的 scanf */
    scanf("%s", s2);

    while (s1[i] != '\0') i++;    /* 空①：先把 i 移到 s1 的末尾 */

    while (s2[j] != '\0') {
        s1[i] = s2[j];            /* 空②：把 s2 的字符逐个搬到 s1 末尾 */
        i++; j++;
    }
    s1[i] = '\0';                 /* 手动补结束标记 —— 这一步原题已经写好 */
    printf("%s\n", s1);
    return 0;
}
▸ 程序输出
helloworld
💡 两个空的考点：
  • 空①：找 s1 的末尾。写 s1[i] 也能工作（'\0' 就是 0，当条件为假），但写全 s1[i] != '\0' 更规范；
  • 空②：赋值方向。s1[i] = s2[j]，不是反过来——目标在左，源在右。
⚠ 易错：空②写成 s2[j] = s1[i]（左右颠倒）→ s2 被覆盖，s1 没变，输出还是 hello。 ⚠ 易错：gets 已经废弃（不检查长度、会溢出）。真题里可能还在用，但你写答案时优先写 fgets(s1, sizeof(s1), stdin)，并在旁边说明 gets 不安全。 ⚠ 易错：忘了最后的 s1[i] = '\0' → 输出会带着原来的脏尾巴。

程序设计：统计字母出现次数

真题 06-数组

题目：输入一行由小写字母组成的字符串（不含空格，长度 < 100），统计每个字母出现的次数，只输出出现过的字母及其次数（按字母顺序），格式 a:2，每个一行。

输入示例

▸ 程序输出
aabbbc

输出示例

▸ 程序输出
a:2
b:3
c:1
参考答案
// in: aabbbc
// >>>
#include <stdio.h>

int main(void) {
    char s[100];
    int cnt[26] = {0};         /* 用「字母 - 'a'」当下标 */
    int i;
    scanf("%s", s);

    for (i = 0; s[i] != '\0'; i++)
        cnt[s[i] - 'a']++;      /* 'a' -> 0, 'b' -> 1, ... */

    for (i = 0; i < 26; i++)
        if (cnt[i] > 0)
            printf("%c:%d\n", i + 'a', cnt[i]);
    return 0;
}
▸ 程序输出
a:2
b:3
c:1
💡 「值当下标」again：字母 'a'~'z' 减去 'a' 就得到 0~25，正好是数组下标。这个技巧在真题里反复出现（Q-033 统计数字出现次数是同一个思路）。 ⚠ 易错：数组开成 cnt[25] → 下标只能到 24，'z' - 'a' = 25 会越界。26 个字母必须开 26。 ⚠ 易错：输出时忘了 i + 'a' 转回字符，直接 printf("%d", i) 输出的是下标 0、1、2。 ⚠ 易错：不加 if (cnt[i] > 0) 判断 → 没出现过的字母也会输出 x:0。
Q-075

程序设计：出租车计费（2025 山西真题）

真题 04-选择结构

题目：2025 山西卷程序设计第 27 题原题。 某城市出租车收费标准：

  1. 起步里程 3 公里，起步费 10 元；
  2. 超过起步里程且总里程 ≤ 10 公里，超出部分每公里 2 元；
  3. 超过 10 公里，10 公里以上的部分每公里加收 50% 回空补贴费，即每公里 3 元。

输入总里程（整型），输出应付车费（整型）。

输入示例

▸ 程序输出
12

输出示例

▸ 程序输出
30
参考答案
// in: 12
// >>>
#include <stdio.h>

int main(void) {
    int km, fee;
    scanf("%d", &km);

    if (km <= 3) {
        fee = 10;                       /* 起步价 */
    } else if (km <= 10) {
        fee = 10 + (km - 3) * 2;        /* 3~10 公里：超出部分每公里 2 元 */
    } else {
        fee = 10 + 7 * 2 + (km - 10) * 3;   /* 超过 10 公里：前 7 公里按 2 元，其余 3 元 */
    }

    printf("%d\n", fee);
    return 0;
}
▸ 程序输出
30
💡 验算 12 公里：起步 10 元 + 3~10 公里的 7 公里 ×2 = 14 元 + 超过 10 公里的 2 公里 ×3 = 6 元 → 10 + 14 + 6 = **30**。
💡 分段计费题的通用解法：把里程拆成几段，每段乘自己的单价再相加。
  • 0~3 公里：10 元（固定）
  • 3~10 公里：每公里 2 元 → 最多 7 公里 = 14 元
  • 10 公里以上：每公里 3 元
