## 一、怎么用（照这个顺序，别跳）

| 步骤 | 做什么 |
|:---:|------|
| 1 | 打开 `C语言编程题库.html`（双击即可，手机也能看），按章节顺序做题 |
| 2 | **先自己写**，卡住也想 10 分钟，再点开「参考答案」折叠块 |
| 3 | 对完答案，问自己：**我错在哪一步？**（是语法、边界，还是思路） |
| 4 | 把错题抄进 `D:\专升本\C语言错题本\错题.md`，知识点填对应章号（如 `05-循环结构`） |
| 5 | 第二天**不看答案重写一遍**，做对后在网页上打勾（进度存在浏览器里） |
| 6 | 每章末尾的「自查清单」逐条过一遍，答不上来的回去补知识点 |

**网页功能**：搜索（题号/考点/关键字）、按题型和知识点筛选、答案折叠、已掌握打勾、夜间模式、打印（可直接打印成纸质题册）。

## 五、校验怎么做的（为什么可以信）

```powershell
cd 'D:\专升本\C语言编程题库'

# 1) 校验所有参考答案：真实编译 + 运行 + 与样例逐字比对
& 'C:\Program Files\nodejs\node.exe' .build\verify.mjs

# 2) 重新生成网页
& 'C:\Program Files\nodejs\node.exe' .build\build.mjs
```

- **75 个参考答案全部是完整可运行程序**，不是伪代码；
- 每个程序都带**测试输入**（`// in:` 那一行，或 `// in: <<<` 多行形式）与**期望输出**，由脚本编译执行后逐字比对；
- 写这批题的过程中，校验脚本抓出了 **6 处我自己的手算错误**，例如：
  | 题 | 我原本写的 | 实测正确 |
  |---|---|---|
  | Q-004 交换两数 | 期望输出写成原值 `3 8` | `8 3` |
  | Q-011 字节重排 | 十进制换算错 | `2016695826` |
  | Q-035 矩阵鞍点 | 答 `none`，其实有鞍点 | `a[0][3]=4` |
  | Q-038 字符串拼接 | 写 `abcd` | `abcabd` |
  | Q-051 字符统计 | `lower=3` | `lower=2` |
  | Q-075 出租车计费 | 期望 `34` | **`30`** |
- 另有 **3 个程序**（Q-026 / Q-034 / Q-055）被本机沙箱判为「拒绝访问」而无法直接运行（换文件名、换目录都无效，与代码无关），已用**等价程序**分别验证逻辑正确。
