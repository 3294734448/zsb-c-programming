## 11.1 程序阅读三步法 ★★★

★ 考点：程序阅读题**不许心算、不许跳步**，必须走完这三步。

### 第一步：先看"这个程序想干什么"（30 秒）

不要一上来就逐行算。先扫三样东西：

| 看什么 | 怎么判断 |
|------|------|
| **函数名 / 变量名** | `factor`（因子）、`sum`（和）、`max`（最大）、`count`（计数）、`reverse`（逆置）——名字就是答案的线索 |
| **关键运算** | `% i == 0` 是因子；`% 10 / /= 10` 是拆数字；`s += i` 是累加；`s *= i` 是累乘；`a[i] > a[i+1]` 是冒泡 |
| **输出格式** | `printf("sum=%d", ...)` —— **前缀 `sum=` 也是答案的一部分**，漏了就是 0 分 |

💡 一句话：**先认功能，再算数值，最后套格式。**

### 第二步：画追踪表（这是核心能力）

拿一张纸，列一张表，**每一轮循环写一行**：

| 轮次 | 循环变量 | 关键变量 | 判断结果 |
|:---:|:---:|:---:|------|
| 初始 | i=1 | s=0 | — |
| 1 | i=1 | s=1 | 真，继续 |
| 2 | i=2 | s=3 | 真，继续 |
| … | … | … | … |

⚠ 三条铁律：

1. **只追踪会变的变量**，常量不要写进去（浪费时间）；
2. **循环条件变化的那一刻要单独记一行**（比如 `i` 变成 6 导致循环结束时，`i` 的最终值常常是考点）；
3. **指针题要追踪"指向哪里"**，不是只追踪值。

### 第三步：套输出格式，检查边界

- 有没有前缀（`sum=`、`max=`）？
- 有没有换行 `\n`？几行输出？
- 循环结束后的变量值要不要输出？
- `printf` 里是 `%d` 还是 `%f`（`%f` 默认 6 位小数）？

📌 **考场时间预算**：程序阅读 3 题，每题 **4—5 分钟**。第一遍不会就跳过，全部做完再回来。

## 11.2 六类必考程序模板速认 ★★★

★ 考点：山西真题的程序阅读题，**90% 逃不出这 6 个模板**。认出来就直接套结论，不用逐行算。

| # | 模板 | 一眼认出的特征 | 结论 |
|:---:|------|------|------|
| 1 | **累加 / 累乘** | `s = 0` + `s += i`；`f = 1` + `f *= i` | 求和、阶乘 |
| 2 | **求最值** | `max = a[0]` + `if (a[i] > max)` | 找最大/最小及其下标 |
| 3 | **数位分解** | `n % 10` 和 `n /= 10` 成对出现 | 拆出各位数字、求和、逆序 |
| 4 | **因子 / 素数** | `n % i == 0` | 因子、完数、素数判断 |
| 5 | **数组换位** | `t = a[i]; a[i] = a[j]; a[j] = t;` | 逆置、排序、首尾交换 |
| 6 | **递归** | 函数内部**调用自己** | 先找出口，再从出口往回加 |

```answer 模板 6 的快速展开法（以真题 25 为例）
题目：`fun(n) = fun(n-1) + 2`，`fun(1) = 18`，求 `fun(5)`。

**永远从出口往上写**（不要从 fun(5) 往下展开，容易乱）：
fun(1) = 18
fun(2) = 18 + 2 = 20
fun(3) = 20 + 2 = 22
fun(4) = 22 + 2 = 24
fun(5) = 24 + 2 = 26 ✔

秒杀公式：fun(n) = 18 + (n-1) × 2
```

## 11.3 输出格式陷阱 ★★★

★ 考点：**算对了但写错格式 = 0 分**。程序阅读题的答案要按字符串比对，一个字符都不能错。

| 陷阱 | 例子 | 你必须写 |
|------|------|------|
| 忘了前缀 | `printf("sum=%d", s)` | `sum=22`（不是 `22`） |
| 忘了几行 | `printf("%d\n%d\n", a, b)` | 两行，各一个数 |
| `%f` 默认 6 位小数 | `printf("%f", 3.14)` | `3.140000` |
| 空格也是内容 | `printf("%d %d", a, b)` | 两个数中间一个空格 |
| 循环结束后的值也要输出 | `printf("i=%d", i)` | 把 i 结束时的值算出来 |
| `puts` 自带换行 | `puts(s)` | 只写字符串本身 |

```answer 一道小题体会"格式决定成败"
```c
int s = 0, i;
for (i = 1; i <= 3; i++) s += i;
printf("s=%d,i=%d", s, i);
```
逐行追踪：i=1→s=1；i=2→s=3；i=3→s=6；i=4 时条件 `4<=3` 为假，退出，**i 的值是 4**。
输出：`s=6,i=4`

⚠ 如果只写 `6`，或者写成 `s=6`（漏了 `,i=4`），都是 0 分。**循环变量结束时的值是高频考点。**
```

i 变 11 时条件 `11<=10` 为假，循环结束。输出 `s=55`（**别忘了 `s=` 这个前缀**）。

### 训练 2 · 求最大值及其下标

```c-run
#include <stdio.h>
int main(void) {
    int a[5] = {3, 7, 1, 9, 4};
    int i, max = a[0], pos = 0;
    for (i = 1; i < 5; i++)
        if (a[i] > max) { max = a[i]; pos = i; }
    printf("max=%d pos=%d\n", max, pos);
    return 0;
}
```

```text
max=9 pos=3
```

```answer 运行结果与追踪
| i | a[i] | 与 max 比较 | max | pos |
|:---:|:---:|:---:|:---:|:---:|
| 初始 | — | — | 3 | 0 |
| 1 | 7 | 7>3 ✔ | 7 | 1 |
| 2 | 1 | 1>7 ✘ | 7 | 1 |
| 3 | 9 | 9>7 ✔ | **9** | **3** |
| 4 | 4 | 4>9 ✘ | 9 | 3 |

输出 `max=9 pos=3`。注意 `pos` 记录的是**下标**（从 0 开始），不是第几个数——第 4 个数，下标是 3。
```

### 训练 4 · i++ 与 ++i 的区别

```c-run
#include <stdio.h>
int main(void) {
    int i = 1, a, b;
    a = i++;
    b = ++i;
    printf("a=%d b=%d i=%d\n", a, b, i);
    return 0;
}
```

```text
a=1 b=3 i=3
```

```answer 运行结果与追踪
| 语句 | 发生了什么 | a | b | i |
|------|------|:---:|:---:|:---:|
| `int i=1;` | 初始化 | — | — | 1 |
| `a = i++;` | **后置**：先把原值 1 给 a，再自增 | **1** | — | 2 |
| `b = ++i;` | **前置**：先自增成 3，再把新值给 b | 1 | **3** | 3 |

输出 `a=1 b=3 i=3`。

💡 口诀：**后置先取值再自增，前置先自增再取值。**
```

### 训练 5 · while 里的后置自减

```c-run
#include <stdio.h>
int main(void) {
    int i = 3, k = 0;
    while (i--) k++;
    printf("k=%d i=%d\n", k, i);
    return 0;
}
```

```text
k=3 i=-1
```

```answer 运行结果与追踪
| 判断 | `i--` 的值（用于判断） | 判断真假 | i | k |
|:---:|:---:|:---:|:---:|:---:|
| 1 | 3 | 真 | 2 | 1 |
| 2 | 2 | 真 | 1 | 2 |
| 3 | 1 | 真 | 0 | 3 |
| 4 | 0 | **假** → 退出 | **-1** | 3 |

关键：`i--` 是**先拿原值判断，再自减**。所以第 4 次判断用的是 0（假），但 i 已经减成了 **-1**。

输出 `k=3 i=-1`。⚠ 这类题 90% 的人会把 i 写成 0，实际是 -1。
```

```c-run

### 训练 9 · 素数判断

```c-run
#include <stdio.h>
int main(void) {
    int n = 17, i, flag = 1;
    for (i = 2; i < n; i++)
        if (n % i == 0) { flag = 0; break; }
    printf("%s\n", flag ? "yes" : "no");
    return 0;
}
```

```text
yes
```

```answer 运行结果与追踪
| i | 17 % i | 是否 break | flag |
|:---:|:---:|:---:|:---:|
| 2 | 1 | 否 | 1 |
| 3 | 2 | 否 | 1 |
| 4 | 1 | 否 | 1 |
| … | 全都不能整除 | 否 | 1 |
| 16 | 1 | 否 | 1 |
| 17 | 条件 `17<17` 假 → 结束 | — | **1** |

flag 保持 1 → 输出 `yes`（是素数）。

💡 模板：**`n % i == 0` 就 break 并把 flag 置 0** —— 这是素数/完数题的标准写法。
⚠ 若把 n 改成 15，i=3 时 `15%3==0` 成立，flag 变 0 并 break，输出 `no`。
```

### 训练 10 · 数组首尾交换（逆置）

```c-run
#include <stdio.h>
int main(void) {
    int a[6] = {1, 2, 3, 4, 5, 6};
    int i, t;
    for (i = 0; i < 3; i++) {
        t = a[i];
        a[i] = a[5 - i];
        a[5 - i] = t;
    }
    for (i = 0; i < 6; i++) printf("%d ", a[i]);
    printf("\n");
    return 0;
}
```

```text
6 5 4 3 2 1
```

```answer 运行结果与追踪
| i | 交换 a[i] ↔ a[5-i] | 交换后数组 |
|:---:|:---:|------|
| 0 | a[0]=1 ↔ a[5]=6 | 6 2 3 4 5 1 |
| 1 | a[1]=2 ↔ a[4]=5 | 6 5 3 4 2 1 |
| 2 | a[2]=3 ↔ a[3]=4 | **6 5 4 3 2 1** |
| 3 | 条件 `3<3` 假 → 结束 | — |

⚠ 关键：循环只做 **3** 次（`i < 6/2`）。如果写成 `i < 6`，每对会被换**两次**，数组又变回原样——这是命题人最爱的陷阱。
```

### 训练 12 · 数组作函数参数

```c-run
#include <stdio.h>
void add(int b[], int n) {
    int i;
    for (i = 0; i < n; i++) b[i] += i;
}
int main(void) {
    int a[4] = {1, 1, 1, 1};
    int i;
    add(a, 4);
    for (i = 0; i < 4; i++) printf("%d ", a[i]);
    printf("\n");
    return 0;
}
```

```text
1 2 3 4
```

```answer 运行结果与追踪
实参是数组名 `a`（首地址），形参 `b` 和 `a` **指向同一块内存**，所以函数里改 b 就是改 a。

| i | b[i] += i | 数组 a |
|:---:|:---:|------|
| 0 | a[0] += 0 | 1 1 1 1 |
| 1 | a[1] += 1 | 1 **2** 1 1 |
| 2 | a[2] += 2 | 1 2 **3** 1 |
| 3 | a[3] += 3 | 1 2 3 **4** |

⚠ 这是与普通变量传参最大的区别：**普通变量传的是副本（改了不影响外面），数组传的是地址（改了就是改了原数组）**。
```

### 训练 13 · 指针遍历数组

```c-run
#include <stdio.h>
int main(void) {
    int a[5] = {1, 2, 3, 4, 5};
    int *p = a, s = 0;
    while (p < a + 5) s += *p++;

}
```

```text

```

```answer 运行结果与追踪
| 轮次 | p 指向 | *p | s | p 之后移向 |
|:---:|:---:|:---:|:---:|:---:|
| 1 | a[0] | 1 | 1 | a[1] |
| 2 | a[1] | 2 | 3 | a[2] |
| 3 | a[2] | 3 | 6 | a[3] |
| 4 | a[3] | 4 | 10 | a[4] |

关键：`*p++` 的含义是 **`*(p++)`** —— 先取 `*p` 的值，再把 p 后移一格，不是把值加 1。

```

### 训练 14 · `*p++` 与 `(*p)++` 的区别

```c-run
#include <stdio.h>
int main(void) {
    int a[3] = {10, 20, 30};
    int *p = a;
    printf("%d ", *p++);
    printf("%d ", (*p)++);
    printf("%d %d\n", *p, a[1]);
    return 0;
}
```

```text
10 20 21 21
```

```answer 运行结果与追踪
| 语句 | 含义 | 输出 | 之后的状态 |
|------|------|:---:|------|
| `*p++` | `*(p++)`：先取值 10，再让 p 指向 a[1] | 10 | p→a[1] |
| `(*p)++` | 把 p 所指的 a[1] **自增**，取值 20 | 20 | a[1] 变成 21 |
| `*p` | p 仍指向 a[1] | 21 | — |
| `a[1]` | 已被自增 | 21 | — |

输出 `10 20 21 21`。

💡 三兄弟区别（必须背下来）：
- `*p++` = 先取值再移动指针（指针变）
- `(*p)++` = 把所指单元的值加 1（值变，指针不变）
- `*++p` = 先移动指针，再取值（指针变，跳过第一个元素）
```

| 0 | 'a' | 'a' | 是 | 继续 |
| 1 | 'b' | 'b' | 是 | 继续 |
| 2 | 'c' | 'd' | **不等** | 退出循环 |

`a[2] - b[2]` = `'c' - 'd'` = 99 - 100 = **-1**。

💡 这正是 `strcmp` 的内部原理：**返回两个字符串第一个不同字符的 ASCII 差值**（a 小于 b 返回负数）。
```

### 训练 19 · 冒泡排序的第一轮

```c-run
#include <stdio.h>
int main(void) {
    int a[5] = {5, 4, 3, 2, 1};
    int i, t;
    for (i = 0; i < 4; i++)
        if (a[i] > a[i + 1]) {
            t = a[i];
            a[i] = a[i + 1];
            a[i + 1] = t;
        }
    for (i = 0; i < 5; i++) printf("%d ", a[i]);
    printf("\n");
    return 0;
}
```

```text
4 3 2 1 5
```

```answer 运行结果与追踪
这是**冒泡排序的一轮**（没有外层循环），效果是把最大的数推到最右边。

| i | 比较 | 是否交换 | 数组 |
|:---:|:---:|:---:|------|
| 0 | 5 > 4 ✔ | 交换 | 4 5 3 2 1 |
| 1 | 5 > 3 ✔ | 交换 | 4 3 5 2 1 |
| 2 | 5 > 2 ✔ | 交换 | 4 3 2 5 1 |
| 3 | 5 > 1 ✔ | 交换 | **4 3 2 1 5** |

输出 `4 3 2 1 5`。
📌 记住：**一轮冒泡只能确定一个最大值的位置**。完整排序需要 `for (j = 0; j < n-1; j++)` 套在外面。
```

```c-run

### 陷阱 1 · 整除与取余

```c-run
#include <stdio.h>
int main(void) {
    printf("%d %d %d %d\n", 5 / 2, -7 / 2, 7 % 2, -7 % 2);
    return 0;
}
```

```text
2 -3 1 -1
```

```answer 运行结果与追踪
| 表达式 | 规则 | 结果 |
|------|------|:---:|
| `5 / 2` | 两个整数相除，**向零取整**（舍去小数） | 2 |
| `-7 / 2` | 向零取整（不是向下取整！-3.5 → -3） | -3 |
| `7 % 2` | 取余 | 1 |
| `-7 % 2` | **余数的符号与被除数相同**（-7 是负 → 余数负） | -1 |

⚠ 三个必考结论：
1. **整数除法会丢掉小数**：`5/2` 是 2，不是 2.5。要小数必须写成 `5.0/2` 或 `(float)5/2`。
2. `-7/2 = -3`（向零取整），不是 -4。
3. `%` 两侧**必须是整数**，`7.5 % 2` 编译错误。
```

### 陷阱 2 · 逻辑短路求值

```c-run
#include <stdio.h>
int main(void) {
    int a = 1, b = 1;
    int r = a++ || b++;
    printf("r=%d a=%d b=%d\n", r, a, b);
    return 0;
}
```

```text
r=1 a=2 b=1
```

```answer 运行结果与追踪
| 步骤 | 发生什么 |
|:---:|------|
| ① | 先算 `a++`：a 的原值 1 非 0 → 为**真** |
| ② | `\|\|` 左边已经为真，**右边不再计算** → `b++` 根本没执行 |
| ③ | r = 1（逻辑或的结果是真，值为 1） |
| ④ | 最终 a=2（自增了），b=**1**（没动） |

⚠ 这就是**短路求值**：`&&` 左边为假时右边不算，`||` 左边为真时右边不算。
📌 与它对称的两个例子：
- `int r = a++ && b++;`（a=1）→ 右边**要算**，b 会变成 2
- `int r = 0 && b++;` → 右边不算，b 不变
```

```c-run
#include <stdio.h>

    float g = 1.0 / 2;

### 陷阱 4 · break 与 continue

```c-run
#include <stdio.h>
int main(void) {
    int i;
    for (i = 1; i <= 5; i++) {
        if (i == 3) continue;
        printf("%d", i);
    }
    printf("\n");
    return 0;
}
```

```text
1245
```

```answer 运行结果与追踪
| i | 判断 | 动作 | 输出 |
|:---:|:---:|------|:---:|
| 1 | ≠3 | 正常执行 printf | 1 |
| 2 | ≠3 | 正常执行 | 2 |
| 3 | **=3** | **continue：跳过本次循环剩下的语句**（printf 不执行），直接进入 i=4 | 无 |
| 4 | ≠3 | 正常 | 4 |
| 5 | ≠3 | 正常 | 5 |

输出 `1245`（**3 被跳过**）。

📌 对比 break：
```c
for (i = 1; i <= 5; i++) {
    if (i == 3) break;     /* 整个循环结束 */
    printf("%d", i);
}
```
输出变成 `12`。
💡 口诀：**continue 只跳过这一次，break 直接不干了。**
```

### 陷阱 5 · switch 的穿透

```c-run
#include <stdio.h>
int main(void) {
    int x = 2, s = 0;
    switch (x) {
        case 1: s += 1;
        case 2: s += 2;
        case 3: s += 3;
        default: s += 4;
    }
    printf("%d\n", s);
    return 0;
}
```

```text
9
```

```answer 运行结果与追踪
x=2 → 从 `case 2` 开始执行，**因为没有 break，一路往下穿透**：

| 执行到 | 动作 | s |
|------|------|:---:|
| case 2 | s += 2 | 2 |
| case 3 | s += 3 | 5 |
| default | s += 4 | **9** |

输出 `9`。
⚠ 注意：`case 1` **没有被执行**（switch 直接跳到 case 2），所以没有加 1。
💡 如果每个 case 后面都有 break，就只会执行 case 2 → s=2。**命题人就靠 break 的有无来出题。**
```

### 陷阱 6 · 逗号表达式的值

```c-run
#include <stdio.h>
int main(void) {
    int x = (1, 2, 3);
    int y = 1, z = 2;
    printf("%d %d\n", x, y + z);
    return 0;
}
```

```text
3 3
```

```answer 运行结果与追踪
| 表达式 | 含义 | 值 |
|------|------|:---:|
| `x = (1, 2, 3)` | 逗号表达式从左到右执行，取**最后一个**的值 | 3 |
| `int y = 1, z = 2;` | 这里的逗号是**声明分隔符**，不是逗号运算符 | y=1, z=2 |

### 陷阱 7 · 字符数组与 `'\0'`

```c-run
#include <stdio.h>
int main(void) {
    char a[3] = "abc";
    char b[] = "abc";
    printf("%d %d %d\n", (int)sizeof(a), (int)sizeof(b), (int)sizeof("abc"));
    return 0;
}
```

```text
3 4 4
```

```answer 运行结果与追踪
| 定义 | 元素个数 | 是否有 `'\0'` | sizeof |
|------|:---:|:---:|:---:|
| `char a[3] = "abc"` | 恰好 3 个字符 | **没有**（空间不够放） | 3 |
| `char b[] = "abc"` | 3 个字符 + `'\0'` | 有 | 4 |
| `"abc"` 字符串常量 | 3 个字符 + `'\0'` | 有 | 4 |

⚠ 结论：
1. 字符串常量**永远比看起来多 1 个字节**（末尾的 `'\0'`）；
2. `char a[3]="abc"` 没有 `'\0'`，用 `printf("%s", a)` 或 `strlen(a)` 会**输出乱码/越界**——这是考点；
3. `strlen("abc")` 是 **3**（不含 `'\0'`），而 `sizeof("abc")` 是 **4**。
```

## 11.7 考场执行清单 ★★

📌 **程序阅读题的标准动作**（每次做题都照做）：

1. **先圈出 `printf`**，把输出格式抄到纸的右上角（前缀、几个数、几行）；
2. **圈出所有会变的变量**，画表头；
3. **一轮一行**，绝不跳步；
4. 循环结束时，**单独记下循环变量的最终值**；
5. 把结果**套回格式**，逐字符检查；
6. 交卷前：**再看一眼有没有漏掉前缀和换行**。

⚠ 三种"看起来对其实是错"的答案：

| 你写的 | 正确答案 | 为什么 |
|------|------|------|
| `22` | `sum=22` | 漏了前缀 |
| `k=3 i=0` | `k=3 i=-1` | 后置自减的最终值算错 |
| `1 2 3` | `1\n2\n3`（三行） | 忘了 `\n` 分行 |

💡 最后一句：**程序阅读不是"看懂"，是"算准"。每天用 3 分钟做 1 题，连续 10 天，正确率一定上 80%。**
