# 02 · 运算符与表达式 ★★★

★ 考点：本章是整张卷子的「隐形分值王」——运算优先级和自增自减是程序阅读中的常见易错点。这一章 8 个知识点，建议用 4 天过完，每天只攻 2 个。

⚠ 铁律：本章所有例题都要**纸笔追踪**，不许心算。写出中间步骤有助于检查计算过程。

📌 通用方法（每道阅读题都按这三步走）：① 找出表达式里**优先级最高**的那一步先算；② 每次只改一个变量的值，写在旁边；③ 全部算完再回头核对一遍。

## 2.1 运算符优先级与结合性总表 ★★★

★ 考点：给你一个混合表达式，问结果是多少。这是山西卷**单选 + 程序阅读**的必考形式，没有例外年份。

**1. 规则：完整优先级表（从高到低）**

| 级别 | 运算符 | 结合性 | 名称 |
|:---:|------|:---:|------|
| 1 | `()` `[]` `->` `.` | 左 | 括号、下标、成员 |
| 2 | `!` `~` `++` `--` `+`（正） `-`（负） `*`（指针） `&`（取地址） `sizeof` | **右** | 单目运算符 |
| 3 | `*` `/` `%` | 左 | 乘、除、取余 |
| 4 | `+` `-` | 左 | 加、减 |
| 5 | `<<` `>>` | 左 | 左移、右移 |
| 6 | `<` `<=` `>` `>=` | 左 | 关系（比较大小） |
| 7 | `==` `!=` | 左 | 等于、不等于 |
| 8 | `&` | 左 | 按位与 |
| 9 | `^` | 左 | 按位异或 |
| 10 | `\|` | 左 | 按位或 |
| 11 | `&&` | 左 | 逻辑与 |
| 12 | `\|\|` | 左 | 逻辑或 |
| 13 | `?:` | **右** | 条件运算符 |
| 14 | `=` `+=` `-=` `*=` `/=` `%=` 等 | **右** | 赋值、复合赋值 |
| 15 | `,` | 左 | 逗号 |

📌 表中第 10、12 级的两个竖线符号，请对照本节末尾的「按位或 / 逻辑或」说明记忆。

**（1）三条必须刻进肌肉记忆的分界**

| 分界 | 谁高谁低 | 记忆抓手 |
|:---:|------|------|
| 单目 vs 双目 | 单目（`!` `~` `++` `--` 负号）**高于**所有双目运算符 | 「一个操作数的先算」 |
| 算术 vs 关系 | 算术（`*` `/` `+` `-`）**高于**关系（`<` `>`） | 先算数，再比较 |
| 关系 vs 逻辑 | 关系（`<` `>` `==`）**高于**逻辑（`&&` `\|\|`） | 先比较，再判真假 |
| `&&` vs `\|\|` | `&&` **高于** `\|\|` | 与比或「紧」 |
| 逻辑 vs 赋值 | 一切**高于**赋值 `=` | 赋值永远最后做 |

**（2）结合性：什么时候看它**

- **左结合**（从左往右算）：绝大多数双目运算符。`10 - 4 - 3` = `(10-4)-3` = **3**，不是 `10-(4-3)` = 9。
- **右结合**（从右往左算）：单目运算符、`?:`、赋值运算符。`a = b = c = 1` 等价于 `a = (b = (c = 1))`。

**（3）实战口诀：没有把握就用括号**

> 考场上不要跟优先级赌博。凡是拿不准的，**直接加括号**——括号优先级最高，加了绝不会错，而且阅卷只看结果。

✔ 写法对照（结果相同，右边零风险）：

| 想算 | 高风险写法 | 安全写法 |
|------|------|------|
| 平均值 | `a + b / 2` ✘（先算 `b/2`） | `(a + b) / 2` ✔ |
| 判断闰年 | `y % 4 == 0 && y % 100 != 0 \|\| y % 400 == 0` | 按 `&&` 高于 `\|\|` 理解，也可整体加括号 |
| 取中间那个数 | `a > b ? a : b > c ? b : c` | `a > b ? a : (b > c ? b : c)` |

**2. 例题**

**例 2.1.1（程序阅读 · 优先级逐条验算）**

```c-run
#include <stdio.h>
int main(void) {
    printf("%d\n", 2 + 3 * 4 - 5);
    printf("%d\n", 1 + 2 < 4);
    printf("%d\n", 3 > 2 > 1);
    printf("%d\n", 10 - 4 - 3);
    printf("%d\n", 10 - (4 - 3));
    return 0;
}
```

```text
9
1
0
3
9
```

```answer 运行结果与追踪
| 行 | 表达式 | 结果 | 追踪（谁先算） |
|:---:|:---:|:---:|------|
| 1 | `2 + 3 * 4 - 5` | **9** | `*` 高于 `+ -` → 先 `3*4=12` → `2+12-5`。`+ -` 同级左结合 → `(2+12)-5 = 9` |
| 2 | `1 + 2 < 4` | **1** | 算术高于关系 → 先 `1+2=3` → `3 < 4` 成立 → 得 **1** |
| 3 | `3 > 2 > 1` | **0** | 关系运算符**左结合** → 先 `3>2` 得 `1` → 再 `1 > 1` **不成立** → 得 **0** |
| 4 | `10 - 4 - 3` | **3** | 左结合 → `(10-4)-3 = 6-3 = 3` |
| 5 | `10 - (4 - 3)` | **9** | 加了括号 → `10 - 1 = 9` |

⚠ 第 3 行是本节最值钱的一行。`3 > 2 > 1` 在数学上「显然成立」，在 C 里却是 **0（假）**。原因是关系运算左结合：先算 `3>2` 得到 `1`，再用 `1 > 1` 比较。

⚠ 第 4、5 行放一起看：**减法不满足结合律**，有没有括号结果完全不同（3 vs 9）。这也是「拿不准就加括号」的理由。
```

**例 2.1.2（程序阅读 · 括号如何改变结果）**

```c-run
#include <stdio.h>
int main(void) {
    int a = 2, b = 3, c = 4;
    printf("%d\n", a + b * c);
    printf("%d\n", (a + b) * c);
    printf("%d\n", a > b && b < c);
    printf("%d\n", a > b || b < c);
    printf("%d\n", !a + b);
    return 0;
}
```

```text
14
20
0
1
3
```

```answer 运行结果与追踪
| 行 | 表达式 | 结果 | 追踪 |
|:---:|:---:|:---:|------|
| 1 | `a + b * c` | **14** | `*` 先算 → `3*4=12` → `2+12=14` |
| 2 | `(a + b) * c` | **20** | 括号最优先 → `(2+3)=5` → `5*4=20` |
| 3 | `a > b && b < c` | **0** | 关系优先于逻辑 → `2>3` 得 0，`3<4` 得 1 → `0 && 1` = **0** |
| 4 | `a > b \|\| b < c` | **1** | `0 \|\| 1` = **1** |
| 5 | `!a + b` | **3** | 单目 `!` 优先级**最高** → `!2` = 0（2 非零即真，取非得 0）→ `0 + 3 = 3` |

⚠ 第 5 行容易写成「`!(a+b)` = `!5` = 0」。`!` 是**单目**运算符、优先级最高，所以它只作用于 `a`，不是 `a+b`。

⚠ 第 3、4 行对比记忆：`&&` 要求**两边都真**才得 1；`||` 只要**一边真**就得 1。
```

**3. 易错清单**

⚠ 把 `3 > 2 > 1` 当成数学不等式。C 里它等于 `0`。要表达「2 在 1 和 3 之间」必须写 `3 > 2 && 2 > 1`。

⚠ 忘记单目运算符优先级最高：`-a * b` 是 `(-a) * b`，`!a + b` 是 `(!a) + b`。

⚠ 以为赋值和其他运算符同级：赋值优先级**倒数第二**（只比逗号高），所以 `x = a > b` 先算 `a > b` 再把结果赋给 `x`。

⚠ 把 `&&` 和 `||` 的优先级记反：**`&&` 高于 `||`**。所以 `a || b && c` = `a || (b && c)`。

💡 口诀：**「单目最高，算术次之；比较再次，与或更低；赋值垫底，逗号最后」**。拿不准就加括号。

## 2.2 算术运算符与表达式 ★★★

★ 考点：①整除「向零取整」；②取余「结果符号跟被除数」；③`%` 两边必须是整数；④除数为 0 的运行时错误。四条都可能单独出题。

**1. 规则**

**（1）五个算术运算符**

| 运算符 | 名称 | 注意 |
|:---:|------|------|
| `+` | 加 | 也可作正号（单目） |
| `-` | 减 | 也可作负号（单目） |
| `*` | 乘 | 不能省略，`2a` 是错的，必须写 `2*a` |
| `/` | 除 | 两边都是整数时是**整除** |
| `%` | 取余 | 两边**必须都是整数**，结果符号**跟被除数** |

**（2）整除：向零取整（不是向下取整）**

| 表达式 | 数学值 | C 的值 | 说明 |
|:---:|:---:|:---:|------|
| `7 / 2` | 3.5 | **3** | 直接砍掉小数 |
| `-7 / 2` | -3.5 | **-3** | **向零**靠拢，得 -3（不是 -4） |
| `7 / -2` | -3.5 | **-3** | 同上 |
| `1 / 2` | 0.5 | **0** | 结果 0，这是程序阅读题头号陷阱 |

**（3）取余：结果符号与被除数相同**

| 表达式 | 结果 | 被除数 | 结论 |
|:---:|:---:|:---:|------|
| `7 % 2` | **1** | 正 | 结果为正 |
| `-7 % 2` | **-1** | 负 | 结果为负 |
| `7 % -2` | **1** | 正 | 结果为**正**（跟被除数 7，不跟除数 -2） |
| `-7 % -2` | **-1** | 负 | 结果为负 |

📌 一句话记死：**`a % b` 的正负号只看 `a`**。这是填空高频点。

**（4）两个禁止**

| 错误 | 后果 |
|------|------|
| `5.5 % 2`（`%` 两边有小数） | **编译错误**：invalid operands to binary % |
| `5 / 0`（整数除 0） | **运行时错误**（程序崩溃），不是编译错误 |

⚠ `5.0 / 0` 在浮点下得到 `inf`（无穷），不崩溃；但**整数**除以 0 会直接崩。考试问「除数为 0」一律按**运行时错误**答。

**2. 例题**

**例 2.2.1（程序阅读 · 整除与取余的全部组合）**

```c-run
#include <stdio.h>
int main(void) {
    printf("%d %d\n", 7 / 2, -7 / 2);
    printf("%d %d\n", 7 % 2, -7 % 2);
    printf("%d %d\n", 7 % -2, -7 % -2);
    printf("%d\n", 1 / 2);
    printf("%d\n", -5 / 2);
    return 0;
}
```

```text
3 -3
1 -1
1 -1
0
-2
```

```answer 运行结果与追踪
| 行 | 表达式 | 结果 | 追踪 |
|:---:|:---:|:---:|------|
| 1 | `7 / 2` | **3** | 3.5 砍掉小数 |
| 1 | `-7 / 2` | **-3** | -3.5 **向零**靠拢 → -3（不是 -4） |
| 2 | `7 % 2` | **1** | 7 = 2×3 余 1 |
| 2 | `-7 % 2` | **-1** | 被除数是负 → 结果负。验算：`2 × (-3) + (-1) = -7` ✔ |
| 3 | `7 % -2` | **1** | 被除数 7 是正 → 结果**正**。验算：`(-2) × (-3) + 1 = 7` ✔ |
| 3 | `-7 % -2` | **-1** | 被除数负 → 结果负。验算：`(-2) × 3 + (-1) = -7` ✔ |
| 4 | `1 / 2` | **0** | 整除，0.5 被砍成 0 |
| 5 | `-5 / 2` | **-2** | -2.5 **向零** → -2（不是 -3） |

✔ 验证整除/取余是否算对的万能公式：**`a / b * b + a % b == a`**。用它检查上面每一行都对得上。

⚠ 第 4 行 `1 / 2` = **0**，不是 0.5。所有「求平均分」「求百分比」的题，只要忘了转浮点，整数部分就被砍没了。
```

**例 2.2.2（程序阅读 · 类型不同时的提升）**

```c-run
#include <stdio.h>
int main(void) {
    int a = 5;
    float f = 2.0f;
    double d = 2.0;
    printf("%d\n", a / 2);
    printf("%.1f\n", (double)(a / 2));
    printf("%.1f\n", a / 2.0);
    printf("%.1f\n", a / f);
    printf("%.1f\n", a / d);
    printf("%d\n", (int)(a / 2.0));
    return 0;
}
```

```text
2
2.0
2.5
2.5
2.5
2
```

```answer 运行结果与追踪
| 行 | 表达式 | 输出 | 追踪 |
|:---:|:---:|:---:|------|
| 1 | `a / 2` | **2** | ⚠ `a` 和 `2` **都是整数** → 整除 → 结果就是整数 2，小数被砍掉 |
| 2 | `(double)(a / 2)` | **2.0** | 括号在**里面**：先整除得 `2`，**再**转成 `2.0` |
| 3 | `a / 2.0` | **2.5** | `2.0` 是 `double` → `a` 提升为 `5.0` → 浮点除法得 2.5 |
| 4 | `a / f` | **2.5** | `f` 是 `float` → 提升后浮点除 = 2.5 |
| 5 | `a / d` | **2.5** | 同上 |
| 6 | `(int)(a / 2.0)` | **2** | 先算 `5 / 2.0 = 2.5`，再转 `int` **截断**成 2 |

⚠ **第 1 行是本节的核心教训**：除法的类型只看**两个操作数**，不看你想得到什么。`a / 2` 里两个操作数都是 `int`，所以**在第 1 步就已经整除成 2**，小数部分永久丢失——后面无论怎么转类型都救不回来（第 2 行只能得到 `2.0`，不是 `2.5`）。

✔ 想得到 2.5，必须**在运算之前**就让其中一个操作数变成浮点（第 3、4、5 行三种写法都可以）：

```c
double r1 = a / 2.0;        /* 把 2 写成 2.0 */
double r2 = (double)a / 2;  /* 强制转换 a */
double r3 = a / (double)2;  /* 强制转换 2 */
```

✘ 反面写法（考场上最常见的错误，也是**求平均值写错**的根因）：

```c
int sum = 7, n = 2;
double avg = sum / n;          /* 整除得 3，avg = 3.0，不是 3.5 */
double ok  = (double)sum / n;  /* 正确：3.5 */
```

⚠ 第 6 行如果写成 `(int)a / 2.0` 结果会是 **2.5**，因为那时先把 `a` 转成了 `5.0` 再除。**括号圈住谁，谁先算**——参见 《01 · C语言基础与数据类型》章的「类型转换」（在《01 · C语言基础与数据类型》章）。

📌 另一个必须避开的坑：**不要用 `%.1f` 去打印一个 `int` 表达式**（例如 `printf("%.1f", a / 2)`）。`%f` 要求对应参数是 `double`，传进去 `int` 属于参数类型不匹配，输出会是**不可预测的垃圾值**（本例实测会打印 `0.0`）。要打印浮点结果，就先把它转成 `double`（如第 2 行）。
```

**3. 易错清单**

⚠ `%` 只能用于整数。`5.5 % 2`、`a % 2.0` 都是**编译错误**，不是结果不对。

⚠ `-7 / 2` 得 **-3**（向零取整），不是 -4（向下取整）。区分方法：C 是「砍掉小数部分」。

⚠ `7 % -2` 得 **1**（跟被除数），不是 -1（跟除数）。记法：**余数的符号永远和 `%` 左边那个数一样**。

⚠ `2a` 不是乘法。C 没有隐式乘法，必须写 `2 * a`。

⚠ 整数除 0 是**运行时**崩溃，浮点除 0 得到 `inf`。问到「编译错误还是运行错误」，答**运行时错误**。

⚠ 想得小数必须在**运算前**转换：`(double)(7 / 2)` 得 `3.0`（括号在里面，**先整除成 3**，转换已经来不及了）；`(double)7 / 2` 才得 `3.5`。**转换永远不嫌早。**

⚠ 用 `%.1f` 打印 `int` 表达式（如 `printf("%.1f", a / 2)`）是**参数类型不匹配**，输出垃圾值。要打印浮点结果就先转 `double`。

💡 口诀：**「整除向零砍小数，取余符号跟左边；两边整型才取余，整数除零会崩溃」**。

## 2.3 关系运算符与逻辑运算符 ★★★

★ 考点：①关系表达式的值只有 `0` 和 `1`；②`=` 与 `==` 的经典陷阱；③**短路求值**（真题反复考）；④判断小写字母的表达式（2025 真题填空题原题）。

**1. 规则**

**（1）六个关系运算符**

| 运算符 | 含义 | 运算符 | 含义 |
|:---:|:---:|:---:|:---:|
| `<` | 小于 | `>=` | 大于或等于 |
| `<=` | 小于或等于 | `==` | **等于** |
| `>` | 大于 | `!=` | **不等于** |

✔ 关系表达式的值**只有两个**：成立得 **1**，不成立得 **0**。它是一个 `int`。

✘ 经典错误：`3 < x < 5` 想表达「x 在 3 和 5 之间」。它实际是 `(3<x)<5`，无论 x 是多少都得 **1**（因为左边结果只有 0 或 1，都小于 5）。
✔ 正确写法：`x > 3 && x < 5`。

**（2）`=` 与 `==`：每年必考的陷阱**

| 写法 | 含义 | 后果 |
|:---:|------|------|
| `if (a == 5)` | 判断 a 是否等于 5 | ✔ 正确 |
| `if (a = 5)` | 把 5 **赋值**给 a，再判断「5 是否非零」 | ✘ 条件**永远成立**（5 非 0） |

📌 `if (a = 5)` 的完整解释：赋值表达式 `a = 5` 本身的值就是 **5**，而 C 里「非 0 即真」，所以条件恒真，同时 `a` 被改成了 5。这是一个**语法合法、逻辑错误**的写法——编译器不会报错。

**（3）逻辑运算符真值表**

| `a` | `b` | `a && b` | `a \|\| b` | `!a` |
|:---:|:---:|:---:|:---:|:---:|
| 真(非0) | 真(非0) | **1** | **1** | 0 |
| 真(非0) | 假(0) | **0** | **1** | 0 |
| 假(0) | 真(非0) | **0** | **1** | 1 |
| 假(0) | 假(0) | **0** | **0** | 1 |

✔ 记忆：`&&` 是「两个都真才真」，`||` 是「一个真就真」，`!` 是「真变假、假变真」。

⚠ 逻辑运算的结果**只有 0 或 1**，不会等于操作数本身。`2 && 3` 的值是 **1**，不是 2、不是 3。

**（4）短路求值（本节最重要的考点）**

`&&` 和 `||` 都会**偷懒**：

| 表达式 | 行为 |
|------|------|
| `a && b` | 先算 `a`；**若 `a` 为假，`b` 根本不执行**，整个式子直接得 0 |
| `a \|\| b` | 先算 `a`；**若 `a` 为真，`b` 根本不执行**，整个式子直接得 1 |

⚠ 这条规则有**副作用**：写在 `b` 里的 `++`、`--`、函数调用或赋值，可能**一次都不执行**。

**2. 例题**

**例 2.3.1（程序阅读 · 短路求值的副作用 · 真题风格）**

```c-run
#include <stdio.h>
int main(void) {
    int a = 0, b = 1, c = 2, d = 3;
    printf("%d\n", a && ++b);
    printf("b=%d\n", b);
    printf("%d\n", b || ++c);
    printf("c=%d\n", c);
    printf("%d\n", c && d++);
    printf("d=%d\n", d);
    return 0;
}
```

```text
0
b=1
1
c=2
1
d=4
```

```answer 运行结果与追踪
**逐条追踪（表格里每一步都要对上）**：

| 语句 | 表达式 | 输出 | 追踪：谁被算了，谁被跳过 |
|:---:|:---:|:---:|------|
| 1 | `a && ++b` | **0** | `a` 是 **0（假）** → `&&` 左边已假 → **右边 `++b` 直接不执行** → 整个式子得 0 |
| 2 | `printf("b=%d", b)` | **b=1** | 因为第 1 行 `++b` **没执行**，`b` 还是 1 —— **这就是短路存在的证据** |
| 3 | `b \|\| ++c` | **1** | `b` 是 **1（真）** → `\|\|` 左边已真 → **右边 `++c` 不执行** → 得 1 |
| 4 | `printf("c=%d", c)` | **c=2** | `++c` 没执行，`c` 仍是 2 |
| 5 | `c && d++` | **1** | `c` 是 2（**非 0 即真**） → 左边真，必须看右边 → `d++` **执行了**：式子取 `d` 的**原值** 3（真）→ 整个式子得 1 |
| 6 | `printf("d=%d", d)` | **d=4** | `d++` 执行过 → `d` 变成 **4** |

**结论（背下来）**：

- `&&` 左边为**假** → 右边**不算**。
- `||` 左边为**真** → 右边**不算**。
- 反之，左边「不足以决定结果」时，右边一定会算。

⚠ 第 2 行输出 `b=1`，第 4 行输出 `c=2`——这两个「没变化」正是得分点。很多同学算出 `b=2`、`c=3`，就是因为忽略了短路。
```

| 1 | `3 < x < 5` | **1** | ⚠ **左结合**：先 `3 < 4` 得 `1` → 再 `1 < 5` 得 **1**。这次「碰巧」对了 |
| 2 | `x > 3 && x < 5` | **1** | 两个条件都成立 → `1 && 1` = 1（**正确写法**） |

**例 2.3.3（填空题 · 2025 山西真题原题）**

> 判断字符变量 `ch` 是否为**小写字母**的 C 表达式是 \_\_\_\_\_\_\_\_\_\_\_\_\_。

```c-run

int main(void) {
    char ch = 'm';
    printf("%d\n", ch >= 'a' && ch <= 'z');
    ch = 'M';

}
```

0
0
```

```answer 参考答案
标准答案：**`ch >= 'a' && ch <= 'z'`**

（若题目要求「是字母」而非「小写字母」，则答 `(ch >= 'a' && ch <= 'z') || (ch >= 'A' && ch <= 'Z')`。）

**追踪验证**：

| `ch` | `ch >= 'a'` | `ch <= 'z'` | `&&` 结果 | 说明 |
|:---:|:---:|:---:|:---:|------|
| `'m'`(109) | 109>=97 真=1 | 109<=122 真=1 | **1** | 是小写字母 ✔ |
| `'M'`(77) | 77>=97 假=0 | — | **0** | 短路！右边不算（77<=122 本为真，但 `&&` 左边已假） |
| `'5'`(53) | 53>=97 假=0 | — | **0** | 短路，同上 |

⚠ 三个必扣分的错误写法：

| ✘ 错误写法 | 为什么错 |
|------|------|
| `'a' <= ch <= 'z'` | 左结合，永远得 1（见例 2.3.2） |
| `ch >= 'a' \|\| ch <= 'z'` | 用了 `\|\|`：任何字符至少满足一边，**恒为真** |
| `'a' <= ch && ch <= 'z'` | ✔ **这个其实也对**，只是习惯上把变量写左边 |

💡 口诀：**「判断范围用与不用或：两个条件都要满足就 `&&`，一个满足就行就 `||`」**。
```

**3. 易错清单**

⚠ `if (a = 5)` 恒为真且会改掉 `a`。想比较必须写 `if (a == 5)`。防手滑技巧：把常量写左边 `if (5 == a)`，写成 `5 = a` 会直接编译报错，错误立刻暴露。

⚠ `2 && 3` 的值是 **1**，不是 2 或 3。逻辑运算结果只有 0/1。

⚠ 忽略短路，把 `b` 算成 2、把 `c` 算成 3。**`&&` 左假则右不算，`||` 左真则右不算。**

⚠ `'a' <= ch <= 'z'` 恒为真。范围判断必须拆成两个条件用 `&&` 连接。

⚠ 判断相等用 `==`，判断不等用 `!=`；`=` 是赋值。这三个符号每年都有人写错。

💡 口诀：**「关系结果零和一，等于要用双等号；与看左假就收工，或看左真就罢手」**（后半句就是短路）。

## 2.4 赋值运算符与复合赋值 ★★

★ 考点：①赋值右结合（`a=b=c=1`）；②复合赋值 `+=` 的展开；③赋值表达式的值（`if (a=b)` 的含义）。

**1. 规则**

**（1）赋值运算符是右结合**

`a = b = c = 1;` 等价于 `a = (b = (c = 1));`，执行顺序**从右往左**：先把 1 给 `c`，再把 `c=1` 这个表达式的值（1）给 `b`，最后给 `a`。三个变量都变成 1。

**（2）复合赋值：先展开再理解**

| 复合写法 | 等价于 | 例（`a=10`） | 结果 |
|:---:|:---:|------|:---:|
| `a += 3` | `a = a + 3` | 10+3 | 13 |
| `a -= 3` | `a = a - 3` | 10-3 | 7 |
| `a *= 3` | `a = a * 3` | 10*3 | 30 |
| `a /= 3` | `a = a / 3` | 10/3（整除！） | 3 |
| `a %= 3` | `a = a % 3` | 10%3 | 1 |

⚠ `a /= 3` 在 `a` 是整型时用的是**整除**，`10 /= 3` 得 **3**，不是 3.33。

**（3）赋值表达式本身有值**

`a = 5` 这个表达式的值就是 **5**。所以：

| 写法 | 含义 |
|------|------|
| `if (a = 5)` | 把 5 赋给 `a`，再用「5 非零」作条件 → **恒为真** |
| `if ((a = 5) != 0)` | 同上，但意图明确 |
| `b = (a = 5) + 1` | `a` 变 5，`b` 得 6 |

**2. 例题**

**例 2.4.1（程序阅读 · 赋值与复合赋值）**

```c-run
#include <stdio.h>
int main(void) {
    int a, b, c;
    a = b = c = 1;
    printf("%d %d %d\n", a, b, c);
    a += 3;
    printf("%d\n", a);
    a -= 1;
    printf("%d\n", a);
    a *= 2;
    printf("%d\n", a);
    a /= 3;
    printf("%d\n", a);
    a %= 4;
    printf("%d\n", a);
    return 0;
}
```

```text
1 1 1
4
3
6
2
2
```

```answer 运行结果与追踪
| 步骤 | 语句 | `a` 的值 | 追踪 |
|:---:|:---:|:---:|------|
| 1 | `a = b = c = 1;` | 1 | **右结合**：先 `c=1`，再 `b=c`，最后 `a=b`。三个都是 1 |
| 2 | `a += 3;` | **4** | `a = 1 + 3` |
| 3 | `a -= 1;` | **3** | `a = 4 - 1` |
| 4 | `a *= 2;` | **6** | `a = 3 × 2` |
| 5 | `a /= 3;` | **2** | `a = 6 / 3 = 2`（整除，此处恰好整除） |
| 6 | `a %= 4;` | **2** | `a = 2 % 4 = 2`（**被除数比除数小，余数就是它自己**） |

⚠ 第 6 步容易答 0：以为「取余总会变小」。实际上 `2 % 4` = **2**，因为 2 里面一个 4 都装不下，商 0 余 2。
```

**例 2.4.2（程序阅读 · 赋值表达式的值）**

```c-run
#include <stdio.h>
int main(void) {
    int a = 1, b = 2, t;
    t = (a = 5) + 1;
    printf("%d %d\n", a, t);
    t = a = b = 3;
    printf("%d %d %d\n", a, b, t);
    if (a = 0) {
        printf("yes\n");
    } else {
        printf("no\n");
    }
    return 0;
}
```

5 6
3 3 3
no
```

```answer 运行结果与追踪
| 行 | 语句 | 输出 | 追踪 |
|:---:|:---:|:---:|------|
| 1 | `t = (a = 5) + 1;` | — | 先算括号 `a = 5`：`a` 变成 5，**这个表达式的值也是 5** → `t = 5 + 1 = 6` |
| 2 | `printf("%d %d", a, t)` | **5 6** | `a` 是 5，`t` 是 6 |
| 3 | `t = a = b = 3;` | — | 右结合：`b=3` → `a=3` → `t=3` |
| 4 | `printf("%d %d %d", a, b, t)` | **3 3 3** | 三个都变成 3 |
| 5 | `if (a = 0)` | — | ⚠ **这是赋值不是比较**：`a` 被赋成 **0**，表达式值为 0 → 条件**为假** |
| 6 | `printf("no")` | **no** | 所以走 `else` 分支 |

⚠ 第 5 行是「`=` 与 `==`」陷阱的完整演示：如果原意是「判断 a 是否为 0」，正确写法是 `if (a == 0)`，此时 `a` 还是 3，判断为假，同样走 `else`——**本例里两条路的结果碰巧一样，但 `a` 的值已经被改掉了**。这就是为什么这种错误极难发现：

| 写法 | 条件真假 | 执行后 `a` 的值 |
|:---:|:---:|:---:|
| `if (a = 0)` | 假 | **被改成 0** |
| `if (a == 0)` | 假（a 原是 3） | 保持 3 |

📌 考场判断技巧：看到 `if (变量 = 常量)` 一律判为**错误写法**，因为条件真假只由那个常量决定，与变量无关。
```

**3. 易错清单**

⚠ 把 `a = b = c = 1` 理解成从左往右：那样 `a` 会先被赋成 `b` 的垃圾值。**赋值是右结合**，必须从右往左。

⚠ 忘记 `a /= 3` 是整除：整型 `10 /= 3` 得 **3**。

⚠ 认为 `2 % 4` 等于 0。**被除数小于除数时，余数就是被除数本身**。

⚠ `if (a = 5)` 恒真、`if (a = 0)` 恒假，且都会改掉 `a` 的值。这是「语法合法、逻辑错误」的典型，编译器不报错。

💡 口诀：**「赋值右结合，复合先展开；表达式也有值，等号用错坑死人」**。

## 2.5 自增自减运算符 ★★★

★ 考点：`++`/`--` 的**前置与后置**区别，以及它们在表达式里的取值时机。这是程序阅读题出现频率最高的单一考点。

**1. 规则**

**（1）前置 `++i` 与后置 `i++` 的差别**

| 写法 | 含义 | 参与运算时取的值 |
|:---:|------|:---:|
| `++i`（前置） | `i` 先加 1 | 取**新值**（加完之后的） |
| `i++`（后置） | `i` 后加 1 | 取**原值**（加之前的） |

✔ **同一个共同点**：不管前置后置，**执行完这一句之后，`i` 都比原来大 1**。区别只在「这一句里用的是哪个值」。

**（2）单独成句时完全等价**

| 语句 | `i` 的最终值 |
|:---:|:---:|
| `i++;` | i+1 |
| `++i;` | i+1 |
| `i = i + 1;` | i+1 |

三种写法在**单独成句**时结果一模一样。只有**参与运算**（放进表达式里）才有区别。

**（3）判分口诀**

> 看 `++` **在变量的哪一边**：`++` 在前面 → 先加再用新值；`++` 在后面 → 先用原值再加。

**2. 例题**

**例 2.5.1（程序阅读 · 单独成句 vs 参与运算）**

```c-run
#include <stdio.h>
int main(void) {
    int i = 5;
    i++;
    printf("%d\n", i);
    i = 5;
    ++i;
    printf("%d\n", i);
    i = 5;
    printf("%d\n", i++);
    printf("%d\n", i);
    ++i;
    printf("%d\n", i);
    return 0;
}
```

```text
6
6
5
6
7
```

```answer 运行结果与追踪
| 步骤 | 语句 | 输出 | 追踪 |
|:---:|:---:|:---:|------|
| 1 | `i = 5; i++;` | — | 单独成句，`i` 变成 6 |
| 2 | `printf("%d", i)` | **6** | `i` 是 6 |
| 3 | `i = 5; ++i;` | — | 单独成句，`i` 变成 6 |
| 4 | `printf("%d", i)` | **6** | ✔ **和 `i++` 结果完全一样** |
| 5 | `i = 5;` | — | 重置为 5 |
| 6 | `printf("%d", i++)` | **5** | ⚠ **后置**：先用 `i` 的**原值 5** 去打印，打印完 `i` 才变成 6 |
| 7 | `printf("%d", i)` | **6** | 上一步的 `++` 生效了，`i` 是 6 |
| 8 | `++i;` | — | `i` 变成 7 |
| 9 | `printf("%d", i)` | **7** | `i` 是 7 |

⚠ 第 2 行和第 4 行都输出 `6`——**证明单独成句时前置后置等价**。第 6 行输出 `5` 而第 7 行输出 `6`——**证明后置是「先用原值，再自增」**。
```

**例 2.5.2（纸笔追踪 · 前置后置赋值给别的变量）**

```c-run
#include <stdio.h>
int main(void) {
    int a, b, i;
    i = 5;
    a = i++;
    printf("%d %d\n", a, i);
    i = 5;
    b = ++i;
    printf("%d %d\n", b, i);
    return 0;
}
```

```text
5 6
6 6
```

```answer 运行结果与追踪
**第一组：`i=5; a = i++;`**

| 时刻 | 动作 | `a` | `i` |
|:---:|------|:---:|:---:|
| ① | 初始 | ? | 5 |
| ② | `i++` **取原值** 5 参与赋值 | 5 | 5 |
| ③ | 赋值完成后 `i` 自增 | 5 | **6** |
| 输出 | `printf("%d %d", a, i)` | **5** | **6** |

**第二组：`i=5; b = ++i;`**

| 时刻 | 动作 | `b` | `i` |
|:---:|------|:---:|:---:|
| ① | 初始 | ? | 5 |
| ② | `++i` **先自增** → `i` 变 6 | ? | 6 |
| ③ | 用**新值 6** 参与赋值 | **6** | 6 |
| 输出 | `printf("%d %d", b, i)` | **6** | **6** |

**对照结论**：

| 写法 | 赋给 `a`/`b` 的值 | 执行后 `i` |
|:---:|:---:|:---:|
| `a = i++`（后置） | **原值 5** | 6 |
| `b = ++i`（前置） | **新值 6** | 6 |

📌 记法：`++` 写在**后面**，就「慢半拍」——这一句还用旧值，下一句才生效。
```

**⚠ 关于「同一表达式里多次自增」——必须知道的事**

⚠ 不要在一个表达式里对**同一个变量**多次自增，例如 `i = 5; printf("%d %d", i++, i);` 或 `i = i++ + ++i;`。这类写法在 C 标准里属于**未定义行为**：不同编译器、甚至同一编译器的不同优化级别，结果都可能不一样。

✔ 考试里的处理原则（**按这个来答题**）：

| 情形 | 考试怎么判 |
|------|------|
| 题目给出 `printf("%d %d", i++, i);` | 山西卷及多数教材按**从左到右**求值：第一个参数取 5，第二个参数取自增后的 6 → 输出 `5 6` |
| 题目给出 `i = i++ + ++i;` 之类 | 属于超纲的未定义行为，**真题不会这样出**；若遇到，说明理由并给出「不确定」 |
| 你自己写代码 | **绝对不要这么写**。拆成两句：`printf("%d ", i); i++; printf("%d", i);` |

📌 应试建议：遇到这类题，**先按「从左到右」算出答案填上去**（拿分优先），同时在 `answer` 里知道它其实是不确定的。更重要的是——**这种题只考 1 分，别为它纠结太久**。

**3. 易错清单**

⚠ 以为 `i++` 和 `++i` 单独用时也不同。**单独成句时完全一样**，两者都让 `i` 加 1。

⚠ 忘记「后置慢半拍」：`a = i++` 之后 `a` 拿的是**旧值**，`i` 才是新值。

⚠ 在同一个表达式里对同一变量多次自增（`i++ + i++`）。这是未定义行为，**别在程序里这么写**；考试遇到就按从左到右作答。

⚠ 把 `i++` 当成「先加后用」。**正好说反了**：`++` 在后面 = 先用后加。

⚠ `++` 只能作用于**变量**，不能作用于常量或表达式：`++5`、`++(a+b)` 都是**编译错误**。

💡 口诀：**「加号在前先加再用，加号在后先用再加；单独成句不分前后，一句之内别加两次」**。

## 2.6 逗号运算符与逗号表达式 ★★★

★ 考点：①逗号表达式的值 = **最后一个子表达式的值**；②`(a=2,b=5,a++,b++,a+b)` 这类真题；③逗号在**函数参数**和**变量声明**里不是逗号运算符。

**1. 规则**

**（1）逗号表达式的求值规则**

`表达式1, 表达式2, 表达式3, ...` 的求值过程：

1. **从左到右**依次计算每个子表达式（每个都真的执行，副作用都生效）；
2. 整个逗号表达式的**值** = **最后一个子表达式的值**。

**（2）逗号运算符的优先级最低**

逗号运算符优先级**最低**（比赋值还低）。所以要看清楚哪些部分被逗号分开了。

**（3）逗号运算符 vs 普通逗号（重点区分）**

| 出现位置 | 是逗号运算符吗 | 说明 |
|------|:---:|------|
| `a = (1, 2, 3);` | ✔ 是 | 括号内是逗号表达式，`a` 得 3 |
| `a = 1, 2, 3;` | ✔ 是 | 整个是逗号表达式，但 `a` 只得到 **1**（见例题） |
| `int a, b, c;` | ✘ 不是 | 变量声明里的分隔符 |
| `printf("%d %d", a, b);` | ✘ 不是 | 函数参数的**分隔符** |
| `int a[3] = {1, 2, 3};` | ✘ 不是 | 初始化列表的分隔符 |

⚠ 高频陷阱：`a = 1, 2, 3;` 里 `a` 得到的是 **1**，不是 3。因为**赋值优先级高于逗号**，它先被切成 `(a = 1), 2, 3`。

**2. 例题**

**例 2.6.1（程序阅读 · 2025 山西真题原题）**

```c-run
#include <stdio.h>
int main(void) {
    int a = 1, b = 2, x;
    x = (a = 2, b = 5, a++, b++, a + b);
    printf("%d\n", x);
    printf("%d %d\n", a, b);
    return 0;
}
```

```text
9
3 6
```

```answer 运行结果与追踪
**逐步追踪表（本题的核心，必须自己先写一遍）**：

| 步骤 | 子表达式 | 做什么 | `a` | `b` | 该子表达式的值 |
|:---:|:---:|------|:---:|:---:|:---:|
| ① | `a = 2` | 把 2 赋给 `a` | **2** | 2 | 2 |
| ② | `b = 5` | 把 5 赋给 `b` | 2 | **5** | 5 |
| ③ | `a++` | **后置**：先取原值 2，再 `a` 变 3 | **3** | 5 | 2（原值） |
| ④ | `b++` | **后置**：先取原值 5，再 `b` 变 6 | 3 | **6** | 5（原值） |
| ⑤ | `a + b` | 用**当前**的 3 和 6 相加 | 3 | 6 | **9** |
| ⑥ | 整个逗号表达式的值 | = 最后一个子表达式的值 | 3 | 6 | **9** |
| ⑦ | 赋给 `x` | `x = 9` | 3 | 6 | — |

**输出**：

- `printf("%d", x)` → **9**
- `printf("%d %d", a, b)` → **3 6**

⚠ 最容易错的地方是第 ⑤ 步：`a + b` 用的是**自增之后**的 3 和 6（因为 ③④ 已经执行完了），所以是 9 而不是 2+5=7。

⚠ 另一个易错点是误以为「逗号表达式只算最后一个」。**不是**：前面每个子表达式都会真的执行，只是**整个表达式的值**取最后一个。`a` 和 `b` 都被改过了，这一点从第 2 行的输出 `3 6` 可以验证。
```

**例 2.6.2（程序阅读 · 有没有括号大不同）**

```c-run
#include <stdio.h>
int main(void) {
    int a, x, y;
    a = 1, x = 2, y = 3;
    printf("%d %d %d\n", a, x, y);
    a = (1, 2, 3);
    printf("%d\n", a);
    x = (y = 4, y + 1);
    printf("%d %d\n", x, y);
    printf("%d\n", (1, 2, 3));
    return 0;
}
```

```text
1 2 3
3
5 4
3
```

```answer 运行结果与追踪
| 行 | 语句 | 输出 | 追踪 |
|:---:|:---:|:---:|------|
| 1 | `a = 1, x = 2, y = 3;` | — | ⚠ **赋值优先级高于逗号** → 相当于 `(a=1), (x=2), (y=3)`，三句都执行 |
| 2 | `printf("%d %d %d", a, x, y)` | **1 2 3** | 三个变量分别得 1、2、3（**碰巧都对**，但原因和你想的不一样） |
| 3 | `a = (1, 2, 3);` | — | 括号内是逗号表达式 → 依次算 1、2、3 → 值为 **3** → `a = 3` |
| 4 | `printf("%d", a)` | **3** | `a` 是 3 |
| 5 | `x = (y = 4, y + 1);` | — | 先 `y = 4`；再算 `y + 1 = 5` → 值为 5 → `x = 5` |
| 6 | `printf("%d %d", x, y)` | **5 4** | `x` = 5，`y` = 4 |
| 7 | `printf("%d", (1, 2, 3))` | **3** | 逗号表达式的值 = 最后一个 = 3 |

⚠ 第 1、2 行要理解透：`a = 1, x = 2, y = 3;` 之所以三个变量都对，是因为**逗号优先级最低**，每个赋值各算各的。但如果写成 `a = 1, 2, 3;`，那 `a` 只得到 **1**，后面的 `2`、`3` 被白算了：

```c
a = 1, 2, 3;      /* a 得 1（相当于 (a=1), 2, 3） */
a = (1, 2, 3);    /* a 得 3（括号改变了逗号的地位） */
```

📌 一句话判据：**逗号表达式「值取最后，但每个都算」；想让它当一个值用，必须加括号。**
```

**3. 易错清单**

⚠ 以为逗号表达式**只算最后一个**。前面每个子表达式都会执行，副作用（`++`、`=`）全部生效。

⚠ `a = 1, 2, 3;` 里 `a` 得 **1** 而不是 3。因为赋值优先级高于逗号。要得 3 必须写 `a = (1, 2, 3);`。

⚠ 把函数参数、变量声明、初始化列表里的逗号当成逗号运算符。那些都是**分隔符**。

⚠ 忘记逗号运算符**优先级最低**：`x = 1, y = 2` 是两条赋值，不是 `x = (1, y = 2)`。

💡 口诀：**「逗号从左算到尾，整串取最后一个值；声明参数不算它，要用它得加括号」**。

## 2.7 条件运算符 ★★

★ 考点：①`a > b ? a : b` 的求值顺序；②右结合与嵌套；③求三个数的最大值（程序设计与阅读都爱考）。

**1. 规则**

**（1）三目运算符 `?:` 是 C 里唯一的三目运算符**

形式：`表达式1 ? 表达式2 : 表达式3`

求值过程：先算 `表达式1`；**若非 0（真）→ 整个式子的值取 `表达式2`**；**若为 0（假）→ 取 `表达式3`**。

⚠ 只算被选中的那一支，另一支**根本不执行**（和 `&&`、`||` 一样有「短路」特性）。

**（2）右结合**

`a > b ? a : b > c ? b : c` 等价于 `a > b ? a : (b > c ? b : c)`——从右往左配对。

📌 虽然右结合是标准规定，但**考试写代码时建议手工加括号**，可读性高且绝不会错。

**（3）与 if-else 的转换**

| `?:` 写法 | 等价的 if-else |
|------|------|
| `max = a > b ? a : b;` | `if (a > b) max = a; else max = b;` |

**2. 例题**

**例 2.7.1（程序阅读 · 条件运算符基础与右结合）**

```c-run
#include <stdio.h>
int main(void) {
    int a = 3, b = 5, c = 4, t;
    printf("%d\n", a > b ? a : b);
    printf("%d\n", a < b ? a + b : a - b);
    printf("%d\n", a > b ? a : b > c ? b : c);
    t = a > b ? (a > c ? a : c) : (b > c ? b : c);
    printf("%d\n", t);
    return 0;
}
```

```text
5
8
5
5
```

```answer 运行结果与追踪
| 行 | 表达式 | 输出 | 追踪 |
|:---:|:---:|:---:|------|
| 1 | `a > b ? a : b` | **5** | `3 > 5` 为假 → 取冒号**后**面的 `b` = 5 |
| 2 | `a < b ? a + b : a - b` | **8** | `3 < 5` 为真 → 取 `a + b = 8`（**`a - b` 根本没算**） |
| 3 | `a > b ? a : b > c ? b : c` | **5** | **右结合**：`a > b ? a : (b > c ? b : c)`。`3>5` 假 → 算右边 `5>4` 真 → 取 `b` = **5** |
| 4 | `t = a > b ? (a > c ? a : c) : (b > c ? b : c)` | **5** | `3>5` 假 → 走 `(b > c ? b : c)` → `5>4` 真 → 取 `b` = 5 |

⚠ 第 2 行注意 `a - b` 那一支**完全没有被求值**。如果写成 `a < b ? a++ : b++`，只有 `a++` 会执行——这是阅读题的常见埋点。

⚠ 第 3 行如果不按右结合理解，容易算错。**考场上请一律加括号**（如第 4 行的写法），既清楚又不会错。
```

**例 2.7.2（程序阅读 · 求三个数中的最大值）**

```c-run
#include <stdio.h>
int main(void) {
    int a = 7, b = 12, c = 9, max;
    max = a > b ? a : b;
    max = max > c ? max : c;
    printf("%d\n", max);
    printf("%d\n", a > b ? (a > c ? a : c) : (b > c ? b : c));
    printf("%d\n", a < b ? (a < c ? a : c) : (b < c ? b : c));
    return 0;
}
```

```text
12
12
7
```

```answer 运行结果与追踪
| 行 | 语句 | 输出 | 追踪 |
|:---:|:---:|:---:|------|
| 1 | `max = a > b ? a : b;` | — | `7 > 12` 假 → `max = b = 12` |
| 2 | `max = max > c ? max : c;` | — | `12 > 9` 真 → `max` 保持 12 |
| 3 | `printf("%d", max)` | **12** | 最大值 12 ✔ |
| 4 | 嵌套条件运算符（**最大值**） | **12** | `7 > 12` 假 → 走 `(b > c ? b : c)` → `12 > 9` 真 → 取 12 |
| 5 | 嵌套条件运算符（**最小值**） | **7** | `7 < 12` 真 → 走 `(a < c ? a : c)` → `7 < 9` 真 → 取 **7** |

✔ 求最值两行法（**建议直接背这个写法**，程序设计题里非常好用）：

```c
max = a > b ? a : b;      /* 先比出前两个里的大者 */
max = max > c ? max : c;  /* 再和第三个比 */
```

⚠ 第 5 行求最小值时，**两个 `>` 都要改成 `<`**，而且内层的比较对象也要跟着换（`a` 对 `c`，`b` 对 `c`）。这是最容易抄错的地方。
```

**3. 易错清单**

⚠ 把 `a > b ? a : b` 读成「a 大于 b 就等于 a」。它是个**表达式**，值是被选中的那一支，不会自动赋值。

⚠ 忘记 `?:` 只算一支：`a < b ? a++ : b++` 里 `b++` 不执行。

⚠ 嵌套时不加括号导致配对错误。**一律手工加括号**。

⚠ 把 `?:` 的三个操作数类型搞混，例如 `a > b ? 1 : "no"` 是类型不匹配的错误写法。

💡 口诀：**「真取问号后，假取冒号后；只算选中那一边，嵌套记得加括号」**。

## 2.8 位运算符 ★★

★ 考点：①`&` `|` `^` `~` `<<` `>>` 的运算规则；②按位与清零/取位、按位或置位；③异或交换两数；④左移右移等价于乘除 2 的幂。选择题里通常直接问某个表达式的值。

**1. 规则**

**（1）六个位运算符**

| 运算符 | 名称 | 规则（对每一位独立运算） |
|:---:|:---:|------|
| `&` | 按位与 | 两位**都为 1** 才得 1，否则 0 |
| `\|` | 按位或 | 两位**有一个为 1** 就得 1 |
| `^` | 按位异或 | 两位**不同**得 1，**相同**得 0 |
| `~` | 按位取反 | **单目**运算符，0 变 1、1 变 0 |
| `<<` | 左移 | 各位左移，右边补 0 |
| `>>` | 右移 | 各位右移，左边补符号位（正数补 0） |

⚠ 区分 `&` 与 `&&`、`|` 与 `||`：**单字符是按位运算，双字符是逻辑运算**。`5 & 3` 得 1，`5 && 3` 也得 1——**碰巧一样**，但 `4 & 2` 得 **0**，`4 && 2` 得 **1**。别用逻辑运算的直觉做位运算。

**（2）按位运算的值（以 4 位演示，实际是 32 位）**

| 表达式 | 二进制演算 | 值 |
|:---:|------|:---:|
| `5 & 3` | `0101 & 0011` = `0001` | **1** |
| `5 \| 3` | `0101 \| 0011` = `0111` | **7** |
| `5 ^ 3` | `0101 ^ 0011` = `0110` | **6** |
| `~5` | `~...0101` = `...1010`（补码）= `-6` | **-6** |
| `1 << 3` | `0001` 左移 3 位 = `1000` | **8** |

**（3）三个实用技巧（程序填空题常考）**

| 目的 | 写法 | 说明 |
|------|------|------|
| 把某一位**清零** | `x & ~(1 << n)` | 与 0 相与得 0 |
| 把某一位**置 1** | `x \| (1 << n)` | 与 1 相或得 1 |
| 取出某一位的值 | `(x >> n) & 1` | 移到最低位再与 1 |
| 交换两数（不用临时变量） | `a ^= b; b ^= a; a ^= b;` | 见例 2.8.2 |

**（4）移位与乘除的关系**

| 写法 | 等价于 | 例（`x = 3`） |
|:---:|:---:|:---:|
| `x << 1` | `x * 2` | 6 |
| `x << 2` | `x * 4` | 12 |
| `x >> 1` | `x / 2`（整除） | 1 |
| `x >> 2` | `x / 4`（整除） | 0 |

📌 口诀：**左移 n 位 = 乘 2ⁿ，右移 n 位 = 除以 2ⁿ（整除）**。

⚠ **负数移位**：`~5` 得 `-6` 就是补码下的取反结果。至于 `-8 >> 1` 这类负数移位，C 标准规定「实现定义」（补 0 还是补 1 取决于编译器），**山西卷不会考**，考试只考**正数或无符号数**的移位。知道 `~5 = -6` 就够了。

**2. 例题**

**例 2.8.1（程序阅读 · 五个基本位运算的值）**

```c-run
#include <stdio.h>
int main(void) {
    printf("%d\n", 5 & 3);
    printf("%d\n", 5 | 3);
    printf("%d\n", 5 ^ 3);
    printf("%d\n", ~5);
    printf("%d\n", 1 << 3);
    printf("%d\n", 3 << 2);
    printf("%d\n", 13 >> 2);
    return 0;
}
```

```answer 运行结果与追踪
| 行 | 表达式 | 值 | 二进制演算（以低 8 位为例） |
|:---:|:---:|:---:|------|
| 1 | `5 & 3` | **1** | `00000101 & 00000011` = `00000001` |
| 2 | `5 \| 3` | **7** | `00000101 \| 00000011` = `00000111` |
| 3 | `5 ^ 3` | **6** | `00000101 ^ 00000011` = `00000110`（第 1、2 位不同得 1） |
| 4 | `~5` | **-6** | `~00000101` = `11111010`（补码）→ 最高位是 1，是负数 → 取反加一得 6 → **-6** |
| 5 | `1 << 3` | **8** | `00000001` 左移 3 位 = `00001000`，等于 1 × 2³ |
| 6 | `3 << 2` | **12** | 3 × 2² = 3 × 4 = 12 |
| 7 | `13 >> 2` | **3** | 13 ÷ 2² = 13 ÷ 4 = 3（**整除**，不是 3.25） |

**`~5 = -6` 的完整推导**（这一步最容易错）：

| 步骤 | 内容 |
|:---:|------|
| ① `5` 的补码（8 位演示） | `00000101` |
| ② 按位取反 | `11111010` |
| ③ 最高位是 1 → 是负数，按补码还原 | 取反 `00000101`，加 1 → `00000110` = 6 |
| ④ 加上负号 | **-6** |

✔ 速算公式：**`~n = -(n + 1)`**。验证：`~5 = -(5+1) = -6` ✔；`~0 = -(0+1) = -1` ✔。
```

**例 2.8.2（程序阅读 · 异或交换与移位技巧）**

```c-run
#include <stdio.h>
int main(void) {
    int a = 12, b = 5, x = 11;
    a ^= b;
    b ^= a;
    a ^= b;
    printf("%d %d\n", a, b);
    printf("%d\n", x & 1);
    printf("%d\n", (x >> 1) & 1);
    printf("%d\n", x | 4);
    printf("%d\n", x & ~4);
    return 0;
}
```

```answer 运行结果与追踪
**① 异或交换两数（不用临时变量）**

| 步骤 | 语句 | `a` | `b` | 演算 |
|:---:|:---:|:---:|:---:|------|
| 初始 | — | 12 | 5 | `1100`、`0101` |
| ① | `a ^= b;` | **9** | 5 | `1100 ^ 0101 = 1001` = 9 |
| ② | `b ^= a;` | 9 | **12** | `0101 ^ 1001 = 1100` = 12 |
| ③ | `a ^= b;` | **5** | 12 | `1001 ^ 1100 = 0101` = 5 |
| 输出 | `printf("%d %d", a, b)` | **5** | **12** | 交换成功 ✔ |

**② 取位与置位（`x = 11`，二进制 `1011`）**

| 行 | 表达式 | 值 | 追踪 |
|:---:|:---:|:---:|------|
| 1 | `x & 1` | **1** | 取最低位：`1011 & 0001 = 0001`。用于判断奇偶（1 是奇数） |
| 2 | `(x >> 1) & 1` | **1** | 右移 1 位得 `0101`，再 `& 1` 得第 2 位的值 `1` |
| 3 | `x \| 4` | **15** | `4` 是 `0100`，把第 3 位置 1：`1011 \| 0100 = 1111` = 15 |
| 4 | `x & ~4` | **11** | `~4` = `...11111011`，把第 3 位**清零**：`1011 & 1011 = 1011` = 11（原来就是 0，没变化） |

⚠ 第 4 行容易答 7（以为 `&` 就是相减）。正确理解是：**`x & ~4` 只把第 3 位清掉，别的位原样保留**。这里 `x` 的第 3 位本来就是 0，所以结果还是 11。

📌 三句口诀对应三个技巧：**「与 0 清零、或 1 置位、异或两次还原」**。
```

**3. 易错清单**

⚠ 把 `&` 和 `&&` 混用。`4 & 2` = **0**，`4 && 2` = **1**，结果完全不同。

⚠ `~5` 答成 2。`~` 是**按位**取反（作用于 32 位），不是「用 1 减」。正确答案是 **-6**（速算 `~n = -(n+1)`）。

⚠ `13 >> 2` 答成 3.25。移位是**整数**运算，13 ÷ 4 = **3**。

⚠ 纠结负数移位。考试只考正数或无符号数；碰到 `~n` 就用 `-(n+1)` 速算。

⚠ `1 << 3` 答成 6（误以为乘 3）。左移 **3 位**是乘 2³ = 8，不是乘 3。

💡 口诀：**「与或异或逐位算，取反加一是负数；左移乘、右移除，二的幂次别数错」**。
