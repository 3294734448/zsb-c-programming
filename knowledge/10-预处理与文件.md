## 10.1 宏定义 ★★★

★ 考点：`#define` 是**预处理命令**，在编译之前由预处理器做**纯文本替换**；宏定义**末尾不加分号**；带参数的宏，**每个参数和整体都要加括号**。

**1. 无参宏**

```c
#define PI 3.14159
```

- 预处理阶段：把源程序中出现的**所有** `PI` 原样换成 `3.14159`。替换发生在**编译之前**，所以**不占运行时间**（运行时根本没有"调用"这个动作）。
- **行尾不加分号**。如果手滑写了分号，分号也会一起进入替换结果：

✘ 错误写法（编译错误）：

```c
#define PI 3.14159;        /* 多了分号 */
...
s = PI * r * r;            /* 展开后变成 s = 3.14159; * r * r;  语法错误 */
```

✔ 正确写法：`#define PI 3.14159`

- 宏名习惯全部大写，用来和变量区分。
- 宏替换**不做类型检查、不做任何计算**，只换字。
- 宏定义不是 C 语句，可以写在程序的任何位置（一般写在文件开头、`#include` 之后）。

**例题 1**（无参宏被替换后正常参与运算）

```c-run
#include <stdio.h>
#define PI 3.14159
int main(void) {
    double r = 3.0;
    printf("%.2f\n", PI * r * r);
    printf("%.2f\n", 2 * PI * r);
    return 0;
}
```

```text
28.27
18.85
```

```answer 运行结果与追踪
输出 `28.27` 和 `18.85`。

- 预处理之后，程序其实长这样：`printf("%.2f\n", 3.14159 * r * r);` 和 `printf("%.2f\n", 2 * 3.14159 * r);`
- 第一行：3.14159 × 3.0 × 3.0 = 28.27431 → `%.2f` 保留两位 → `28.27`
- 第二行：2 × 3.14159 × 3.0 = 18.84954 → `%.2f` → `18.85`

⚠ 注意 `%f` 默认输出 6 位小数，`%.2f` 才是两位小数，这在填空里经常考。
```

**2. 带参宏与括号陷阱**

带参宏的形式是 `#define 宏名(参数表) 字符串`。注意：**宏名和左括号之间不能有空格**，否则 `(参数表)` 会被当成宏体的一部分。

```c
#define S(a,b) a*b
```

看起来 `S(1+2, 3+4)` 应该算 (1+2)×(3+4)=21，实际展开是：

```
S(1+2, 3+4)  →  1+2*3+4  →  1+6+4  →  11
```

因为宏只是**把参数原样抄进去**，抄进去以后**再按 C 的优先级算**。乘号先算，所以是 11 不是 21。

✔ 正确写法（每个参数加括号，整体再加一层括号）：

```c
#define S(a,b) ((a)*(b))
```

展开：`((1+2)*(3+4))` → `21`。

**例题 2**（同一个计算，错宏和正宏的结果对比）

```c-run
#include <stdio.h>
#define S(a,b) a*b
#define S2(a,b) ((a)*(b))
#define SQ(n) n*n
#define SQ2(n) ((n)*(n))
int main(void) {
    printf("%d\n", S(1+2, 3+4));
    printf("%d\n", S2(1+2, 3+4));
    printf("%d\n", SQ(2+1));
    printf("%d\n", SQ2(2+1));
    printf("%d\n", 100 / SQ(2));
    printf("%d\n", 100 / SQ2(2));
    return 0;
}
```

```text
11
21
5
9
100
25
```

```answer 运行结果与追踪
六行输出依次是 `11 21 5 9 100 25`。逐条展开：

| 语句 | 展开后 | 计算 | 结果 |
|------|--------|------|:---:|
| `S(1+2, 3+4)` | `1+2*3+4` | 1+6+4 | 11 |
| `S2(1+2, 3+4)` | `((1+2)*(3+4))` | 3×7 | 21 |
| `SQ(2+1)` | `2+1*2+1` | 2+2+1 | 5 |
| `SQ2(2+1)` | `((2+1)*(2+1))` | 3×3 | 9 |
| `100 / SQ(2)` | `100 / 2*2` | 先算 100/2=50，再 ×2 | 100 |
| `100 / SQ2(2)` | `100 / ((2)*(2))` | 100/4 | 25 |

⚠ 最后两行最能说明问题：不加括号时 `100/SQ(2)` 得到 100（相当于 `100/2*2`），加了括号才得到正确的 25。所以带参宏的规矩是：**参数加括号、整体再加一层括号**。
```

**3. 宏与函数的区别**（表格必背）

| 比较项 | 带参宏 | 函数 |
|--------|--------|------|
| 处理时机 | **预处理阶段**（编译之前） | **运行阶段**（程序执行时） |
| 本质 | 文本替换 | 函数调用（传参、跳转、返回） |
| 类型检查 | 不做 | 做，形参有确定类型 |
| 参数类型要求 | 无，什么类型都能传 | 必须类型匹配（或能隐式转换） |
| 运行开销 | 无（不占运行时间） | 有调用开销（压栈、跳转、返回） |
| 代码体积 | 每用一次就展开一份，代码变长 | 只有一份，代码短 |
| 副作用 | 参数被**多次求值**，`SQ(i++)` 会自增两次 | 参数只求值一次 |
| 定义位置 | 一般写在文件开头 | 任意位置，但必须先声明后使用 |
| 行尾 | **不加分号** | 函数体内的语句要加分号 |

⚠ 关于副作用：`#define SQ(n) ((n)*(n))` 遇到 `SQ(i++)` 会展开成 `((i++)*(i++))`，同一个变量在一条表达式里被修改两次，结果**不确定**，考场和实际写代码都要避开。函数 `f(i++)` 只自增一次。

**例题 3**（程序阅读：宏是"层层替换"，不是"先算再替换"）

```c-run
#include <stdio.h>
#define A 3
#define B A+2
#define C B*A
int main(void) {
    printf("%d\n", C);
    return 0;
}
```

```text
9
```

```answer 运行结果与追踪
输出 `9`，不是 15。

追踪替换过程（每一步都只换字，不算数）：

1. `C` → `B*A`
2. `B*A` 里的 `B` → `A+2`，得到 `A+2*A`
3. 再把两个 `A` 换成 `3`，得到 `3+2*3`
4. **最后才按优先级计算**：3 + 6 = 9

⚠ 最容易错的想法是"B 先算出来等于 5，再 5×3=15"。宏不做计算，只换字，所以是 9。
```

**4. `#undef` 取消宏定义**

```c
#undef 宏名
```

- 作用：取消前面定义过的宏。取消以后，这个名字就是普通标识符了。
- 典型小题：`#undef N` 之后再写 `N`，编译器不认识它 → **编译错误（未定义的标识符）**。

✘ 错误写法（编译错误）：

```c
#include <stdio.h>
#define N 10
int main(void) {
    printf("%d\n", N);
#undef N
    printf("%d\n", N);     /* N 已经被取消，编译报错：N 未定义 */
    return 0;
}
```

**例题 4**（先 `#undef` 再重新 `#define`，宏可以换一个值继续用）

```c-run
#include <stdio.h>
#define N 10
int main(void) {
    int a[N];
    int i, s = 0;
    for (i = 0; i < N; i++) a[i] = i + 1;
#undef N
#define N 5
    for (i = 0; i < N; i++) s += a[i];
    printf("%d\n", s);
    return 0;
}
```

```text
15
```

```answer 运行结果与追踪
输出 `15`。

1. `#define N 10` 时，`int a[N];` 展开成 `int a[10];`，循环把 a[0]~a[9] 赋成 1~10。
2. `#undef N` 取消 10，紧跟 `#define N 5` 重新定义成 5。
3. 第二个循环 `for (i = 0; i < N; i++)` 展开成 `for (i = 0; i < 5; i++)`，累加 a[0]~a[4] = 1+2+3+4+5 = **15**。

📌 想用同名宏换个值，必须**先 `#undef` 再 `#define`**，直接重定义会报"宏重定义"警告或错误。
```

**5. 预处理命令以 `#` 开头**（2025 真题原题）

★ 2025 真题（填空题第 11 题）：C 语言中编译预处理命令以 ______ 开头。

**答案：`#`（井号）。** 解析原文：C 语言中，预处理命令都以 `#` 开头。

- 常见预处理命令：`#include`、`#define`、`#undef`、`#ifdef`、`#ifndef`、`#endif`、`#if`、`#else`、`#elif`。
- 预处理命令**单独占一行**，**行尾不加分号**。
- 预处理在**编译之前**完成，预处理之后 `#` 开头的行就都消失了。

**例题 5**（程序阅读：宏 + 循环，考"展开后算"）

```c-run
#include <stdio.h>
#define N 4
#define SQR(x) ((x)*(x))
int main(void) {
    int i, s = 0;
    for (i = 1; i <= N; i++) s += SQR(i);
    printf("%d\n", s);
    return 0;
}
```

```text
30
```

```answer 运行结果与追踪
输出 `30`。

展开后：`for (i = 1; i <= 4; i++) s += ((i)*(i));`

| i | ((i)*(i)) | s |
|:-:|:---------:|:-:|
| 1 | 1 | 1 |
| 2 | 4 | 5 |
| 3 | 9 | 14 |
| 4 | 16 | 30 |

结论：1+4+9+16 = **30**。
```

**6. 易错清单**

⚠ `#define` 行尾加分号 → 展开后多一个分号 → 编译错误（这是最高频的错）。

⚠ 带参宏不加括号 → 结果错但**能编译**，属于"运行结果错"，比编译错误更危险。

⚠ 带参宏名和左括号之间**不能有空格**：`#define S (a,b) a*b` 会被理解成"把 `S` 定义成 `(a,b) a*b`"，根本不是带参宏。

⚠ 宏不做类型检查，也不做计算。看到嵌套宏就先**一层层展开成一行**，最后一步才算。

⚠ `#define` 不是语句，后面**没有分号**；`#undef` 同样没有分号。

💡 口诀：**宏是换字不是算，末尾无分号，参数整体双括号，嵌套先展开再计算。**

## 10.2 文件包含 ★★

★ 考点：`#include <文件名>` 从系统目录找，`#include "文件名"` 先找当前目录；**一个 `#include` 只能包含一个文件**；头文件里一般放**声明**。

**1. 两种写法的区别（必背表）**

| 写法 | 查找顺序 | 用在哪 |
|------|----------|--------|
| `#include <stdio.h>` | 只到**系统目录**（编译器的 include 目录）找 | 包含系统提供的标准头文件 |
| `#include "my.h"` | **先到当前源文件所在目录**找，找不到再到系统目录找 | 包含自己写的头文件 |

📌 考试常考句式："`#include <stdio.h>` 中的尖括号表示到系统目录中查找"。自己写的头文件用双引号，也能用尖括号，只是找不到自己目录里的文件。

**2. 三条硬规则**

- **一个 `#include` 命令只能包含一个文件**，不能写成 `#include <stdio.h> <math.h>`。
- 文件包含也是**预处理阶段**完成的：把被包含文件的全部内容**原样插入**到 `#include` 那一行的位置。所以 `#include` 行尾也**不加分号**。
- 头文件里一般放：**函数声明、宏定义、结构体类型定义、全局变量声明（extern）**。函数定义一般不往头文件里放，因为被多个源文件包含时会重复定义。

**3. 常用头文件与对应函数（必背表）**

| 头文件 | 主要提供 | 常用函数 |
|--------|----------|----------|
| `stdio.h` | 输入输出 | `printf`、`scanf`、`putchar`、`getchar`、`puts`、`gets`、`fopen`、`fclose`、`fgetc`、`fputc`、`fgets`、`fputs`、`fread`、`fwrite`、`fprintf`、`fscanf`、`feof` |
| `string.h` | **字符串处理** | `strlen`、`strcpy`、`strcat`、`strcmp`、`strlwr`、`strupr`、`strstr` |
| `math.h` | 数学函数 | `sqrt`、`fabs`、`pow`、`exp`、`log`、`sin`、`cos` |
| `stdlib.h` | 通用工具 | `malloc`、`free`、`abs`、`atoi`、`atof`、`rand`、`srand`、`exit` |

★ 2025 真题（填空题第 19 题）：C 语言的标准函数中，字符串的处理函数包含在 ______ 头文件中。

**答案：`string.h`。** 解析原文：C 语言中，字符串的处理函数包含在 `string.h` 头文件中。

⚠ 最容易混的两个：`strlen`/`strcpy`/`strcat`/`strcmp` 在 **`string.h`**；`sqrt`/`fabs`/`pow` 在 **`math.h`**。做题时先看函数名：`str` 开头的一律 `string.h`。

**例题 1**（`string.h` 里的函数怎么用）

```c-run
#include <stdio.h>
#include <string.h>
int main(void) {
    char s1[20] = "abc";
    char s2[] = "de";
    printf("%d\n", (int)strlen(s1));
    strcat(s1, s2);
    printf("%s\n", s1);
    printf("%d\n", (int)strlen(s1));
    printf("%d\n", strcmp("abc", "abd") < 0);
    return 0;
}
```

```text
3
abcde
5
1
```

```answer 运行结果与追踪
输出四行：`3`、`abcde`、`5`、`1`。

1. `strlen(s1)`：`s1` 是 `"abc"`，长度 3（**不含**结尾的 `'\0'`）。
2. `strcat(s1, s2)`：把 `s2` 接到 `s1` 后面，`s1` 变成 `"abcde"`。注意 `strcat` 的**第一个参数必须是字符数组**（有足够空间），不能是字符串常量。
3. 再求长度 = 5。
4. `strcmp("abc","abd")` 比较到第 3 个字符时 `'c' < 'd'`，返回**负数**；这里只判断"是不是小于 0"，所以输出 1。

📌 `strcmp` 的返回值只保证"负数 / 0 / 正数"三种情况，**具体数值由编译系统决定**，考试里不要去背"-1"或"1"。
```

**例题 2**（`math.h` 里的函数）

```c-run
#include <stdio.h>
#include <math.h>
int main(void) {
    printf("%.2f\n", sqrt(16.0));
    printf("%.2f\n", fabs(-3.5));
    return 0;
}
```

```text
4.00
3.50
```

```answer 运行结果与追踪
输出 `4.00` 和 `3.50`。

- `sqrt(16.0)` 求平方根 = 4.0，用 `%.2f` 输出成 `4.00`。
- `fabs(-3.5)` 求浮点数的绝对值 = 3.5，输出 `3.50`。
- 两个函数都在 `math.h` 中声明。**少了 `#include <math.h>` 会报"函数未声明"的警告/错误。**

⚠ 区分：`abs()` 在 `stdlib.h`，求**整数**绝对值；`fabs()` 在 `math.h`，求**浮点数**绝对值。
```

**4. 易错清单**

⚠ `#include` 行尾加分号 → 多了个分号，虽然多数编译器只是警告，但严格来说是错误写法。

⚠ 一个 `#include` 只能带一个文件：✘ `#include <stdio.h> <string.h>`。

⚠ "文件包含在预处理阶段完成"是填空题常考结论：`#include` 不是函数调用，不占运行时间。

⚠ 双引号和尖括号的区别是**查找顺序**，不是"能不能用"。

💡 口诀：**尖括号找系统，双引号先找自己；一行只包一个文件；str 开头找 string.h。**

## 10.3 条件编译 ★

★ 考点：条件编译让预处理器**按条件决定哪段代码参与编译**，不参与编译的代码等于不存在。三种形式：`#ifdef`、`#ifndef`、`#if`，最后都必须用 `#endif` 收尾。

**1. 三种基本形式**

形式一：`#ifdef`（如果定义过）

```c
#ifdef 标识符
    程序段1
#else
    程序段2
#endif
```

标识符**被 `#define` 定义过**就编译程序段1，否则编译程序段2。`#else` 部分可以省略。

形式二：`#ifndef`（如果没定义过）—— 与 `#ifdef` 正好相反。

这是**防止头文件被重复包含**的经典写法：

```c
#ifndef MY_H
#define MY_H
    ...头文件内容...
#endif
```

第一次包含 `MY_H` 时它还没被定义 → 进入 → 顺手把它定义掉；第二次再包含时它已定义 → 整段跳过，避免"重复定义"。

形式三：`#if 常量表达式`

```c
#if 常量表达式1
    程序段1
#elif 常量表达式2
    程序段2
#else
    程序段3
#endif
```

**2. 例题**（条件编译 + `#if` 的经典陷阱）

```c-run
#include <stdio.h>
#define VERSION 2
int main(void) {
    int a = 7, b = 5;
#ifdef VERSION
    printf("with version\n");
#else
    printf("without version\n");
#endif
#if VERSION >= 2
    printf("new mode\n");
#else
    printf("old mode\n");
#endif
#if a > b
    printf("a bigger\n");
#else
    printf("b bigger\n");
#endif
    printf("a+b=%d\n", a + b);
    return 0;
}
```

```text
with version
new mode
b bigger
a+b=12
```

```answer 运行结果与追踪
四行输出：`with version`、`new mode`、`b bigger`、`a+b=12`。

| 条件 | 判断过程 | 结果 |
|------|----------|------|
| `#ifdef VERSION` | `VERSION` 被 `#define` 过 → 成立 | 输出 with version |
| `#if VERSION >= 2` | 预处理器把 `VERSION` 换成 2，2>=2 成立 | 输出 new mode |
| `#if a > b` | **`a`、`b` 是变量不是宏**，预处理器把它们都当成 **0** → `0 > 0` 不成立 | 走 `#else`，输出 b bigger |
| `printf("a+b=%d\n", a + b)` | 普通语句，7+5 | 输出 a+b=12 |

⚠ 最关键的一条：**`#if` 只能判断宏，不能判断变量**。`a` 明明是 7、`b` 明明是 5，但预处理器在编译之前根本不知道有这两个变量，一律当 0。所以判断变量大小必须写 `if (a > b)`，不能写 `#if a > b`。
```

**3. 条件编译的三种典型用途**

| 用途 | 写法 |
|------|------|
| 防止头文件重复包含 | `#ifndef ... #define ... #endif` |
| 调试信息开关 | `#ifdef DEBUG printf(...); #endif` |
| 多版本 / 跨平台选择 | `#if 版本号 ... #elif ... #else ... #endif` |

**4. 易错清单**

⚠ 忘记写 `#endif` → 编译报错"未终止的条件编译"。

⚠ `#if` 后面的标识符没定义时按 0 处理，这在选择题里经常变成"看起来该输出 A，实际输出 B"的坑。

⚠ `#ifdef X` 判断的是"X 有没有被 `#define` 过"，**和 X 的值是多少无关**。`#define X 0` 之后 `#ifdef X` 依然成立（因为定义过），但 `#if X` 是假。

💡 口诀：**ifdef 看有没有定义，ifndef 反过来，if 后面只认宏，变量一律当 0 算，最后别忘 endif。**

## 10.4 文件的基本概念与文件指针 ★★

★ 考点：C 语言把文件看作**字符流**；`FILE *fp;` 是文件指针；`fopen` 失败返回 `NULL`，打开文件**必须判断是否成功**。

**1. 文件是什么**

- 文件是存储在**外部介质**（磁盘等）上的**相关数据的集合**。
- C 语言把文件当作**字符流（字节流）**处理：不管是读还是写，都看成"一串字符/字节按顺序流动"，程序不需要关心它具体存在哪种设备上。
- 程序使用文件的标准三步：**打开 → 读写 → 关闭**。

**2. 文本文件与二进制文件**

| 比较项 | 文本文件（ASCII 文件） | 二进制文件 |
|--------|------------------------|------------|
| 存储方式 | 每个字符存它的 **ASCII 码** | 数据在内存中的**二进制形式原样**存储 |
| 整数 12345 | 占 5 个字节：`'1''2''3''4''5'` | 占 `sizeof(int)` = 4 个字节 |
| 记事本能看懂吗 | 能看懂 | 看不懂（乱码） |
| 空间与效率 | 占空间多、转换费时间 | 省空间、读写快 |
| 换行处理 | Windows 下 `'\n'` 实际写成 CR+LF 两个字节 | 原样写入，不做转换 |
| 打开方式 | 不加 `b`：`"r"`、`"w"` | 加 `b`：`"rb"`、`"wb"` |
| 常用函数 | `fgetc`/`fputc`/`fgets`/`fputs`/`fprintf`/`fscanf` | `fread`/`fwrite` |

**3. 文件指针**

```c
FILE *fp;
```

- `FILE` 是系统在 `stdio.h` 里定义好的**结构体类型**，里面装着文件号、缓冲区位置、当前读写位置等信息。
- `FILE *fp;` 定义的是一个**指向 FILE 类型结构体的指针变量**，习惯叫"文件指针"。
- 之后所有文件操作都用 `fp` 指明"操作哪个文件"。

**4. 打开文件必须判断是否成功**

`fopen` 成功返回文件指针，**失败返回 `NULL`**。标准写法：

```c
FILE *fp;
fp = fopen("data.txt", "r");
if (fp == NULL) {
    printf("open failed\n");
    return 1;
}
```

⚠ 不判断的后果：文件不存在时 `fp` 是 `NULL`，接着用 `fgetc(fp)` 之类的函数会**程序崩溃**。程序填空题最爱在这里挖空。

⚠ 易错：`if (fp = NULL)` 是**赋值**（条件永远为假，还破坏了 fp）；判断必须用 `==`。

**5. 例题**（程序填空）

下面程序要打开当前目录下的 `data.txt` 读取内容，请补全空缺。

```c
#include <stdio.h>
int main(void)
{
    FILE *fp;
    char ch;
    fp = fopen("data.txt", "r");
    if (__________) {
        printf("open failed\n");
        return 1;
    }
    while ((ch = fgetc(fp)) != EOF)
        putchar(ch);
    __________;
    return 0;
}
```

```answer 参考答案
第一空：`fp == NULL`
第二空：`fclose(fp);`

- `fopen` 失败时返回 `NULL`，所以判断"打开失败"要写 `fp == NULL`（或 `!fp`）。
- 文件用完必须关闭，关闭函数是 `fclose(文件指针)`。
```

💡 口诀：**文件是字符流；FILE * 是把手；失败给 NULL，用前先判空；用完 fclose。**

## 10.5 文件的打开与关闭 ★★★

★ 考点：`fopen(文件名, 使用方式)` 六种方式的含义；路径里的反斜杠要写成 `\\`；`fclose(fp);` 关闭文件，以及"为什么必须关"。

**1. fopen 的函数形式**

```c
FILE *fopen(char *文件名, char *使用方式);
```

- 两个参数都是**字符串**（要加双引号）：第一个是文件名（可带路径），第二个是使用方式。
- 返回值：成功 → 文件指针；失败 → `NULL`。

**2. 六种使用方式（必背表）**

| 使用方式 | 含义 | 文件不存在时 | 文件已存在时 | 能读 | 能写 |
|:---:|------|------|------|:---:|:---:|
| `"r"` | 只读打开文本文件 | **出错，返回 NULL** | 正常打开 | ✔ | ✘ |
| `"w"` | 只写打开文本文件 | 建立新文件 | **把原内容全部清空** | ✘ | ✔ |
| `"a"` | 追加打开文本文件 | 建立新文件 | 在**末尾追加**，原内容保留 | ✘ | ✔ |
| `"r+"` | 读写打开文本文件 | 出错，返回 NULL | 正常打开 | ✔ | ✔ |
| `"w+"` | 读写打开文本文件 | 建立新文件 | **清空**原内容 | ✔ | ✔ |
| `"a+"` | 读写打开文本文件 | 建立新文件 | 末尾追加，原内容保留 | ✔ | ✔ |

- 加 `b` 表示二进制：`"rb"`、`"wb"`、`"ab"`、`"r+b"`（也可写 `"rb+"`）。
- 三个记忆抓手：**`r` 要求文件必须存在；`w` 一打开就清空；`a` 只在末尾追加。**

⚠ 最高频陷阱：用 `"w"` 打开一个已存在的文件，**原有内容全部丢失**。想保留原内容再写，必须用 `"a"`。

**例题 1**（选择使用方式）

程序要把一批新成绩**追加**到已存在的 `score.txt` 末尾，且不能破坏原有数据，`fopen` 的第二个参数应该是（  ）。
A. `"r"`　B. `"w"`　C. `"a"`　D. `"r+"`

```answer 参考答案
选 **C. `"a"`**。

- `"r"`：只能读，不能写。
- `"w"`：会先把 `score.txt` 的原有内容**清空**，不符合"不能破坏原有数据"。
- `"a"`：在文件末尾追加，原有内容保留 ✔
- `"r+"`：能读能写，但写入位置从文件**开头**开始，会覆盖原数据。
```

**3. 路径中的反斜杠要写两个 `\\`**（2025 真题原题）

★ 2025 真题（单项选择题第 10 题）：打开 d 盘下 hhh 目录下二进制文件 tt.bin，在调用函数 fopen 时，第一个参数的正确格式是（  ）。
A. `"d:hhhtt.bin"`
B. `"d:\hhh\\t.bin"`
C. `"d:\\hhh\\tt.bin"`
D. `"d:hhh\tt.bin"`

**答案：C。** 解析原文：C 语言中，字符串中的反斜杠 `\` 是转义字符，所以在表示路径时，需要用双反斜杠 `\\` 来表示一个反斜杠。

四个选项逐个看：

| 选项 | 写法 | 问题在哪 |
|:---:|------|----------|
| A | `"d:hhhtt.bin"` | 目录分隔符一个都没写，盘符和目录粘成一片，找不到文件 |
| B | `"d:\hhh\\t.bin"` | 第一个 `\h` 不是合法转义字符；而且文件名变成了 `t.bin`（少一个 t） |
| C | `"d:\\hhh\\tt.bin"` | ✔ `\\` 表示一个反斜杠，实际路径是 `d:\hhh\tt.bin`，正确 |
| D | `"d:hhh\tt.bin"` | 少了目录分隔符，且 `\t` 是**制表符**，路径变成 `d:hhh` + 制表符 + `t.bin` |

★ 必背转义字符表：

| 转义字符 | 含义 | ASCII 值 |
|:---:|------|:---:|
| `\n` | 换行 | 10 |
| `\t` | 制表符（Tab） | 9 |
| `\r` | 回车 | 13 |
| `\0` | 空字符（字符串结束标志） | 0 |
| `\\` | 一个反斜杠 | 92 |
| `\'` | 一个单引号 | 39 |
| `\"` | 一个双引号 | 34 |
| `\b` | 退格 | 8 |

📌 一句话记死：**要表示一个反斜杠，必须写两个。** 所以磁盘上的路径 `d:\hhh\tt.bin`，在 C 语言里要写成 `"d:\\hhh\\tt.bin"`。

✔ 另一种同样正确的写法是用**正斜杠**：`"d:/hhh/tt.bin"`。C 语言在 Windows 下也认正斜杠，只是标准答案给的是双反斜杠。

**4. fclose 关闭文件**（2025 真题原题）

```c
fclose(fp);
```

★ 2025 真题（填空题第 18 题）：将文件指针 fp 所指向的文件关闭的语句是 ______。

**答案：`fclose(fp);`** 解析原文：关闭文件使用函数 `fclose(文件指针)`。

**文件用完必须关闭的三个原因**（简答、填空都可能考）：

1. **防止数据丢失**：写文件时数据先进内存缓冲区，缓冲区满才真正写盘。`fclose` 会把缓冲区里剩下的数据**强制写回磁盘**；不关闭，最后一批数据可能还在内存里就丢了。
2. **释放资源**：关闭时释放文件结构体和缓冲区占用的内存。
3. **解除占用**：系统能同时打开的文件个数有限，不关闭会耗尽句柄，别的程序也可能打不开这个文件。

📌 补充：`fclose` 成功返回 0，失败返回非 0。

**5. 易错清单**

⚠ `fopen` 的两个参数都是**字符串**，都要双引号：`fopen("a.txt", "r")`。

⚠ 忘记判断 `fp == NULL` —— 程序填空题的高频空格。

⚠ `"w"` 会清空原文件内容 —— 选择题最爱考这个。

⚠ 路径里的 `\` 要写 `\\`；`\t` 会被当成制表符。

⚠ `fclose` 的参数是**文件指针**，不是文件名：✘ `fclose("a.txt")`；✔ `fclose(fp);`

💡 口诀：**r 要存在，w 清空，a 追加，加 b 是二进制；路径反斜杠写两个；用完必须 fclose。**

## 10.6 文件的读写函数 ★★

★ 考点：`fputc`/`fgetc`、`fputs`/`fgets`、`fprintf`/`fscanf`、`fread`/`fwrite` 的用法与**返回值**；判断文件结束用 `feof(fp)` 或判断返回值是否为 `EOF`。

**1. 读写函数速查表（必背）**

| 函数 | 功能 | 返回值 | 要点 |
|------|------|--------|------|
| `fputc(ch, fp)` | 写一个字符 | 成功返回写入的字符，失败返回 `EOF` | 等价于 `putc` |
| `fgetc(fp)` | 读一个字符 | 成功返回读到的字符，**到文件尾或出错返回 `EOF`** | 等价于 `getc` |
| `fputs(s, fp)` | 写一个字符串 | 成功返回非负值，失败返回 `EOF` | **不会自动换行** |
| `fgets(s, n, fp)` | 读最多 n-1 个字符（或一整行） | 成功返回 `s`，失败或文件尾返回 **`NULL`** | 读入的 `'\n'` 会保留在 s 中 |
| `fprintf(fp, 格式, ...)` | 按格式写文件 | 成功返回写入的字符数 | 用法同 `printf`，只多一个 `fp` |
| `fscanf(fp, 格式, ...)` | 按格式从文件读 | 成功返回**读入的项数**，失败返回 `EOF` | 用法同 `scanf`，只多一个 `fp` |
| `fread(p, size, n, fp)` | 读数据块（二进制） | 返回**实际读到的项数** | 参数：地址、每项字节数、项数、文件指针 |
| `fwrite(p, size, n, fp)` | 写数据块（二进制） | 返回**实际写入的项数** | 同上 |

📌 `EOF` 是 `stdio.h` 里定义的符号常量，值是 **-1**，表示"文件结束"。

**2. 判断文件结束的两种写法**

✔ 推荐写法（判断 `fgetc` 的返回值）：

```c
while ((ch = fgetc(fp)) != EOF) {
    ...处理 ch...
}
```

另一种写法（用 `feof`）：

```c
while (!feof(fp)) {
    ch = fgetc(fp);
    ...处理 ch...
}
```

⚠ `feof(fp)` 是**事后判断**：只有**读操作已经失败之后**它才返回真。所以上面这种写法会在文件末尾**多处理一次**（把 `EOF` 当成一个字符）。要理解：`feof` 的含义是"上一次读操作是不是因为到达文件尾而失败"，不是"下一个字符是不是文件尾"。

⚠ `feof(fp)` **返回非 0 表示已到文件末尾**，返回 0 表示没到。判断"没到末尾"要写 `!feof(fp)`。

**3. 完整示例：写文件 + 读文件**

```c
#include <stdio.h>

int main(void)
{
    FILE *fp;
    char ch;
    int n = 0;

    /* 第一步：写文件，用 "w" 方式打开 */
    fp = fopen("demo.txt", "w");
    if (fp == NULL) {
        printf("open failed\n");
        return 1;
    }
    fputs("hello c file\n", fp);              /* 写一个字符串 */
    fputc('A', fp);                           /* 写一个字符 */
    fputc('\n', fp);
    fprintf(fp, "%d %s\n", 2025, "shanxi");   /* 按格式写 */
    fclose(fp);                               /* 写完必须关闭，数据才真正落盘 */

    /* 第二步：读文件，用 "r" 方式打开 */
    fp = fopen("demo.txt", "r");
    if (fp == NULL) {
        printf("open failed\n");
        return 1;
    }
    while ((ch = fgetc(fp)) != EOF) {         /* 读到 EOF 就结束 */
        putchar(ch);                          /* 逐字符输出到屏幕 */
        n++;                                  /* 顺便统计字符个数 */
    }
    fclose(fp);
    printf("count=%d\n", n);
    return 0;
}
```

```answer 运行结果（已在本机实测）
屏幕上先原样显示文件内容，最后输出字符个数：

```text
hello c file
A
2025 shanxi
count=27
```

**为什么是 27 个字符？**

| 写入内容 | 字符数 |
|----------|:---:|
| `"hello c file\n"` | 12 + 1 = 13 |
| `'A'` 和 `'\n'` | 2 |
| `"2025 shanxi\n"` | 11 + 1 = 12 |
| 合计 | **27** |

⚠ 一个有意思的细节：磁盘上 `demo.txt` 的文件大小是 **30** 字节，比 27 多 3 字节。因为 Windows 的文本模式会把 3 个 `'\n'` 各写成 CR+LF 两个字节（多出 3 个 `\r`）；读的时候文本模式又把 CR+LF 还原成一个 `'\n'`，所以 `fgetc` 数出来仍然是 27。这就是"文本文件与二进制文件的区别"在真实程序里的样子。
```

**例题**（`fprintf` 写、`fscanf` 读，注意 `fscanf` 的返回值）

```c
#include <stdio.h>

int main(void)
{
    FILE *fp;
    int i, x, sum = 0;

    fp = fopen("n.txt", "w");
    if (fp == NULL) return 1;
    for (i = 1; i <= 100; i++)
        fprintf(fp, "%d\n", i);          /* 把 1~100 逐行写入文件 */
    fclose(fp);

    fp = fopen("n.txt", "r");
    if (fp == NULL) return 1;
    while (fscanf(fp, "%d", &x) == 1)    /* 读成功一项就返回 1 */
        sum += x;
    fclose(fp);
    printf("%d\n", sum);
    return 0;
}
```

```answer 运行结果与追踪
输出 `5050`。

- `fprintf(fp, "%d\n", i)` 把 1 到 100 依次写进 `n.txt`，每行一个数。
- `fscanf(fp, "%d", &x)` 从文件里读一个整数到 `x`：**读成功返回 1**，到文件末尾返回 `EOF`，所以 `while (fscanf(...) == 1)` 就是"只要能读到一个整数就继续"。
- 累加 1+2+…+100 = **5050**。

📌 记住 `fscanf` 的返回值是**成功读入的项数**，不是读到的数字本身。这是填空和改错题的高频点。
```

**4. 易错清单**

⚠ `fgets` 的第二个参数是**缓冲区大小**，最多读 `n-1` 个字符（留一个位置放 `'\0'`）。

⚠ `fputs` **不会自动换行**，要换行得自己写 `fputs("\n", fp)` 或 `fputc('\n', fp)`。

⚠ `fread`/`fwrite` 的第一个参数是**地址**（数组名或 `&变量`）。

⚠ 判断文件结束**不要用** `while (!feof(fp)) { ch = fgetc(fp); ... }` 直接处理（会多处理一次），要么用 `while ((ch = fgetc(fp)) != EOF)`，要么在循环体里再判断一次。

⚠ `fgetc` 的返回值是 `int` 不是 `char`：要把它和 `EOF`（-1）比较，用 `char` 接可能永远等不到 EOF。

💡 口诀：**写字符 fputc，读字符 fgetc，串用 fputs/fgets，格式化用 fprintf/fscanf，二进制用 fread/fwrite；结束看 EOF 或 feof。**

```

**第 3 题（选择：使用方式判断）**

下列四种需求，`fopen` 的第二个参数应该分别填什么？

1. 打开已存在的 `a.txt` 只读取内容
2. 新建 `b.txt` 并写入，要求原来的内容不要
3. 在已存在的 `c.txt` 末尾接着写
4. 打开二进制文件 `d.dat` 读取

```answer 参考答案
| 需求 | 使用方式 | 理由 |
|------|:---:|------|
| 只读 `a.txt` | `"r"` | 只读；文件不存在会返回 NULL |
| 新建/覆盖 `b.txt` | `"w"` | 文件不存在则新建，存在则**清空**后写 |
| 在 `c.txt` 末尾接着写 | `"a"` | 追加方式，打开后写指针在文件末尾，原内容保留 |
| 读二进制 `d.dat` | `"rb"` | 二进制读要在 `r` 后面加 `b` |
```

**第 4 题（程序填空：路径写法）**

要求用 `fopen` 以二进制只读方式打开 **D 盘 data 目录下的 a.dat**，补全语句。

```c
fp = fopen("__________", "rb");
```

```answer 参考答案
正确写法（两种都对）：

```c
fp = fopen("d:\\data\\a.dat", "rb");
fp = fopen("d:/data/a.dat", "rb");     /* 正斜杠在 Windows 下也认 */
```

⚠ 错误写法及后果：

| 错误写法 | 后果 |
|----------|------|
| `"d:\data\a.dat"` | `\d`、`\a` 不是合法转义字符，路径被破坏 |
| `"d:\data\a.dat"` 中的 `\a` | `\a` 是**响铃符**（ASCII 7），路径彻底错 |
| `"d:dataa.dat"` | 没有目录分隔符，找不到文件 |

📌 记忆：**路径里要一个反斜杠，C 语言里就得写两个。**
```

**第 5 题（改错：`feof` 的典型错用）**

下面的程序想把 `data.txt` 的内容原样输出，请指出错误并改正。

```c
#include <stdio.h>
int main(void)
{
    FILE *fp;
    char ch;
    fp = fopen("data.txt", "r");
    while (!feof(fp)) {
        ch = fgetc(fp);
        putchar(ch);
    }
    fclose(fp);
    return 0;
}
```

```answer 参考答案
**错误**：`feof(fp)` 是"事后判断"——它只有在**读操作已经失败之后**才为真。所以当读指针到达文件末尾时，`feof` 仍返回假，循环体再执行一次 `fgetc`，这次读到的是 `EOF`，而 `EOF` 被当成一个字符 `putchar` 输出，屏幕上会**多出一个乱码字符**（通常是 `ÿ` 或一个怪符号）。另外没有判断 `fp == NULL`。

**正确写法一**（推荐，直接判断返回值）：

```c
#include <stdio.h>
int main(void)
{
    FILE *fp;
    int ch;                            /* 用 int 接 fgetc 的返回值 */
    fp = fopen("data.txt", "r");
    if (fp == NULL) return 1;
    while ((ch = fgetc(fp)) != EOF)
        putchar(ch);
    fclose(fp);
    return 0;
}
```

**正确写法二**（保留 feof，但在循环里再判一次）：

```c
    while (!feof(fp)) {
        ch = fgetc(fp);
        if (ch == EOF) break;          /* 把最后那次假数据挡掉 */
        putchar(ch);
    }
```

⚠ 结论：**判断文件结束优先用"返回值 != EOF"**，`feof` 只适合在读完以后确认"是不是正常读到结尾"。
```

**第 6 题（程序阅读：读文件并分类统计）**

文件 `data.txt` 中存放的内容是：`abc123 XY`（后面跟一个换行符）。下面程序运行后输出什么？

```c
#include <stdio.h>

int main(void)
{
    FILE *fp;
    char ch;
    int letter = 0, digit = 0, other = 0;

    fp = fopen("data.txt", "w");
    if (fp == NULL) return 1;
    fputs("abc123 XY\n", fp);          /* 先造出这个文件 */
    fclose(fp);

    fp = fopen("data.txt", "r");
    if (fp == NULL) return 1;
    while ((ch = fgetc(fp)) != EOF) {
        if ((ch >= 'a' && ch <= 'z') || (ch >= 'A' && ch <= 'Z'))
            letter++;
        else if (ch >= '0' && ch <= '9')
            digit++;
        else
            other++;
    }
    fclose(fp);
    printf("%d %d %d\n", letter, digit, other);
    return 0;
}
```

```answer 运行结果与追踪
输出 `5 3 2`。

`data.txt` 的内容是 10 个字符：`a` `b` `c` `1` `2` `3` ` `（空格）`X` `Y` `\n`

| 字符 | 分类 | 计数 |
|------|------|------|
| a、b、c、X、Y | 字母 | letter = 5 |
| 1、2、3 | 数字字符 | digit = 3 |
| 空格、`\n` | 其他 | other = 2 |

⚠ 两个易错点：① `'X'`、`'Y'` 是大写字母，也在字母范围里（判断条件必须带 `(ch >= 'A' && ch <= 'Z')`）；② **换行符 `'\n'` 也被 `fgetc` 读到了**，算进 other，所以 other 是 2 不是 1。
```

**本节总结：文件部分的考法就这 6 种**

| 考法 | 出现在 | 关键点 |
|------|--------|--------|
| 补全写文件循环 | 程序填空 | `fprintf(fp, ...)`、`fclose(fp);` |
| 补全读文件循环 | 程序填空 | `fgetc(fp) != EOF` |
| 选使用方式 | 单选/填空 | r 要存在、w 清空、a 追加 |
| 写路径 | 单选/填空 | 反斜杠写 `\\` |
| 改 `feof` 错误 | 改错/程序填空 | 优先用返回值判 EOF |
| 读程序说结果 | 程序阅读 | 逐字符追踪，注意 `'\n'` 也占一个字符 |

💡 口诀：**打开判 NULL，写入 fprintf，读出 fgetc，结束比 EOF，收尾 fclose。**
