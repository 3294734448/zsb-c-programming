# 12 · 程序设计专项 ★★★

> 程序设计题是**写代码**的题，占分最重，也是"会了就能稳拿"的题——因为题型高度固定。
> 这一章给你：**万能骨架 → 六类必考题型 → 完整可运行答案 → 失分点清单**。
> ⚠ 所有程序都**必须在电脑上敲一遍并编译运行**，看懂不算会。

## 12.1 答题框架：五步法 ★★★

★ 考点：程序设计题**按步骤给分**，写不出完整答案也要把框架写出来。

| 步骤 | 写什么 | 分值来源 |
|:---:|------|------|
| ① | `#include <stdio.h>` + `int main(void) {` | 基本框架分 |
| ② | **定义变量**（题目要几个就定义几个） | 变量定义分 |
| ③ | **输入**（`scanf` 记得加 `&`） | 输入分 |
| ④ | **核心逻辑**（循环 + 分支，这才是主体） | 主要分值 |
| ⑤ | **输出**（格式要对）+ `return 0;` + `}` | 输出分 |

📌 **考场做法**：

1. 先读题两遍，用笔在题面上圈出**输入是什么、输出是什么**；
2. 把"规则"翻译成 if 分支（分段）或 for 循环（重复）；
3. **先在草稿纸上写循环的边界**（从几到几、要不要等号），这是最容易错的地方；
4. 写完检查三件事：**分号、花括号、`&`**。

## 12.2 万能程序骨架 ★★★

★ 考点：把这四套骨架背下来，考场上直接往上填内容。

```answer 骨架一 · 输入若干个数，逐个处理
```c
#include <stdio.h>
int main(void) {
    int n, i, x, sum = 0;      /* n=个数，i=循环变量，x=每次读入的数，sum=累加结果 */
    scanf("%d", &n);
    for (i = 0; i < n; i++) {
        scanf("%d", &x);
        sum += x;              /* 对 x 做处理：这里是累加，也可换成比较 / 计数 */
    }
    printf("%d\n", sum);
    return 0;
}
```
**适用**：求和、求最值、统计个数、平均数。
```

```answer 骨架二 · 用数组存一批数再处理
```c
#include <stdio.h>
int main(void) {
    int a[100], n, i;
    scanf("%d", &n);
    for (i = 0; i < n; i++) scanf("%d", &a[i]);   /* 输入 */
    for (i = 0; i < n; i++) {                     /* 处理 */ }
    for (i = 0; i < n; i++) printf("%d ", a[i]);  /* 输出 */
    printf("\n");
    return 0;
}
```
**适用**：排序、查找、逆置、去重、输出整个数组。
```

```answer 骨架三 · 分段函数 / 多条件判断
```c
#include <stdio.h>
int main(void) {
    int x, y;
    scanf("%d", &x);
    if (x <= 3)        y = 10;                 /* 第一档 */
    else if (x <= 10)  y = 10 + (x - 3) * 2;   /* 第二档 */
    else               y = 24 + (x - 10) * 3;  /* 第三档 */
    printf("%d\n", y);
    return 0;
}
```
**要点**：`else if` 的**顺序必须从窄到宽**（先写小区间，再写大区间），否则后面的分支永远进不去。
```

```answer 骨架四 · 结构体 + 查找
```c
#include <stdio.h>
struct stu { int id; char name[20]; float score; };   /* 末尾分号！ */
int main(void) {
    struct stu s[100];
    int n, i, key, found = 0;
    scanf("%d", &n);
    for (i = 0; i < n; i++)
        scanf("%d %s %f", &s[i].id, s[i].name, &s[i].score);
    scanf("%d", &key);
    for (i = 0; i < n; i++)
        if (s[i].id == key) { printf("%s %.1f\n", s[i].name, s[i].score); found = 1; break; }
    if (!found) printf("Not exists!\n");
    return 0;
}
```
**要点**：`char` 数组成员**不加 &**，其他成员要加 &；`found` 的判断必须在**循环外**。
```

## 12.3 六类必考题型 ★★★

### 题型一 · 分段计算（分支类）

**典型题**：出租车计费（真题 27）、阶梯电价、分段函数求值、工资个税、快递计费。

**统一套路**：把题目里的"每档规则"写成 `if / else if / else`，**从窄到宽**排序。

```c-run
#include <stdio.h>
int main(void) {
    int x = 12;
    float y;
    if (x < 0)          y = -1;
    else if (x == 0)    y = 0;
    else                y = 1;
    printf("x=%d y=%.0f\n", x, y);
    return 0;
}
```

```text
x=12 y=1
```

```answer 为什么会这样
| 判断 | 结果 | y |
|------|:---:|:---:|
| x < 0 | 12<0 假 | — |
| x == 0 | 假 | — |
| else | 执行 | 1 |

⚠ 边界写法：题目说"超过 3 公里"，就写 `x <= 3` 进第一档（等号给第一档）；
如果写成 `x < 3`，那么正好 3 公里就会掉进第二档，公式算出来还是 10 元（因为 (3-3)*2=0），但**逻辑已经错了**，遇到"超过 3 公里才加价"的题目会判错。
```

---

### 题型二 · 累加累乘（循环类）

**典型题**：1~100 求和、求 n!、求奇偶项和、求斐波那契前 n 项、求 π 近似值。

```c-run
#include <stdio.h>
int main(void) {
    int i, s1 = 0, s2 = 0;
    for (i = 1; i <= 100; i++) {
        if (i % 2 == 0) s2 += i;
        else            s1 += i;
    }
    printf("odd=%d even=%d total=%d\n", s1, s2, s1 + s2);
    return 0;
}
```

```text
odd=2500 even=2550 total=5050
```

```answer 验证方法（把公式背下来对答案）
| 项 | 公式 | 值 |
|------|------|:---:|
| 1~100 之和 | n(n+1)/2 = 100×101/2 | 5050 |
| 奇数和 | 1+3+…+99 = 50² | 2500 |
| 偶数和 | 5050 − 2500 | 2550 |

💡 奇数和公式：前 50 个奇数的和 = 50² = 2500。
⚠ 累加变量**必须初始化为 0**，累乘变量**必须初始化为 1**，这是最常见的 0 分点。
```

---

### 题型三 · 数组统计与排序（数组类）

**典型题**：统计每个数出现的次数（真题 28）、求最大值及其下标、成绩分段统计、排序。

```c-run
#include <stdio.h>
int main(void) {
    int a[8] = {45, 92, 78, 60, 55, 88, 100, 30};
    int i, max = a[0], min = a[0], sum = 0, pass = 0;
    float avg;
    for (i = 0; i < 8; i++) {
        if (a[i] > max) max = a[i];
        if (a[i] < min) min = a[i];
        if (a[i] >= 60) pass++;
        sum += a[i];
    }
    avg = sum / 8.0;
    printf("max=%d min=%d pass=%d avg=%.1f\n", max, min, pass, avg);
    return 0;
}
```

```text
max=100 min=30 pass=5 avg=68.5
```

```answer 运行结果与追踪
| i | a[i] | max | min | pass | sum |
|:---:|:---:|:---:|:---:|:---:|:---:|
| 0 | 45 | 45 | 45 | 0 | 45 |
| 1 | 92 | **92** | 45 | 1 | 137 |
| 2 | 78 | 92 | 45 | 2 | 215 |
| 3 | 60 | 92 | 45 | **3**（60 算及格） | 275 |
| 4 | 55 | 92 | 45 | 3 | 330 |
| 5 | 88 | 92 | 45 | 4 | 418 |
| 6 | 100 | **100** | 45 | 5 | 518 |
| 7 | 30 | 100 | **30** | 5 | 548 |

平均值：548 ÷ 8 = 68.5 —— 注意代码里写的是 `sum / 8.0`，**不能写 `sum / 8`**（整数除法会得到 68）。
及格人数是 **5**（92、78、60、88、100 这 5 个），45、55、30 不及格。

⚠ 三个易错点：
1. `max = a[0]` 初始化，**不能写 `max = 0`**（如果全是负数就错了）；
2. 求平均要写 `8.0` 或 `(float)`；
3. `a[i] >= 60` 中 60 分算及格。
```

### 题型四 · 字符串处理（字符串类）

**典型题**：字符串逆置、大小写转换、统计字母/数字/空格个数、判断回文、删除某字符。

```c-run
#include <stdio.h>
int main(void) {
    char s[] = "Hello World 2026";
    int i, upper = 0, lower = 0, digit = 0, space = 0;
    for (i = 0; s[i] != '\0'; i++) {
        if (s[i] >= 'A' && s[i] <= 'Z') upper++;
        else if (s[i] >= 'a' && s[i] <= 'z') lower++;
        else if (s[i] >= '0' && s[i] <= '9') digit++;
        else if (s[i] == ' ') space++;
    }
    printf("upper=%d lower=%d digit=%d space=%d\n", upper, lower, digit, space);
    return 0;
}
```

```text
upper=2 lower=8 digit=4 space=2
```

```answer 逐个字符数给你看
| 类别 | 有哪些 | 个数 |
|------|------|:---:|
| 大写 | H、W | 2 |
| 小写 | e l l o o r l d | 8 |
| 数字 | 2 0 2 6 | 4 |
| 空格 | 两个空格 | 2 |

💡 四个必背判断式：
- 大写：`c >= 'A' && c <= 'Z'`
- 小写：`c >= 'a' && c <= 'z'`
- 数字：`c >= '0' && c <= '9'`
- 小写转大写：`c = c - 32`

⚠ 循环结束条件用 `s[i] != '\0'`，**不要用固定长度**（除非题目明确给了长度）。
```

### 题型五 · 数位分解与素数（数学类）

**典型题**：水仙花数、素数个数、最大公约数、整数逆序、各位数字之和。

```c-run
#include <stdio.h>
int main(void) {
    int n, a, b, c, count = 0;
    for (n = 100; n <= 999; n++) {
        a = n / 100;          /* 百位 */
        b = n / 10 % 10;      /* 十位 */
        c = n % 10;           /* 个位 */
        if (a * a * a + b * b * b + c * c * c == n) {
            printf("%d ", n);
            count++;
        }
    }
    printf("\ncount=%d\n", count);
    return 0;
}
```

```text
153 370 371 407
count=4
```

```answer 水仙花数的判断与三位数拆解
拆解公式（背下来）：
| 位 | 公式 | 以 n=153 为例 |
|:---:|------|:---:|
| 百位 | `n / 100` | 1 |
| 十位 | `n / 10 % 10` | 5 |
| 个位 | `n % 10` | 3 |

验证 153：1³ + 5³ + 3³ = 1 + 125 + 27 = **153** ✔
100~999 之间共 4 个水仙花数：**153、370、371、407**（背下来，考试直接写答案）。
```

### 题型六 · 结构体查找 / 排序（结构体类）

**典型题**：老师信息查找（真题 29）、学生成绩排序、按条件筛选。

```c-run
#include <stdio.h>
struct stu {
    int id;
    char name[20];
    int score;
};
int main(void) {
    struct stu s[3] = {{101, "Li", 85}, {102, "Wang", 92}, {103, "Zhao", 78}};
    int i, j;
    struct stu t;
    for (i = 0; i < 2; i++)                 /* 按成绩从高到低冒泡排序 */
        for (j = 0; j < 2 - i; j++)
            if (s[j].score < s[j + 1].score) { t = s[j]; s[j] = s[j + 1]; s[j + 1] = t; }
    for (i = 0; i < 3; i++)
        printf("%d %s %d\n", s[i].id, s[i].name, s[i].score);
    return 0;
}
```

```text
102 Wang 92
101 Li 85
103 Zhao 78
```

```answer 结构体排序的关键点
| 关键点 | 说明 |
|------|------|
| 交换整个结构体 | `t = s[j]; s[j] = s[j+1]; s[j+1] = t;` —— 同类型结构体变量**可以整体赋值**，不用逐个成员搬 |
| 比较用成员 | `s[j].score < s[j+1].score`，不能直接比较结构体 |
| 从高到低 | 条件写 `<`（前面的比后面的小就交换） |
| `t` 的类型 | 必须是 `struct stu`，不能是 `int` |
```

## 12.4 程序填空题技巧 ★★★

★ 考点：程序填空 3 题，每题通常 1—2 空，是**性价比最高**的题。

### 三个反推套路

| 套路 | 怎么用 | 例子 |
|:---:|------|------|
| **看输出反推** | 题目给了输出结果，就从输出的形态倒推 | 输出下三角 → 内层条件必是 `j <= i` |
| **看变量名反推** | 变量名就是注释：`s` 是 sum、`cnt` 是 count、`t` 是 temp | 看到 `sum +=` 就知道在累加 |
| **看上下文成对** | 循环、函数调用、字符串操作都有固定搭配 | 看到 `while (s2[j] != '\0')` 就知道要在 s1 里搬字符 |

### 三空练习

```answer 练习 1 · 输出 1 到 n 的阶乘
```c
long f = 1;
int i, n;
scanf("%d", &n);
for (i = 1; ______; i++) {     /* ①  答案：i <= n */
    f = ______;                /* ②  答案：f * i */
    printf("%ld\n", f);
}
```
① 循环边界看"输出 1 到 n" → `i <= n`；② 阶乘要连乘 → `f = f * i`（或写 `f *= i`）。
```

```answer 练习 2 · 统计字符串中数字字符的个数
```c
char s[100];
int i, cnt = 0;
gets(s);
for (i = 0; ______; i++)       /* ①  答案：s[i] != '\0' */
    if (______) cnt++;         /* ②  答案：s[i] >= '0' && s[i] <= '9' */
printf("%d\n", cnt);
```
① 字符串循环的标准结束条件；② 数字字符的两端判断，**必须用 && 连起来**，不能写 `'0' <= s[i] <= '9'`。
```

```answer 练习 3 · 求数组中的最大值
```c
int a[10], i, max;
for (i = 0; i < 10; i++) scanf("%d", &a[i]);
max = ______;                       /* ①  答案：a[0] */
for (i = 1; i < 10; i++)
    if (______) max = a[i];         /* ②  答案：a[i] > max */
printf("%d\n", max);
```
① 最大值**必须初始化为数组的第一个元素**（写 0 在负数数组时就错）；② 比较后更新。
```

📌 填空题的**最后检查**：把答案代回去，**从第一行读到最后一行**，确认逻辑通顺、括号配对、分号齐全。

## 12.5 编程题失分点清单（考前必看）★★★

⚠ 按扣分频率排序，**每一条都是真实考场上扣分的地方**：

| # | 失分点 | 后果 | 正确做法 |
|:---:|------|------|------|
| 1 | `scanf` 漏写 `&` | 程序崩溃（运行错误） | `scanf("%d", &x);` |
| 2 | 数组开小了 | 结果乱/崩溃 | 题目说 100 个就开 `a[100]`，范围 0~15 就开 `cnt[16]` |
| 3 | 循环边界写错 | 少算/多算一个 | 手算验证第 1 次和第 n 次 |
| 4 | 累加变量没初始化 | 结果随机 | `int s = 0;` / `long f = 1;` |
| 5 | 整数除法丢小数 | 平均值差 0.5 | `sum / 8.0` 或 `(float)sum / n` |
| 6 | 用中文标点 | 编译错误 | 分号、逗号、括号、引号全部用英文半角 |
| 7 | 忘记 `#include <stdio.h>` | 编译错误 | 第一行就写 |
| 8 | 结构体定义末尾漏分号 | 编译错误 | `struct stu { ... };` |
| 9 | `if` 后面加分号 | 逻辑全错 | `if (x > 0);` 后面那句永远执行 |
| 10 | `=` 与 `==` 混用 | 逻辑全错 | 判断相等用 `==` |
| 11 | 字符串比较用 `==` | 永远不相等 | 用 `strcmp(s1, s2) == 0` |
| 12 | 输出格式与题目不符 | 扣分 | 严格照题目给的格式（空格、换行、小数点） |
| 13 | 忘了 `return 0;` | 一般不扣分，但要写 | 养成习惯 |
| 14 | 变量未定义就使用 | 编译错误 | 先声明后用（C89 风格更保险） |

💡 **交卷前的 30 秒自检**：数一遍花括号配不配对 → 看一眼每行末尾有没有分号 → 检查所有 `scanf` 有没有 `&`。
