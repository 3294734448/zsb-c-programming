# 04 · 选择结构 ★★★

★ 考点：选择结构是**程序阅读题出现频率最高的一章**。分数拿不到，通常不是不会 `if`，而是被三个陷阱套住：**`=` 写成 `==`**、**不加花括号只控制一条语句**、**`else` 配对错**。

📌 本章的每一道例题都要**自己在纸上推一遍再看答案**，推的时候把每个变量的值写下来。

---

## 4.1 if 语句的三种形式 ★★★

★ 考点：`if` 的控制条件可以是**任意表达式**——C 语言里"**非 0 即真，0 即假**"（2025 真题考点）。

**1. 三种形式**

| 形式 | 语法 | 适用 |
|:---:|------|------|
| 单分支 | `if (表达式) 语句;` | 条件成立才做事 |
| 双分支 | `if (表达式) 语句1; else 语句2;` | 二选一 |
| 多分支 | `if ... else if ... else if ... else ...` | 多区间判断 |

⚠ 语法硬规则：
- `if` 后面的**表达式必须加圆括号**：`if (a > b)` ✔，`if a > b` ✘（编译错误）。
- `if (...)` 后面**不要写分号**：`if (a > b);` 会让 `if` 控制一条空语句，后面的大括号块**无条件执行**。
- `else` 后面**不能**再写表达式。

**2. "非 0 即真"——任何表达式都能当条件**

★ 考点：C 语言没有真正的"布尔类型"（C99 之前），判断条件是"**值是否为 0**"：

| 表达式 | 值 | 当条件时 |
|------|:---:|:---:|
| `5` | 非 0 | **真** |
| `0` | 0 | 假 |
| `-1` | 非 0 | **真**（负数也是真！） |
| `0.0` | 0 | 假 |
| `'A'` | 65 | 真 |
| `'\0'` | 0 | 假 |
| `3 > 2` | 1 | 真 |
| `a = 5` | 5 | **真**（赋值表达式的值是赋进去的值） |

```c-run
#include <stdio.h>
int main(void) {
    int x = 0;
    if (x) printf("T\n");
    else printf("F\n");
    x = -1;
    if (x) printf("T\n");
    else printf("F\n");
    if (0.0) printf("T\n");
    else printf("F\n");
    if ('\0') printf("T\n");
    else printf("F\n");
    return 0;
}
```

```text
F
T
F
F
```

```answer 运行结果与追踪
| 语句 | 条件表达式的值 | 真假 | 输出 |
|------|:---:|:---:|:---:|
| `if (x)`，x=0 | 0 | 假 | `F` |
| `if (x)`，x=-1 | -1 | **真** | `T` |
| `if (0.0)` | 0.0 | 假 | `F` |
| `if ('\0')` | 0 | 假 | `F` |

⚠ 最容易错的一行是第二个：**`-1` 是真**！很多人以为"只有 1 才是真"。
💡 记住：**只有 0 是假，其它一切都是真**（包括负数、小数、字符）。
```

**3. 陷阱一：`=` 与 `==`**

⚠ 易错：`if (a == b)` 是判断相等；写成 `if (a = b)` 是**赋值**，表达式的值就是 `b` 的值，只要 `b` 非 0 就永远为真。

```c-run
#include <stdio.h>
int main(void) {
    int a = 5, b = 3;
    if (a = b) printf("a==b\n");
    printf("a=%d b=%d\n", a, b);
    if (a == 0) printf("zero\n");
    else printf("not zero\n");
    return 0;
}
```

```text
a==b
a=3 b=3
not zero
```

```answer 运行结果与追踪
| 语句 | 动作 | a | b |
|------|------|:---:|:---:|
| `int a=5, b=3;` | 初始化 | 5 | 3 |
| `if (a = b)` | **把 b 的值赋给 a**，表达式值是 3（非 0 → 真） | **3** | 3 |
| `printf("a==b\n");` | 条件为真，执行 | 3 | 3 |
| `printf("a=%d b=%d\n")` | 输出 | 输出 `a=3 b=3` | |
| `if (a == 0)` | a 是 3，不等于 0 → 假 | 3 | 3 |
| `else printf("not zero\n");` | 走 else | 输出 `not zero` | |

⚠ 关键错误点：
1. `if (a = b)` **不报错、不警告**，但把 `a` 的值改掉了（5 → 3）。
2. 条件用的是**赋值后的值**，所以永远等于 `b`，只要 `b` 不是 0 就一定进 if。

💡 防错写法：把常量写在左边 `if (3 == b)`，这样漏写一个 `=` 变成 `if (3 = b)` 会直接**编译报错**，错误提前暴露。
```

**4. 陷阱二：不加花括号，`if` 只控制一条语句**

⚠ 易错：`if (...)` 后面不加 `{ }` 时，只有**紧跟着的那一条语句**受它控制，第二条语句**无条件执行**。

```c-run
#include <stdio.h>
int main(void) {
    int a = 1, b = 2, t;
    if (a < b) { t = a; a = b; b = t; }
    printf("a=%d b=%d\n", a, b);
    if (a < b)
        t = a; a = b; b = t;
    printf("a=%d b=%d\n", a, b);
    return 0;
}
```

```text
a=2 b=1
a=1 b=1
```

```answer 运行结果与追踪
**第一段（有花括号）**：

| 语句 | a | b | t |
|------|:---:|:---:|:---:|
| 初始 | 1 | 2 | 未赋值 |
| `if (a < b)` → 真 | 1 | 2 | — |
| `{ t=a; a=b; b=t; }` 整块执行 | 2 | 1 | 1 |
| 输出 | | `a=2 b=1` | |

**第二段（没有花括号）**：

| 语句 | a | b | t |
|------|:---:|:---:|:---:|
| 上一段结束时 | 2 | 1 | 1 |
| `if (a < b)` → `2 < 1` **假** | 2 | 1 | 1 |
| `t = a;` 是 if 的**唯一**受控语句，**被跳过** | 2 | 1 | 1 |
| `a = b;` **无条件执行** | **1** | 1 | 1 |
| `b = t;` **无条件执行** | 1 | **1** | 1 |
| 输出 | | `a=1 b=1` | |

⚠ 结论：**交换三个变量的代码必须用花括号包起来**。只缩进不加大括号，缩进只是给人看的，编译器完全不认。
```

💡 口诀：**if 管一句，括号管一块；想让多句受控，必须加花括号。**

## 4.2 if 的嵌套与 else 配对 ★★★

★ 考点：`else` 永远与**离它最近的那个、还没有配对的 `if`** 配对——**跟缩进无关**。这是程序阅读题的经典送命题。

**1. 配对规则（只用记这一条）**

- 一个 `else` 往前找，找到**最近的、还没有 `else` 的 `if`**，就和它配对。
- **缩进、换行、空行都不能改变配对结果**，编译器只看"最近的未配对 if"。
- 想强制配对，就**加花括号**把内层 `if` 关起来。

**2. 经典陷阱题：缩进骗人**

```c-run
#include <stdio.h>
int main(void) {
    int x = 3, y = 0;
    if (x > 0)
        if (x > 5) y = 1;
    else y = 2;
    printf("y=%d\n", y);
    return 0;
}
```

```text
y=2
```

```answer 运行结果与追踪
**先看编译器怎么配对**：`else` 往前找最近的未配对 `if`，就是 `if (x > 5)`，所以它的真实结构是：

```c
if (x > 0) {
    if (x > 5) y = 1;
    else y = 2;        /* 这个 else 属于内层 if */
}
```

追踪：

| 步骤 | 判断 | 结果 | y |
|:---:|------|:---:|:---:|
| ① | `x > 0` → `3 > 0` | 真，进入内层 | 0 |
| ② | `x > 5` → `3 > 5` | 假 | 0 |
| ③ | 走内层 `else` | `y = 2` | **2** |

输出：`y=2`

⚠ 注意：这一段代码**从缩进看**好像 `else` 属于外层 `if`，但实际不是。**永远别信缩进，只信"最近未配对 if"规则。**
```

**3. 用花括号强制配对，结果完全不同**

★ 考点：**要看出差别，必须让"外层条件为真、内层条件为假"**（例如 `x = 5`：`x > 0` 真，`x > 5` 假）。

```c-run
#include <stdio.h>
int main(void) {
    int x = 5, y = 0;
    if (x > 0)
        if (x > 5) y = 1;
    else y = 2;
    printf("A: y=%d\n", y);

    y = 0;
    if (x > 0) {
        if (x > 5) y = 1;
    } else y = 2;
    printf("B: y=%d\n", y);
    return 0;
}
```

```text
A: y=2
B: y=0
```

```answer 运行结果与追踪
同样的 `x = 5`，两种写法结果**完全相反**：

| 写法 | else 配给谁 | 判断过程 | y |
|:---:|:---:|------|:---:|
| A（无花括号） | **内层** `if (x > 5)` | `5 > 0` 真 → `5 > 5` 假 → 执行内层 `else` → `y = 2` | **2** |
| B（花括号关住内层） | **外层** `if (x > 0)` | `5 > 0` 真 → 进入块，`5 > 5` 假 → **块里没有 else**，什么也不做；外层 else 也轮不到 | **0** |

⚠ 差别在哪：A 里 `else` 抢给了内层 `if`，所以 `x>5` 为假时它**反而会执行**；B 用花括号把内层 `if` 封成了一个块，`else` 只能配给外层 `if`，而外层条件为真，所以 `else` **不执行**。

📌 一条口诀记死：**else 是"就近配对**，加花括号是为了改变"谁离得近"。
```

**4. 换个数值再看一遍**

```c-run
#include <stdio.h>
int main(void) {
    int x = 3, y = 0;
    if (x > 0) {
        if (x > 5) y = 1;
    } else y = 2;
    printf("y=%d\n", y);
    return 0;
}
```

```text
y=0
```

```answer 运行结果与追踪
| 步骤 | 判断 | 结果 | y |
|:---:|------|:---:|:---:|
| ① | `x > 0` → `3 > 0` | 真，进入块 | 0 |
| ② | `x > 5` → `3 > 5` | 假，块内无事可做 | 0 |
| ③ | 外层 `else` | **不执行**（因为 ① 为真） | **0** |

输出：`y=0`

⚠ 对比上面的 A 写法（同样 `x=3`）：A 会输出 `y=2`。**同一份数值、同样的缩进，只因为花括号位置不同，答案就变了**——这就是命题人最爱设的坑。

⚠ 考试遇到这种题，**别背结论，按三步推**：
1. 先圈出 `else` 配给哪个 `if`（往前找最近的未配对 `if`）；
2. 把题目给的数值代进去；
3. 逐层判断真假，走到哪一层就只执行那一层的语句。
```

💡 口诀：**else 不认缩进，只认最近未配对 if；想让它听你的，就用花括号关门。**

⚠ 易错：`if` 嵌套层数别超过 3 层。层数太多时，用 `else if` 拉平，或把内层抽成单独的函数（见《07 · 函数》章）。

## 4.3 switch 语句 ★★★

★ 考点：`switch` 的四条硬规则 + `break` 的穿透效果。程序阅读题里"**故意不写 break**"的累加题几乎年年出现。

**1. 语法格式**

```c
switch (表达式) {
case 常量1: 语句序列1; break;
case 常量2: 语句序列2; break;
default:   语句序列n;
}
```

**2. 四条硬规则（考试就考这四条）**

| 规则 | 说明 | 反例 |
|:---:|------|------|
| ① 表达式类型 | 必须是**整型或字符型**（含枚举） | `switch (3.5)` ✘、`switch ("abc")` ✘ |
| ② case 后是常量 | 必须是**常量表达式**，且各 case 的**值互不相同** | `case x:` ✘、`case 1: ... case 1:` ✘ |
| ③ 遇 break 才跳出 | 不写 `break` 会**继续往下执行**（穿透） | 见下面例题 |
| ④ default 位置任意 | 可以放开头、中间、结尾；不写也可以 | 见下面例题 |

⚠ 易错：`switch` 后面括号里的表达式**不能是浮点型**：`switch (x)` 里 `x` 是 `double` 就错。
⚠ 易错：`case` 后面是**冒号不是分号**：`case 1:` ✔，`case 1;` ✘。
⚠ 易错：`case` 的**值不能重复**，重复是编译错误。

**3. `break` 的作用与"穿透"**

- 有 `break`：执行完本 case 的语句就**跳出整个 switch**。
- 没 `break`：从这个 case 开始，**一直往下执行后面所有 case 的语句**（包括 `default`），直到遇到 `break` 或 switch 结束。

```c-run
#include <stdio.h>
int main(void) {
    int x = 2;
    switch (x) {
    case 1: printf("one\n");
    case 2: printf("two\n");
    case 3: printf("three\n"); break;
    case 4: printf("four\n");
    default: printf("other\n");
    }
    return 0;
}
```

```text
two
three
```

```answer 运行结果与追踪
`x = 2`，从 `case 2` 进入：

| 步骤 | 执行 | 说明 |
|:---:|------|------|
| ① | `case 1:` | 不匹配，跳过 |
| ② | `case 2:` 匹配 → 执行 `printf("two\n")` | 输出 `two` |
| ③ | **没有 break** → 继续往下"穿透" | |
| ④ | `case 3:` 执行 `printf("three\n")` | 输出 `three` |
| ⑤ | 遇到 `break` → 跳出 switch | |
| ⑥ | `case 4`、`default` 都不执行 | |

输出两行：`two`、`three`

💡 记忆方法：`switch` 像"从匹配的 case 开始，**一路往下滑**，直到撞上 break 这堵墙"。
```

**4. `default` 位置任意**

```c-run
#include <stdio.h>
int main(void) {
    int x = 9;
    switch (x) {
    default: printf("d");
    case 1: printf("1"); break;
    case 2: printf("2");
    }
    printf("\n");
    return 0;
}
```

```text
d1
```

```answer 运行结果与追踪
`x = 9` 没有匹配的 case → 进入 `default`（它在最前面）：

| 步骤 | 执行 | 输出 |
|:---:|------|------|
| ① | `default: printf("d")` | `d` |
| ② | 没有 break → 穿透到 `case 1` | |
| ③ | `printf("1")`，然后 `break` | `1` |
| ④ | 跳出，`printf("\n")` 换行 | |

输出：`d1`

⚠ 两个易错点：
1. **`default` 放在第一个，照样会穿透**到下面去——`default` 不是"最后才执行"的意思。
2. 如果 `switch` 里没有 `default` 且没有匹配的 `case`，**整个 switch 什么都不做**，直接跳到后面继续执行。
```

**5. 经典累加题：故意不写 break**

★ 考点：这种题的做法是"**从入口一路往下，把经过的每条语句都执行一遍**"。

```c-run
#include <stdio.h>
int main(void) {
    int c = 0;
    switch (c) {
    case 0: c += 1;
    case 1: c += 2;
    case 2: c += 3; break;
    case 3: c += 4;
    }
    printf("c=%d\n", c);
    return 0;
}
```

```text
c=6
```

```answer 运行结果与追踪
`c = 0`，从 `case 0` 进入：

| 步骤 | 语句 | 执行前 c | 执行后 c |
|:---:|------|:---:|:---:|
| ① | `case 0: c += 1;` | 0 | 1 |
| ② | （无 break，穿透）`case 1: c += 2;` | 1 | 3 |
| ③ | （无 break，穿透）`case 2: c += 3;` | 3 | **6** |
| ④ | `break;` 跳出 | 6 | 6 |
| ⑤ | `case 3` 不执行 | | |

输出：`c=6`

⚠ 如果每个 case 后面都有 break，答案就是 `c=1`。**"有没有 break"直接决定答案**，读题时先用笔把每个 `break` 圈出来。
```

**6. switch 与 if 的互相转换**

| 场景 | 用 if | 用 switch |
|------|:---:|:---:|
| 判断**区间**（成绩段 90~100） | ✔ 首选 | 麻烦（要写成 `case 90: case 91: ...`） |
| 判断**具体几个值**（菜单 1/2/3） | 可以 | ✔ 首选，更清晰 |
| 判断**浮点/字符串** | ✔ 可以 | ✘ 不行 |

💡 口诀：**区间用 if，等值用 switch；switch 只认整数和字符。**

**7. `continue` 在 switch 里的坑（进阶）**

⚠ 易错：`switch` 里写 `continue`，它作用于**外层循环**，不是 switch（`switch` 不是循环，`break` 会跳出它，但 `continue` 不会）。

```c-run
#include <stdio.h>
int main(void) {
    int k;
    int s = 0;
    for (k = 1; k <= 4; k++) {
        switch (k) {
        case 1:
        case 2: s += 1; break;
        case 3: continue;
        default: s += 2;
        }
        s += 10;
    }
    printf("s=%d\n", s);
    return 0;
}
```

```text
s=34
```

```answer 运行结果与追踪
| k | 进入哪个 case | switch 内动作 | switch 后 `s += 10` | s |
|:---:|:---:|------|:---:|:---:|
| 1 | `case 1`（无 break）→ 穿透到 `case 2` | `s += 1` → s=1，`break` | 执行，s=11 | 11 |
| 2 | `case 2` | `s += 1` → s=12，`break` | 执行，s=22 | 22 |
| 3 | `case 3` | `continue` → **跳过本轮循环剩下的部分** | **不执行** | 22 |
| 4 | `default` | `s += 2` → s=24 | 执行，s=34 | **34** |

输出：`s=34`

⚠ 关键：`k=3` 时 `continue` 直接进入下一轮循环，**连 `s += 10` 都跳过了**。
📌 这一题同时考了"case 穿透 + break + continue 作用于循环"，是选择结构里最难的题型，务必自己再推一遍。
```

⚠ 易错：`switch` 的每个 case 分支都要检查三件事：① 有没有 `break`；② 是不是穿透；③ 语句有没有漏分号。

### 训练 1：分段函数求值

题目：输入 x，按下式输出 y：x<0 时 y=-1；x=0 时 y=0；x>0 时 y=1。

```c
#include <stdio.h>
int main(void) {
    int n, s;
    scanf("%d", &n);
    if (n < 0) s = -1;
    else if (n == 0) s = 0;
    else s = 1;
    printf("s=%d\n", s);
    return 0;
}
```

```answer 参考答案与追踪
输入 `-8` → 输出 `s=-1`

| 判断顺序 | 条件 | 输入 -8 | 结果 |
|:---:|:---:|:---:|:---:|
| ① | `n < 0` | `-8 < 0` 真 | `s = -1`，**后面不再判断** |
| ② | `n == 0` | 不执行 | — |
| ③ | `else` | 不执行 | — |

📌 `else if` 的精髓：**只要前面有一个条件为真，后面全部跳过**。
⚠ 输入 0 时：① 假、② 真 → `s=0`；输入 5 时：①② 都假 → 走最后的 `else`，`s=1`。
```

### 训练 3：判断闰年

题目：输入年份，是闰年输出 `yes`，否则输出 `no`。闰年条件：**能被 4 整除且不能被 100 整除，或者能被 400 整除**。

```c
#include <stdio.h>
int main(void) {
    int year;
    scanf("%d", &year);
    if ((year % 4 == 0 && year % 100 != 0) || year % 400 == 0)
        printf("yes\n");
    else
        printf("no\n");
    return 0;
}
```

```answer 参考答案与追踪
核心表达式：`(year % 4 == 0 && year % 100 != 0) || year % 400 == 0`

⚠ 括号**不能省**！`&&` 的优先级高于 `||`，靠优先级虽然结果一样，但加上括号更清楚、不怕写错。

| 输入 year | `%4==0` | `%100!=0` | 前半 `&&` | `%400==0` | 整个 `\|\|` | 输出 |
|:---:|:---:|:---:|:---:|:---:|:---:|:---:|
| 2000 | 真 | 假 | 假 | **真** | 真 | `yes` |
| 1900 | 真 | 假 | 假 | 假 | 假 | `no` |
| 2024 | 真 | 真 | **真** | 假 | 真 | `yes` |
| 2023 | 假 | 真 | 假 | 假 | 假 | `no` |

📌 三个必背判断：
1. `1900` 是**平年**（能被 100 整除但不能被 400 整除）。
2. `2000` 是**闰年**（能被 400 整除）。
3. `2024` 是**闰年**（能被 4 整除且不能被 100 整除）。

💡 口诀：**四年一闰，百年不闰，四百年再闰。**
```

**程序填空**：判断闰年（用嵌套 if 写）

```c
#include <stdio.h>
int main(void) {
    int year, leap;
    scanf("%d", &year);

        leap = 0;
    else if (____①____)
        leap = 0;
    else
        leap = ____②____;
    printf("%d\n", leap);
    return 0;
}
```

```answer 参考答案
① `year % 100 == 0 && year % 400 != 0`　② `1`

推理：能被 4 整除之后再分两种情况——能被 100 整除的，只有同时能被 400 整除才算闰年，其余都是平年；不能被 100 整除的就是闰年。

⚠ ① 也可以写成 `year % 100 == 0 && year % 400 != 0`；如果只写 `year % 100 == 0`，那么 2000 会被误判为平年。
```

### 训练 4：字符类型判断

题目：输入一个字符，若是小写字母输出 `lower`，大写字母输出 `upper`，数字字符输出 `digit`，其它输出 `other`。

```c
#include <stdio.h>
int main(void) {
    char ch;
    scanf("%c", &ch);
    if (ch >= 'a' && ch <= 'z')
        printf("lower\n");
    else if (ch >= 'A' && ch <= 'Z')
        printf("upper\n");
    else if (ch >= '0' && ch <= '9')
        printf("digit\n");
    else
        printf("other\n");
    return 0;
}
```

```answer 参考答案与追踪
输入 `k` → 输出 `lower`

⚠ 三个必须注意的点：

1. **判断字符范围必须用 `&&`，不能连写**：
   - ✔ `ch >= 'a' && ch <= 'z'`
   - ✘ `'a' <= ch <= 'z'` —— 这个写法**永远为真**！因为 `'a' <= ch` 先算出 0 或 1，再用 0 或 1 和 `'z'`（122）比较，恒成立。
2. **比较的是字符常量 `'a'`，不是变量 a**，引号不能掉。
3. 判断顺序：**先小写、再大写、再数字**；如果把 `other` 的判断提到前面，后面就永远轮不到了。

| 输入 | 判断过程 | 输出 |
|:---:|------|:---:|
| `k` | `k` 在 `a`~`z` 之间 → 真 | `lower` |
| `M` | ① 假；② `M` 在 `A`~`Z` → 真 | `upper` |
| `7` | ①② 假；③ `7` 在 `0`~`9` → 真 | `digit` |
| `#` | ①②③ 全假 | `other` |
```

### 训练 5：三数排序（从小到大）

题目：输入三个整数，按从小到大输出。

```c
#include <stdio.h>
int main(void) {
    int a = 7, b = 3, c = 5, t;
    if (a > b) { t = a; a = b; b = t; }
    if (a > c) { t = a; a = c; c = t; }
    if (b > c) { t = b; b = c; c = t; }
    printf("%d %d %d\n", a, b, c);
    return 0;
}
```

```c-run
#include <stdio.h>
int main(void) {
    int a = 7, b = 3, c = 5, t;
    if (a > b) { t = a; a = b; b = t; }
    if (a > c) { t = a; a = c; c = t; }
    if (b > c) { t = b; b = c; c = t; }
    printf("%d %d %d\n", a, b, c);
    return 0;
}
```

```text
3 5 7
```

```answer 运行结果与追踪
| 步骤 | 判断 | 动作 | a | b | c | t |
|:---:|:---:|------|:---:|:---:|:---:|:---:|
| 初始 | — | — | 7 | 3 | 5 | — |
| ① | `a > b` → `7>3` 真 | 交换 a、b | **3** | **7** | 5 | 7 |
| ② | `a > c` → `3>5` 假 | 不动 | 3 | 7 | 5 | 7 |
| ③ | `b > c` → `7>5` 真 | 交换 b、c | 3 | **5** | **7** | 7 |
| 输出 | | | `3 5 7` | | | |

💡 三步排序法（背下来，考试直接套）：
1. 让 `a` 和 `b` 比，把小的放 `a`；
2. 让 `a` 和 `c` 比，把小的放 `a`（此时 `a` 已是最小）；
3. 让 `b` 和 `c` 比，把小的放 `b`（此时 `b` 是第二小）。

⚠ 交换必须用**临时变量 t** 并且**三条语句要用花括号包住**，否则像 [4.1](#4.1 if 语句的三种形式 ★★★) 那样出乱子。
⚠ 每个 `if` 的**花括号位置也要对**：`if (a > b) { t=a; a=b; b=t; }` 是一个完整块，别写成 `if (a > b) { t=a; } a=b; b=t;`。
```

### 训练 6：switch 改写（程序填空）

题目：用 switch 输出成绩等级的首字符（A/B/C/D/E）。已知 `score / 10` 的结果：90~99 → 9，80~89 → 8，…，60~69 → 6。

```c
#include <stdio.h>
int main(void) {
    int score, k;
    scanf("%d", &score);
    k = score / 10;
    switch (k) {
    case 10:
    case ____①____: printf("A\n"); break;
    case 8: printf("B\n"); break;
    case 7: printf("C\n"); break;
    case ____②____: printf("D\n"); break;
    ____③____: printf("E\n");
    }
    return 0;
}
```

```answer 参考答案
① `9`　② `6`　③ `default`

推理：
- `case 10:` 后面**不写语句也不写 break**，故意让它穿透到 `case 9:`，这样 100 分和 90~99 分都输出 `A`。
- `case 6:` 输出 `D`。
- 剩下的（0~59 分，`k` 是 0~5）都落到 `default`，输出 `E`。

⚠ 注意 `default` 后面**不需要 break**（它本来就是最后一个），但写上也不报错。
⚠ `case 10:` 那一行的穿透是**故意设计**的，这正是"多个 case 共用一个出口"的标准写法。
```

### 训练 7：判断能否构成三角形（综合）

题目：输入三条边长 a、b、c，若能构成三角形输出 `yes`，否则输出 `no`。条件：任意两边之和大于第三边。

```answer 参考答案
```c
#include <stdio.h>
int main(void) {
    int a, b, c;
    scanf("%d%d%d", &a, &b, &c);
    if (a + b > c && a + c > b && b + c > a)
        printf("yes\n");
    else
        printf("no\n");
    return 0;
}
```

验证：
- 输入 `3 4 5` → `3+4>5` ✔、`3+5>4` ✔、`4+5>3` ✔ → `yes`
- 输入 `1 2 3` → `1+2>3` 假（等于不算大于）→ `no`

⚠ 三个条件必须用 `&&` 全部满足，写成 `,` 或 `||` 都是错的。
⚠ 这三条要**全部满足**，漏掉任何一条都会把退化三角形（如 1、2、3）误判成三角形。
```

💡 选择结构阅读题口诀：**先圈 else 配对谁，再代数值逐层推；switch 先找入口点，一路下滑到 break。**
