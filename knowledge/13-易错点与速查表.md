## 13.1 运算符优先级与结合性总表 ★★★

★ 考点：优先级从高到低，**同一行内按"结合性"方向运算**。

| 级别 | 运算符 | 名称 | 结合性 |
|:---:|------|------|:---:|
| 1 | `()`　`[]`　`->`　`.` | 括号、下标、成员 | 左→右 |
| 2 | `!`　`~`　`++`　`--`　`+`(正) `-`(负)　`*`(指针)　`&`(取址)　`sizeof` | 单目运算符 | **右→左** |
| 3 | `*`　`/`　`%` | 乘除取余 | 左→右 |
| 4 | `+`　`-` | 加减 | 左→右 |
| 5 | `<<`　`>>` | 移位 | 左→右 |
| 6 | `<`　`<=`　`>`　`>=` | 关系 | 左→右 |
| 7 | `==`　`!=` | 相等/不等 | 左→右 |
| 8 | `&` | 按位与 | 左→右 |
| 9 | `^` | 按位异或 | 左→右 |
| 10 | `\|` | 按位或 | 左→右 |
| 11 | `&&` | 逻辑与 | 左→右 |
| 12 | `\|\|` | 逻辑或 | 左→右 |
| 13 | `?:` | 条件运算符 | **右→左** |
| 14 | `=`　`+=`　`-=`　`*=`　`/=`　`%=` | 赋值、复合赋值 | **右→左** |
| 15 | `,` | 逗号 | 左→右 |

💡 记忆口诀（背这四句就够用）：

1. **括号最牛**，单目第二；
2. **乘除取余 > 加减 > 移位 > 关系 > 相等 > 位与 > 异或 > 位或 > 逻辑与 > 逻辑或**；
3. **赋值和条件运算符是右结合**（`a=b=c=1` 等价于 `a=(b=(c=1))`）；
4. **逗号最低**。

⚠ 最容易错的三处：

| 表达式 | 常见错答 | 正确答案 | 原因 |
|------|:---:|:---:|------|
| `!5 + 3` | 1 | **3** | `!` 优先级高于 `+`：`(!5)+3 = 0+3 = 3` |
| `1 && 0 \|\| 1` | 0 | **1** | `&&` 先算：`(1&&0)\|\|1 = 0\|\|1 = 1` |
| `x = 1, 2, 3` | x=3 | **x=1** | 逗号优先级低于赋值：`(x=1),2,3` |

## 13.2 printf / scanf 格式符速查 ★★★

### printf 常用格式符

| 格式符 | 含义 | 例（值） | 输出 |
|:---:|------|------|------|
| `%d` | 十进制整数 | 520 | `520` |
| `%o` | 八进制（无前缀） | 520 | `1010` |
| `%x` | 十六进制（无前缀，小写） | 520 | `208` |
| `%u` | 无符号十进制 | 520 | `520` |
| `%c` | 单个字符 | 'A' | `A` |
| `%s` | 字符串 | "abc" | `abc` |
| `%f` | 浮点，默认 6 位小数 | 3.14 | `3.140000` |
| `%e` | 指数形式 | 520.0 | `5.200000e+02` |
| `%lf` | double（**scanf 里必须用**） | — | — |
| `%%` | 一个百分号 | — | `%` |
| `%ld` / `%lld` | long / long long | — | — |

### 宽度与精度（**考点密集区**）

| 写法 | 含义 | 例（值 520.467 / 值 42） |
|------|------|------|
| `%5d` | 宽度 5，右对齐补空格 | `   42` |
| `%-5d` | 宽度 5，左对齐 | `42   ` |
| `%05d` | 宽度 5，前补 0 | `00042` |
| `%.2f` | 保留 2 位小数（**四舍五入**） | `520.47` |
| `%8.2f` | 总宽 8 + 2 位小数 | `  520.47` |
| `%3d`（高考式输出用） | 每个数占 3 格 | `  0` `  1` |
| `%.3s` | 只输出字符串前 3 个字符 | `abc` |

### scanf 的四个坑

| # | 坑 | 正确做法 |
|:---:|------|------|
| 1 | 漏写 `&` | `scanf("%d", &x);`（`%s` 读数组名除外） |
| 2 | 格式串里有普通字符 | 输入时必须原样敲：`scanf("a=%d", &a)` → 输入 `a=5` |
| 3 | `%c` 会读到空格/回车 | 在读字符前加 `getchar();` 吃掉回车，或写 `scanf(" %c", &ch);`（%c 前加空格） |
| 4 | double 用 `%f` | scanf 里 double **必须用 `%lf`**；printf 里 `%f` 和 `%lf` 都可以 |

⚠ 高频结论：**`printf("sum=%d", x)` 的输出包含 `sum=`；`scanf("a=%d")` 的输入要含 `a=`。**

## 13.4 ASCII 码必背表 ★★★

★ 考点：ASCII 用 **7 位二进制**表示 **128** 个字符；记住这几个关键值，其余靠推。

| 字符 | 十进制 | 十六进制 | 记忆法 |
|:---:|:---:|:---:|------|
| `'\0'` | **0** | 00 | 字符串结束标志 |
| `'\n'` | **10** | 0A | 换行 |
| 空格 `' '` | **32** | 20 | — |
| `'0'` | **48** | 30 | 数字从 48 开始 |
| `'9'` | 57 | 39 | 48+9 |
| `'A'` | **65** | 41 | 大写从 65 开始 |
| `'Z'` | 90 | 5A | 65+25 |
| `'a'` | **97** | 61 | 小写从 97 开始 |
| `'z'` | 122 | 7A | 97+25 |

💡 三条必背规律：

1. **数字字符与数值差 48**：`'7' - '0' = 7`，`'0' + 9 = '9'`；
2. **大小写差 32**：`'a' - 'A' = 32`，小写转大写 `ch -= 32`，大写转小写 `ch += 32`；
3. **字符可以当整数用**：`printf("%d", 'A')` 输出 `65`，`printf("%c", 66)` 输出 `B`。

🔗 相关：见《15 · 附录 · 进制转换与数据表示》的 ASCII 一节

## 13.5 数据类型、字节数与取值范围 ★★★

| 类型 | 字节 | 位 | 取值范围 |
|------|:---:|:---:|------|
| `char` | 1 | 8 | −128 ~ 127 |
| `unsigned char` | 1 | 8 | 0 ~ 255 |
| `short` | 2 | 16 | −32768 ~ 32767 |
| `unsigned short` | 2 | 16 | 0 ~ 65535 |
| `int` | 4 | 32 | **−2147483648 ~ 2147483647** |
| `unsigned int` | 4 | 32 | 0 ~ 4294967295 |
| `long` | 4（32位系统） | 32 | 同 int |
| `float` | 4 | 32 | 约 ±3.4×10³⁸（6~7 位有效数字） |
| `double` | 8 | 64 | 约 ±1.7×10³⁰⁸（15~16 位有效数字） |

💡 两个必背公式（**考试直接考**）：

| 类型 | 能表示多少个不同的值 | 范围 |
|------|------|------|
| n 位**无符号** | 2ⁿ | 0 ~ 2ⁿ−1 |
| n 位**有符号**（补码） | 2ⁿ | −2ⁿ⁻¹ ~ 2ⁿ⁻¹−1 |

📌 例：int 占 4 字节 = 32 位 → 共 `2³² = 4294967296` 个不同的值；有符号范围 `−2³¹ ~ 2³¹−1`，即 **−2147483648 ~ 2147483647**（负数比正数多一个，因为 0 占了一个"正数"的位置）。

⚠ 易错：**1KB = 1024B，1MB = 1024KB，1GB = 1024MB，1TB = 1024GB**（不是 1000）；**1 字节 = 8 位**。

🔗 相关：见《15 · 附录 · 进制转换与数据表示》

## 13.6 文件打开模式速查 ★★

| 模式 | 含义 | 文件不存在时 | 能否读 | 能否写 |
|:---:|------|------|:---:|:---:|
| `"r"` | 只读（文本） | **返回 NULL，失败** | ✔ | ✘ |
| `"w"` | 只写（文本） | 新建 | ✘ | ✔（**清空原内容**） |
| `"a"` | 追加（文本） | 新建 | ✘ | ✔（在末尾追加） |
| `"r+"` | 读写 | 失败 | ✔ | ✔ |
| `"w+"` | 读写 | 新建 | ✔ | ✔（清空） |
| `"a+"` | 读 + 追加 | 新建 | ✔ | ✔（只能末尾追加） |
| `"rb"` `"wb"` `"ab"` | 二进制方式 | 同上 | — | — |

📌 三个必考结论：

1. **`"r"` 打开不存在的文件会失败**，所以打开后要判断：`if ((fp = fopen("a.txt", "r")) == NULL) { printf("open error"); return; }`
2. **`"w"` 会清空原文件**；
3. 路径里的反斜杠要写两个：`fopen("d:\\hhh\\tt.bin", "rb")`。

🔗 相关：[文件的打开与关闭](#文件的打开与关闭 ★★★)

## 13.8 易错清单 40 条（考前逐条过）★★★

⚠ 每一条都是真实扣分点。**能一眼说出"为什么错"的划掉，说不出的回到对应章节。**

### 语法类（1—12）

1. C 程序从 **main** 开始、到 main 结束，其他函数不会自动执行。
2. 一个程序**只能有一个 main**，但可以有多个函数。
3. 每条语句以**分号**结束，但 `#include`、`#define` 等预处理命令**不加分号**。
4. 注释 `/* */` 不能嵌套；`//` 只能注释一行。
5. `=` 是赋值，`==` 是判断相等。
6. `if (x > 0);` 后面那个分号会让 if 变成空语句。
7. 花括号 `{}` 必须配对，`if/for/while` 后只跟一条语句时也必须写花括号（防错）。
8. `switch` 的 case 后必须是**常量**，不能是变量或范围。
9. 数组长度必须是**常量表达式**，不能用变量（C99 的变长数组考试不考）。
10. 函数不能嵌套定义，但可以嵌套调用。
11. `void` 函数不能有返回值，也不能 `return 值;`。
12. 结构体、联合体、枚举定义末尾**必须有分号**。

### 数据与运算类（13—26）

13. 标识符不能以数字开头，不能含 `-`，不能是关键字；**区分大小写**（`INT` 合法、`int` 不合法）。
14. 整数除法**向零取整**：`5/2=2`、`-7/2=-3`。
15. `%` 两侧必须是整数，且**余数符号与被除数相同**：`-7%2=-1`。
16. `7.5 % 2` 编译错误。
17. 浮点赋给整型**截断**（不四舍五入）：`int i = 3.9;` → `i=3`。
18. `printf("%.2f", 520.467)` 是**四舍五入** → `520.47`。
19. 字符参与运算是用它的 **ASCII 值**：`'A' + 1 = 66`。
20. `'a'` 是字符（1 字节），`"a"` 是字符串（2 字节，含 `'\0'`）。
21. `sizeof("abc")` 是 **4**，`strlen("abc")` 是 **3**。
22. 前置 `++i` 先加后用，后置 `i++` 先用后加。
23. 不要在同一表达式里对同一变量多次自增（结果不确定）。
24. `&&` 和 `||` 有**短路求值**：左边能定结果时右边不执行。
25. 判断 `a <= x <= b` 是**错的**，必须写 `x >= a && x <= b`。
26. 逗号表达式的值是**最后一个**子表达式的值。

### 数组与字符串类（27—33）

27. 数组下标**从 0 开始**，`a[10]` 的合法下标是 0~9。
28. 部分初始化时，其余元素**自动为 0**；完全不初始化时是**随机值**。
29. 数组名是首元素地址，**不能整体赋值**（`a = b` 非法）、**不能自增**（`a++` 非法）。
30. 字符串必须以 `'\0'` 结尾；`char a[3]="abc"` 没有 `'\0'`，用 `%s` 输出会乱码。
31. 判断字符串相等要用 `strcmp(a,b)==0`，不能用 `a==b`。
32. 输入字符串用 `scanf("%s", s)`（**不加 &**，遇空格就停）或 `gets(s)`（读整行）。
33. 二维数组可以省略**行数**，不能省略**列数**。

### 函数、指针与文件类（34—40）

34. 函数中形参的作用域是**它所在函数体**。
35. 普通变量传参是**值传递**（改了不影响实参）；数组传的是**地址**（改了会影响原数组）。
36. 指针定义用 `int *p;`，赋值用 `p = &m;`，取值用 `*p`。
37. `*p++` 是"先取值再移动指针"；`(*p)++` 是"把所指单元的值加 1"。
38. 数组名 `a` 等价于 `&a[0]`；`a[i]` 等价于 `*(a+i)`。
39. `fopen` 的模式 `"r"` 打不开不存在的文件，必须判断返回值是否为 NULL。
40. 文件用完要 `fclose(fp);`；字符串里的路径每个反斜杠写两个。
