# 03 · 顺序结构与输入输出 ★★★

★ 考点：本章是**填空、选择的高频区**，也是程序阅读题的"第一道关卡"——程序读不懂，常常不是逻辑难，而是 `printf`/`scanf` 的格式符没吃透。

📌 本章必须拿下 4 件事：① `printf` 宽度精度怎么变；② `scanf` 里 `&` 和"原样输入"；③ `%c` 与回车残留；④ 字符与整数的互通。

---

## 3.1 语句与顺序结构 ★

★ 考点：C 程序的基本单位是**语句**，而**分号是语句的结束标志**；复合语句 `{ }` 在语法上被当成"一条语句"。

**1. 语句分类（背下这 5 类）**

| 语句类型 | 形式 | 例子 |
|------|------|------|
| 表达式语句 | 表达式 + `;` | `a = b + c;` `i++;` |
| 函数调用语句 | 函数调用 + `;` | `printf("hi");` `scanf("%d", &n);` |
| 控制语句 | 9 种：if/switch/while/do-while/for/break/continue/goto/return | `if (a > b) ...;` |
| 复合语句 | `{ 若干语句 }` | `{ t = a; a = b; b = t; }` |
| 空语句 | 只有一个 `;` | `for (i = 0; i < 10; i++) ;` |

**2. 三条硬规则**

- **一个分号 = 一条语句的结束**。漏分号是编译错误（error），多分号是空语句（不报错但可能改变逻辑）。
- 顺序结构 = 语句**从上到下依次执行，每条恰好执行一次**，没有跳转。
- 复合语句 `{ }` 后面**不加分号**：`{ ... }` 是完整的语句，写成 `{ ... };` 会多出一个空语句。

**3. 顺序结构的特点**

- 只有**一个人口、一个出口**，执行路径是一条直线。
- 想改变执行顺序，必须用选择结构（第 04 章）或循环结构（第 05 章）。

⚠ 易错：`#include <stdio.h>`、`#define N 10` 这类**预处理命令后面不加分号**，加了会报错。

⚠ 易错：`if (a > b);` 后面这个分号让 `if` 控制了一条**空语句**，下面的大括号块将无条件执行——这是程序阅读题最常见的"陷阱"，第 04 章还会细讲。

💡 口诀：**分号断句，括号成块；预处理不带分号，复合语句不带分号。**

**4. 例题：看清"顺序执行"与"空语句"**

```c-run
#include <stdio.h>
int main(void) {
    int a = 3, b = 5;
    a = a + b;
    b = a - b;
    a = a - b;
    printf("a=%d b=%d\n", a, b);
    return 0;
}
```

```text
a=5 b=3
```

```answer 运行结果与追踪
输出 `a=5 b=3`。这是**不用第三个变量交换两个数**的经典写法：

| 步骤 | 语句 | a | b |
|:---:|------|:---:|:---:|
| 初始 | `a=3, b=5` | 3 | 5 |
| ① | `a = a + b` | 8 | 5 |
| ② | `b = a - b` | 8 | 3 |
| ③ | `a = a - b` | 5 | 3 |

要点：三条赋值语句**按顺序**执行，后一条用的是前一条改过的值。

⚠ 注意：`a`、`b` 相加可能溢出，考试里用这种写法要确保数字不大。
```

## 3.2 printf 格式控制 ★★★

★ 考点：`printf` 的格式符、**宽度**、**精度**、**四舍五入**，是填空题和程序阅读题的第一考点，几乎每年必考。

**1. 格式符总表（必背）**

| 格式符 | 含义 | 例子 | 输出 |
|:---:|------|------|------|
| `%d` `%i` | 十进制有符号整数 | `printf("%d", -25);` | `-25` |
| `%u` | 无符号十进制整数 | `printf("%u", 10u);` | `10` |
| `%o` | 八进制（无前缀） | `printf("%o", 64);` | `100` |
| `%x` `%X` | 十六进制（小写/大写） | `printf("%x %X", 255, 255);` | `ff FF` |
| `%c` | 单个字符 | `printf("%c", 80);` | `P` |
| `%s` | 字符串 | `printf("%s", "Hi");` | `Hi` |
| `%f` | 实数（小数形式，默认 6 位小数） | `printf("%f", 3.5);` | `3.500000` |
| `%e` `%E` | 实数（指数形式） | `printf("%e", 12345.678);` | `1.234568e+04` |
| `%g` | 自动选 `%f` 或 `%e`（去掉多余的 0） | `printf("%g", 12345.678);` | `12345.7` |
| `%%` | 输出一个百分号 | `printf("100%%");` | `100%` |

**2. 长度修饰符（决定"占几个字节"）**

| 修饰符 | 配合 | 含义 |
|:---:|:---:|------|
| `l` | `%ld` `%lu` | long 型整数 |
| `ll` | `%lld` | long long 型整数 |
| `l` | `%lf` | **printf 里 `%lf` 与 `%f` 完全等价**（float 会自动提升为 double） |
| `h` | `%hd` | short 型整数 |

⚠ 易错：**`%f` 对应的必须是 `float`/`double`，`%d` 对应的必须是整型**。把 `int` 用 `%f` 打印，或把 `double` 用 `%d` 打印，结果是**不可预测的乱值**（不是"自动转换"）。要转就显式写 `(double)a` 或 `(int)x`。

⚠ 易错：`scanf` 里读 `double` **必须用 `%lf`**（用 `%f` 会写错内存）——这一点和 printf 不一样，见 [3.3](#3.3 scanf 格式控制 ★★★)。

**3. 宽度与精度：`%[标志][宽度][.精度]格式符`**

- **宽度**：输出**至少**占几个字符位，不够就补空格（默认右对齐）。
- **精度**：对 `%f` 是小数位数；对 `%s` 是最多取几个字符；对整数是"至少输出几位数字"。
- 标志 `-`：左对齐（右边补空格）；标志 `0`：左边补 0（**只有右对齐时才补 0**）。

| 写法 | 含义 | `printf` 参数为 12 | 参数为 1234 |
|:---:|------|:---:|:---:|
| `%d` | 原样 | `12` | `1234` |
| `%5d` | 宽度 5，右对齐补空格 | `   12` | ` 1234` |
| `%-5d` | 宽度 5，左对齐补空格 | `12   ` | `1234 ` |
| `%05d` | 宽度 5，左补 0 | `00012` | `01234` |
| `%8.2f` | 总宽 8，2 位小数 | — | — |

```c-run
#include <stdio.h>
int main(void) {
    int a = 12, b = 1234;
    double x = 3.14159;
    printf("[%d][%5d][%-5d][%05d]\n", a, a, a, a);
    printf("[%d][%5d][%-5d][%05d]\n", b, b, b, b);
    printf("[%.2f][%8.2f][%-8.2f]\n", x, x, x);
    return 0;
}
```

```text
[12][   12][12   ][00012]
[1234][ 1234][1234 ][01234]
[3.14][    3.14][3.14    ]
```

```answer 运行结果与追踪
关键在"宽度不够才补，够了就不管"：

| 写法 | a=12 | 说明 | b=1234 | 说明 |
|:---:|:---:|------|:---:|------|
| `%d` | `12` | 原样 | `1234` | 原样 |
| `%5d` | `   12` | 补 3 个空格 | ` 1234` | 补 1 个空格 |
| `%-5d` | `12   ` | 空格补在右边 | `1234 ` | 空格补在右边 |
| `%05d` | `00012` | 补 3 个 0 | `01234` | 补 1 个 0 |

再看浮点：
- `%.2f` → `3.14`（2 位小数，四舍五入）
- `%8.2f` → `    3.14`（`3.14` 只有 4 位，前面补 4 个空格到总宽 8）
- `%-8.2f` → `3.14    `（同理，空格补在右边）

📌 数格子技巧：先按要求把数字本体写出来（`3.14`），再数字符数——**小数点也算 1 个字符位**。宽度 8 就补到 8 个字符。
```

**4. 四舍五入（2025 真题同型）**

★ 考点：`%.2f` 会按第 3 位小数**四舍五入**。

```c-run
#include <stdio.h>
int main(void) {
    float f = 520.467f;
    printf("%.2f\n", f);
    return 0;
}
```

```text
520.47
```

```answer 运行结果与追踪
**这是 2025 年真题填空题的原题**，答案是 `520.47`。

追踪：`520.467` 保留 2 位小数 → 看第 3 位小数是 `7`，**≥5 就进位** → `.46` 进位成 `.47` → 结果 `520.47`。

⚠ 三个必须注意的点：
1. 是**看第 3 位决定第 2 位**，不要一位一位往前推。
2. 输出结果**只有 2 位小数**，不会带多余的 0（除非本来就该补：`3.5` 用 `%.2f` 输出 `3.50`）。
3. `%.2f` 不改变 `f` 本身的值，只是**打印时**四舍五入。

💡 补充：`%.0f` 的进位规则在 C 里是"就近取整、恰好 .5 时取偶数"（银行家舍入），实测 `0.5 1.5 2.5 3.5` 用 `%.0f` 输出 `0 2 2 4`。考试遇到 `.5` 的边界要留个心。
```

**5. 漏写 `\n` 会导致"粘在一起"**

⚠ 易错：`printf` **不会自动换行**，忘了 `\n` 两次输出会连成一行——这是丢分重灾区。

```c-run
#include <stdio.h>
int main(void) {
    printf("a=1");
    printf("b=2");
    printf("c=3\n");
    printf("a=1\n");
    printf("b=2\n");
    printf("c=3\n");
    return 0;
}
```

```text
a=1b=2c=3
a=1
b=2
c=3
```

```answer 运行结果与追踪
前三行 `printf` 都没有 `\n`，输出一个接一个**粘成一行**：`a=1b=2c=3`；直到第 3 句末尾的 `\n` 才换行。

后三句每一句末尾都有 `\n`，所以各占一行。

📌 考场提醒：写程序阅读答案时，**先把换行位置画出来**再落笔。题目问"输出结果"时，行数错一样扣分。
```

**6. 转义字符（在输出里怎么显示）**

| 转义符 | 含义 | 输出效果 |
|:---:|------|------|
| `\n` | 换行 | 光标移到下一行行首 |
| `\t` | 水平制表 | 跳到下一个制表位（约 8 的倍数） |
| `\\` | 反斜杠 | 一个 `\` |
| `\'` | 单引号 | `'` |
| `\"` | 双引号 | `"` |
| `\0` | 空字符（ASCII 0） | 字符串结束标志，不显示 |
| `\ddd` | 1~3 位八进制 | `\101` 输出 `A` |
| `\xhh` | 十六进制 | `\x41` 输出 `A` |

```c-run
#include <stdio.h>
int main(void) {
    printf("%d %i %u\n", 255, 255, 255);
    printf("%o %x %X\n", 64, 255, 255);
    printf("%c%c%c\n", 'C', 80, 85);
    printf("[%s][%5s][%-5s]\n", "Hi", "Hi", "Hi");
    printf("%f %.2f\n", 3.5, 3.5);
    printf("%e\n", 12345.678);
    printf("%g\n", 12345.678);
    printf("100%%\n");
    return 0;
}
```

```text
255 255 255
100 ff FF
CPU
[Hi][   Hi][Hi   ]
3.500000 3.50
1.234568e+04
12345.7
100%
```

```answer 运行结果与追踪
逐条对照格式符总表：

| 语句 | 输出 | 关键点 |
|------|------|------|
| `%d %i %u` 都是 255 | `255 255 255` | `%i` 在 `printf` 里等价 `%d` |
| `%o %x %X`，参数 64、255、255 | `100 ff FF` | 64 的八进制是 100；255 的十六进制是 ff |
| `%c%c%c` → `'C'`, 80, 85 | `CPU` | ASCII 80=`P`、85=`U` |
| `%s %5s %-5s` | `[Hi][   Hi][Hi   ]` | 宽度对 `%s` 同样生效 |
| `%f` vs `%.2f` | `3.500000 3.50` | `%f` 默认 6 位小数 |
| `%e` | `1.234568e+04` | 指数形式：1 位整数 + 6 位小数 |
| `%g` | `12345.7` | 共 6 位有效数字，自动去掉多余的 0 |
| `100%%` | `100%` | `%%` 输出一个百分号 |
```

💡 口诀：**d 整数 c 字符，s 字符串 f 小数；o 八 x 十六，e 指数 g 自由；百分号要写两遍。**

⚠ 易错：`%o` 和 `%x` 输出**不带前缀**（不会出现 `0` 或 `0x`），要加前缀得自己写 `printf("0x%x", n)`。

💡 秒杀技巧：看到 `"%o"` 参数是 64 → 立刻想 `64 = 8²` → 八进制 `100`。看到 `"%x"` 参数 255 → `255 = 15×16+15` → `ff`。

## 3.3 scanf 格式控制 ★★★

★ 考点：`&`、格式串里的普通字符、`%c` 读到回车/空格、`double` 必须 `%lf`——这四点每年都在填空题或程序阅读题里出现。

**1. `&` 不能漏**

- `scanf` 的作用是"把输入的数据**存到某个地址**去"，所以要给它**地址**：`&a` 表示"变量 a 的地址"。
- 漏掉 `&` → `scanf` 会把你变量里的**垃圾值当成地址**去写 → 运行时崩溃（或悄悄改坏别的内存）。

```c
#include <stdio.h>
int main(void) {
    int a;
    scanf("%d", a);      /* ✘ 漏了 & */
    printf("%d\n", a);
    return 0;
}
```

```answer 为什么是错的
`scanf("%d", a)` 把 `a` 的**当前值**（未初始化的随机数，例如 4198864）当成内存地址，往里写数据。

- 结果是**未定义行为**：轻则 `a` 不变（打印乱值），重则"程序已停止工作"。
- 考试判断"哪句有错"时，看到 `scanf` 后面缺 `&` 就是标准答案。

✔ 正确写法：`scanf("%d", &a);`

⚠ 唯一的例外：用 `%s` 读**字符数组名**时不用 `&`，因为数组名本身就是地址：`scanf("%s", s);`
```

**2. 格式串里的普通字符必须原样输入**（2025 真题原题）

★ 考点：`scanf` 的格式串里，**除格式符以外的字符（字母、`=`、`,`、空格）必须由用户一模一样地敲进去**，否则读取提前结束。

📌 2025 年真题：`scanf("a=%d,%d,%d", &a, &b, &c);` 要从键盘输入 1、2、3，正确的输入形式是 **`a=1,2,3`**。

```c
#include <stdio.h>
int main(void) {
    int a, b, c;
    scanf("a=%d,%d,%d", &a, &b, &c);
    printf("%d %d %d\n", a, b, c);
    return 0;
}
```

```answer 输入与输出
**正确输入**（回车结尾）：`a=1,2,3`

**输出**：`1 2 3`

逐字符拆解格式串 `a=%d,%d,%d`：

| 格式串片段 | 要求用户输入 | 说明 |
|:---:|:---:|------|
| `a` | 字母 `a` | 普通字符，必须原样敲 |
| `=` | 等号 | 普通字符，必须原样敲 |
| `%d` | `1` | 读入整数给 `a` |
| `,` | 逗号 | 普通字符，必须原样敲 |
| `%d` | `2` | 读入整数给 `b` |
| `,` | 逗号 | 普通字符，必须原样敲 |
| `%d` | `3` | 读入整数给 `c` |

⚠ 如果只敲 `1,2,3`：`scanf` 期待第一个字符是 `a`，实际读到 `1`，**匹配失败，三个变量一个都没读到**（保留原垃圾值），后面全乱。
⚠ 如果敲 `a=1 2 3`：读到第二个 `%d` 后期待 `,`，实际是空格，**匹配失败**，只有 `a` 拿到了 1。
```

**3. 输入分隔符：什么算分隔符**

| 格式符 | 空格 / Tab / 回车 | 说明 |
|:---:|:---:|------|
| `%d` `%f` `%lf` `%s` | ✔ 都算分隔符，且**自动跳过** | 可以 `3 4 5`，也可以 `3`回车`4`回车`5` |
| `%c` | ✘ 不算分隔符 | **原样读走一个字符**，空格和回车照读不误 |

```c
#include <stdio.h>
int main(void) {
    int a, b, c;
    printf("input a,b,c: ");
    scanf("%d%d%d", &a, &b, &c);
    printf("%d+%d+%d=%d\n", a, b, c, a + b + c);
    return 0;
}
```

```answer 三种输入都正确
输入 `3 4 5` → 输出 `input a,b,c: 3+4+5=12`
输入 `3 4 5`（用 Tab 分隔）→ 同上
输入（每行一个数字，回车分隔）`3`⏎`4`⏎`5`⏎ → 同上

结论：**`%d` 面前，空格、Tab、回车完全等价，都是"分隔符"，输入时随便用哪种。**

⚠ 但格式串里不要写 `scanf("%d,%d\n", ...)` 这种带 `\n` 的写法，`\n` 在 `scanf` 里表示"跳过任意多个空白字符"，会让程序卡住等输入。
```

**4. `%c` 会读到回车和空格（最容易丢分的点）**

⚠ 易错：上一个 `scanf("%d")` 读完数字后，**回车还留在输入缓冲区里**，紧接着的 `scanf("%c")` 会把这个回车读走。

```c
#include <stdio.h>
int main(void) {
    char c1, c2;
    scanf("%c%c", &c1, &c2);
    printf("[%c][%c] %d %d\n", c1, c2, c1, c2);
    return 0;
}
```

```answer 运行结果与追踪
输入（敲的是 `x`、空格、`y`、回车）：`x y`

输出：`[x][ ] 120 32`

追踪：

| 步 | 读到的字符 | 变量 | ASCII |
|:---:|:---:|:---:|:---:|
| 第 1 个 `%c` | `x` | `c1 = 'x'` | 120 |
| 第 2 个 `%c` | 空格 | `c2 = ' '` | 32 |

关键：**两个 `%c` 中间的空格被第二个 `%c` 吃掉了**，`y` 还留在缓冲区里没人要。

⚠ 如果输入是 `x`⏎`y`：第 2 个 `%c` 读到的是**回车**（ASCII 10），打印出来会把光标移到下一行，看起来像"少读了一个字符"。
```

**5. 两个标准解法：`getchar()` 吃回车 / `" %c"` 跳空白**

✔ 正解一：在 `%d` 后面用 `getchar();` 把回车**吃掉**。

```c
#include <stdio.h>
int main(void) {
    int n;
    char ch;
    scanf("%d", &n);
    getchar();
    scanf("%c", &ch);
    printf("n=%d ch=%c\n", n, ch);
    return 0;
}
```

```answer 输入与输出
输入：`7`⏎`K`⏎ → 输出 `n=7 ch=K`

追踪：`%d` 读走 `7`，回车留在缓冲区；`getchar()` 读走并丢弃那个回车；`%c` 顺利读到 `K`。
```

✔ 正解二：把格式串改成 `" %c"`（**百分号前面加一个空格**），空格在 `scanf` 里表示"跳过任意多个空白字符"。

```c
#include <stdio.h>
int main(void) {
    int n;
    char ch;
    scanf("%d", &n);
    scanf(" %c", &ch);
    printf("n=%d ch=%c\n", n, ch);
    return 0;
}
```

```answer 输入与输出
输入：`7`⏎`K`⏎ → 输出 `n=7 ch=K`

两种写法效果相同。区别是：`getchar()` 只吃掉**一个**字符；`" %c"` 能跳过**任意多个**空格/回车/Tab，更保险。

💡 口诀：**%d 后面接 %c，前面加空格或先 getchar()。**
```

**6. `double` 必须用 `%lf`**

⚠ 易错：`scanf` 读 `double` 一定要用 `%lf`，用 `%f` 是**错的内存写入**（`%f` 对应 4 字节 float，`double` 是 8 字节）。

```c
#include <stdio.h>
int main(void) {
    double d;
    scanf("%lf", &d);
    printf("%.2f\n", d);
    return 0;
}
```

```answer 输入与输出
输入：`3.14159` → 输出 `3.14`

对照记忆：

| 场景 | float | double |
|------|:---:|:---:|
| `scanf` 读取 | `%f` | **`%lf`** |
| `printf` 输出 | `%f` | `%f` 或 `%lf`（等价） |
```

💡 口诀：**输入 double 带 l，输出带不带都行。**

## 3.4 字符输入输出 ★★

★ 考点：`putchar`/`getchar` 一次只处理**一个字符**；字符与整数在 ASCII 表上互通。

**1. 四个函数对照**

| 函数 | 方向 | 用法 | 特点 |
|------|:---:|------|------|
| `putchar(c)` | 输出 | `putchar('A');` | 输出一个字符，参数可以是整数（按 ASCII 转字符） |
| `getchar()` | 输入 | `c = getchar();` | 读**一个**字符并返回其 ASCII 值（int 型） |
| `puts(s)` | 输出 | `puts("hello");` | 输出字符串并**自动换行** |
| `gets(s)` | 输入 | `gets(s);` | 读**一整行**（含空格），遇回车结束 |

⚠ 易错：`gets` **已经不安全**（不检查数组长度，会溢出），新标准里已删除，gcc 会给出警告。但**考试题里仍然出现**，看到就当"读整行字符串、能读空格"理解即可。自己写程序时用 `fgets`。

⚠ 易错：`puts` **自带换行**，`printf("%s\n", s)` 才和它等价；写成 `puts(s); printf("\n");` 会多空一行。

```c-run
#include <stdio.h>
int main(void) {
    char c = 'g';
    putchar(c);
    putchar('\n');
    putchar(c - 32);
    putchar('\n');
    return 0;
}
```

```text
g
G
```

```answer 运行结果与追踪
（程序里 `char c = 'g';` 相当于从键盘读入了 `g`；如果写成 `c = getchar();`，就是读 1 个字符。）

| 语句 | 动作 | 说明 |
|------|------|------|
| `c = 'g'`（或 `c = getchar();`） | `c = 'g'` | `'g'` 的 ASCII 是 103 |
| `putchar(c);` | 输出 `g` | 原样输出 |
| `putchar('\n');` | 换行 | |
| `putchar(c - 32);` | 输出 `G` | `'g'` 是 103，`103 - 32 = 71`，ASCII 71 是 `'G'` |

💡 关键结论：**小写字母 - 32 = 对应的大写字母**（因为 `'a'`=97、`'A'`=65，差 32）。
```

**2. 字符与整数是互通的**

★ 考点：C 里 `char` 本质是**小整数**（存的是 ASCII 码），所以字符可以当整数算，整数也可以当字符打印。

| 表达式 | 值 | 说明 |
|------|:---:|------|
| `'A'` | 65 | 字符常量就是它的 ASCII 码 |
| `'a'` - `'A'` | 32 | 大小写字母的固定差值 |
| `'0'` | 48 | 数字字符 `'0'` 的码，**不是** 0 |
| `'9'` - `'0'` | 9 | 数字字符转数值的常用手法 |
| `'A' + 32` | 97，即 `'a'` | 大写转小写 |

```c-run
#include <stdio.h>
int main(void) {
    printf("%d\n", 'A');
    printf("%c\n", 'A' + 32);
    printf("%c%c%c\n", 'a' - 32, 'b' - 32, 'c' - 32);
    return 0;
}
```

```text
65
a
ABC
```

```answer 运行结果与追踪
| 语句 | 输出 | 原因 |
|------|------|------|
| `printf("%d\n", 'A');` | `65` | `%d` 打印字符的 ASCII 码 |
| `printf("%c\n", 'A' + 32);` | `a` | `65 + 32 = 97`，`%c` 按 ASCII 转字符 |
| `printf("%c%c%c\n", 'a'-32, 'b'-32, 'c'-32);` | `ABC` | 三个小写字母各减 32，变大写 |

📌 这里的核心是**格式符决定怎么解释那串二进制**：同一个 65，`%d` 输出 `65`，`%c` 输出 `A`。
```

**3. `gets` 能读空格，`scanf("%s")` 不能**

⚠ 易错：`scanf("%s", s)` 遇到空格就**停**；`gets(s)` 会一直读到回车。这是程序阅读题的常见对比点。

```c
#include <stdio.h>
int main(void) {
    char s[20];
    gets(s);
    puts(s);
    puts("hello");
    return 0;
}
```

```answer 输入与输出
输入：`ab cd ef`⏎

输出：
```
ab cd ef
hello
```

说明：`gets` 把整行 `ab cd ef`（**含空格**）都读进了 `s`；`puts(s)` 输出后自动换行，`puts("hello")` 再输出一行。

⚠ 如果换成 `scanf("%s", s);`，`s` 里只有 `ab`，空格后面的内容留在缓冲区里等着下一个输入函数读——这是"输入被吃掉"类错误的根源。

⚠ 数组长度一定要够：`gets` 不检查长度，输入 `abcdefghijklmnopqrstuvwxyz` 会溢出，考试里要看出这个隐患。
```

## 3.5 常用库函数速用 ★★

★ 考点：`math.h` 的函数**返回 double**，打印要用 `%f` 或强制转换；`fabs` 与 `abs` 别搞混（一个在 `math.h`，一个在 `stdlib.h`）。

**1. math.h 常用函数**

| 函数 | 功能 | 参数类型 | 返回类型 | 例子 |
|------|------|:---:|:---:|------|
| `sqrt(x)` | 平方根 | double | **double** | `sqrt(4)` → `2.0` |
| `fabs(x)` | 绝对值 | double | **double** | `fabs(-3.5)` → `3.5` |
| `pow(x, y)` | x 的 y 次方 | double | **double** | `pow(2, 10)` → `1024.0` |
| `fmod(x, y)` | 浮点取余 | double | **double** | `fmod(7.5, 2)` → `1.5` |

⚠ 易错：**`sqrt(4)` 的值是 `2.0` 而不是 `2`**，用 `%d` 打印是乱值！三种正确处理：

- `printf("%f", sqrt(4));` → `2.000000`
- `printf("%.0f", sqrt(4));` → `2`
- `printf("%d", (int)sqrt(4));` → `2`（强制转换）

**2. stdlib.h 常用函数**

| 函数 | 功能 | 参数 | 返回 | 例子 |
|------|------|:---:|:---:|------|
| `abs(n)` | **整数**绝对值 | int | int | `abs(-3)` → `3` |
| `rand()` | 产生伪随机整数 | 无 | int | `rand() % 100` → 0~99 |
| `srand(n)` | 设置随机数种子 | unsigned | void | `srand(1);` |
| `exit(n)` | 结束程序 | int | void | `exit(0);` |

```c-run
#include <stdio.h>
#include <math.h>
int main(void) {
    printf("%f\n", sqrt(4));
    printf("%d\n", (int)sqrt(4));
    printf("%.3f\n", fabs(-3.5));
    printf("%d\n", abs(-3));
    printf("%.1f\n", pow(2, 10));
    printf("%.1f\n", fmod(7.5, 2));
    return 0;
}
```

```text
2.000000
2
3.500
3
1024.0
1.5
```

```answer 运行结果与追踪
| 语句 | 输出 | 关键点 |
|------|------|------|
| `printf("%f\n", sqrt(4));` | `2.000000` | `sqrt` 返回 double，`%f` 默认 6 位小数 |
| `printf("%d\n", (int)sqrt(4));` | `2` | 必须先 `(int)` 强转，才能用 `%d` |
| `printf("%.3f\n", fabs(-3.5));` | `3.500` | `fabs` 是**浮点**绝对值，返回 double |
| `printf("%d\n", abs(-3));` | `3` | `abs` 是**整数**绝对值，返回 int，可以直接 `%d` |
| `printf("%.1f\n", pow(2, 10));` | `1024.0` | `pow` 返回 double |
| `printf("%.1f\n", fmod(7.5, 2));` | `1.5` | `7.5 = 3×2 + 1.5` |

⚠ 最容易错的一句：把 `sqrt(4)` 直接写成 `printf("%d", sqrt(4));` → 输出乱值（不是 2）。
```

⚠ 易错：`fabs` 与 `abs` 一字之差，考试专门考这个：

| 写法 | 头文件 | 结果 |
|------|:---:|:---:|
| `abs(-3.5)` | stdlib.h | **错**：参数被截断成 int，结果不可靠 |
| `fabs(-3.5)` | math.h | ✔ `3.5` |
| `fabs(-3)` | math.h | ✔ `3.0`（可以，但返回 double） |
| `abs(-3)` | stdlib.h | ✔ `3` |

⚠ 易错：用了 `math.h` 的函数，**必须 `#include <math.h>`**，否则编译器按隐式声明处理，`sqrt` 返回值会被当成 int，结果错。

💡 口诀：**sqrt 开方 fabs 绝对值，pow 乘方 fmod 余；math 家族返回 double，要 %f 或者强转。**

## 3.6 顺序结构程序阅读训练 ★★★

★ 考点：顺序结构阅读题的套路是"**输入 → 按顺序算 → 输出**"。做法固定：① 把输入值写进变量表；② 一句一句往下推；③ 别忘了格式符决定输出的样子。

📌 做题流程（每道题都照这个走）：

1. 先把 `scanf` 读到的值填进变量表；
2. 从左到右逐条语句执行，**每次改变量就更新表格**；
3. 遇到 `printf` 先看清格式符（宽度、精度、`%c` 还是 `%d`）；
4. 画清楚**换行位置**再写答案。

---

### 训练 1：基本输入输出

```c
#include <stdio.h>
int main(void) {
    int n;
    double x;
    scanf("%d", &n);
    scanf("%lf", &x);
    printf("n=%d x=%.2f\n", n, x);
    printf("n*n=%d\n", n * n);
    return 0;
}
```

输入：`15` ⏎ `2.5`

```answer 运行结果与追踪
输出：
```
n=15 x=2.50
n*n=225
```

| 语句 | n | x | 说明 |
|------|:---:|:---:|------|
| `scanf("%d", &n);` | 15 | — | 读整数 |
| `scanf("%lf", &x);` | 15 | 2.5 | double 必须 `%lf` |
| `printf("n=%d x=%.2f\n", ...)` | 15 | 2.5 | `%.2f` 把 2.5 输出成 `2.50`（**补 0**） |
| `printf("n*n=%d\n", n*n)` | 15 | 2.5 | `15×15=225` |

⚠ 易错点：输入 `1.5` 是 `double`，输出 `%.2f` 时 `1.5` 会变成 `1.50`——**小数位数靠格式符补齐，不是原样输出**。
```

### 训练 2：字符与 ASCII

```c
#include <stdio.h>
int main(void) {
    char c;
    scanf("%c", &c);
    printf("%d\n", c);
    printf("%c\n", c + 1);
    return 0;
}
```

输入：`A`

```answer 运行结果与追踪
输出：
```
65
B
```

| 语句 | c | 说明 |
|------|:---:|------|
| `scanf("%c", &c);` | `'A'` | 读 1 个字符 |
| `printf("%d\n", c);` | `'A'` | `%d` 打印 ASCII 码 → `65` |
| `printf("%c\n", c + 1);` | `'A'` | `65 + 1 = 66`，`%c` 按字符输出 → `B` |

💡 记住：**同一个变量，`%d` 看码，`%c` 看字**。
```

### 训练 3：整数运算的"整除陷阱"

```c-run
#include <stdio.h>
int main(void) {
    int x = 5, y = 2;
    double z;
    z = x / y;
    printf("z=%.1f\n", z);
    z = (double)x / y;
    printf("z=%.1f\n", z);
    return 0;
}
```

```text
z=2.0
z=2.5
```

```answer 运行结果与追踪
| 语句 | 计算过程 | z |
|------|------|:---:|
| `z = x / y;` | `x`、`y` **都是 int**，先做整数除法 `5/2 = 2`，再转 double 赋给 `z` | 2.0 |
| `z = (double)x / y;` | `x` 先转成 `5.0`，`5.0/2` 变成浮点除法 `2.5` | 2.5 |

⚠ 这就是"整数除法丢小数"的经典考法：**两个整数相除，小数部分直接扔掉（不是四舍五入）**。
📌 只要除号两边出现一个 `double`（强转或写成 `1.0*x`），结果就是浮点。
```

### 训练 4：格式宽度与精度

```c
#include <stdio.h>
int main(void) {
    int a = 7;
    double b = 12.3456;
    printf("[%d][%3d][%-3d]\n", a, a, a);
    printf("[%.3f][%8.3f][%.1f]\n", b, b, b);
    return 0;
}
```

```c-run
#include <stdio.h>
int main(void) {
    int a = 7;
    double b = 12.3456;
    printf("[%d][%3d][%-3d]\n", a, a, a);
    printf("[%.3f][%8.3f][%.1f]\n", b, b, b);
    return 0;
}
```

```text
[7][  7][7  ]
[12.346][  12.346][12.3]
```

```answer 运行结果与追踪
第一行：

| 写法 | 输出 | 说明 |
|:---:|:---:|------|
| `%d` | `7` | 原样 |
| `%3d` | `  7` | 宽度 3，右边对齐，补 2 个空格 |
| `%-3d` | `7  ` | 宽度 3，左边对齐，补 2 个空格 |

第二行：

| 写法 | 输出 | 说明 |
|:---:|:---:|------|
| `%.3f` | `12.346` | 保留 3 位小数：`12.3456` 的第 4 位是 6，进位 |
| `%8.3f` | `  12.346` | 本体 `12.346` 共 6 个字符位，补 2 个空格到宽度 8 |
| `%.1f` | `12.3` | 保留 1 位小数，第 2 位是 4，舍去 |

⚠ 数格子时**小数点也算一位**：`12.346` = `1`,`2`,`.`,`3`,`4`,`6` 共 6 位。
```

### 训练 5：综合小账本

```c
#include <stdio.h>
int main(void) {
    int price, num;
    int total;
    double avg;
    scanf("%d%d", &price, &num);
    total = price * num;
    avg = total / 3.0;
    printf("total=%d\n", total);
    printf("avg=%.2f\n", avg);
    printf("%d*%d=%d, 100%%\n", price, num, total);
    return 0;
}
```

输入：`12 5`

```answer 运行结果与追踪
输出：
```
total=60
avg=20.00
12*5=60, 100%
```

| 语句 | price | num | total | avg |
|------|:---:|:---:|:---:|:---:|
| `scanf("%d%d", ...)` | 12 | 5 | — | — |
| `total = price * num;` | 12 | 5 | 60 | — |
| `avg = total / 3.0;` | 12 | 5 | 60 | `60/3.0 = 20.0` |
| `printf("total=%d\n", total);` | | | | 输出 `total=60` |
| `printf("avg=%.2f\n", avg);` | | | | 输出 `avg=20.00`（补两位小数） |
| `printf("%d*%d=%d, 100%%\n", ...)` | | | | 输出 `12*5=60, 100%` |

⚠ 两个考点：
1. `avg = total / 3.0;` 里 `/ 3.0` 是浮点除法才对；如果写成 `/ 3`，`total/3` 先做整数除法，`20.00` 就变成 `20.00`（这次恰好整除看不出来）——换成 `total = 61` 就能看出差别。
2. `%%` 才输出一个百分号；只写一个 `%` 是错的。
```

💡 顺序结构阅读题口诀：**先填输入表，再逐句推；格式符决定长相，换行别漏画。**
