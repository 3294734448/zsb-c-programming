# 08 · 指针 ★★★

指针是山西专升本 C 程序设计里**分值最高、失分最狠**的一章：单选、填空、程序阅读、程序设计四种题型都能出，历年分值大约 **15—25 分**。理解指针有助于追踪程序阅读题中的变量和内存变化。

这一章只有一个学法：**每读一条语句，就在纸上写出「p 现在指向谁」**。凡是跳过这一步的人，做题时全靠猜，`*p++` 和 `(*p)++` 永远分不清。

先把本章的 5 条铁律背下来，后面所有内容都是这 5 条的展开：

| 序号 | 铁律 | 一句话解释 |
|:---:|------|------|
| 1 | 指针变量里存的是**地址** | `int *p = &m;` 之后，p 的值就是 m 的地址 |
| 2 | `*p` 是「p 所指那个变量」 | 对 `*p` 赋值 = 改 p 指向的那个变量 |
| 3 | 数组名 = 首元素地址 | 所以 `a[i]` 和 `*(a+i)` 完全等价 |
| 4 | 只有传地址才能改实参 | 函数里改形参指针本身没用，要改 `*形参` |
| 5 | 指针的字节数与类型无关 | 考试环境（32 位）一律 4 字节 |

## 8.1 地址与指针变量 ★★★

★ 考点：`&` 取地址、`*` 取内容；指针变量的定义与初始化；`*` 在不同位置的三种含义；2025 年填空题直接考「让 p 指向 m」的赋值语句。

**1. 内存地址：每个变量都住在有编号的房间里**

- 内存被切成一个个**字节**，每个字节有一个编号，这个编号叫**地址**。
- 一个变量占若干个字节，**首字节的编号就是变量的地址**。`int` 占 4 字节，那么这 4 个字节里第一个字节的编号就是它的地址。
- 变量名是给人看的，**计算机只认地址**。指针就是用来"记地址"的变量。

内存示意图（假设系统从 0x1000 开始给变量分配空间）：

| 变量 | 地址 | 占几字节 | 内存里存的内容 |
|:---:|:---:|:---:|:---:|
| `int m = 10;` | 0x1000 | 4 | 10 |
| `int n = 20;` | 0x1004 | 4 | 20 |
| `int *p = &m;` | 0x1008 | 4 | **0x1000**（也就是 m 的地址）|

看懂这张表，指针就懂一半了：**p 这个格子里装的不是 10，而是 0x1000**。所以我们说「p 指向 m」。

**2. 两个运算符：`&` 和 `*`**

| 运算符 | 名称 | 作用 | 举例（接着上面的表） |
|:---:|:---:|------|------|
| `&` | 取地址运算符 | 取出变量的地址 | `&m` 的值是 0x1000 |
| `*` | 取内容（解引用）运算符 | 取出指针所指单元的值 | `*p` 的值是 10 |

- `&m` 读作"m 的地址"；`*p` 读作"p 所指单元的内容"。
- 两者互为逆运算：`*&m` 就是 `m`，`&*p` 就是 `p`。
- `*p` 既可以**读**，也可以**写**：`*p = 25;` 的意思是"把 25 存进 p 所指的那个单元"，也就是把 m 改成 25。

```c-run
#include <stdio.h>

int main(void) {
    int m = 10;
    int *p = &m;              /* p 指向 m */
    printf("%d %d\n", m, *p);
    *p = 25;                  /* 通过 p 改 m 的值 */
    printf("%d %d\n", m, *p);
    printf("%d\n", *&m);      /* * 和 & 抵消，还是 m */
    return 0;
}
```

```text
10 10
25 25
25
```

```answer 运行结果与追踪
**输出**

```text
10 10
25 25
25
```

**逐行追踪（关键是第 3 行 `*p = 25;`）**

| 语句 | p 指向 | `*p` 的值 | m 的值 |
|------|:---:|:---:|:---:|
| `int m = 10;` | —（p 还没定义） | — | 10 |
| `int *p = &m;` | m | 10 | 10 |
| `printf("%d %d\n", m, *p);` | m | 10 | 10 |
| `*p = 25;` | m | **25** | **25** |
| `printf("%d %d\n", m, *p);` | m | 25 | 25 |
| `printf("%d\n", *&m);` | m | 25 | 25 |

**结论**：`*p = 25` 改的不是 p，而是 **p 指向的 m**。这就是"通过指针间接访问变量"，也是后面所有指针题的基础。
```

**3. 指针变量的定义与初始化**

定义格式：`基类型 *指针变量名;`

```c
int *p;        /* 定义 p 是指向 int 型数据的指针变量 */
float *q;      /* q 只能指向 float 型数据 */
char *r;       /* r 只能指向 char 型数据 */
```

- `*` 只是**说明符**，表示"后面这个变量是指针"，不是运算符。`int *p;` 里 p 的类型是 `int *`。
- 刚定义的指针**里面是随机值**，必须赋了地址才能用（否则是野指针，见 8.8）。
- 赋值只能赋**同类型变量的地址**：

```c
int m = 10, *p;
p = &m;            /* ✔ 正确：把 int 型变量 m 的地址赋给 int 型指针 p */
```

★ 考点（2025 山西真题·填空题原题）：已有说明语句 `float *p, m = 3.14;`，要让指针变量 p 指向 m，应填的赋值语句是 **`p = &m;`**。

为什么不是别的写法：
- ✘ `p = m;` —— 类型不匹配，p 是指针，m 是 float 值（编译报错或警告）。
- ✘ `*p = &m;` —— `*p` 是 float 型单元，`&m` 是地址，类型不匹配。
- ✘ `p = *m;` —— `*m` 对普通变量用解引用，语法错误。
- ✔ `p = &m;` —— 取出 m 的地址放进 p，正是"让 p 指向 m"。

```c-run
#include <stdio.h>

int main(void) {
    float *p, m = 3.14f;
    p = &m;
    printf("%.2f\n", *p);
    return 0;
}
```

```text
3.14
```

```answer 参考答案
输出的就是 m 的值 `3.14`（`*p` 与 `m` 是同一块内存的两种写法）。

**踩分点**：题目问的是"赋值语句"，答案要写完整的 `p = &m;`（带分号），只写 `&m` 或 `p=&m` 都可能被判不规范。考场上先判断**谁是地址、谁是普通变量**：`&m` 是地址，`p` 是指针变量，地址只能赋给指针。
```

**4. `*` 的三重含义（选择、填空题的经典陷阱）**

同一个 `*`，出现在三个位置，意思完全不同，判断方法只有一条：**看它左边有没有类型名**。

| 出现位置 | 例子 | 含义 | 判断依据 |
|------|------|------|------|
| 类型名后面（定义/声明中） | `int *p;` `float *q;` | 说明符，"p 是指针" | `*` 左边紧挨着类型名 `int` |
| 表达式中，单目 | `*p = 25;` `x = *p;` | 解引用，取内容 | `*` 左边没有类型名 |
| 两个变量之间，双目 | `c = a * b;` | 乘法 | 两边都是变量/表达式 |

```c
int a = 3, b = 4, c;
int *p = &a;
c = a * b;        /* 这里是乘法：c = 12 */
c = *p * b;       /* 第一个 * 是解引用（得 3），第二个 * 是乘法：c = 12 */
```

⚠ 判断口诀：**左有类型是说明，左无类型是取内容，左右都有是乘法。**

**5. 指针变量"自己的类型"和"它指向的类型"**

| 说明语句 | p 自己的类型 | p 指向的类型 | 能指向谁 |
|------|:---:|:---:|------|
| `int *p;` | `int *` | `int` | 只能指向 int 型变量 |
| `float *p;` | `float *` | `float` | 只能指向 float 型变量 |
| `char *p;` | `char *` | `char` | 只能指向 char 型数据 |

- 指针的基类型决定了**一次 `p+1` 走多少个字节**：`int *p` 加 1 走 4 字节，`char *p` 加 1 走 1 字节。
- 所以「指针加 1」不是地址值加 1，而是**跳过它所指类型的一个元素**。

**6. 指针占几个字节：与类型无关**

```c-run
#include <stdio.h>

int main(void) {
    int *p = NULL;
    char *q = NULL;
    double *r = NULL;
    /* 三个不同类型的指针，占用的字节数完全相同 */
    printf("%d %d\n", sizeof(p) == sizeof(q), sizeof(p) == sizeof(r));
    return 0;
}
```

```text
1 1
```

```answer 运行结果与追踪
两个 `1` 表示 `sizeof(int *)`、`sizeof(char *)`、`sizeof(double *)` **完全相等**。

| 表达式 | 含义 | 结果 |
|------|------|:---:|
| `sizeof(p)` | int 型指针占的字节数 | 与下面两个相同 |
| `sizeof(q)` | char 型指针占的字节数 | 与上面相同 |
| `sizeof(p) == sizeof(q)` | 是否相等 | 1（真） |
| `sizeof(p) == sizeof(r)` | 是否相等 | 1（真） |

**结论**：指针变量占几个字节，只跟**机器/编译器**有关，跟它指向什么类型**无关**。原因是所有地址的位数都一样（本质上都是一个编号）。
```

📌 考试提醒：山西专升本的卷子按 **32 位环境**出题，**指针一律按 4 字节算**（不管 `int *` 还是 `double *`）。你在自己电脑上（64 位编译器）用 `printf("%d", sizeof(int *));` 看到的是 **8**，这是正常的，考场上写 **4**。

**7. 易错清单**

⚠ `int *p, q;` 只定义了**一个**指针 `p`，`q` 是普通 int 变量。想定义两个指针必须写 `int *p, *q;`。

⚠ `*p` 里的 p 必须**已经指向某个有效变量**。`int *p; *p = 5;` 是往随机地址写数据 —— 未定义行为（可能崩溃，也可能悄悄改坏别的变量），绝不能这么写。

⚠ 不要写 `p = 1000;`。指针只能赋**地址**（`&变量`、数组名、另一个指针），不能赋整数。

⚠ `&` 只能作用于**变量或数组元素**，`&(a+b)`、`&3` 都是错的。

💡 口诀：**`&` 取地址，`*` 取内容；定义时的 `*` 不是运算符；指针加 1 跳一个"它指的类型"。**

## 8.2 指针与一维数组 ★★★

★ 考点：数组名就是首元素地址；`a[i]` 与 `*(a+i)` 完全等价；`*(p+i)`、`*++p`、`*p++`、`(*p)++` 的区别（**程序阅读题最爱考的陷阱**）；用指针遍历数组。

**1. 数组名到底是什么**

`int a[5];` 中，数组名 `a` 代表**首元素地址**，即 `a` 等价于 `&a[0]`，它的类型是 `int *`。

内存示意（`int a[5] = {1, 2, 3, 4, 5};`，假设首地址是 0x1000）：

| 元素 | a[0] | a[1] | a[2] | a[3] | a[4] |
|------|:---:|:---:|:---:|:---:|:---:|
| 地址 | 0x1000 | 0x1004 | 0x1008 | 0x100C | 0x1010 |
| 内容 | 1 | 2 | 3 | 4 | 5 |
| 指针写法 | `*a` | `*(a+1)` | `*(a+2)` | `*(a+3)` | `*(a+4)` |
| 下标写法 | `a[0]` | `a[1]` | `a[2]` | `a[3]` | `a[4]` |

★ 必背结论：**`a[i]` ≡ `*(a+i)` ≡ `*(p+i)`（当 `p = a` 时）**。这不是巧合，是 C 语言的规定：`a[i]` 在编译时就被翻译成 `*(a+i)`。

📌 冷知识（选择题可能出现）：既然 `*(a+i)` 里的加法可以交换，那么 `i[a]` 也合法，和 `a[i]` 等价。知道就行，别在程序设计题里这么写。

**2. 指针变量指向数组**

```c
int a[5] = {1, 2, 3, 4, 5};
int *p = a;              /* 等价于 int *p = &a[0]; */
```

- `p[i]`、`*(p+i)`、`a[i]` 三者可以互换。
- **`a` 是地址常量，不能自增**；**`p` 是指针变量，可以自增**。这是两者最本质的区别。

✘ 错误写法：

```c
int a[5], i;
for (i = 0; i < 5; i++) printf("%d", *a++);
```

**编译错误**：`a++` 相当于 `a = a + 1`，而数组名不是可修改的左值（它是常量地址）。

✔ 正确写法：

```c
int a[5] = {1, 2, 3, 4, 5}, i;
int *p = a;
for (i = 0; i < 5; i++) printf("%d", *p++);
```

**3. 四种写法必须分清（本节的核心）**

| 表达式 | 结合顺序 | 表达式本身的值 | 执行后 p 指向 | 数组元素有没有被改 |
|------|------|------|:---:|:---:|
| `*p` | `*(p)` | `a[0]` | 不变 | 没改 |
| `*(p+i)` | `*(p+i)` | `a[i]` | 不变 | 没改 |
| `*++p` | `*(++p)` | `a[1]` | 后移 1 个 | 没改 |
| `*p++` | `*(p++)` | `a[0]`（旧位置的值） | 后移 1 个 | 没改 |
| `(*p)++` | `((*p))++` | `a[0]` 的**原值** | 不变 | **a[0] 加了 1** |

★ 一句话分辨（背下来）：

- `++` 在 `*` **右边**（`*p++`）→ **先取值，指针后移**；
- `++` 在 `*` **左边**（`*++p`）→ **指针先移，再取值**；
- 括号把 `*p` **整个括住**（`(*p)++`）→ 动的是**数组元素**，指针不动。

原因是优先级：**后缀 `++` > 前缀 `++` 和单目 `*`**；前缀 `++` 与 `*` 同优先级，从右往左结合。

**4. 例题：`*p++` 系列追踪**

```c-run
#include <stdio.h>

int main(void) {
    int a[5] = {10, 20, 30, 40, 50};
    int *p = a;
    printf("%d ", *p++);      /* 先取 *p，再 p++ */
    printf("%d ", *++p);      /* 先 ++p，再取 *p */
    printf("%d ", (*p)++);    /* 先取 *p，再把 a[2] 加 1 */
    printf("%d ", *p);
    printf("%d ", *p--);
    printf("%d\n", *p);
    printf("%d %d %d\n", a[1], a[2], a[3]);
    return 0;
}
```

```text
10 30 30 31 31 20
20 31 40
```

```answer 运行结果与追踪
**输出**

```text
10 30 30 31 31 20
20 31 40
```

**逐语句追踪表（考试就按这张表写）**

| 语句 | p 指向 | `*p` 的值 | 表达式输出的值 | a 数组的变化 |
|------|:---:|:---:|:---:|------|
| `int *p = a;` | a[0] | 10 | — | {10,20,30,40,50} |
| `*p++` | a[0] → **a[1]** | 10 → 20 | **10** | 不变 |
| `*++p` | a[1] → **a[2]** | 30 | **30** | 不变 |
| `(*p)++` | a[2] | 30 → 31 | **30** | **a[2] 变成 31** |
| `*p` | a[2] | 31 | **31** | 不变 |
| `*p--` | a[2] → **a[1]** | 31 → 20 | **31** | 不变 |
| `*p` | a[1] | 20 | **20** | 不变 |
| 最后一行 printf | a[1] | 20 | 20 31 40 | a[1]=20, a[2]=31, a[3]=40 |

**易错点**

1. 第二句 `*++p` 是**先移后取**，从 a[1] 移到 a[2]，所以是 30 不是 20。很多人这里写 20，就是把 `*++p` 当成了 `*p++`。
2. `(*p)++` 改的是**数组元素 a[2]**，不是 p。所以后面 `*p` 输出 31，并且最后一行 a[2] 也是 31。
3. `*p--` 与 `*p++` 同理，先取值再后退。
```

**5. 例题：`a[i]` 与 `*(a+i)` 的等价性**

```c-run
#include <stdio.h>

int main(void) {
    int a[5] = {1, 2, 3, 4, 5};
    int *p = a;                      /* 等价于 int *p = &a[0]; */
    printf("%d %d %d\n", a[2], *(a + 2), *(p + 2));
    printf("%d %d\n", *p, *(p + 4));
    printf("%d\n", (int)(&a[3] - p));  /* 两个指针相减 = 相隔元素个数 */
    return 0;
}
```

```text
3 3 3
1 5
3
```

```answer 运行结果与追踪
**输出**

```text
3 3 3
1 5
3
```

| 语句 | p 指向 | `*p` 的值 | 输出 |
|------|:---:|:---:|:---:|
| `int *p = a;` | a[0] | 1 | — |
| `a[2]` | a[0] | 1 | 3 |
| `*(a+2)` | a[0] | 1 | 3 |
| `*(p+2)` | a[0] | 1 | 3 |
| `*p` | a[0] | 1 | 1 |
| `*(p+4)` | a[0] | 1 | 5 |
| `&a[3] - p` | a[0] | 1 | 3 |

**两个结论**

1. `a[2]`、`*(a+2)`、`*(p+2)` 输出完全相同 → 三种写法等价。
2. **两个指针相减**得到的是"相隔多少个元素"，不是相隔多少字节。`&a[3] - p` = 3（从 a[0] 到 a[3] 隔 3 个元素，虽然地址差了 12 字节）。指针相减的前提是两个指针指向**同一个数组**。
```

**6. 例题：用指针遍历数组求和**

```c-run
#include <stdio.h>

int main(void) {
    int a[6] = {3, 1, 4, 1, 5, 9};
    int *p = a;
    int sum = 0, i;
    for (i = 0; i < 6; i++) sum += *(p + i);
    printf("%d\n", sum);
    sum = 0;
    for (p = a; p < a + 6; p++) sum += *p;
    printf("%d\n", sum);
    return 0;
}
```

```text
23
23
```

```answer 运行结果与追踪
**输出**

```text
23
23
```

| 循环 | p 的移动方式 | 每次取的元素 | sum 累加过程 |
|------|------|------|------|
| 第一种 | p **不动**，用 `*(p+i)` | a[0]…a[5] | 3 → 4 → 8 → 9 → 14 → **23** |
| 第二种 | p **每次后移**，用 `*p` | a[0]…a[5] | 3 → 4 → 8 → 9 → 14 → **23** |

两种写法结果一样。**第二种是考试的标准写法**（模板）：

```c
int *p = a, sum = 0;
for (p = a; p < a + n; p++) sum += *p;
```

注意循环条件 `p < a + n`：`a + n` 是**数组最后一个元素后面那个位置**的地址，p 走到它时就停，正好取完 n 个元素，没有越界。
```

**7. 易错清单**

⚠ **`*p+1` 与 `*(p+1)` 完全不同**：单目 `*` 优先级高于加法，`*p+1` 是 `(*p)+1`（值加 1），`*(p+1)` 才是"下一个元素"。若 `a[0]=10`，则 `*p+1` = 11，`*(p+1)` = a[1]。

⚠ `a++`、`a = p`、`a += 1` 一律**编译错误**，数组名不是可修改的左值。

⚠ `sizeof(a)` 是**数组占的总字节数**（`int a[5]` 得 20），`sizeof(a)/sizeof(a[0])` 才是元素个数 5；但 `sizeof(p)` 只是指针自己的字节数（4 或 8），**不能**用它求数组长度。这是"指针传参丢失长度"的根源（见 8.4）。

⚠ 指针越界**编译器不会报错**：`int a[5]; int *p = a; p += 10; *p = 1;` 能编译通过，运行结果不确定（可能"看起来正常"，也可能直接崩溃），因为它已经写坏了别的内存 —— 属于未定义行为。

💡 口诀：**`a[i]` 就是 `*(a+i)`；`a` 不能跑，`p` 能跑；`++` 在右先取值，`++` 在左先移动，括号一括改元素。**

## 8.3 指针与字符串 ★★★

★ 考点：字符指针指向字符串的**首字符**；`s += 3` 后 `%s` 输出什么（**2025 山西真题·填空题原题**）；用指针遍历、计数、逆置、复制字符串；字符数组名与字符指针的区别。

**1. 字符串在内存里长什么样**

C 语言没有"字符串类型"。一个字符串 = 一串字符 + 结尾的结束标记 `'\0'`（ASCII 值为 0）。

`char *s = "program";` 的内存示意：

| 下标 | 0 | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
|:---:|:---:|:---:|:---:|:---:|:---:|:---:|:---:|:---:|
| 字符 | p | r | o | g | r | a | m | `'\0'` |
| 地址 | 0x2000 | 0x2001 | 0x2002 | 0x2003 | 0x2004 | 0x2005 | 0x2006 | 0x2007 |

| 表达式 | 含义 | 值 |
|------|------|:---:|
| `s` | 首字符的地址 | 0x2000 |
| `*s` | 首字符 | `'p'` |
| `*(s+3)` | 第 4 个字符 | `'g'` |
| `s[3]` | 同上，下标写法 | `'g'` |

★ 三个必背结论：

1. **字符指针指向的是首字符，不是整个字符串**。
2. `printf("%s", s)` 里的 `%s` 要的是**地址**，它从该地址开始一个字符一个字符输出，遇到 `'\0'` 停止。
3. `%c` 输出**一个字符**，要配 `*s` 或 `s[i]`；`%s` 输出**一个字符串**，要配 `s`。写反了程序就崩。

**2. 2025 山西真题（填空题原题）**

题目：`char *s = "program"; s += 3; printf("%s", s);` 的输出结果是 ______。

```c-run
#include <stdio.h>

int main(void) {
    char *s = "program";
    s += 3;
    printf("%s\n", s);
    return 0;
}
```

```text
gram
```

```answer 参考答案与追踪
**输出 `gram`**

| 语句 | s 指向的字符 | s 相对首字符的偏移 | 输出 |
|------|:---:|:---:|:---:|
| `char *s = "program";` | `'p'` | 0 | — |
| `s += 3;` | `'g'` | 3 | — |
| `printf("%s", s);` | 从 `'g'` 开始 | 3 | **gram** |

**为什么是 gram 而不是 program**：`s += 3` 让 s 从首字符 `'p'` 向后跳过 3 个字符（p、r、o），落到 `'g'` 上。`%s` 从 s 当前所指的位置开始输出，一直到 `'\0'`，所以只剩 `gram` 这 4 个字符。

**易错提醒**

1. ✘ 写 `program`：以为 `s += 3` 没影响。
2. ✘ 写 `gram\0`：`'\0'` 是结束标记，**不会**被输出。
3. ✘ 写 `ogram`：偏移数错了，`s += 3` 是跳过 3 个字符（下标 0、1、2），停在**下标 3**。
```

**3. 用指针遍历字符串的三种写法**

```c
char *s = "China";
while (*s != '\0') { printf("%c", *s); s++; }   /* 标准写法 */
while (*s) { printf("%c", *s); s++; }           /* '\0' 的 ASCII 是 0，等价 */
for (; *s != '\0'; s++) printf("%c", *s);       /* for 写法 */
```

三个写法完全等价，都靠 **`*s` 是否为 `'\0'`** 判断结束。

⚠ 致命错误：`while (s != '\0')` —— 这里把**指针**和**字符**比较了，条件永远为真（s 是个非空地址），程序会一直跑下去直到崩溃。必须写成 `while (*s != '\0')`（注意那个 `*`）。

**4. 例题：统计字符串中的字母、数字和其他字符**

```c-run
#include <stdio.h>

int main(void) {
    char *s = "Hello World 2025";
    int letters = 0, digits = 0, others = 0;
    while (*s != '\0') {
        if ((*s >= 'a' && *s <= 'z') || (*s >= 'A' && *s <= 'Z')) letters++;
        else if (*s >= '0' && *s <= '9') digits++;
        else others++;
        s++;
    }
    printf("%d %d %d\n", letters, digits, others);
    return 0;
}
```

|------|------|:---:|
| 字母 | H e l l o W o r l d | 10 |
| 数字 | 2 0 2 5 | 4 |
| 其他 | 两个空格 | 2 |

**追踪要点**

1. 每轮循环先判断 `*s` 是哪一类，再 `s++` 往后移一个字符。
2. `*s >= 'a' && *s <= 'z'` 用的是**字符的比较**，本质是比较 ASCII 码（`'a'`=97，`'z'`=122）。也可以用 `islower(*s)`（需要 `#include <ctype.h>`），但考试里手写比较更稳。

**5. 例题：用指针逆置字符串**

```c-run
#include <stdio.h>
#include <string.h>

int main(void) {
    char s[] = "abcdef";
    char *p = s;                       /* 指向首字符 */
    char *q = s + strlen(s) - 1;       /* 指向最后一个字符 */
    char t;
    while (p < q) {                    /* 首尾交换 */
        t = *p;
        *p = *q;
        *q = t;
        p++;
        q--;
    }
    printf("%s\n", s);
    return 0;
}
```

```

```answer 运行结果与追踪
**输出 `fedcba`**

| 轮次 | p 指向 | q 指向 | 交换后 s |
|:---:|:---:|:---:|:---:|
| 初始 | a | f | abcdef |
| 第 1 轮 | a ↔ f | | **f**bcde**a** |
| 第 2 轮 | b ↔ e | | f**e**cd**b**a |
| 第 3 轮 | c ↔ d | | fe**dc**ba |
| 结束时 | p 与 q 相遇（p > q），循环停止 | | fedcba |

**关键点**

1. `q = s + strlen(s) - 1`：`strlen(s)` 是 6（不含 `'\0'`），所以最后一个字符在偏移 5 处，即 `s + 5`。
2. 这里必须用**字符数组** `char s[] = "abcdef";` 而不能用 `char *s = "abcdef";` —— 因为要**修改**字符串内容，字符指针指向的是常量区，不可修改（见下面第 7 条）。
3. `p < q` 用指针比较当循环条件，比用下标 `i < j` 更符合指针题的要求；`p == q`（长度为奇数，中间那个字符）时不用交换，所以条件写 `<` 而不是 `<=`。

**7. 字符数组名 vs 字符指针（选择题必考对比）**

| 对比项 | `char s[] = "abc";` | `char *s = "abc";` |
|------|------|------|
| s 的身份 | 数组名（首元素地址，**常量**） | 指针**变量** |
| 能否 `s++` / `s += 3` | ✘ 编译错误 | ✔ 可以 |
| 能否改内容 `s[0] = 'X'` | ✔ 可以（数组在栈上，可写） | ✘ **运行时崩溃**（字符串常量在只读区） |
| 能否整体换一个字符串 `s = "xyz";` | ✘ 不可以 | ✔ 可以（改的是指针指向） |
| `sizeof(s)` | 4（3 个字符 + `'\0'`） | 指针本身的字节数（4 或 8），**不是字符串长度** |
| 求长度 | `strlen(s)` = 3 | `strlen(s)` = 3 |

✘ 危险写法（**编译能过，运行崩溃**）：

```c
char *s = "program";
s[0] = 'P';        /* 试图修改常量区的字符串：运行时访问违规 */
```

本机实测：程序以访问违规（0xC0000005）异常结束。要修改内容，必须用字符数组：

```c
char s[] = "program";
s[0] = 'P';        /* ✔ 正确：改的是数组自己的可写空间 */
```

**8. 易错清单**

⚠ `char *s; scanf("%s", s);` —— **野指针**！s 没有指向任何有效空间，输入会写进随机内存导致崩溃。正确做法：`char s[20]; scanf("%s", s);`（数组已经分配了 20 字节），或用 `char *s = (char *)malloc(20);`。

⚠ `scanf("%s", s)` 里的 s **不能**写成 `&s`：数组名本身就是地址。但 `scanf("%d", &n)` 里的 `&` 不能丢。规律：**输入字符串/数组用名字，输入单个变量用 `&`**。

⚠ `printf("%c", s);` 是错的（`%c` 要字符，s 是地址）；`printf("%s", *s);` 也是错的（`%s` 要地址，`*s` 是字符）。这两个错在改错题里反复出现。

⚠ 字符串不能比较、不能赋值：`if (s1 == s2)` 比的是两个地址，不是内容；要用 `strcmp(s1, s2) == 0`。`s1 = s2;` 只改指针指向，不是复制内容；复制要用 `strcpy`。

💡 口诀：**字符指针能跑不能改，字符数组能改不能跑；`%s` 要地址，`%c` 要字符；数到 `*s == '\0'` 就收工。**

## 8.4 指针作为函数参数 ★★★

★ 考点：**指针传参才能真正改变实参**（与值传递对比）；用指针"返回"多个结果；数组名作实参的本质。程序阅读、程序填空、程序设计三种题型都会考。

**1. 值传递：形参只是实参的副本**

```c
#include <stdio.h>

void f(int x) { x = 100; }        /* 改的是形参 x，不是实参 a */
int main(void) {
    int a = 5;
    f(a);
    printf("%d\n", a);            /* 输出 5，a 没变 */
    return 0;
}
```

**原因**：调用 `f(a)` 时，系统为形参 x **另开一块空间**，把 a 的值拷进去。函数里改的是 x 那块空间，函数一结束 x 就没了，a 从头到尾没被碰过。

| 位置 | 变量 | 内容 | 说明 |
|------|:---:|:---:|------|
| main | a | 5 | 实参 |
| f | x | 5 → 100 | 形参（a 的副本，独立空间）|
| 返回后 | a | **5** | a 从未被修改 |

**2. 地址传递：形参是指针，指向实参**

```c
#include <stdio.h>

void swap2(int *x, int *y) {
    int t = *x;  *x = *y;  *y = t;
}
int main(void) {
    int a = 3, b = 8;
    swap2(&a, &b);        /* 传的是地址 */
    printf("%d %d\n", a, b);
    return 0;
}
```

**原因**：传 `&a` 之后，形参 x 里存的就是 a 的地址，`*x` 就是 a 本身。所以 `*x = *y;` 真的把 a 改掉了。

| 位置 | 变量 | 内容 | 说明 |
|------|:---:|:---:|------|
| main | a / b | 3 / 8 | 实参 |
| swap2 | x / y | &a / &b | 形参指针，**指向**实参 |
| swap2 | `*x` / `*y` | 3 / 8 | 就是 a、b 本人 |
| 执行后 | a / b | **8 / 3** | 真正交换成功 |

★ 一句话结论：**函数里改 `*x` 能改实参，改 `x` 不能。** 因为 `x` 只是形参自己，`*x` 才是主调函数里的变量。

**3. 例题：交换两个数（正反两版对照）**

```c-run
#include <stdio.h>

void swap1(int x, int y) {          /* 值传递：改不动实参 */
    int t = x;
    x = y;
    y = t;
}

void swap2(int *x, int *y) {        /* 地址传递：真正交换 */
    int t = *x;
    *x = *y;
    *y = t;
}

int main(void) {
    int a = 3, b = 8;
    swap1(a, b);
    printf("%d %d\n", a, b);
    swap2(&a, &b);
    printf("%d %d\n", a, b);
    return 0;
}
```

```text
3 8
8 3
```

```answer 运行结果与追踪
**输出**

```text
3 8
8 3
```

**第一次调用 `swap1(a, b)`：交换失败**

| 语句 | a | b | x | y |
|------|:---:|:---:|:---:|:---:|
| 调用前 | 3 | 8 | — | — |
| 进入 swap1（x、y 是副本） | 3 | 8 | 3 | 8 |
| `t = x;` | 3 | 8 | 3 | 8（t=3）|
| `x = y;` | 3 | 8 | **8** | 8 |
| `y = t;` | 3 | 8 | 8 | **3** |
| 返回主函数 | **3** | **8** | 已销毁 | 已销毁 |

形参 x、y 确实交换了，但它们和 a、b 是**两块不同的内存**，函数一返回就销毁。所以 a、b 原封不动。

**第二次调用 `swap2(&a, &b)`：交换成功**

| 语句 | a | b | x | y |
|------|:---:|:---:|:---:|:---:|
| 调用前 | 3 | 8 | — | — |
| 进入 swap2 | 3 | 8 | &a（指向 a） | &b（指向 b） |
| `t = *x;` | 3 | 8 | &a | &b（t=3）|
| `*x = *y;` | **8** | 8 | &a | &b |
| `*y = t;` | 8 | **3** | &a | &b |
| 返回主函数 | **8** | **3** | 已销毁，但 a、b 已被改 | |

**关键区别**：x、y 虽然也会销毁，但它们在销毁前**通过 `*x`、`*y` 修改了 main 里的 a、b**。

**考试写法提醒**：调用时必须写 `swap2(&a, &b)`，**不能**写 `swap2(a, b)`（类型不匹配）。
```

**4. 例题：用指针"返回"多个结果**

C 函数的 `return` 只能带回一个值。想同时得到最大值和最小值，就把**存放结果的两个变量的地址**传进去。

```c-run
#include <stdio.h>

void maxmin(int a[], int n, int *pmax, int *pmin) {
    int i;
    *pmax = *pmin = a[0];
    for (i = 1; i < n; i++) {
        if (a[i] > *pmax) *pmax = a[i];
        if (a[i] < *pmin) *pmin = a[i];
    }
}

int main(void) {
    int a[5] = {5, 3, 9, 1, 7};
    int max, min;
    maxmin(a, 5, &max, &min);       /* 用两个指针"带回"两个结果 */
    printf("%d %d\n", max, min);
    return 0;
}
```

```text
9 1
```

```answer 运行结果与追踪
**输出 `9 1`**

| i | a[i] | `*pmax` | `*pmin` | 判断过程 |
|:---:|:---:|:---:|:---:|------|
| 初始 | — | 5 | 5 | `*pmax = *pmin = a[0];` |
| 1 | 3 | 5 | **3** | `3 > 5` 不成立 → pmax 不变；`3 < 5` 成立 → pmin = 3 |
| 2 | 9 | **9** | 3 | `9 > 5` 成立 → pmax = 9；`9 < 3` 不成立 → pmin 不变 |
| 3 | 1 | 9 | **1** | `1 > 9` 不成立；`1 < 3` 成立 → pmin = 1 |
| 4 | 7 | 9 | 1 | 两个条件都不成立，都不变 |

**最终 max = 9、min = 1。**

**设计要点**

1. `*pmax = *pmin = a[0];` 先把两个结果都初始化成第一个元素，避免拿随机值去比较。
2. 形参 `int *pmax, int *pmin` 是**输出参数**：函数不通过 return，而是"写进调用者给的地址里"。
3. 调用时传 `&max, &min`，函数里写 `*pmax`、`*pmin` 就等于写 max、min。
4. 这种"输入参数 + 输出指针"的写法是程序设计题的标准套路：**要带回几个结果，就传几个指针**。
```

**5. 数组名作实参的本质**

- 调用 `maxmin(a, 5, &max, &min)` 时，数组名 `a` 传过去的是**首元素地址**，不是整个数组的拷贝。
- 所以形参写成 `int a[]` 和写成 `int *a` **完全等价**，函数里 `a[i]`、`*(a+i)`、`p[i]` 都能用。
- 函数里对 `a[i]` 的修改，会真正改到主调函数的数组 —— 这就是"数组能带回结果，普通变量不能"的根本原因。

⚠ **长度必须另传**：形参 `int a[]` 已经退化成指针，函数里 `sizeof(a)` 得到的是**指针的字节数**（4 或 8），不是数组长度。所以标准写法是把长度一起传：`void f(int a[], int n)`。

**6. 易错清单**

⚠ 想改实参就必须传地址：`swap2(&a, &b)` ✔，`swap2(a, b)` ✘（编译错误或警告，且改不动）。

⚠ 函数里把**形参指针本身**改掉是没用的：

```c
void swapA(int *x, int *y) { int *t = x; x = y; y = t; }   /* 白改：只换了形参自己 */
```

`x`、`y` 是 main 传来的地址的**副本**，换掉它们不影响 main 里的 a、b（详见 8.8 题 4）。

⚠ 只传了地址但忘了"解引用"：`void f(int *p) { p = 100; }` —— 把 100 赋给指针变量，类型不匹配；应该是 `*p = 100;`。

⚠ 数组作形参时不要试图用 `sizeof(a)/sizeof(a[0])` 求长度，答案恒为 1 或 2（在 64 位下 `sizeof(int*)/sizeof(int)` = 2），一定是错的。

💡 口诀：**要改实参，就传地址；函数里改 `*p` 才算数，改 `p` 白费劲；数组名作参数传的是首地址，长度得另外给。**

## 8.5 指针与二维数组 ★★

★ 考点：二维数组名是**行指针**；`a[i][j]`、`*(*(a+i)+j)`、`*(a[i]+j)` 三种写法等价；用一级指针遍历二维数组；`int (*p)[4]` 与 `int *p[4]` 的区别（**选择题高频**）。

**1. 二维数组的行与列**

`int a[3][4];` 要理解成"**3 个元素，每个元素是 `int[4]`**"——也就是"数组的数组"。

内存示意（`int a[2][3] = {{1, 2, 3}, {4, 5, 6}};`，按行连续存放）：

| 行 \ 列 | 第 0 列 | 第 1 列 | 第 2 列 | 行首地址 |
|:---:|:---:|:---:|:---:|:---:|
| a[0] | 1 | 2 | 3 | 0x1000 |
| a[1] | 4 | 5 | 6 | 0x100C |

★ **三种写法完全等价**（必背）：

| 写法 | 含义 |
|------|------|
| `a[i][j]` | 下标写法 |
| `*(*(a+i)+j)` | 指针写法（考试最爱考） |
| `*(a[i]+j)` | 混合写法 |

分步拆开看 `*(*(a+i)+j)`：

| 表达式 | 含义 | 类型 |
|------|------|------|
| `a` | 第 0 行的地址（**行指针**） | `int (*)[3]` |
| `a + i` | 第 i 行的地址 | `int (*)[3]` |
| `*(a+i)` 即 `a[i]` | 第 i 行**首元素**的地址 | `int *` |
| `*(a+i)+j` 即 `a[i]+j` | 第 i 行第 j 列元素的地址 | `int *` |
| `*(*(a+i)+j)` | 第 i 行第 j 列元素的值 | `int` |

📌 `a` 是行指针，所以 **`a + 1` 不是移动 1 个字节、也不是移动 1 个元素，而是移动一整行（3 个 int = 12 字节）**。这是二维数组题最容易错的地方。

**2. 例题：sizeof 三连（看清"一行有多少字节"）**

```c-run
#include <stdio.h>

int main(void) {
    int a[3][4] = {{0}};
    printf("%d %d %d\n", (int)sizeof(a), (int)sizeof(a[0]), (int)sizeof(a[0][0]));
    return 0;
}
```

```text
48 16 4
```

```answer 运行结果与追踪
**输出 `48 16 4`**

| 表达式 | 含义 | 计算 | 结果 |
|------|------|------|:---:|
| `sizeof(a)` | 整个二维数组 | 3 行 × 4 列 × 4 字节 | 48 |
| `sizeof(a[0])` | 一行 | 4 × 4 字节 | 16 |
| `sizeof(a[0][0])` | 一个元素 | 1 × 4 字节 | 4 |

**由此得到两个常用公式**

- 行数 = `sizeof(a) / sizeof(a[0])` = 48 / 16 = 3
- 列数 = `sizeof(a[0]) / sizeof(a[0][0])` = 16 / 4 = 4

**注意**：`a[0]` 是"第 0 行"这个一维数组的**数组名**，所以 `sizeof(a[0])` 才能得到一整行的大小；如果你把二维数组名传给了函数（退化成指针），这两个公式就失效了，长度必须另外传。
```

**3. 例题：三种写法等价 + 一级指针遍历**

```c-run
#include <stdio.h>

int main(void) {
    int a[2][3] = {{1, 2, 3}, {4, 5, 6}};
    int *p = &a[0][0];              /* 一级指针指向二维数组的首元素 */
    int i, sum = 0;
    for (i = 0; i < 6; i++) sum += *(p + i);
    printf("%d %d %d\n", a[1][2], *(*(a + 1) + 2), *(a[1] + 2));
    printf("%d %d\n", *(p + 1 * 3 + 2), sum);
    return 0;
}
```

```text
6 6 6
6 21
```

```answer 运行结果与追踪
**输出**

```text
6 6 6
6 21
```

**第一行：三种写法输出同一个数**

| 写法 | 计算过程 | 值 |
|------|------|:---:|
| `a[1][2]` | 第 1 行第 2 列 | 6 |
| `*(*(a+1)+2)` | 先 `a+1` 到第 1 行，解引用得该行首元素地址，再 +2 解引用 | 6 |
| `*(a[1]+2)` | `a[1]` 是第 1 行首元素地址，+2 后解引用 | 6 |

**第二行：一级指针按行优先顺序扫**

`p = &a[0][0]` 指向 1，内存里 6 个元素是**连续存放**的：1 2 3 4 5 6。

| 表达式 | 偏移量 | 指向的元素 |
|------|:---:|:---:|
| `*(p + 0)` | 0 | 1 |
| `*(p + 1*3 + 2)` | 5 | **6** |
| `sum` | 累加全部 6 个 | 1+2+3+4+5+6 = **21** |

**核心公式**：二维数组用一级指针访问时，`a[i][j]` 对应 `*(p + i * 列数 + j)`，其中**列数必须写对**（这里是 3）。总元素个数 = 行数 × 列数 = 2 × 3 = 6。
```

**4. 例题：用行指针遍历二维数组**

```c-run
#include <stdio.h>

int main(void) {
    int a[2][3] = {{1, 2, 3}, {4, 5, 6}};
    int (*p)[3] = a;                /* 行指针：p 指向"一行"，一行有 3 个 int */
    int i, j, sum = 0;
    for (i = 0; i < 2; i++)
        for (j = 0; j < 3; j++)
            sum += p[i][j];
    printf("%d %d\n", p[1][2], *(*(p + 1) + 1));
    printf("%d %d\n", (int)sizeof(*p), sum);
    return 0;
}
```

```text
6 5
12 21
```

```answer 运行结果与追踪
**输出**

```text
6 5
12 21
```

| 表达式 | 含义 | 值 |
|------|------|:---:|
| `p[1][2]` | 第 1 行第 2 列 | 6 |
| `*(*(p+1)+1)` | 第 1 行第 1 列 | 5 |
| `sizeof(*p)` | `*p` 是"一行"，类型 `int[3]` | **12**（3 × 4 字节）|
| `sum` | 全部 6 个元素之和 | 21 |

**行指针的两个关键性质**

1. `int (*p)[3] = a;` 中 p 的类型是 `int (*)[3]`，与二维数组名 `a` 的类型**一致**，所以能直接赋值。
2. **`p + 1` 跳一整行（12 字节）**，而 `*p` 是"第 0 行"这个数组，`*p + 1` 才跳一个元素（4 字节）。

**不能这样写**：`int *p = a;` —— `a` 的类型是 `int (*)[3]`，与 `int *` 不匹配（编译警告/错误）。要一级指针就得写 `int *p = a[0];` 或 `int *p = &a[0][0];`。
```

**5. 行指针 vs 指针数组（选择题必考）**

| 写法 | 名称 | 到底是什么 | 典型用法 |
|------|------|------|------|
| `int (*p)[4];` | **行指针**（数组指针） | p 是**指针**，指向"含 4 个 int 的一维数组" | `p = a;` 遍历二维数组 |
| `int *p[4];` | **指针数组** | p 是**数组**，里面放 4 个 `int *` | `p[0] = &x; p[1] = &y;` |
| `int (*p)(int);` | 函数指针 | p 是**指针**，指向函数 | `p = add;` 通过指针调用函数 |

★ 判断口诀：**看括号。`(*p)` 先结合 → p 是指针；`*p[4]` 因为 `[]` 优先级高于 `*` → p 先是数组。**

- `int (*p)[4]` 中 `p + 1` 走 16 字节（一整行）；`int *p[4]` 中 `p + 1` 走一个"指针元素"的大小。
- 选择题常见问法："`int (*p)[4]` 中 p 是（ ）" → 答案：**指向含 4 个整型元素的一维数组的指针**（行指针）。

**6. 易错清单**

⚠ `int **p = a;` ✘ —— 二维数组名**不是**二级指针（它是行指针）。这是概念题最爱出的错项。


⚠ `int *p = a;` ✘ 类型不匹配。要一级指针必须写 `int *p = a[0];` 或 `int *p = &a[0][0];`。

⚠ `*(a+i)` 不是"第 i 行的值"，而是**第 i 行首元素的地址**。想取值要再解引用一次：`*(*(a+i)+j)`。

⚠ 行指针 `p + 1` 跳一行，别当成跳一个元素。

💡 口诀：**二维数组名是行指针，加 1 跳一行；`a[i][j]` ≡ `*(*(a+i)+j)`；括号里带 `*` 是行指针，不带括号是指针数组。**

## 8.6 指针数组与二级指针 ★★

★ 考点：`char *name[] = {"Li", "Zhang"};` 存放多个字符串；二级指针 `int **pp` 的解引用层级；用指针数组输出多个字符串。

**1. 指针数组：一排指针**

定义：`char *name[3];` —— 它是**数组**，3 个元素，每个元素都是 `char *`。

初始化：

```c
char *name[3] = {"Li", "Zhang", "Wang"};
```

内存示意：

| 数组元素 | 存放的内容 | 指向的字符串 |
|:---:|:---:|:---:|
| name[0] | 0x3000 | "Li" |
| name[1] | 0x3010 | "Zhang" |
| name[2] | 0x3020 | "Wang" |

- `name[i]` 是**地址**，`printf("%s", name[i])` 输出整个字符串。
- `*name[i]` 是字符串的**第一个字符**，即 `name[i][0]`。
- 与二维字符数组 `char name[3][10]` 的对比：

| 对比项 | `char *name[3]`（指针数组） | `char name[3][10]`（二维字符数组） |
|------|------|------|
| 每行长度 | 可以不一样，按实际分配 | 固定 10 字节，短名字浪费空间 |
| 能不能改内容 | ✘（指向字符串常量） | ✔ 可以 |
| 排序时交换什么 | 只交换指针（快） | 要交换整行字符（慢） |

**2. 例题：用指针数组输出多个字符串**

```c-run
#include <stdio.h>

int main(void) {
    char *name[] = {"Li", "Zhang", "Wang"};
    int i;
    for (i = 0; i < 3; i++) printf("%s\n", name[i]);
    printf("%c %c\n", *(name[1] + 1), name[2][0]);
    return 0;
}
```

```text
Li
Zhang
Wang
h W
```

```answer 运行结果与追踪
**输出**

```text
Li
Zhang
Wang
h W
```

| 表达式 | 含义 | 值 |
|------|------|:---:|
| `name[0]` | 第一个字符串的地址 | 输出 `Li` |
| `name[1]` | 第二个字符串的地址 | 输出 `Zhang` |
| `name[2]` | 第三个字符串的地址 | 输出 `Wang` |
| `*(name[1] + 1)` | `name[1]` 是 `'Z'` 的地址，+1 后是 `'h'` | `h` |
| `name[2][0]` | 第三个字符串的首字符 | `W` |

**要点**：`name` 是"指针的数组"，`name[i]` 已经是地址，所以 `%s` 直接用它；要取字符就再解引用一次（`*name[i]` 或 `name[i][0]`）。注意这里**没有** `name[3]`（只有 3 个元素，下标 0—2），越界访问不会报错但结果不可预测。
```

**3. 二级指针：指向指针的指针**

`int **pp;` 的类型是 `int **`，它指向一个 `int *` 型变量。

内存示意：

| 变量 | 内容 | 说明 |
|:---:|:---:|------|
| `int m = 5;` | 5 | 普通变量 |
| `int *p = &m;` | &m | 一级指针，指向 m |
| `int **pp = &p;` | &p | 二级指针，指向 p |

| 表达式 | 值 | 含义 |
|------|:---:|------|
| `m` | 5 | 直接访问 |
| `*p` | 5 | 通过一级指针访问 |
| `**pp` | 5 | 通过二级指针访问（解引用两次）|
| `*pp` | &m | 解引用一次，就降级成 `p` |

★ 规律：**每解引用一次就降一级**。`pp` 是二级 → `*pp` 是一级（就是 p）→ `**pp` 是普通变量（就是 m）。

所以 `**pp = 9;` 与 `*p = 9;` 与 `m = 9;` **完全等价**。

```c-run
#include <stdio.h>

int main(void) {
    int m = 5;
    int *p = &m;
    int **pp = &p;                 /* 二级指针：存放"指针 p 的地址" */
    printf("%d %d %d\n", m, *p, **pp);
    **pp = 9;                      /* 通过二级指针改 m */
    printf("%d %d\n", m, *p);
    return 0;
}
```

```text
5 5 5
9 9
```

```answer 运行结果与追踪
**输出**

```text
5 5 5
9 9
```

| 语句 | pp 内容 | p 内容 | m | 说明 |
|------|:---:|:---:|:---:|------|
| `int m = 5;` | — | — | 5 | |
| `int *p = &m;` | — | &m | 5 | p 指向 m |
| `int **pp = &p;` | &p | &m | 5 | pp 指向 p |
| `printf("%d %d %d")` | &p | &m | 5 | 三种写法都是 5 |
| `**pp = 9;` | &p | &m | **9** | 两次解引用落到 m 上 |
| `printf("%d %d")` | &p | &m | 9 | `*p` 也是 9 |

**为什么 `**pp = 9` 能改到 m**：`pp` → 找到 `p` → 再找到 `m` → 写入 9。这就是"两次解引用"。

**考试范围提醒**：山西考纲对二级指针的要求是"**理解概念、能读懂解引用层级**"，一般不会让你写复杂的二级指针程序。真正高频的是**指针数组存字符串**（上面第 2 条）。
```

**4. 易错清单**

⚠ `int **pp = &&m;` ✘ —— 不存在"二级取地址"这种运算，只能先 `p = &m;` 再 `pp = &p;`。

⚠ 别把 `int *p[4]`（指针数组，p 是数组）和 `int **p`（二级指针，p 是指针）搞混。虽然 `p[0]` 和 `*p` 都能取到一个指针，但一个是数组、一个是指针。

⚠ 用指针数组存字符串时，字符串是**常量**，不能改：`name[0][0] = 'X';` 会崩溃。

💡 口诀：**指针数组是"一排指针"，二级指针是"指向指针的指针"；解引用一次降一级，`*pp` 就是 `p`，`**pp` 就是 `m`。**

## 8.7 返回指针的函数与函数指针 ☆

☆ 考纲边缘，**了解定义形式、能看懂即可**，不必花时间写复杂程序。

**1. 返回指针的函数**

定义形式：`类型名 *函数名(形参表)`

要点：

- `int *findmax(...)` 中 `*` 贴着函数名，表示**返回值的类型是 `int *`**。
- 返回的地址必须是"函数结束后依然存在"的内存：**数组元素、全局变量、malloc 出来的空间**。
- ✘ **绝对不能返回函数内部局部变量的地址**：

```c
int *f(void) {
    int x = 5;
    return &x;        /* ✘ 运行结果错误：函数结束，局部变量 x 的内存已被回收 */
}
```

```c-run
#include <stdio.h>

int *findmax(int *a, int n) {      /* 返回指针的函数 */
    int *p = a, i;
    for (i = 1; i < n; i++)
        if (a[i] > *p) p = &a[i];
    return p;
}

int main(void) {
    int a[3] = {3, 9, 4};
    int *q = findmax(a, 3);
    printf("%d %d\n", *q, (int)(q - a));
    return 0;
}
```

```text
9 1
```

```answer 运行结果与追踪
**输出 `9 1`**

| 步骤 | p 指向 | `*p` | 说明 |
|:---:|:---:|:---:|------|
| 初始 | a[0] | 3 | `int *p = a;` |
| i = 1 | a[1] | 9 | 9 > 3，p 改指 a[1] |
| i = 2 | a[1] | 9 | 4 > 9 不成立，p 不变 |
| 返回 | a[1] | 9 | 返回的是**数组元素的地址**，安全 |

主函数里 `*q` 输出 9；`q - a` 是 1，说明最大元素在下标 1 处。

**为什么这个写法安全**：返回的地址属于 main 的数组 a，它的生存期比函数长。如果返回的是函数里的局部变量地址，函数一返回那块内存就失效了。
```

**2. 函数指针**

定义形式：`返回类型 (*指针名)(形参类型表);`

```c
int add(int a, int b) { return a + b; }
int (*fp)(int, int);       /* 定义函数指针 fp */
fp = add;                  /* 让 fp 指向函数 add（函数名就是函数地址）*/
printf("%d", fp(3, 4));    /* 通过指针调用函数，输出 7 */
```

```c-run
#include <stdio.h>

int add(int a, int b) { return a + b; }

int main(void) {
    int (*fp)(int, int) = add;      /* 函数指针：fp 指向函数 add */
    printf("%d\n", fp(3, 4));
    return 0;
}
```

```text
7
```

```answer 运行结果与追踪
**输出 `7`**

| 写法 | 含义 |
|------|------|
| `int (*fp)(int, int)` | fp 是**指针**，指向"参数为两个 int、返回 int"的函数 |
| `fp = add;` | 函数名代表函数的入口地址，可以直接赋给函数指针（写成 `&add` 也对）|
| `fp(3, 4)` | 通过指针调用函数，等价于 `add(3, 4)`，得 7 |
| `(*fp)(3, 4)` | 另一种等价写法，结果同样是 7 |

**和"返回指针的函数"的区别（易混）**

| 写法 | 名称 |
|------|------|
| `int *f(int);` | **返回指针的函数**：f 是函数，返回 `int *` |
| `int (*f)(int);` | **函数指针**：f 是指针，指向函数 |

判断方法还是那句：**看 `*` 和名字有没有被括号括在一起**。
```

**3. 易错清单**

⚠ 返回**函数内部局部变量的地址**是严重错误：函数一结束那块内存就失效，结果不可预测。

⚠ 函数指针定义时 `(*fp)` 的括号不能省：`int (*fp)(int, int);` 是指针，`int *fp(int, int);` 是函数。

⚠ 函数名本身就是函数地址，`fp = add;` 与 `fp = &add;` 等价，调用写 `fp(3, 4)` 或 `(*fp)(3, 4)` 都对。

⚠ 这一节考纲只要求"看懂定义形式、能判断类型"，选择题出现时按"**类型名后面的 `*` 和括号位置**"判断即可。

💡 口诀：**`*` 贴类型是"返回指针"，`(*名字)` 被括号括住是"指针指向函数"。**

## 8.8 指针易错与程序阅读训练 ★★★

★ 考点：这一节全是**程序阅读题（写运行结果）**。指针的程序阅读只有一种正确做法 —— **纸笔追踪**，四步走：

| 步骤 | 做什么 | 具体动作 |
|:---:|------|------|
| ① | 找初始状态 | 把每个数组的元素、每个指针**指向谁**写下来 |
| ② | 逐行执行 | 每执行一行就更新"p 指向"和"数组元素的值" |
| ③ | 遇到自增自减先拆 | 判断是"动指针"还是"动元素"：`*p++` 动指针，`(*p)++` 动元素 |
| ④ | 最后才写输出 | `printf` 里的表达式按**当前**状态取值，一行一行写 |

📌 下面每道题都**先自己在纸上做一遍**，再点开答案。答案里有逐语句追踪表，哪一行对不上就说明那一步的理解有漏洞。

**第 1 题 · `*p++` 三连（程序阅读高频）**

```c-run
#include <stdio.h>

int main(void) {
    int a[4] = {2, 4, 6, 8};
    int *p = a;
    int x, y, z;
    x = *p++;
    y = (*p)++;
    z = *++p;
    printf("%d %d %d\n", x, y, z);
    printf("%d %d\n", *p, a[1]);
    return 0;
}
```

```text
2 4 6
6 5
```

```answer 运行结果与追踪
**输出**

```text
2 4 6
6 5
```

| 语句 | p 指向 | `*p` 的值 | 其他变量 |
|------|:---:|:---:|------|
| `int *p = a;` | a[0] | 2 | a = {2,4,6,8} |
| `x = *p++;` | a[0] → **a[1]** | 2 → 4 | **x = 2**（取的是移动前的值）|
| `y = (*p)++;` | a[1]（不动） | 4 → 5 | **y = 4**，**a[1] 变成 5** |
| `z = *++p;` | a[1] → **a[2]** | 6 | **z = 6** |
| `printf("%d %d\n", *p, a[1]);` | a[2] | 6 | 输出 `6 5`（a[1] 已被 `(*p)++` 改成 5）|

**三个坑**

1. `x = *p++;` 里 p 移动了，但**x 拿到的是旧位置的值 2**，不是 4。
2. `y = (*p)++;` 里 p **不动**，动的是 a[1]（4 → 5）。所以最后一行输出 a[1] 是 **5** 而不是 4。
3. `z = *++p;` 是**先移后取**：从 a[1] 移到 a[2]，取 6。
```

**第 2 题 · 指针与数组下标混用（负下标）**

```c-run
#include <stdio.h>

int main(void) {
    int a[5] = {1, 2, 3, 4, 5};
    int *p = &a[2];
    int i;
    printf("%d %d %d\n", p[-1], p[0], p[2]);
    p++;
    printf("%d %d\n", *p, (int)(p - a));
    printf("%d %d %d\n", p[-2], p[-1], p[0]);
    for (i = 0; i < 5; i++) printf("%d", *(a + i));
    printf("\n");
    return 0;
}
```

```text
2 3 5
4 3
2 3 4
12345
```

```answer 运行结果与追踪
**输出**

```text
2 3 5
4 3
2 3 4
12345
```

| 语句 | p 指向 | `*p` 的值 | 其他变量 |
|------|:---:|:---:|------|
| `int *p = &a[2];` | a[2] | 3 | a = {1,2,3,4,5} |
| `p[-1]` | a[2] | 3 | 取 a[1] = **2** |
| `p[0]` | a[2] | 3 | **3** |
| `p[2]` | a[2] | 3 | 取 a[4] = **5** |
| `p++;` | a[2] → **a[3]** | 3 → 4 | — |
| `*p` | a[3] | 4 | 输出 **4** |
| `p - a` | a[3] | 4 | **3**（下标值）|
| `p[-2]` | a[3] | 4 | 取 a[1] = **2** |
| `p[-1]` | a[3] | 4 | 取 a[2] = **3** |
| `p[0]` | a[3] | 4 | **4** |
| 最后一行循环 | a[3] | 4 | 依次输出 a[0]…a[4] = **12345** |

**两条结论**

1. **`p[i]` 就是 `*(p+i)`，i 可以为负数**：`p[-1]`、`p[-2]` 都是合法的（只要没跑出数组）。考试里出现过负下标，别以为写错了。
2. `p - a` 得到的是**下标**（相隔元素个数），不是字节差。`p = &a[3]` 时 `p - a` 就是 3。
```

#include <stdio.h>

int main(void) {

    printf("%c %c\n", *(s + 1), s[4]);

}
```

```answer 运行结果与追踪
**输出**

```text
b e
cdefg 5
b
```

| 语句 | s 指向 | `*s` 的值 | 说明 |
|------|:---:|:---:|------|
| `char *s = "abcdefg";` | `'a'`（下标 0） | a | 字符串常量在只读区，**不能改内容**，但可以移动指针 |
| `*(s + 1)` | `'a'` | a | 取下标 1 → **b** |
| `s[4]` | `'a'` | a | 下标写法取下标 4 → **e** |
| `s += 2;` | `'c'`（下标 2） | c | 指针后移 2 个字符 |

3. `s += 2` 之后 `*(s-1)` 仍然合法（下标 1 还在字符串里），但如果写成 `s -= 3` 再访问就越界了。

**第 4 题 · 指针传参交换（含失败版本）**

```c-run
#include <stdio.h>

void swapA(int *x, int *y) {        /* 只交换了两个形参指针本身 */
    int *t = x;
    x = y;
    y = t;
}

void swapB(int *x, int *y) {        /* 交换指针所指变量的内容 */
    int t = *x;
    *x = *y;
    *y = t;
}

int main(void) {
    int a = 1, b = 2;
    swapA(&a, &b);
    printf("%d %d\n", a, b);
    swapB(&a, &b);
    printf("%d %d\n", a, b);
    return 0;
}
```

```text
1 2
2 1
```

```answer 运行结果与追踪
**输出**

```text
1 2
2 1
```

**第一次调用 `swapA(&a, &b)`：失败**

| 语句 | x 指向 | y 指向 | a | b |
|------|:---:|:---:|:---:|:---:|
| 进入函数 | a | b | 1 | 2 |
| `t = x;` | a | b | 1 | 2（t 指向 a）|
| `x = y;` | **b** | b | 1 | 2 |
| `y = t;` | b | **a** | 1 | 2 |
| 返回主函数 | 销毁 | 销毁 | **1** | **2** |

x、y 确实互换了指向，但 x、y 只是**形参指针变量**（main 传来的地址副本），换掉它们跟 a、b 一点关系都没有。所以输出 `1 2`。

**第二次调用 `swapB(&a, &b)`：成功**

| 语句 | x 指向 | `*x` | `*y` | a | b |
|------|:---:|:---:|:---:|:---:|:---:|
| 进入函数 | a | 1 | 2 | 1 | 2 |
| `t = *x;` | a | 1 | 2 | 1 | 2（t = 1）|
| `*x = *y;` | a | 2 | 2 | **2** | 2 |
| `*y = t;` | a | 2 | 1 | 2 | **1** |
| 返回主函数 | 销毁 | — | — | **2** | **1** |

**一句话结论**：**改 `x` 没用（那是形参自己），改 `*x` 才有用（那才是实参）。**
```

**第 5 题 · 二维数组指针访问**

```c-run
#include <stdio.h>

int main(void) {
    int a[3][2] = {{1, 2}, {3, 4}, {5, 6}};
    int *p = a[0];
    int i;
    printf("%d %d\n", a[2][1], *(*(a + 1) + 1));
    for (i = 0; i < 6; i++) printf("%d", *(p + i));
    printf("\n");
    printf("%d\n", *(p + 2 * 2 + 1));
    return 0;
}
```

```text
6 4
123456
6
```

```answer 运行结果与追踪
**输出**

```text
6 4
123456
6
```

内存布局（按行连续存放，每行 2 个元素）：

| 偏移 | 0 | 1 | 2 | 3 | 4 | 5 |
|:---:|:---:|:---:|:---:|:---:|:---:|:---:|
| 值 | 1 | 2 | 3 | 4 | 5 | 6 |
| 等价下标 | a[0][0] | a[0][1] | a[1][0] | a[1][1] | a[2][0] | a[2][1] |

| 表达式 | 分析 | 值 |
|------|------|:---:|
| `a[2][1]` | 第 2 行第 1 列 | **6** |
| `*(*(a+1)+1)` | `a+1` 是第 1 行地址 → `*(a+1)` 是第 1 行首元素地址（偏移 2）→ `+1` 得偏移 3 → 解引用 | **4** |
| `*(p + i)`（i=0…5） | p 指向偏移 0，一路扫到偏移 5 | **123456** |
| `*(p + 2*2 + 1)` | 2 * 列数(2) + 1 = 偏移 5 | **6** |

**核心公式**：一级指针访问二维数组时 `a[i][j]` 对应 `*(p + i * 列数 + j)`。这里的**列数是 2**（每行 2 个元素），不是 3（行数）。写错列数是最常见的失分点。

**为什么第 2 行 `*(*(a+1)+1)` 是 4 不是别的**：二维数组里 `a + 1` 跳过**一整行**（2 个 int），落到第 1 行；解引用得到第 1 行首元素的地址（也就是偏移 2 的位置，值为 3）；再 `+1` 到偏移 3，解引用得 4。
```

**第 6 题 · 指针比较与空指针**

```c-run
#include <stdio.h>

int main(void) {
    int a[5] = {9, 7, 5, 3, 1};
    int *p = a, *q = a + 4;
    printf("%d %d\n", p < q, (int)(q - p));
    while (p < q) {
        if (*p < *q) printf("swap\n");
        p++;
        q--;
    }
    printf("%d %d\n", *p, *q);
    {
        int *r = NULL;
        printf("%d\n", r == NULL);
        if (r != NULL) printf("%d\n", *r);
    }
    return 0;
}
```

```text
1 4
5 5
1
```

```answer 运行结果与追踪
**输出**

```text
1 4
5 5
1
```

| 语句 | p 指向 | q 指向 | `*p` | `*q` | 输出 |
|------|:---:|:---:|:---:|:---:|:---:|
| 初始 | a[0] | a[4] | 9 | 1 | — |
| `p < q`、`q - p` | a[0] | a[4] | 9 | 1 | **1 4** |
| 第 1 轮 `*p < *q`？ | a[0] | a[4] | 9 | 1 | 9 < 1 假，不打印 |
| 移动后 | a[1] | a[3] | 7 | 3 | — |
| 第 2 轮 `*p < *q`？ | a[1] | a[3] | 7 | 3 | 7 < 3 假，不打印 |
| 移动后 | a[2] | a[2] | 5 | 5 | — |
| 判断 `p < q` | a[2] | a[2] | 5 | 5 | 假 → 退出循环 |
| `printf("%d %d")` | a[2] | a[2] | 5 | 5 | **5 5** |
| 空指针部分 | — | — | — | — | `r == NULL` 打印 **1**；`r != NULL` 为假，`*r` 不执行 |

**四个关键点**

1. **指针比较的是地址（先后位置），不是所指内容**。`p < q` 为真说明 p 在 q 前面。
2. **两个指针相减**得到相隔元素个数：`q - p` = 4（下标 4 - 0），不是 16 字节。
3. 相减/比较只能用于**同一个数组**内的指针，否则无意义。
4. **空指针只做判断是安全的**：`r == NULL`、`r != NULL` 都没问题；`*r` 会访问 0 号地址，**必定崩溃**。所以程序里用 `if (r != NULL)` 挡在前面，`*r` 永远不会执行。`NULL` 的值就是 0，定义在 `stdio.h` 中。
```

**第 7 题 · 双指针相向遍历（综合）**

```c-run
#include <stdio.h>

int main(void) {
    int a[5] = {1, 2, 3, 4, 5};
    int *p = a, *q = a + 4;
    int s = 0;
    while (p <= q) {
        s += *p + *q;
        p++;
        q--;
    }
    printf("%d %d\n", s, (int)(q - p));
    return 0;
}
```

```text
18 -2
```

```answer 运行结果与追踪
**输出**

```text
18 -2
```

| 轮次 | p 指向 | q 指向 | `*p` | `*q` | 本轮的 `*p + *q` | s | 移动后 |
|:---:|:---:|:---:|:---:|:---:|:---:|:---:|:---:|
| 初始 | a[0] | a[4] | 1 | 5 | — | 0 | — |
| 第 1 轮 | a[0] | a[4] | 1 | 5 | 6 | **6** | p→a[1]，q→a[3] |
| 第 2 轮 | a[1] | a[3] | 2 | 4 | 6 | **12** | p→a[2]，q→a[2] |
| 第 3 轮 | a[2] | a[2] | 3 | 3 | 6 | **18** | p→a[3]，q→a[1] |
| 判断 `p <= q` | a[3] | a[1] | 4 | 2 | — | — | a[3] <= a[1] 为假 → 退出 |

**两个答案**

1. `s = 18`。因为 5 个元素被"从两头往中间"各取了一次，**中间元素 a[2] 被加了两次**（第 3 轮 `*p` 和 `*q` 都是 3）。总效果 = 1+2+3+4+5 + 3 = 18。
2. `q - p = -2`。循环结束时 p 指向 a[3]、q 指向 a[1]，所以 `q - p` = 1 - 3 = **-2**（可以是负数，因为指针已经交叉）。
```

**8. 野指针、空指针、越界：这三类题为什么不能上机跑**

⚠ 下面三种写法都是**未定义行为（UB）**：可能崩溃，也可能"看起来正常"地悄悄改坏别的变量。所以本节**不给它们配 `c-run` 可运行示例**（同一个程序每次运行结果都可能不同，没有参考价值）。你要记的是"**这么写是错的**"。

✘ 类型 1：未初始化的指针（野指针）

```c
int *p;          /* p 里是随机地址，不知道指向哪儿 */
*p = 10;         /* 往随机地址写 10 */
```

后果：未定义行为。**必须先让指针指向一个有效变量或数组**：`int m; int *p = &m; *p = 10;` ✔

✘ 类型 2：空指针解引用

```c
int *p = NULL;
printf("%d\n", *p);      /* 访问 0 号地址，必定崩溃 */
```

✔ 正确做法是**先判断再访问**：

```c
#include <stdio.h>

int main(void) {
    int *p = NULL;
    if (p == NULL) printf("p is null\n");     /* ✔ 只比较，安全 */
    if (p != NULL) printf("%d\n", *p);        /* ✔ 判断通过才解引用 */
    return 0;
}
```

✘ 类型 3：指针越界

```c
int a[5], *p = a;
p += 10;                 /* p 已经跑到数组外面 */
*p = 1;                  /* 改坏了别人的内存，编译器不会报错 */
```

📌 考试提醒：`NULL` 的值就是 **0**，定义在 `stdio.h` / `stdlib.h` 里。题目说"p 的值为 0"或"p 不指向任何变量"，指的就是空指针。空指针**可以比较、可以赋值、可以判断**，只有**解引用**才崩。

**9. 程序阅读题速查：9 条结论**

| # | 写法 | 结果 |
|:---:|------|------|
| 1 | `a[i]` / `*(a+i)` / `*(p+i)`（p=a） | 完全等价 |
| 2 | `*p++` | 先取 `*p`（旧位置的值），再 p 后移 |
| 3 | `*++p` | 先 p 后移，再取 `*p` |
| 4 | `(*p)++` | 取 `*p` 的旧值，再把**元素**加 1（p 不动）|
| 5 | `*p+1` | 是 `(*p)+1`，值加 1，不是下一个元素 |
| 6 | `p - q` | 相隔**元素个数**（可为负），不是字节数 |
| 7 | `sizeof(a)`（数组）/ `sizeof(p)`（指针） | 数组是总字节数；指针是自己的字节数（4 或 8）|
| 8 | `*s != '\0'` / `*s` | 遍历字符串的正确条件；`s != '\0'` 是错的 |
| 9 | `a++` | 编译错误（数组名是常量地址）；`p++` 可以 |

**10. 本章易错清单（考前最后一遍看这里）**

⚠ 定义 `int *p, q;` 只定义了一个指针，`q` 是普通 int。

⚠ 指针必须"先指向，后使用"：野指针、空指针解引用都是未定义行为。

⚠ `*` 有三种含义（说明符 / 解引用 / 乘法），判断看左边有没有类型名。

⚠ `*p++` 与 `(*p)++` 与 `*++p` 完全不同，考试必考其中一个，先把优先级拆清楚。

⚠ 数组名不能自增、不能被赋值；`int (*p)[4]` 是行指针，`int *p[4]` 是指针数组。

⚠ 函数里改形参指针本身（`x = y;`）不影响实参，必须改 `*x`。

⚠ 二维数组名不是二级指针；`a[i][j]` ≡ `*(*(a+i)+j)`；一级指针遍历要用 `i * 列数 + j`。

⚠ `char *s = "abc";` 的内容不能改，`char s[] = "abc";` 才能改；`s += 1` 只有指针能做。

💡 本章总口诀：**指针存地址，`*` 取内容，`&` 取地址；`a[i]` 就是 `*(a+i)`；`++` 在右先取值、在左先移动、括号一括改元素；要改实参传地址，改 `*p` 才有效；数组名是常量，指针才能跑。**
