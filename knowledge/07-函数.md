## 7.1 函数的定义与调用 ★★★

★ 考点：函数定义的三个组成部分、**函数不能嵌套定义但可以嵌套调用**、**调用必须在声明之后**、`return` 的双重作用。2025 年单选题原题考了「形参的作用域」。

**1. 函数定义格式**

```c
返回类型 函数名(形参表)
{
    函数体
    return 表达式;      /* 返回类型为 void 时可省略 */
}
```

```c
int add(int a, int b) {     /* 返回类型 int，函数名 add，两个形参 */
    int s;                   /* 函数体内定义局部变量 */
    s = a + b;
    return s;                /* 把 s 的值返回给调用者 */
}
```

| 组成部分 | 说明 | 常见错误 |
|:---|:---|:---|
| 返回类型 | 函数返回值的类型；不写默认为 `int` | 写成 `void main()`（不标准） |
| 函数名 | 合法标识符，不能与库函数重名 | 命名随意导致和 `read`、`index` 冲突 |
| 形参表 | `类型 名字` 列表，用逗号分隔；无参写 `void` 或留空 | `int f(a, b)`——**每个形参都要写类型** |
| 函数体 | `{ }` 内的语句 | 函数体内**不能再定义函数** |

**2. 函数不能嵌套定义，但可以嵌套调用**

```c
/* ✘ 编译错误：函数不能定义在另一个函数里面 */
int f(int x) {
    int g(int y) { return y + 1; }   /* 错！嵌套定义 */
    return g(x);
}
```

```c
/* ✔ 正确：定义都写在最外层，调用可以嵌套 */
int max3(int a, int b, int c) { ... }
int twice(int x) { return 2 * x; }

int main(void) {
    printf("%d\n", twice(max3(3, 9, 5)));   /* 嵌套调用：先算 max3，再把结果交给 twice */
    return 0;
}
```

**3. 调用必须在声明之后（或先用原型声明）**

C 编译器**从上往下**读代码。如果 `main` 写在函数定义之前，编译器还没见过这个函数，就会按"隐式声明"处理——返回类型默认当成 `int`，参数类型不做检查，可能报错也可能悄悄产生错误结果。

两种正确做法：

| 做法 | 写法 | 说明 |
|:---|:---|:---|
| ① 先定义后调用 | 函数定义写 `main` 前面 | 最简单，考试里最常用 |
| ② 先声明原型 | 在 `main` 前写 `int add(int a, int b);` | 定义可以放到 `main` 后面 |

**4. `return` 语句的两个作用**

| 作用 | 说明 |
|:---|:---|
| ① 返回值 | 把 `return` 后面表达式的值交给调用者 |
| ② 结束函数 | 执行到 `return`，函数**立刻结束**，后面的语句不再执行 |

```c
int f(int n) {
    if (n < 0) return -1;      /* 只返回，不带值参与运算 */
    return n * 2;              /* 正常返回值 */
    printf("never\n");         /* ✘ 永远不会执行（编译只警告） */
}
```

⚠ `return` 后面可以**没有表达式**（用于 `void` 函数提前结束），也可以有表达式。但**一个函数中可以有多条 `return`，实际只会执行到第一条**。

**5. `void` 函数**

- `void` 表示"**不返回任何值**"。
- `void` 函数里可以写 `return;`（用来提前结束），但**不能写 `return 表达式;`**。
- 调用 `void` 函数时**不能把它放在表达式里**：`x = show(5);` 是错的，只能写成单独的语句 `show(5);`。

**6. `main` 也是函数**

`main` 是被**操作系统**调用的函数，它是整个程序的入口。程序里所有其他函数最终都是被 `main`（直接或间接）调用起来的。`main` 的返回值 `0` 表示程序正常结束，所以标准写法是：

```c
int main(void) {
    ...
    return 0;
}
```

**7. 形参的作用域（2025 山西真题单选原题）**

> **一个函数中形参的作用域是——**
> A. 整个程序  B. 形参所在函数体  C. 主函数  D. 从定义处到文件结束
>
> **答案：B. 形参所在函数体**

理由：

- 形参本质上是**该函数的局部变量**，只在**这个函数的函数体**内有效。
- 出了这个函数，形参的名字就不存在了，别的函数**看不到**它，也不可能用同名的变量访问它。
- 形参是在**函数被调用时**才分配空间、才有的；调用结束就释放。

```c-run
#include <stdio.h>
int add(int a, int b) {
    return a + b;
}
int main(void) {
    printf("%d\n", add(3, 4));
    return 0;
}
```

```text
7
```

```answer 运行结果与追踪

输出 `7`。

调用过程逐步展开：

| 步骤 | 发生的事 |
|:---:|:---|
| ① | `main` 执行到 `add(3, 4)`，先算出实参表达式的值：3 和 4 |
| ② | 把 3 **拷贝**给形参 `a`，把 4 **拷贝**给形参 `b`（此时才为 `a`、`b` 分配空间） |
| ③ | 进入 `add` 的函数体，执行 `return a + b;`，算出 7 |
| ④ | 函数结束，`a`、`b` 的空间被释放，7 作为函数的值返回 |
| ⑤ | `printf("%d\n", 7)` 输出 `7` |

关于形参作用域：

- `a`、`b` 只在 `add` 的函数体里存在。在 `main` 里写 `printf("%d", a);` 是**编译错误**（未声明的标识符）。
- `main` 里如果再写一个 `int a = 100;`，与 `add` 的形参 `a` **互不干扰**——它们是两个完全不同的变量。
```

**⚠ 易错清单**

⚠ **形参表里每个参数都必须写类型**：`int f(int a, int b)` ✔；`int f(int a, b)` ✘（编译错误）。

⚠ **函数不能嵌套定义**，但**可以嵌套调用**。选择题常把这两句对调来设陷阱。

⚠ 函数定义在 `main` 之后而没写原型声明 → 编译器报隐式声明错误/警告，返回类型被当成 `int`。考试里看到这种程序，问题往往就出在这里。

⚠ `void` 函数里写 `return 0;` 是错的（`void` 函数不能返回值）；`void` 函数的调用结果不能赋给变量。

⚠ `return` 一旦执行，函数**立刻结束**。`return` 后面同层的语句是死代码。

⚠ `main` 不是"特殊到不受规则约束"的函数：它同样有返回类型、同样有函数体，同样可以带形参 `int main(int argc, char *argv[])`（考试一般用 `int main(void)`）。

💡 口诀：**类型 名字（形参）＋花括号；不能嵌套定义，可以嵌套调用；先定义或先声明；return 一返回二结束；形参作用域＝所在函数体。**

## 7.2 参数传递与返回值 ★★★

★ 考点：C 语言**只有值传递**（实参 → 形参是单向拷贝）。这是整本书里最容易被扣分的一个概念，也是「交换两数的函数为什么失败」这类题的唯一答案。

**1. 值传递：拷贝，不是共享**

```c
void change(int x) {
    x = x + 10;
}
```

调用 `change(a)` 时发生的事：

| 步骤 | 内存里发生的事 |
|:---:|:---|
| ① | 实参 `a` 的值被**复制**一份 |
| ② | 这份复制品交给形参 `x`（`x` 是新开的、独立的空间） |
| ③ | 函数里改的是 `x`，**和 `a` 没有任何关系** |
| ④ | 函数返回，`x` 被销毁，`a` 一点没变 |

★ 必背：**实参 → 形参是单向的、一次性的复制。形参怎么改都影响不到实参。**

**例题 1：形参改变不影响实参**

```c-run
#include <stdio.h>
void change(int x) {
    x = x + 10;
    printf("in change: x=%d\n", x);
}
int main(void) {
    int a = 5;
    change(a);
    printf("in main: a=%d\n", a);
    return 0;
}
```

```text
in change: x=15
in main: a=5
```

```answer 运行结果与追踪

输出两行：`in change: x=15` 和 `in main: a=5`。

| 时刻 | 实参 a | 形参 x | 说明 |
|:---|:---:|:---:|:---|
| 调用前 | 5 | 不存在 | `x` 还没分配空间 |
| 调用 `change(a)` | 5 | **5**（a 的拷贝） | 拷贝发生后两者完全独立 |
| 执行 `x = x + 10` | 5 | **15** | 改的是 `x` |
| 打印 `in change` | 5 | 15 | 输出 x=15 |
| 函数返回 | 5 | 销毁 | `x` 的空间被回收 |
| 打印 `in main` | **5** | — | `a` 从头到尾没变 |

一句话：**函数里改的是形参这个"副本"，实参原封不动。**
```

**例题 2：经典陷阱——交换两数的函数为什么失败**

```c-run
#include <stdio.h>
void swap(int x, int y) {
    int t = x;
    x = y;
    y = t;
}
int main(void) {
    int a = 1, b = 2;
    swap(a, b);
    printf("a=%d b=%d\n", a, b);
    return 0;
}
```

```text
a=1 b=2
```

```answer 运行结果与追踪（必考陷阱）

输出 `a=1 b=2`——**交换失败**，`a`、`b` 一点没变。

逐步追踪：

| 时刻 | 实参 a | 实参 b | 形参 x | 形参 y | 临时 t |
|:---|:---:|:---:|:---:|:---:|:---:|
| 调用前 | 1 | 2 | — | — | — |
| 调用 `swap(a, b)` | 1 | 2 | **1** | **2** | — |
| `int t = x;` | 1 | 2 | 1 | 2 | 1 |
| `x = y;` | 1 | 2 | **2** | 2 | 1 |
| `y = t;` | 1 | 2 | 2 | **1** | 1 |
| 函数返回 | **1** | **2** | 销毁 | 销毁 | 销毁 |
| 打印 | 1 | 2 | — | — | — |

关键：**函数内部的 `x`、`y` 确实被交换成了 2 和 1，但它们只是 `a`、`b` 的副本**。副本之间换得再漂亮，原变量一动不动。

✘ 错误理解的写法（以为传进去就是原变量）：

```c
void swap(int x, int y) { int t = x; x = y; y = t; }   /* 改了副本，没用 */
```

✔ **正确做法：传地址（指针）**——把 `a`、`b` 的**地址**传进去，函数里通过地址去改原来的变量。这样"拷贝"的虽然是地址，但顺着地址找到的是**同一个存储单元**：

```c
void swap(int *x, int *y) {      /* 形参是指针 */
    int t = *x;
    *x = *y;
    *y = t;
}
/* 调用：swap(&a, &b);   —— 实参写取地址符 & */
```

这一段的完整原理（`*`、`&` 怎么用）见《08 · 指针》章。**现在只要记住结论：想让函数改变实参的值，必须传地址，不能靠返回值以外的任何"传值"手段。**

另一个替代方案是用**返回值**：`int swap(int a, int b)` 借助结构体或全局变量才能返回两个值——C 语言的 `return` 只能返回一个值，所以考试里凡是要"通过函数改变两个变量的值"，答案一律是**传指针**。
```

**3. `return` 只能返回一个值**

| 想法 | 能不能实现 | 正确做法 |
|:---|:---:|:---|
| 返回两个数 | ✘ | 用指针参数带回（见《08 · 指针》章），或返回结构体（见《09 · 结构体与自定义类型》章） |
| 返回数组 | ✘（不能返回局部数组） | 通过数组参数就地修改（7.3 节） |
| 返回一个值 | ✔ | `return 表达式;` |

⚠ `return a, b;` 是**逗号表达式**，只会返回 `b`——不是"返回两个值"。

**4. 返回类型与 return 表达式类型不一致时的转换**

规则：**以函数的返回类型为准，`return` 后面的表达式会被自动转换成返回类型**（和赋值语句的规则一样）。

```c-run
#include <stdio.h>
int f(double x) {
    return x;
}
int main(void) {
    printf("%d\n", f(3.99));
    return 0;
}
```

```text
3
```

```answer 运行结果与追踪

输出 `3`。

- 函数声明返回类型是 `int`，所以 `return x;`（`x = 3.99`，double）会被**截断取整**成 `3`。
- 注意：**不是四舍五入**，是直接砍掉小数部分。3.99 → 3。

对照下面的例子（返回类型换成 double）：

```c
double g(void) { return 7 / 2; }        /* 输出 3.0 —— 先做整数除法得 3，再转 double */
double h(void) { return 7 / 2.0; }      /* 输出 3.5 —— 有 double 参与，按浮点算 */
```

| 写法 | 中间运算 | 返回类型 | 最终值 |
|:---|:---|:---|:---:|
| `int f(double x){ return x; }` 传 3.99 | double 3.99 | int | **3** |
| `double g(){ return 7 / 2; }` | 整数除法 = 3 | double | **3.0** |
| `double h(){ return 7 / 2.0; }` | 浮点除法 = 3.5 | double | **3.5** |

💡 判断方法：**先看 `return` 后面表达式的运算（按整数/浮点规则算出中间结果），再按返回类型做一次转换。**
```

**⚠ 易错清单**

⚠ **C 语言只有值传递**。数组名作实参时看着像"传引用"，本质仍然是传值——只不过传的值是**地址**（见 7.3）。这个说法在选择题里会被反复考。

⚠ 形参名和实参名**可以相同也可以不同**，改形参名不影响任何逻辑；它们本来就是两组独立的变量。

⚠ `return` 只能返回**一个**值，`return a, b;` 返回的是 `b`。

⚠ 返回类型是 `int` 而 `return` 一个 `double` → **截断**，不是四舍五入。

⚠ 不要返回**局部数组**：`int *f(void){ int a[5]; return a; }` 是错的（函数结束后 `a` 被销毁），考试里这种写法一律判为错误。

💡 口诀：**实参拷贝给形参，形参改了实参不变；要改实参传地址；return 只带一个值；类型不符按返回类型转。**

## 7.3 数组作为函数参数 ★★★

★ 考点：**数组名作实参时传的是首地址**，所以函数里改数组元素会**真的改到原数组**——这是数组参数与普通变量参数最大的区别，也是程序填空题的固定考法。2025 真题原题就在这里。

**1. 形参与实参的写法**

| 位置 | 写法 | 说明 |
|:---|:---|:---|
| 形参 | `int a[]` 或 `int a[10]` 或 `int *a` | **三种写法完全等价**，方括号里的数字**会被忽略** |
| 实参 | `score`（只写数组名） | **不写方括号，不写下标** |
| 长度 | 必须**另开一个参数**传 | 形参里得不到数组长度 |

```c
int fun(int array[]) { ... }        /* ✔ 推荐 */
int fun(int array[10]) { ... }      /* ✔ 等价，10 被忽略 */
int fun(int *array) { ... }         /* ✔ 等价（指针写法，见《08 · 指针》章） */

fun(score);                         /* ✔ 传数组名 */
fun(score[5]);                      /* ✘ 这是"第 5 个元素的值"，类型不对 */
fun(score[]);                       /* ✘ 语法错误 */
```

**2. 为什么函数里改数组会改到原数组**

数组名是**首元素地址**。传值传递的是这个**地址值**——函数里的形参拿到的是"原数组在内存里的位置"。所以：

- 通过这个地址**读**，读到的是原数组的元素；
- 通过这个地址**写**，写进去的就是原数组的元素。

| 参数类型 | 传的是什么 | 函数里改了会怎样 |
|:---|:---|:---|
| 普通变量 `int x` | 变量的**值**（一份拷贝） | 实参**不变** |
| 数组 `int a[]` | 数组的**首地址** | 实参数组**跟着变** |

★ 一句话：**普通变量传"值"，数组传"地址"。**

**3. 数组长度必须另外传**

`int fun(int a[])` 里**问不出**数组有多长：

- `sizeof(a)` 在函数里得到的是**指针的大小**（32 位系统 4 字节、64 位系统 8 字节），**不是数组的总字节数**。
- 所以标准做法是多加一个形参 `int n` 表示元素个数。

✔ 正确写法：

```c
int sum(int a[], int n) {       /* n 表示处理前 n 个元素 */
    int i, s = 0;
    for (i = 0; i < n; i++) s += a[i];
    return s;
}
/* 调用：sum(b, 5); */
```

**例题 1：数组求和**

```c-run
#include <stdio.h>
int sum(int a[], int n) {
    int i, s = 0;
    for (i = 0; i < n; i++) s += a[i];
    return s;
}
int main(void) {
    int b[5] = {1, 2, 3, 4, 5};
    printf("%d\n", sum(b, 5));
    return 0;
}
```

```text
15
```

```answer 运行结果与追踪

输出 `15`。

| 步骤 | 发生的事 |
|:---:|:---|
| ① | 实参 `b` 的值是**首元素地址** `&b[0]`，把它拷贝给形参 `a` |
| ② | 形参 `n` 拿到 5 |
| ③ | 循环里 `a[i]` 等价于 `b[i]`——因为它们指向**同一块内存** |
| ④ | 返回 15 |

要点：

- 形参写 `int a[]` 或 `int *a` 都行，**考试填空写 `int a[]` 最稳**。
- 实参写 `sum(b, 5)`，**不能**写 `sum(b[5], 5)`。
- 函数里若写 `sizeof(a)` 得到的是指针大小（4 或 8），**不是 20**。所以长度只能靠参数 `n` 传进来。
```

**例题 2：函数内修改数组，实参数组跟着变**

```c-run
#include <stdio.h>
void fun(int a[], int n) {
    int i;
    for (i = 0; i < n; i++) a[i] = a[i] + 1;
}
int main(void) {
    int b[4] = {1, 2, 3, 4};
    int i;
    fun(b, 4);
    for (i = 0; i < 4; i++) printf("%d ", b[i]);
    printf("\n");
    return 0;
}
```

```text
2 3 4 5 
```

```answer 运行结果与追踪（与普通变量对照）

输出 `2 3 4 5 `——**原数组真的被改了**。

| 下标 | b 原来 | 函数里 a[i]+1 | 函数返回后 b |
|:---:|:---:|:---:|:---:|
| 0 | 1 | 2 | **2** |
| 1 | 2 | 3 | **3** |
| 2 | 3 | 4 | **4** |
| 3 | 4 | 5 | **5** |

**对照实验**：把数组换成普通变量，结果完全不同。

```c
#include <stdio.h>
void fun(int a, int n) { a = a + 1; }     /* 形参是普通变量 */
int main(void) {
    int b = 10;
    fun(b, 5);
    printf("%d\n", b);                    /* 输出 10 —— 没变！ */
    return 0;
}
```

| 形参类型 | 传进去的东西 | 函数里改了 | 主函数里看到 |
|:---|:---|:---|:---|
| `int a` | 值的一份拷贝 | `a` 变了 | **不变**（10） |
| `int a[]` | 首地址 | `a[i]` 变了 | **变了**（2 3 4 5） |

这就是 7.2 说的"值传递"的延伸：数组之所以能被改，是因为**拷贝的是地址**，顺着地址改到了同一块内存。
```

**例题 3（2025 山西真题程序填空原题）**

真题结构：全局数组 `score` 存放成绩，要求补全函数 `fun` 里的判断条件，以及主函数里的调用语句。

```c
#include <stdio.h>
int score[5] = {90, 55, 72, 48, 60};

int fun(int array[]) {
    int i, s = 0;
    for (i = 0; i < 5; i++)
        if (______) s++;          /* 空 ① */
    return s;
}

int main(void) {
    int count;
    count = ______;                /* 空 ② */
    printf("%d\n", count);
    return 0;
}
```

```answer 参考答案

**空 ①**：`array[i] >= 60`
**空 ②**：`fun(score)`

完整程序与追踪：

```c
#include <stdio.h>
int score[5] = {90, 55, 72, 48, 60};

int fun(int array[]) {
    int i, s = 0;
    for (i = 0; i < 5; i++)
        if (array[i] >= 60) s++;
    return s;
}

int main(void) {
    int count;
    count = fun(score);
    printf("%d\n", count);
    return 0;
}
```

运行结果：`3`

| i | array[i] | array[i] >= 60 | s |
|:---:|:---:|:---|:---:|
| 0 | 90 | 真 | 1 |
| 1 | 55 | 假 | 1 |
| 2 | 72 | 真 | 2 |
| 3 | 48 | 假 | 2 |
| 4 | 60 | **真**（60 分及格） | 3 |

四个得分点：

1. 空 ② 的实参**只写数组名** `score`，不能写 `score[5]`（那是取第 5 个元素），也不能写 `score[]`（语法错误）。
2. 空 ① 的条件是 `>= 60`，写成 `> 60` 会漏掉刚好 60 分的那个人（结果变成 2）。
3. 计数变量 `s` 必须在函数里**初始化为 0**。如果它忘了初始化，由于是局部变量，初值是随机的，结果是错的。
4. 函数返回类型是 `int`，所以函数体必须有 `return s;`；主函数用 `count` 接住这个返回值。

⚠ 注意真题里循环用的是 `i < 5`（写死的长度）。如果改成用 `n` 传长度会更通用，但按题目给的框架填空即可。
```

**⚠ 易错清单**

⚠ 形参 `int a[10]` 里的 `10` **没有任何作用**（会被忽略成指针），别指望它能限制数组长度。

⚠ 实参写数组名时**不加方括号**：`fun(score)` ✔；`fun(score[])` ✘；`fun(score[5])` ✘。

⚠ 在函数内部**不能用 `sizeof(a)/sizeof(a[0])` 求长度**——`a` 在这里是指针，结果是 1 或 2，不是真实长度。

⚠ `int a[]` 与 `int *a` 等价，但**填空时写 `int a[]` 更符合题意**（题目给的是数组语义）。

⚠ 数组传参时，函数对数组的修改会**永久生效**（就地修改）。所以程序阅读题里看到"函数里对数组元素做了运算"，回到 `main` 打印时**必须用改过的值**。

⚠ 形参数组和实参数组**共用同一块内存**，不是两份数据。别把它当成"拷贝了一份数组进去"。

💡 口诀：**数组名是首地址，传参只写名字不带括号；长度必须另外传；函数改数组，原数组跟着变。**

## 7.4 递归 ★★★

★ 考点：**递归追踪是程序阅读题的必考题型**。2025 年真题原题就是 `fun(5)` 的展开。看到递归不要慌，按「**先展开到底，再一层层往回算**」两步走，永远能算对。

**1. 递归的两个必备条件**

| 条件 | 作用 | 少了会怎样 |
|:---|:---|:---|
| ① **递推公式**（把大问题化简为同类的小问题） | 让函数调用自己 | 写不出递归结构 |
| ② **终止条件**（边界条件，最小规模直接给答案） | 让递归停下来 | **无限递归 → 栈溢出崩溃** |

```c
int fact(int n) {
    if (n == 0 || n == 1) return 1;      /* ② 终止条件 */
    return n * fact(n - 1);              /* ① 递推公式 */
}
```

**2. 递归追踪的标准两步法**

| 步骤 | 做什么 | 记法 |
|:---:|:---|:---|
| 第一步 | 从 `f(n)` 开始**往下展开**，直到碰到终止条件 | 「递」——一层层**深入** |
| 第二步 | 从终止条件那一层开始**往回代值**，一层层算出结果 | 「归」——一层层**返回** |

★ 关键心法：**展开时不要算，只写式子；回代时从最里面往外算。**

**3. 阶乘**

```c-run
#include <stdio.h>
int fact(int n) {
    if (n == 0 || n == 1) return 1;
    return n * fact(n - 1);
}
int main(void) {
    printf("%d\n", fact(5));
    return 0;
}
```

```text
120
```

```answer 运行结果与追踪（完整展开）

输出 `120`。

**第一步：往下展开（递）**

```text
fact(5) = 5 * fact(4)
fact(4) = 4 * fact(3)
fact(3) = 3 * fact(2)
fact(2) = 2 * fact(1)
fact(1) = 1            ← 终止条件，到此为止
```

**第二步：往回代值（归）**

```text
fact(1) = 1
fact(2) = 2 * 1     = 2
fact(3) = 3 * 2     = 6
fact(4) = 4 * 6     = 24
fact(5) = 5 * 24    = 120
```

| 层 | 表达式 | 本层结果 |
|:---:|:---|:---:|
| 1 | fact(1) | 1 |
| 2 | fact(2) = 2 × fact(1) | 2 |
| 3 | fact(3) = 3 × fact(2) | 6 |
| 4 | fact(4) = 4 × fact(3) | 24 |
| 5 | fact(5) = 5 × fact(4) | **120** |

⚠ 三个常见错误：

1. 把递推方向写反：`n * fact(n+1)` 永远不会到达终止条件 → **无限递归**。
2. 终止条件写成 `if (n == 0) return 1;` 而实际会调到 `fact(1)` 就停——两个都对，但**必须覆盖到实际会停下来的那一层**。调用 `fact(5)` 时会一直降到 `fact(1)`，所以 `n == 1` 这个条件必须有。
3. `fact(0)` 的答案按定义是 1，不是 0。题目若问 `fact(0)`，答案写 1。
```

**4. 斐波那契数列**

```c-run
#include <stdio.h>
int fib(int n) {
    if (n == 1 || n == 2) return 1;
    return fib(n - 1) + fib(n - 2);
}
int main(void) {
    int i;
    for (i = 1; i <= 8; i++) printf("%d ", fib(i));
    printf("\n");
    return 0;
}
```

```text
1 1 2 3 5 8 13 21 
```

```answer 运行结果与追踪

输出 `1 1 2 3 5 8 13 21 `。

| n | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
|:---:|:---:|:---:|:---:|:---:|:---:|:---:|:---:|:---:|
| fib(n) | 1 | 1 | 2 | 3 | 5 | 8 | 13 | 21 |

**展开 `fib(5)` 作为示范**（这是最常考的）：

```text
fib(5) = fib(4) + fib(3)
fib(4) = fib(3) + fib(2)
fib(3) = fib(2) + fib(1)
fib(2) = 1     ← 终止
fib(1) = 1     ← 终止
```

回代：

```text
fib(3) = 1 + 1 = 2
fib(4) = 2 + 1 = 3
fib(5) = 3 + 2 = 5
```

要点：

- 两个终止条件 `n == 1` 和 `n == 2` **缺一不可**，因为递推时 `n` 每次减 1 或减 2，会同时用到这两层。
- 数列规律：从第 3 项起，每项等于前两项之和（1, 1, 2, 3, 5, 8, 13, 21, 34 …）。
- 递归版斐波那契的**效率很低**（大量重复计算），考试里只考"结果是多少"，不考效率。
```

**5. 求 1 + 2 + … + n**

#include <stdio.h>
int sum(int n) {
    if (n == 1) return 1;
    return sum(n - 1) + n;
}
int main(void) {
    printf("%d\n", sum(100));
    return 0;
}
```

```text
5050
```

```answer 运行结果与追踪

输出 `5050`。

展开：

```text
sum(100) = sum(99) + 100
sum(99)  = sum(98) + 99
...
sum(2)   = sum(1) + 2
sum(1)   = 1            ← 终止条件
```

回代（用等差求和公式验证）：

```text

sum(2) = 1 + 2 = 3
sum(3) = 3 + 3 = 6
sum(4) = 6 + 4 = 10
...
sum(100) = 1 + 2 + ... + 100 = 100 × 101 / 2 = 5050

**6. 汉诺塔**

规则：把 n 个盘子从 A 柱移到 C 柱，借助 B 柱；每次只能移一个盘子，且任何时候大盘不能压在小盘上。

思路：

| 步骤 | 动作 |
|:---:|:---|
| ① | 把上面 `n-1` 个盘子从 A 移到 B（借助 C） |
| ② | 把最底下那个大盘从 A 移到 C |
| ③ | 把 B 上的 `n-1` 个盘子移到 C（借助 A） |

```c-run
#include <stdio.h>
void hanoi(int n, char a, char b, char c) {
    if (n == 1) { printf("%c->%c\n", a, c); return; }
    hanoi(n - 1, a, c, b);
    printf("%c->%c\n", a, c);
    hanoi(n - 1, b, a, c);
}
int main(void) {
    hanoi(3, 'A', 'B', 'C');
    return 0;
}
```

```text
A->C
A->B
C->B
A->C
B->A
B->C
A->C
```

```answer 运行结果与追踪

输出 7 行移动步骤。

| 序号 | 移动 | 说明 |
|:---:|:---|:---|
| 1 | A->C | 把 1 号盘从 A 移到 C |
| 2 | A->B | 把 2 号盘从 A 移到 B |
| 3 | C->B | 把 1 号盘从 C 移到 B（现在 B 上 1、2 号叠好） |
| 4 | A->C | **把 3 号盘（最大的）从 A 移到 C** |
| 5 | B->A | 把 1 号盘从 B 移到 A |
| 6 | B->C | 把 2 号盘从 B 移到 C |
| 7 | A->C | 把 1 号盘从 A 移到 C |

展开 `hanoi(3,A,B,C)`：

```text
hanoi(3,A,B,C)
  = hanoi(2,A,C,B) + "A->C" + hanoi(2,B,A,C)
hanoi(2,A,C,B)
  = hanoi(1,A,B,C) + "A->B" + hanoi(1,C,A,B)
  = "A->C" + "A->B" + "C->B"
hanoi(2,B,A,C)
  = hanoi(1,B,C,A) + "B->C" + hanoi(1,A,B,C)
  = "B->A" + "B->C" + "A->C"
```

★ 必背结论：**n 个盘子的汉诺塔最少移动 `2^n − 1` 次**。n=3 时是 7 次（上面的输出正好 7 行），n=64 时是 2⁶⁴−1 次。

⚠ 三个形参 `a`、`b`、`c` 的含义是「起始柱、辅助柱、目标柱」，**调用时实参的顺序决定了谁是辅助柱**。这是汉诺塔最容易写错的地方：递归调用里 `hanoi(n-1, a, c, b)` 的 b 和 c **交换了位置**。
```

**7. 2025 山西真题原题：递归追踪**

```c
int fun(int n) {
    if (n == 1) return 18;
    else return fun(n - 1) + 2;
}
```

问：`fun(5)` 的值是多少？

```c-run
#include <stdio.h>
int fun(int n) {
    if (n == 1) return 18;
    else return fun(n - 1) + 2;
}
int main(void) {
    printf("%d\n", fun(5));
    return 0;
}
```

```text
26
```

```answer 运行结果与追踪（真题完整展开过程）

**答案：26。**

**第一步：往下展开（递）**

```text
fun(5) = fun(4) + 2
fun(4) = fun(3) + 2
fun(3) = fun(2) + 2
fun(2) = fun(1) + 2
fun(1) = 18          ← 终止条件，到此为止
```

**第二步：往回代值（归）**

```text
fun(1) = 18
fun(2) = fun(1) + 2 = 18 + 2  = 20
fun(3) = fun(2) + 2 = 20 + 2  = 22
fun(4) = fun(3) + 2 = 22 + 2  = 24
fun(5) = fun(4) + 2 = 24 + 2  = 26
```

**第三步：写成一条链（考场上最快最稳的写法）**

```text
fun(5) = fun(4) + 2 = fun(3) + 2 + 2 = fun(2) + 2 + 2 + 2 = fun(1) + 2 + 2 + 2 + 2
       = 18 + 4 × 2
       = 26
```

| 层 | 表达式 | 本层结果 |
|:---:|:---|:---:|
| 1 | fun(1) | 18 |
| 2 | fun(2) = fun(1) + 2 | 20 |
| 3 | fun(3) = fun(2) + 2 | 22 |
| 4 | fun(4) = fun(3) + 2 | 24 |
| 5 | fun(5) = fun(4) + 2 | **26** |

**秒杀结论（同类题通用）**：这类题的形状是 `fun(n) = fun(n-1) + 常数`，边界是 `fun(1) = 起点值`，所以

```text
fun(n) = 起点值 + (n - 1) × 常数
fun(5) = 18 + (5 - 1) × 2 = 18 + 8 = 26
```

⚠ 三个高频丢分点：

1. 把 `+2` 的次数算成 5 次（应该是 **4** 次——fun(1) 是边界，不再加 2）。
2. 展开方向搞反，写成 `fun(n+1)` → 无限递归。
3. 忘记边界值 18 是**返回**而不是累加：`fun(1)` 直接就是 18，不是 `18 + 2`。
```

**8. 递归的输出顺序（进阶但常考）**

```c-run
#include <stdio.h>
void f(int n) {
    if (n == 0) return;
    printf("%d ", n);
    f(n - 1);
    printf("%d ", n);
}
int main(void) {
    f(3);
    printf("\n");
    return 0;
}
```

```text
3 2 1 1 2 3 
```

```answer 运行结果与追踪

输出 `3 2 1 1 2 3 `。

关键：`printf` 在**递归调用之前**和**之后**各有一个，前者按"往下走"的顺序执行，后者按"往回返"的顺序执行。

展开过程（把每个函数的两个打印标成 ⬇ 和 ⬆）：

```text
f(3): ⬇打印3   → f(2): ⬇打印2   → f(1): ⬇打印1   → f(0): 返回
                          ↑                              ↓
       ⬆打印3   ←        ⬆打印2   ←        ⬆打印1   ←
```

执行顺序：

| 顺序 | 语句 | 输出 |
|:---:|:---|:---|
| 1 | f(3) 的第一个 printf | 3 |
| 2 | f(2) 的第一个 printf | 2 |
| 3 | f(1) 的第一个 printf | 1 |
| 4 | f(1) 的第二个 printf | 1 |
| 5 | f(2) 的第二个 printf | 2 |
| 6 | f(3) 的第二个 printf | 3 |

★ 结论：**递归调用前面的语句按"递"的顺序执行（3→2→1），递归调用后面的语句按"归"的顺序执行（1→2→3）**。这就是"递归天然能倒序输出"的原因。
```

**⚠ 易错清单**

⚠ 递归必须有**终止条件**，否则无限递归 → 程序崩溃（栈溢出）。

⚠ 递推公式的方向只能**朝终止条件走**（`n-1`、`n-2`），写成 `n+1` 到不了边界。

⚠ 展开时**不要在"递"的阶段算结果**，先在纸上把式子列全，再从最里层往外代。

⚠ 数 `+2`、`+3` 这类常数的**次数**：`fun(n)` 从 `n` 降到边界值，次数 = `n - 边界`，不是 `n`。

⚠ 递归调用**前面**的语句顺序执行、**后面**的语句逆序执行——这是"输出逆序"类题目的核心。

⚠ `fun(1) = 18` 这类边界值是**直接返回**，不参与任何运算。

💡 口诀：**递推公式＋终止条件；先展开到底，再一层层回代；常数加几次＝n 减边界；调用前正序，调用后倒序。**

## 7.5 变量的作用域与存储类别 ★★

★ 考点：局部变量 / 全局变量的作用域、同名遮蔽；`auto`、`static`、`register`、`extern` 四种存储类别。**`static` 局部变量"只初始化一次、值保留"是程序阅读题的固定考点。**

**1. 局部变量 vs 全局变量**

| 对比项 | 局部变量 | 全局变量 |
|:---|:---|:---|
| 定义位置 | 函数体 / 复合语句 `{ }` 内 | 所有函数之外 |
| 作用域 | 从定义处到所在 `{ }` 结束 | 从定义处到**本文件结束** |
| 生命周期 | 函数本次调用期间 | **整个程序运行期间** |
| 初值 | **随机值**（不初始化不能用） | **自动为 0**（int 为 0，字符为 `'\0'`） |
| 能否被别的函数访问 | 不能 | 能（定义之后的函数都能用） |

⚠ **全局变量不初始化自动是 0，局部变量不初始化是随机值**——这是选择题的经典对比点。

**2. 同名遮蔽（局部优先）**

如果全局变量和局部变量同名，在局部变量的作用域内，**局部变量"遮蔽"全局变量**，用的是局部的那个。

```c-run
#include <stdio.h>
int a = 10;
void f(void) {
    int a = 20;
    printf("%d ", a);
}
int main(void) {
    printf("%d ", a);
    f();
    printf("%d\n", a);
    return 0;
}
```

```text
10 20 10
```

```answer 运行结果与追踪

输出 `10 20 10`。

| 输出顺序 | 位置 | 用的是哪个 a | 值 |
|:---:|:---|:---|:---:|
| 第 1 个 | `main` 里的 printf | **全局** `a`（main 里没有同名局部变量） | 10 |
| 第 2 个 | `f` 里的 printf | **`f` 的局部** `a`（遮蔽了全局的） | 20 |
| 第 3 个 | `main` 里的 printf | 又是**全局** `a`（从未被修改） | 10 |

三个要点：

1. `f` 里的 `int a = 20;` 是一个**全新的变量**，它和全局 `a` 只是重名，不是同一个存储单元。
2. 给局部 `a` 赋值 **不会**改变全局 `a`。
3. 出 `f` 之后，局部 `a` 被销毁，全局 `a` 重新"露出来"，值还是 10。

💡 记住一句话：**近的遮远的**。
```

**3. 四种存储类别**

| 存储类别 | 关键字 | 存储位置 | 生命周期 | 初值 | 说明 |
|:---|:---:|:---|:---|:---|:---|
| 自动 | `auto` | 栈 | 函数调用期间 | 随机 | 局部变量**默认**就是 auto，所以平时都省略不写 |
| 静态 | `static` | 静态存储区 | **整个程序运行期间** | **0** | 局部 static：只初始化一次，值保留；全局 static：只能本文件用 |
| 寄存器 | `register` | 寄存器（尽量） | 函数调用期间 | 随机 | 建议把变量放寄存器以提高速度，**不能取地址 `&`** |
| 外部 | `extern` | 静态存储区 | 整个程序运行期间 | 0 | 声明"这个变量/函数在别的地方定义" |

**4. `static` 局部变量（重点）**

★ 三条铁律：

1. **只初始化一次**——函数第一次被调用时初始化，以后再调用**不再执行初始化语句**。
2. **值会保留**——函数返回后它**不销毁**，下次调用时还能看到上次留下的值。
3. **不初始化则自动为 0**（这一点和普通局部变量不同）。

**例题：连续调用时 static 变量的累加效果**

```c-run
#include <stdio.h>
void fun(void) {
    int x = 0;
    static int y = 0;
    x++;
    y++;
    printf("x=%d y=%d\n", x, y);
}
int main(void) {
    fun();
    fun();
    fun();
    return 0;
}
```

```text
x=1 y=1
x=1 y=2
x=1 y=3
```

```answer 运行结果与追踪（经典必考）

输出三行：`x=1 y=1`、`x=1 y=2`、`x=1 y=3`。

| 调用次数 | 局部 x（每次重建） | static y（一直活着） | x++ 后 | y++ 后 | 输出 |
|:---:|:---|:---|:---:|:---:|:---|
| 第 1 次 | 初始化为 0 | 初始化为 0 | 1 | 1 | `x=1 y=1` |
| 第 2 次 | **重新初始化为 0** | **保持 1，不再初始化** | 1 | 2 | `x=1 y=2` |
| 第 3 次 | **重新初始化为 0** | **保持 2** | 1 | 3 | `x=1 y=3` |

这就是 `static` 和普通局部变量的全部区别：

| 对比项 | `int x = 0;` | `static int y = 0;` |
|:---|:---|:---|
| 每次调用是否重新初始化 | **是**（每次都执行 `= 0`） | **否**（只在第 1 次执行） |
| 函数返回后是否销毁 | 销毁 | **不销毁**，值保留 |
| 不写初值时 | 随机值 | **0** |
| 打印出来的效果 | 每次都是 1 | 1、2、3 递增 |

💡 遇到 `static` 局部变量，追踪时**在表格外面单独为它记一列**，并标注"跨调用保留"。
```

**5. `static` 变量的另一类考法：函数返回值累积**

```c-run
#include <stdio.h>
int fun(int n) {
    static int s = 0;
    s += n;
    return s;
}
int main(void) {
    printf("%d ", fun(1));
    printf("%d ", fun(2));
    printf("%d\n", fun(3));
    return 0;
}
```

```text
1 3 6
```

```answer 运行结果与追踪

输出 `1 3 6`。

| 调用 | 传入 n | static s 进入时的值 | s += n 后 | 返回值 | 输出 |
|:---:|:---:|:---:|:---:|:---:|:---:|
| 第 1 次 | 1 | 0（首次初始化） | 1 | 1 | 1 |
| 第 2 次 | 2 | **1**（保留） | 3 | 3 | 3 |
| 第 3 次 | 3 | **3**（保留） | 6 | 6 | 6 |

⚠ 如果把 `static` 去掉成 `int s = 0;`，结果会变成 `1 2 3`——每次调用 s 都从 0 重新开始。**这就是出题人设的空：加不加 `static`，输出完全不同。**

📌 注意 `printf("%d ", fun(1));` 里，**每个 `fun` 调用都在同一条语句里按顺序求值**，这里三个 `printf` 是三条独立语句，所以求值顺序是确定的 1 → 2 → 3。真题一般不把多个含 static 的函数调用塞进同一个 `printf`。
```

**⚠ 易错清单**

⚠ 全局变量不初始化**自动为 0**；局部变量不初始化是**随机值**。这两句不能混。

⚠ 同名时**局部遮蔽全局**，且修改局部不会影响全局。

⚠ `static` 局部变量的初始化语句**只执行一次**。写 `static int y = 0;` 不代表每次调用 `y` 都是 0。

⚠ `static` 变量也**不能被别的函数直接访问**（它仍然是局部的），只是生命周期变长了——"作用域"和"生命周期"是两件事。

⚠ 全局 `static` 变量 / 函数表示"只在本文件内可用"，与多文件编译有关（见 7.6）。

⚠ `register` 变量**不能取地址**：`register int i; scanf("%d", &i);` 是错的。

⚠ `extern` 是**声明**不是定义，它不分配新空间，只是告诉编译器"这个变量在别处定义"。

💡 口诀：**全局默认 0，局部是随机；近的遮远的；static 只初始化一次、值保留；register 不能取地址；extern 只声明。**

## 7.6 函数声明与多文件基础 ★

★ 考点：函数原型的写法与作用。这一节分值低，掌握基本写法即可，不要展开。

**1. 函数原型声明**

```c
返回类型 函数名(形参类型列表);
```

```c
int add(int a, int b);      /* ✔ 完整写法：带形参名 */
int add(int, int);          /* ✔ 省略形参名也行（只有类型） */
```

| 要点 | 说明 |
|:---|:---|
| 位置 | 写在所有函数之前（`main` 之前），通常在 `#include` 之后 |
| 结尾 | **必须有分号**——这是"声明"和"定义"最直观的区别 |
| 作用 | 告诉编译器：这个函数的返回类型和参数类型是什么，让调用时能正确检查 |
| 与定义的关系 | 一个函数可以**声明多次**，但**只能定义一次** |

```c-run
#include <stdio.h>
void f(int n);            /* 原型声明，结尾有分号 */

int main(void) {
    f(3);                 /* 合法：编译器已经知道 f 的存在 */
    return 0;
}

void f(int n) {           /* 真正的定义写在后面 */
    printf("n=%d\n", n);
}
```

```text
n=3
```

```answer 运行结果与追踪

输出 `n=3`。

要点：

- 没有第 2 行的声明，`main` 里调用 `f` 时编译器还没见过 `f`，会报「隐式声明」错误/警告。
- 声明和定义的**返回类型、参数个数和类型必须一致**，否则编译器报"类型冲突"。
- 声明只需要写类型（`void f(int);`），不写形参名也完全合法。

⚠ 不要把声明和定义搞混：

| | 写法 | 结尾 | 函数体 |
|:---|:---|:---:|:---:|
| 声明（原型） | `int add(int a, int b);` | **有 `;`** | 没有 |
| 定义 | `int add(int a, int b) { ... }` | 无 `;` | **有 `{ }`** |
```

**2. `#include` 与多文件编译（了解即可）**

| 概念 | 说明 |
|:---|:---|
| `#include <stdio.h>` | 尖括号：从**系统目录**找头文件（标准库） |
| `#include "my.h"` | 双引号：**先找当前目录**，再找系统目录（自己写的头文件） |
| `#include` 的作用 | 把被包含文件的内容**原样插入**到这一行所在位置（预处理阶段完成） |
| 多文件编译 | 大程序拆成多个 `.c`，每个 `.c` 单独编译成目标文件，最后**链接**成一个可执行文件 |
| 跨文件使用函数 | 在 A 文件里写 `extern int f(int);` 声明，B 文件里定义 `int f(int x) {...}`，链接时自动找到 |
| 头文件里放什么 | 通常只放**函数原型、`#define` 常量、结构体定义**，**不放函数定义**（否则多文件包含时会重复定义） |

📌 考试范围：知道"函数原型要写在头文件或文件开头""`extern` 用来引用别的文件里的变量/函数"就够。多文件工程的实际操作不考。

💡 口诀：**声明带分号，定义带花括号；尖括号找系统，双引号先找自己；extern 引外部。**

## 7.7 函数程序阅读与程序填空训练 ★★★

★ 考点：考场模拟。**先在纸上追踪，再点开 answer**。6 道题限时 25 分钟。

📌 函数题的追踪要领：① 每个函数单独画一张"形参 + 局部变量"表；② 值传递的参数**画个箭头表示"拷贝"**，别和实参混在一起；③ 遇到 `static` 单独标注"跨调用保留"；④ 遇到递归先写展开式。

### 训练 1：函数嵌套调用

```c-run
#include <stdio.h>
int max3(int a, int b, int c) {
    int m = a;
    if (b > m) m = b;
    if (c > m) m = c;
    return m;
}
int twice(int x) {
    return 2 * x;
}
int main(void) {
    printf("%d\n", twice(max3(3, 9, 5)));
    return 0;
}
```

```text
18
```

```answer 运行结果与追踪

输出 `18`。

求值顺序（由内向外）：

| 步骤 | 求值内容 | 结果 |
|:---:|:---|:---:|
| ① | `max3(3, 9, 5)`：m 依次与 3、9、5 比较 → 9 | 9 |
| ② | `twice(9)` = 2 × 9 | **18** |

`max3` 内部追踪：

| 语句 | m | 说明 |
|:---|:---:|:---|
| `int m = a;` | 3 | 先把 a 当成最大 |
| `if (b > m) m = b;` | **9** | 9 > 3，更新 |
| `if (c > m) m = c;` | 9 | 5 > 9 假，不更新 |

要点：**嵌套调用是从最内层开始算，把内层的结果当作外层的实参**。这和数学里的复合函数 `f(g(x))` 一样。
```

### 训练 2：递归追踪

```c-run
#include <stdio.h>
int f(int n) {
    if (n == 1) return 1;
    return n + f(n - 1);
}
int main(void) {
    printf("%d\n", f(3) + f(2));
    return 0;
}
```

```text
9
```

```answer 运行结果与追踪

输出 `9`。

分两步算：

**`f(3)` 的展开**

```text
f(3) = 3 + f(2)
f(2) = 2 + f(1)
f(1) = 1            ← 终止
```

回代：`f(2) = 2 + 1 = 3` → `f(3) = 3 + 3 = 6`

**`f(2)` 的展开**

```text
f(2) = 2 + f(1) = 2 + 1 = 3
```

**相加**

```text
f(3) + f(2) = 6 + 3 = 9
```

| 调用 | 展开 | 结果 |
|:---|:---|:---:|
| f(1) | 1 | 1 |
| f(2) | 2 + f(1) = 2 + 1 | 3 |
| f(3) | 3 + f(2) = 3 + 3 | 6 |
| f(3) + f(2) | 6 + 3 | **9** |

⚠ 常见错法：把 `f(3) + f(2)` 当成 `f(5)`。**两个调用是独立的**，分别算完再相加。

💡 顺带记住：`f(n) = n + f(n-1)`、`f(1) = 1` 这个递归求的是 `1+2+…+n`。所以 `f(3) = 6`、`f(2) = 3`、和为 9。
```

### 训练 3：`static` 变量追踪

```c-run
#include <stdio.h>
int fun(void) {
    static int c = 0;
    c++;
    return c;
}
int main(void) {
    int i;
    for (i = 0; i < 4; i++) printf("%d ", fun());
    printf("\n");
    return 0;
}
```

```text
1 2 3 4 
```

```answer 运行结果与追踪

输出 `1 2 3 4 `。

| 循环轮次 i | 调用 | static c 进入时 | c++ 后 | 返回/输出 |
|:---:|:---:|:---:|:---:|:---:|
| 0 | 第 1 次 | 0（首次初始化） | 1 | 1 |
| 1 | 第 2 次 | **1**（保留，**不重新初始化**） | 2 | 2 |
| 2 | 第 3 次 | **2** | 3 | 3 |
| 3 | 第 4 次 | **3** | 4 | 4 |

关键：`static int c = 0;` **只在第一次调用时执行**。后面三次调用都跳过了初始化，直接用上次留下的值。

⚠ 如果把 `static` 删掉，输出会变成 `1 1 1 1 `——每次调用 `c` 都重新变成 0。这就是本题的考点。
```

### 训练 4：数组传参 + 求和

```c-run
#include <stdio.h>
int fun(int a[], int n) {
    int i, s = 0;
    for (i = 0; i < n; i++) s += a[i];
    return s;
}
int main(void) {
    int b[5] = {1, 2, 3, 4, 5};

    return 0;
}
```

```text
15
```

```answer 运行结果与追踪

输出 `15`。

|:---:|:---:|:---:|
| 0 | 1 | 1 |
| 1 | 2 | 3 |
| 2 | 3 | 6 |
| 3 | 4 | 10 |
| 4 | 5 | 15 |

### 训练 6：程序填空——补全函数体

题目：补全函数 `prime`，判断 `n` 是否为素数（是返回 1，不是返回 0）。

```c
int prime(int n) {
    int i;
    if (n < 2) return 0;
    for (i = 2; i < n; i++)
        if (______) return 0;      /* 空 ① */
    return ______;                 /* 空 ② */
}
```

```c-run
#include <stdio.h>
int prime(int n) {
    int i;
    if (n < 2) return 0;
    for (i = 2; i < n; i++)
        if (n % i == 0) return 0;
    return 1;
}
int main(void) {
    printf("%d %d %d\n", prime(7), prime(9), prime(1));
    return 0;
}
```

```text
1 0 0
```

```answer 参考答案与追踪

**空 ①**：`n % i == 0`（能整除，说明还有别的因子，不是素数）
**空 ②**：`1`（循环走完都没找到因子，是素数）

输出 `1 0 0`：7 是素数，9 不是素数，1 不是素数。

逐个追踪：

**`prime(7)`**

| i | 7 % i | 是否为 0 |
|:---:|:---:|:---|
| 2 | 1 | 否 |
| 3 | 1 | 否 |
| 4 | 3 | 否 |
| 5 | 2 | 否 |
| 6 | 1 | 否 |
| 循环结束 | — | 返回 **1** |

**`prime(9)`**

| i | 9 % i | 是否为 0 |
|:---:|:---:|:---|
| 2 | 1 | 否 |
| 3 | **0** | **是 → 立即 return 0** |

**`prime(1)`**：`1 < 2` 成立 → 直接 `return 0`。

三个得分点：

1. **空 ① 必须写 `==` 不能写 `=`**：`if (n % i = 0)` 是赋值表达式，编译报错（左值不可赋值），而且逻辑完全错。
2. `if (n < 2) return 0;` 这一句**不能省**：1 和负数都不是素数，而且 `n = 1` 时若没有这句，`for (i = 2; i < 1; ...)` 循环体一次都不执行，会错误地返回 1。
3. `return 0;` 一旦执行，函数**立即结束**，后面不用再判断——这是"提前返回"的典型用法。

📌 变式：如果题目要求"找出 100 以内的素数并输出"，就把 `prime` 放在循环里调用：`for (i = 2; i <= 100; i++) if (prime(i)) printf("%d ", i);`
```

**⚠ 函数部分最容易丢分的 10 个点（考前再过一遍）**

⚠ 形参表里每个参数都要写类型：`int f(int a, int b)` ✔。

⚠ 函数**不能嵌套定义**，**可以嵌套调用**。

⚠ 调用在定义之前时，必须先写**原型声明**（结尾有分号）。

⚠ **C 语言只有值传递**：改形参不影响实参；数组传的是**地址**，所以改数组会影响实参。

⚠ 想让函数改变普通变量的值 → **必须传地址（指针）**，见《08 · 指针》章。

⚠ `return` 只能返回**一个**值；执行到 `return` 函数立即结束。

⚠ `void` 函数不能 `return 值;`，调用结果不能赋给变量。

⚠ 数组作形参时 `sizeof` 求不出长度，**长度必须另传**。

⚠ 递归必须有终止条件，追踪时**先展开、再回代**。

⚠ `static` 局部变量**只初始化一次、值保留**；全局变量不初始化是 **0**，局部变量不初始化是**随机值**。

💡 本章总口诀：**形参作用域只在函数体；值传递拷贝、数组传地址；递归先展开再回代；static 初始化只一次；全局默认零，局部是随机。**
