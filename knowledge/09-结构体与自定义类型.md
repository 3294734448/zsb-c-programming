# 09 · 结构体与自定义类型 ★★★

结构体是"把**不同类型**的数据打包成一个整体"。山西专升本里这一章大约 **10—20 分**，四种题型都能出：

| 题型 | 怎么考 | 难度 |
|------|------|:---:|
| 单项选择题 | 定义形式、`sizeof` 计算、union 与 struct 的区别、枚举的值 | 送分 |
| 填空题 | 成员引用写法、初始化、`->` 与 `.`、union 占多少字节 | 送分 |
| 程序阅读题 | 结构体数组 / 结构体指针遍历，逐行追踪成员值 | 中等 |
| 程序设计题 | **2025 年真题就是结构体数组查找**（工号、姓名、工资） | 必须拿满 |

这一章的特点是：**语法细节多，但逻辑比指针简单**。`.` 和 `->` 用对了、分号没丢、`sizeof` 会算，绝大部分分值就到手了。

📌 学习顺序建议：9.1—9.3 是必须练到能默写的（真题就出在这里），9.4 了解，9.5 的 union/enum/typedef 属于"背结论就得分"，9.6 用来验收。

## 9.1 结构体类型的定义与变量声明 ★★★

★ 考点：`struct 结构体名 { 成员表 };` 的定义形式与**末尾分号**；三种声明变量的方式；结构体类型不占存储空间、变量才占；结构体可以嵌套。

**1. 为什么需要结构体**

- 数组只能存**同一种类型**的一批数据，比如 100 个 `int`。
- 但一个学生有：学号（int）、姓名（字符串）、成绩（float）——类型不同，数组装不下。
- 结构体就是**把若干个类型可以不同的数据成员打包成一个整体**，当作一个新类型来用。

**2. 定义形式**

```c
struct 结构体名 {
    类型名 成员名1;
    类型名 成员名2;
    ...
};                          /* ← 这个分号是定义的一部分，不能少 */
```

例子：

```c
struct student {
    int num;                /* 学号 */
    char name[10];          /* 姓名 */
    float score;            /* 成绩 */
};                          /* 分号！ */
```

⚠ **末尾分号是最高频的失分点**。少写这个分号，编译器会继续往下找变量名，报出一连串莫名其妙的错误（比如"未声明的标识符"出现在几十行之后）。写结构体先写分号，再写成员。

**3. 三种声明变量的方式**

```c
/* 方式一：定义类型的同时顺便声明变量 */
struct student {
    int num;
    char name[10];
    float score;
} s1, s2;
```

```c
/* 方式二：先定义类型，再声明变量（最常用、最清楚） */
struct student {
    int num;
    char name[10];
    float score;
};
struct student s1, s2;
```

```c
/* 方式三：匿名结构体（不写结构体名，只能用这一次） */
struct {
    int num;
    char name[10];
} s1, s2;
```

| 方式 | 写法 | 之后还能不能再声明新变量 |
|:---:|------|------|
| 一 | 定义类型 + 直接跟变量名 | ✔ 能，`struct student s3;` |
| 二 | 先定义类型，再单独声明 | ✔ 能，最常用 |
| 三 | 不写结构体名 | ✘ 不能（没有名字可以引用） |

📌 关键区分：`struct student` 才是**类型名**，`s1` 是**变量名**。C 语言里单写 `student` 不是类型名，必须写 `struct student`（想省掉 `struct` 就得用 `typedef`，见 9.5）。

**4. 结构体类型不占存储空间，变量才占**

★ 结论（选择题常考）：

- `struct student { ... };` 只是**画了一张图纸**（定义了一个类型），**不分配内存**，不占空间。
- `struct student s1;` 才真正分配内存，大小 = 各成员大小之和（实际上还要考虑内存对齐）。
- 所以 `sizeof(struct student)` 得到的是**类型的大小**，也就是这种变量要占多少字节。

**5. 结构体可以嵌套**

成员本身也可以是另一个结构体类型（"结构体的成员是结构体"）：

```c
struct date {
    int year, month, day;
};

struct student {
    int num;
    char name[10];
    struct date birthday;      /* 成员是一个结构体 */
};
```

访问嵌套成员要**一层一层点下去**：`s.birthday.year`。

**6. 例题：定义、声明与成员访问**

```c-run
#include <stdio.h>

struct student {
    int num;
    char name[10];
    float score;
};

int main(void) {
    struct student s = {101, "Li", 90.5f};
    printf("%d %s %.1f\n", s.num, s.name, s.score);
    s.score = 95.0f;
    printf("%.1f\n", s.score);
    return 0;
}
```

```text
101 Li 90.5
95.0
```

```answer 运行结果与追踪
**输出**

```text
101 Li 90.5
95.0
```

| 语句 | s.num | s.name | s.score |
|------|:---:|:---:|:---:|
| `struct student s = {101, "Li", 90.5f};` | 101 | "Li" | 90.5 |
| `printf("%d %s %.1f\n", ...)` | 101 | Li | 90.5（输出 `101 Li 90.5`）|
| `s.score = 95.0f;` | 101 | Li | **95.0** |
| `printf("%.1f\n", s.score)` | 101 | Li | 95.0（输出 `95.0`）|

**要点**

1. 初始化 `{101, "Li", 90.5f}` 是**按成员定义的顺序**依次赋值：先 num、再 name、最后 score。顺序错了类型就错（`{"Li", 101, 90.5f}` 编译报错或警告）。
2. 成员用 **`.`** 访问：`s.num`。点号读作"的"，`s.num` 就是"s 的 num"。
3. `s.name` 是字符数组，用 `%s` 输出，**不加 `&`、也不用写 `[]`**。
```

**7. 例题：嵌套结构体**

```c-run
#include <stdio.h>

struct date {
    int year, month, day;
};

struct student {
    int num;
    char name[10];
    struct date birthday;      /* 结构体嵌套 */
};

int main(void) {
    struct student s = {101, "Li", {2005, 3, 18}};
    printf("%s %d-%d-%d\n", s.name, s.birthday.year, s.birthday.month, s.birthday.day);
    s.birthday.year = 2006;
    printf("%d\n", s.birthday.year);
    return 0;
}
```

```text
Li 2005-3-18
2006
```

```answer 运行结果与追踪
**输出**

```text
Li 2005-3-18
2006
```

| 语句 | s.num | s.name | s.birthday.year | s.birthday.month | s.birthday.day |
|------|:---:|:---:|:---:|:---:|:---:|
| `struct student s = {101, "Li", {2005, 3, 18}};` | 101 | Li | 2005 | 3 | 18 |
| 第一个 printf | 101 | Li | 2005 | 3 | 18（输出 `Li 2005-3-18`）|
| `s.birthday.year = 2006;` | 101 | Li | **2006** | 3 | 18 |
| 第二个 printf | 101 | Li | 2006 | 3 | 18（输出 `2006`）|

**初始化嵌套结构体的写法**：外层一对 `{}` 是整个 `s`，里面的 `{2005, 3, 18}` 是成员 `birthday` 这个结构体的三个成员，**必须单独再用一对花括号**。

⚠ 常见错误：写成 `{101, "Li", 2005, 3, 18}`（把嵌套成员拉平了）——编译会警告或报错，初始化结果也可能不对。
```

**8. 易错清单**

⚠ 结构体定义末尾**必须有分号**：`};`。

⚠ 类型名必须带 `struct` 关键字：声明变量写 `struct student s1;`，不能写 `student s1;`（除非用了 typedef）。

⚠ 结构体**类型**不占内存，只有**变量**才占内存。`sizeof(struct student)` 算的是变量大小。

⚠ 结构体成员名可以和普通变量名重名，互不影响（如结构体里有 `int num;`，外面也可以有 `int num;`）。

⚠ 结构体**不能**包含自己（`struct student { struct student s; };` 会无限递归、编译错误），但可以包含**指向自己的指针**（链表就是这样，见 9.4）。

💡 口诀：**struct 定义末尾分号别丢；类型不占空间、变量才占；点号读作"的"，一层一层点下去。**

## 9.2 结构体变量的初始化与引用 ★★★

★ 考点：初始化写法；`.` 与 `->` 的区别；同类型结构体变量可以**整体赋值**；结构体**不能整体输入输出**；成员地址与 `&`。

**1. 初始化**

```c
struct student {
    int num;
    char name[10];
    float score;
};

struct student s = {101, "Li", 90.5f};     /* 按成员顺序依次赋值 */
struct student t = {101, "Li"};            /* 可以只给前面几个，后面的自动补 0 */
```

| 写法 | 结果 |
|------|------|
| `{101, "Li", 90.5f}` | num=101，name="Li"，score=90.5 |
| `{101, "Li"}` | num=101，name="Li"，**score=0**（数值成员补 0，字符数组成员补 `'\0'`）|
| `{}`（C99） | 全部成员为 0 |

- 初始化只能用**常量**，成员顺序必须和定义顺序一致。
- 声明之后再赋值，就必须**逐个成员**赋：

```c
struct student s;
s.num = 101;
strcpy(s.name, "Li");        /* 字符数组不能直接 s.name = "Li"; */
s.score = 90.5f;
```

⚠ `s.name = "Li";` 是**编译错误**（数组名不是可修改的左值）。字符数组成员要用 `strcpy`，或声明时直接初始化。这是改错题的高频点。

**2. 成员引用：`.` 和 `->`**

| 情形 | 写法 | 例子 |
|------|------|------|
| 普通结构体变量 | `变量名.成员名` | `s.num` |
| 结构体指针 | `指针->成员名` | `p->num` |
| 结构体指针（另一种等价写法）| `(*指针).成员名` | `(*p).num` |
| 结构体数组 | `数组名[下标].成员名` | `a[i].num` |
| 嵌套成员 | 一层一层点 | `s.birthday.year` |

★ 必背：**`p->num` 完全等价于 `(*p).num`**，`->` 就是"指针取成员"的简写。

⚠ **优先级陷阱**：`.` 和 `->` 的优先级比 `*` 高，所以：

| 写法 | 实际含义 | 对不对 |
|------|------|:---:|
| `p->num` | p 所指结构体的 num | ✔ |
| `(*p).num` | 同上（括号不能少）| ✔ |
| `*p.num` | `*(p.num)`，把 num 当指针解引用 | ✘ 编译错误 |
| `*p->num` | `*(p->num)`，num 需是指针类型 | 一般 ✘ |

**3. 同类型结构体变量可以整体赋值**

```c
struct student s1 = {101, "Li", 90.5f}, s2;
s2 = s1;                  /* ✔ 整体赋值：把 s1 的每个成员逐一复制给 s2 */
```

- 对比记忆：**数组不能整体赋值**（`int a[5], b[5]; b = a;` ✘），**结构体变量可以**（`s2 = s1;` ✔）。
- 整体赋值是**值复制**：改 s2 的任何成员（包括字符数组成员）都**不影响** s1。

**4. 不能整体输入输出，必须逐个成员**

✘ 错误写法：

```c
struct student s;
scanf("%d", &s);                  /* ✘ 结构体不能整体输入 */
printf("%d %s %.1f", s);          /* ✘ 结构体不能整体输出 */
```

✔ 正确写法：

```c
struct student s;
scanf("%d %s %f", &s.num, s.name, &s.score);
printf("%d %s %.1f\n", s.num, s.name, s.score);
```

★ 哪个成员要加 `&`，规律和普通变量一样：

| 成员类型 | 输入时 | 原因 |
|------|------|------|
| `int num;` | `&s.num` | 普通变量要取地址 |
| `float score;` | `&s.score` | 普通变量要取地址 |
| `char name[10];` | `s.name`（**不加 &**）| 数组名本身就是地址 |

**5. 成员地址与 `&`**

| 表达式 | 类型 | 含义 |
|------|------|------|
| `&s.num` | `int *` | 成员 num 的地址 |
| `s.name` | `char *` | 字符数组首元素地址（等价于 `&s.name[0]`）|
| `&s` | `struct student *` | **整个结构体变量**的地址 |

📌 `&s` 和 `&s.num` 的**数值相同**（结构体第一个成员的地址就是结构体的地址），但**类型不同**：`&s` 是 `struct student *`，用它加 1 会跳过一整个结构体。

**6. 例题：整体赋值**

```c-run
#include <stdio.h>

struct stu {
    int num;
    char name[10];
    float score;
};

int main(void) {
    struct stu s1 = {101, "Li", 90.5f}, s2;
    s2 = s1;                   /* 同类型结构体变量可以整体赋值 */
    s2.score = 60.0f;
    s2.name[0] = 'X';          /* 改 s2 的数组，s1 不受影响 */
    printf("%s %.1f\n", s1.name, s1.score);
    printf("%s %.1f\n", s2.name, s2.score);
    return 0;
}
```

```text
Li 90.5
Xi 60.0
```

```answer 运行结果与追踪
**输出**

```text
Li 90.5
Xi 60.0
```

| 语句 | s1.num / s1.name / s1.score | s2.num / s2.name / s2.score |
|------|------|------|
| `struct stu s1 = {101, "Li", 90.5f}, s2;` | 101 / "Li" / 90.5 | 未初始化 |
| `s2 = s1;` | 101 / "Li" / 90.5 | **101 / "Li" / 90.5**（整体复制）|
| `s2.score = 60.0f;` | 101 / "Li" / **90.5 不变** | 101 / "Li" / **60.0** |
| `s2.name[0] = 'X';` | 101 / **"Li" 不变** | 101 / **"Xi"** / 60.0 |
| 最后两个 printf | 输出 `Li 90.5` | 输出 `Xi 60.0` |

**两条结论**

1. **结构体整体赋值是"值复制"**：连字符数组成员 `name` 也会被复制一份，s1 和 s2 从此是两块独立内存。
2. 所以改 s2 的成员（哪怕是数组元素）**不会影响** s1。对比一下：如果写 `char *p = s1.name;` 那才是共享同一块内存。
```

**7. 例题：用结构体指针访问成员**

```c-run
#include <stdio.h>

struct stu {
    int num;
    char name[10];
    float score;
};

int main(void) {
    struct stu s = {101, "Li", 90.5f};
    struct stu *p = &s;
    printf("%d %s %.1f\n", p->num, p->name, p->score);
    printf("%d %s\n", (*p).num, (*p).name);     /* (*p).成员 与 p->成员 等价 */
    p->score = 99.0f;
    printf("%.1f\n", s.score);
    return 0;
}
```

```text
101 Li 90.5
101 Li
99.0
```

```answer 运行结果与追踪
**输出**

```text
101 Li 90.5
101 Li
99.0
```

| 语句 | p 指向 | `p->num` | `p->name` | `p->score` | s.score |
|------|:---:|:---:|:---:|:---:|:---:|
| `struct stu *p = &s;` | s | 101 | Li | 90.5 | 90.5 |
| 第一个 printf | s | 101 | Li | 90.5 | 90.5 |
| 第二个 printf（用 `(*p).成员`）| s | 101 | Li | 90.5 | 90.5 |
| `p->score = 99.0f;` | s | 101 | Li | **99.0** | **99.0** |
| 第三个 printf | s | 101 | Li | 99.0 | 99.0 |

**要点**

1. `p->score = 99.0f;` 改的是 **p 指向的那个结构体**（也就是 s）的 score，所以 `s.score` 也变成 99.0。
2. 两种写法的关系：`p->成员` ≡ `(*p).成员`。**`(*p)` 的括号不能省**，因为 `.` 的优先级比 `*` 高。
3. 如果写成 `*p.score`，编译器会理解成 `*(p.score)`（把 score 当指针用），直接报错。
```

**8. 易错清单**

⚠ `s.name = "Li";` ✘ 编译错误。字符数组成员只能声明时初始化，或用 `strcpy(s.name, "Li")`。

⚠ 结构体变量**不能整体输入输出**，必须逐个成员。`scanf` 时字符数组成员不加 `&`。

⚠ `*p.num` 与 `(*p).num` 不是一回事；前者错，后者对。用 `p->num` 最省事。

⚠ 整体赋值 `s2 = s1;` 只对**同类型**结构体成立，`struct A` 和 `struct B` 之间不能赋值（即使成员完全一样也不行）。

⚠ 结构体变量的地址 `&s` 与首成员地址 `&s.num` 数值相同、类型不同，别混用。

💡 口诀：**变量用点、指针用箭头；点号读作"的"；结构体能整体赋值不能整体输入输出；`p->成员` 就是 `(*p).成员`。**

## 9.3 结构体数组 ★★★

★ 考点：结构体数组的定义与初始化；遍历输入输出；**2025 山西真题·程序设计题**（100 位老师信息 + 按工号查找 + `Not exists!`）。

**1. 定义与内存**

```c
struct stu {
    int num;
    char name[10];
    float score;
};
struct stu a[3];              /* 3 个元素，每个元素是一个 struct stu */
```

内存示意（每个元素占 `sizeof(struct stu)` 字节，**连续存放**）：

| 数组元素 | num | name | score |
|:---:|:---:|:---:|:---:|
| a[0] | 101 | "Li" | 90.5 |
| a[1] | 102 | "Zhang" | 78.0 |
| a[2] | 103 | "Wang" | 88.5 |

- `a[i]` 是**一个结构体变量**，所以用 `a[i].num` 访问成员。
- `a[i].name` 是字符数组，用 `%s` 输出、输入时不加 `&`。

**2. 初始化：外层一对括号，每个元素一对括号**

```c
struct stu a[3] = {
    {101, "Li", 90.5f},
    {102, "Zhang", 78.0f},
    {103, "Wang", 88.5f}
};
```

**3. 遍历输入输出模板（背下来）**

```c
int i, n = 3;
for (i = 0; i < n; i++)                                   /* 输入 */
    scanf("%d %s %f", &a[i].num, a[i].name, &a[i].score);
for (i = 0; i < n; i++)                                   /* 输出 */
    printf("%d %s %.1f\n", a[i].num, a[i].name, a[i].score);
```

**4. 例题：结构体数组的初始化与遍历**

```c-run
#include <stdio.h>

struct stu {
    int num;
    char name[10];
    float score;
};

int main(void) {
    struct stu a[3] = {
        {101, "Li", 90.5f},
        {102, "Zhang", 78.0f},
        {103, "Wang", 88.5f}
    };
    int i;
    float sum = 0;
    for (i = 0; i < 3; i++) {
        printf("%d %s %.1f\n", a[i].num, a[i].name, a[i].score);
        sum += a[i].score;
    }
    printf("%.2f\n", sum / 3);
    return 0;
}
```

```text
101 Li 90.5
102 Zhang 78.0
103 Wang 88.5
85.67
```

**输出**

```text

102 Zhang 78.0
103 Wang 88.5
85.67
```

| i | `a[i].num` | `a[i].name` | `a[i].score` | sum |
|:---:|:---:|:---:|:---:|:---:|
| 0 | 101 | Li | 90.5 | 90.5 |
| 1 | 102 | Zhang | 78.0 | 168.5 |
| 2 | 103 | Wang | 88.5 | 257.0 |
| 循环结束 | — | — | — | 257.0 |

**平均值** = 257.0 / 3 = 85.6666… → `%.2f` 输出 **85.67**。

**易错点**

1. `sum` 必须定义成 `float`（或 `double`），定义成 `int` 会丢掉小数部分，平均数就错了。
2. 除以 3 时，若写成 `sum / 3` 而 sum 是 int，会做整数除法（257/3 = 85），输出 `85.00`。
3. 初始化时每个元素都要有自己的 `{}`，写成一长串 `{101,"Li",90.5,102,"Zhang",78.0,...}` 是错的。
```

**5. 2025 山西真题 · 程序设计题（原题）**

★ 题目：设计结构体类型，包含老师的**工号、姓名、工资**，编写程序，输入 **100 位**老师的信息存入结构体数组，再输入一个工号，查找该工号是否存在，如果存在则输出该老师的**姓名和工资**，否则输出 `Not exists!`（每位老师的工号唯一）。

**完整程序（可直接编译运行）**

```c
#include <stdio.h>
#define N 100

struct teacher {
    int id;             /* 工号 */
    char name[20];      /* 姓名 */
    float salary;       /* 工资 */
};

int main(void) {
    struct teacher t[N];
    int i, key, found = 0;
    for (i = 0; i < N; i++)
        scanf("%d %s %f", &t[i].id, t[i].name, &t[i].salary);
    scanf("%d", &key);                      /* 输入要查找的工号 */
    for (i = 0; i < N; i++) {
        if (t[i].id == key) {
            printf("%s %.2f\n", t[i].name, t[i].salary);
            found = 1;
            break;
        }
    }
    if (found == 0) printf("Not exists!\n");
    return 0;
}
```

输入样例（实际考试是 100 行，这里只列前几行示意格式）：

```text
1001 T1001 5001.00
1002 T1002 5002.00
...
1100 T1100 5100.00
1050
```

输出结果（工号 1050 存在时）：

```text
T1050 5050.00
```

如果输入的待查工号在 100 位老师中不存在（例如 `9999`），输出：

```text

```answer 思路拆解与评分点
**思路拆解（按这 6 步写，一步都别省）**

| 步骤 | 做什么 | 代码要点 |
|:---:|------|------|
| ① | 定义结构体类型 `struct teacher` | 三个成员：`int id`、`char name[20]`、`float salary`；**末尾分号** |
| ② | 定义结构体数组 | `struct teacher t[N];`，`#define N 100` 或直接写 `t[100]` |

| ⑤ | 遍历比对工号 | `if (t[i].id == key)` 找到就 `printf` 姓名和工资并 `break`；用 `found` 标记 |
| ⑥ | 循环**结束后**判断 | `if (found == 0) printf("Not exists!\n");` |

| 评分点 | 说明 |
|------|------|
| 结构体定义 | 三个成员类型正确（工号 int、姓名 char 数组、工资 float）；**分号不能丢** |
| 输入 | 100 次循环；`t[i].name` **不能加 &**，另外两个必须加 & |

**4 个常见失分点（必须避免）**

3. ✘ 输出时打了工号：题目要求输出**姓名和工资**。
4. ✘ 定义结构体时漏掉末尾分号，后面一路报错。

    scanf("%d %s %f", &t[i].id, t[i].name, &t[i].salary);
```

**7. 易错清单**

⚠ 结构体数组的每个元素都是结构体，成员访问必须写 `a[i].成员`，**不能**写 `a.num[i]` 或 `a[i]num`。

## 9.4 结构体指针与链表初步 ★★

★ 考点：指向结构体的指针、`->` 运算符、`(*p).name` 与 `p->name` 等价；用结构体指针遍历数组；**链表的概念与最简单的建立、遍历**（考纲以基础为主，不要求复杂的插入删除）。

**1. 指向结构体的指针**

```c
struct stu s = {101, "Li", 90.5f};
struct stu *p = &s;          /* p 指向一个结构体变量 */
```

| 表达式 | 含义 | 值 |
|------|------|:---:|
| `p` | 结构体变量的地址 | &s |
| `p->num` | p 所指结构体的 num | 101 |
| `(*p).num` | 同上（另一种写法） | 101 |
| `p->name` | 字符数组成员，是地址 | "Li" |
| `sizeof(p)` | 指针自己的大小 | 4 或 8（与结构体多大无关）|

★ 结论：**`p->成员` 完全等价于 `(*p).成员`**。因为 `.` 优先级高于 `*`，所以 `(*p)` 的括号**不能省**。

**2. 结构体指针的加减**

```c
struct stu a[3];
struct stu *p = a;      /* p 指向 a[0] */
p++;                    /* p 跳过一整个结构体，指向 a[1] */
```

- `p + 1` 跳过的是 `sizeof(struct stu)` 个字节，**不是 4 个字节**。
- 所以结构体指针可以像普通指针一样遍历数组，这是程序设计题里最常用的写法。

**3. 例题：用结构体指针遍历数组**

```c-run
#include <stdio.h>

struct stu {
    int num;
    char name[10];
    int score;
};

int main(void) {
    struct stu a[3] = {{101, "Li", 90}, {102, "Zhang", 78}, {103, "Wang", 88}};
    struct stu *p;
    int sum = 0;
    for (p = a; p < a + 3; p++) {
        printf("%s:%d\n", p->name, p->score);
        sum += p->score;
    }
    printf("%d\n", sum / 3);
    return 0;
}
```

```text
Li:90
Zhang:78
Wang:88
85
```

```answer 运行结果与追踪
**输出**

```text
Li:90
Zhang:78
Wang:88
85
```

| 轮次 | p 指向 | `p->num` | `p->name` | `p->score` | sum | 输出 |
|:---:|:---:|:---:|:---:|:---:|:---:|:---:|
| 0 | a[0] | 101 | Li | 90 | 90 | `Li:90` |
| 1 | a[1] | 102 | Zhang | 78 | 168 | `Zhang:78` |
| 2 | a[2] | 103 | Wang | 88 | 256 | `Wang:88` |
| 循环结束 | a[3]（越界位置）| — | — | — | 256 | `256/3 = 85` |

**三个关键点**

1. `p->name` 和 `a[i].name` 取到的是同一个字符串，只是 p 用指针、i 用下标。
2. `sum` 定义成 `int`，`256 / 3` 做的是**整数除法**，结果是 **85**（不是 85.33）。想输出小数必须把 sum 定义成 `float`，并用 `%.2f`。
3. 循环结束时 p 指向 `a + 3`（数组后面的位置），此时**不能**再访问 `p->name`，否则越界。

**4. 链表初步（结构体自引用）**

**（1）什么是链表**

数组要求所有元素**连续存放**，插入删除很麻烦；链表用指针把一批**分散存放**的结点串起来：

```c
struct node {
    int data;              /* 数据域：存数据 */
    struct node *next;     /* 指针域：指向下一个同类型结点 */
};
```

| 概念 | 含义 |
|------|------|
| 结点 | 一个结构体变量，含数据域 + 指针域 |
| 头指针 `head` | 指向链表的第一个结点；`head == NULL` 表示空链表 |
| 尾结点 | 最后一个结点，它的 `next` 为 `NULL`（链表结束标志）|
| 自引用 | 成员是指向**自己这种类型**的指针，所以必须写 `struct node *next;` |

⚠ `struct node *next;` 不能写成 `struct node next;` —— 后者会无限递归，编译器直接报错（无法确定结构体大小）。**结构体不能包含自己，只能包含指向自己的指针。**

**（2）最简单的建立与遍历**

```c
struct node *head = NULL, *p;
p = (struct node *)malloc(sizeof(struct node));   /* 申请一个结点 */
p->data = 10;
p->next = head;                                  /* 头插法：新结点插在表头 */
head = p;
```

遍历模板（**必须记住**）：

```c
for (q = head; q != NULL; q = q->next)
    printf("%d\n", q->data);
```

**5. 例题：建立 3 个结点的链表并遍历**

```c-run
#include <stdio.h>
#include <stdlib.h>

struct node {
    int data;
    struct node *next;
};

int main(void) {
    struct node *head = NULL, *p, *q;
    int i;
    for (i = 3; i >= 1; i--) {                 /* 头插法建表 */
        p = (struct node *)malloc(sizeof(struct node));
        p->data = i * 10;
        p->next = head;
        head = p;
    }
    for (q = head; q != NULL; q = q->next) printf("%d\n", q->data);
    while (head != NULL) {                     /* 释放内存 */
        q = head;
        head = head->next;
        free(q);
    }
    return 0;
}
```

```text
10
20
30
```

```answer 运行结果与追踪
**输出**

```text
10
20
30
```

**建表过程（头插法，i 从 3 递减到 1）**

| i | 新结点 data | 执行 `p->next = head` 后 | 执行 `head = p` 后，链表从表头到表尾 |
|:---:|:---:|------|------|
| 3 | 30 | 30 → NULL | 30 |
| 2 | 20 | 20 → 30 | 20 → 30 |
| 1 | 10 | 10 → 20 | **10 → 20 → 30** |

**遍历过程**

| 轮次 | q 指向的 data | `q = q->next` 后 |
|:---:|:---:|------|
| 1 | 10 | 指向 data=20 的结点 |
| 2 | 20 | 指向 data=30 的结点 |
| 3 | 30 | 变成 NULL，循环条件不成立 → 退出 |

**四个要点**

1. **头插法**的特点：最后插入的结点在最前面，所以 i 从 3 递减反而输出 10、20、30（正序）。
2. 遍历条件必须是 `q != NULL`，写成 `q->next != NULL` 会漏掉最后一个结点。
3. 链表结点在内存里**不连续**，所以**不能用 `q++` 移动**，只能 `q = q->next`。
4. `malloc` 需要 `#include <stdlib.h>`，返回的是 `void *`，习惯上强制转换成 `struct node *`；用完要 `free` 释放，避免内存泄漏。

**考纲提醒**：山西考纲对链表的要求是"**理解概念、会建立、会遍历**"，不要求写复杂的插入、删除、逆置。重点仍是 9.3 的结构体数组。
```

**6. 易错清单**

⚠ `(*p).成员` 的括号不能省；能写 `p->成员` 就别写 `(*p).成员`。

⚠ 结构体指针 `p + 1` 跳过一整个结构体，不是 4 字节。

⚠ 链表结点**不连续**，只能用 `q = q->next` 移动，不能 `q++`。

⚠ `struct node *next;` 里的 `struct` 关键字不能省（此时 `struct node` 还没定义完，不能用 typedef 别名）。

⚠ `head == NULL` 表示空链表，遍历前要先判断（否则 `q->data` 会解引用空指针，程序崩溃）。

💡 口诀：**变量用点、指针用箭头；结构体指针加 1 跳一整个结构体；链表靠 next 串，遍历写 `q != NULL`。**

## 9.5 共用体与枚举 ★★

★ 考点：`union` 的定义、与 `struct` 的区别、**内存占用计算**；`enum` 的定义与使用（枚举元素是常量、默认从 0 开始）；`typedef` 给类型起别名。

**1. 共用体 union**

```c
union data {
    int i;
    char c;
    float f;
};
```

- **所有成员共用同一块内存**，起始地址相同。
- 长度 = **最长成员的长度**（考虑对齐后可能更大，见下面第 3 条）。
- **同一时刻只有一个成员是有效的**：后写入的成员会覆盖前面的。

**2. union 与 struct 的区别（必背对比表）**

| 对比项 | `struct` 结构体 | `union` 共用体 |
|------|------|------|
| 内存分配 | 每个成员**各占一块**，总长 = 各成员之和（+ 对齐）| 所有成员**共用一块**，总长 = **最长成员** |
| 成员之间 | 互不影响，可以同时有效 | 互相覆盖，**同时只有一个有效** |
| 定义形式 | `struct 名 { ... };` | `union 名 { ... };` |
| 关键字 | `struct` | `union` |
| 典型用途 | 描述一个对象的多个属性（学生：学号+姓名+成绩）| 让同一块内存在不同时刻存放不同类型的数据 |

**3. union 的内存占用计算题**

考纲算法：**取最长成员的长度**。

| union 定义 | 各成员大小 | 按考纲（取最长）| 用编译器实测 |
|------|:---:|:---:|:---:|
| `union { char c; int i; }` | 1、4 | **4** | 4 |
| `union { int i; double d; }` | 4、8 | **8** | 8 |
| `union { char c; double d; }` | 1、8 | **8** | 8 |

📌 注意：如果最长成员的长度**不是对齐数的整数倍**，真实编译器会补齐。例如 `union { int a[5]; double d; };` 里最长成员是 20 字节，考试按 **20** 写；本机 gcc 实测是 **24**（为对齐 double 补到 8 的倍数）。**考场上按"最长成员"算，除非题目明确给了对齐规则。**

**4. 例题：union 的大小与成员共享**

```c-run
#include <stdio.h>

union u1 {
    char c;
    int i;
};

union u2 {
    int i;
    double d;
};

int main(void) {
    union u1 u;
    union u2 v;
    u.i = 65;                  /* 先给 i 赋值，4 个字节全部确定 */
    printf("%c\n", u.c);       /* 小端机器上低字节就是 65，即 'A' */
    printf("%d %d\n", (int)sizeof(union u1), (int)sizeof(union u2));
    printf("%d\n", (int)sizeof(v));
    return 0;
}
```

```text
A
4 8
8
```

```answer 运行结果与追踪
**输出**

```text
A
4 8
8
```

| 语句 | `u.i` | `u.c` | 说明 |
|------|:---:|:---:|------|
| `union u1 u;` | 未初始化 | 未初始化 | 4 个字节共用 |
| `u.i = 65;` | **65** | 65（低字节）| 给 i 赋值 = 把这 4 个字节都写成 65 的低位形式 |
| `printf("%c\n", u.c);` | 65 | `'A'` | 65 正是 'A' 的 ASCII 码 → 输出 **A** |

| 表达式 | 计算 | 结果 |
|------|------|:---:|
| `sizeof(union u1)` | 成员 1、4 → 取最长 | **4** |
| `sizeof(union u2)` | 成员 4、8 → 取最长 | **8** |
| `sizeof(v)` | 同上 | **8** |

**两个关键点**

1. **共用内存**：`u.c` 和 `u.i` 是同一块内存的两种看法。给 `u.i` 赋值后，`u.c` 读到的是它的低字节，所以 65 → `'A'`（这是小端机器的行为，也是考试的标准答案）。
2. **长度取最长**：`union u2` 里 `double` 占 8 字节 > `int` 的 4 字节，所以整个 union 占 8 字节，**不是 12**（对比结构体就是 4+8=12，还可能因对齐变成 16）。
```

**5. 枚举 enum**

```c
enum weekday { SUN, MON, TUE, WED, THU, FRI, SAT };
```

| 规则 | 说明 |
|------|------|
| 枚举元素是**常量**，不是变量 | `SUN = 1;` ✘ 编译错误 |
| 默认值从 **0** 开始，依次 +1 | SUN=0, MON=1, TUE=2, WED=3, THU=4, FRI=5, SAT=6 |
| 可以指定初值 | `enum color { RED = 1, GREEN, BLUE = 5, YELLOW };` → RED=1, GREEN=2, BLUE=5, YELLOW=**6** |
| 没指定的元素 | 接着上一个元素的值 +1 |
| 本质 | enum 的值就是 **int**，输出用 `%d` |
| 定义变量 | `enum weekday d = WED;`（d 的值是 3）|

**6. 例题：枚举的取值**

**7. typedef 给类型起别名**

```c
typedef struct {
    int num;
    char name[10];
    float score;
} STU;                       /* 现在 STU 就是上面这个结构体类型 */

STU s = {101, "Li", 90.5f};  /* 声明变量时不用再写 struct */

| 常用 | `typedef int INT;`、`typedef struct node {...} NODE;` |

| 对比项 | `typedef` | `#define` |

**8. 易错清单**

⚠ `union` 的所有成员**共用一块内存**，后写的覆盖先写的，不能同时使用。

⚠ `union` 的长度是**最长成员**（+对齐），不是各成员之和 —— 这一点和 struct 正好相反。

⚠ 枚举元素是**常量**，不能赋值：`MON = 5;` ✘ 编译错误。

⚠ 枚举里没给初值的元素，值是**前一个元素 +1**（不是从 0 重新开始）。

⚠ `typedef` 末尾必须有分号；`typedef` 不产生新类型，只是别名。

💡 口诀：**struct 各占各的、union 挤一块；union 长度取最长；枚举从 0 数、指定后接着数；typedef 起别名、末尾别丢分号。**

**第 1 题 · 成员引用与 sizeof**

| `struct S s = {1, 'A', 3};` | 1 | A | 3 | — | — | — |

1. **`t = s;` 是整体赋值**（结构体变量可以整体赋值，数组不行），所以 t 拿到了 s 的全部成员值。

**第 2 题 · 结构体数组排序（按成绩从高到低）**

```c-run
#include <stdio.h>

struct stu {
    char name[10];
    int score;
};

int main(void) {
    struct stu a[4] = {{"Li", 90}, {"Zhang", 78}, {"Wang", 95}, {"Zhao", 60}};
    struct stu t;
    int i, j;
    for (i = 0; i < 3; i++)                     /* 冒泡排序，按成绩从高到低 */
        for (j = 0; j < 3 - i; j++)
            if (a[j].score < a[j + 1].score) {
                t = a[j];                       /* 结构体整体交换 */
                a[j] = a[j + 1];
                a[j + 1] = t;
            }
    for (i = 0; i < 4; i++) printf("%s %d\n", a[i].name, a[i].score);
    return 0;
}
```

```text
Wang 95
Li 90
Zhang 78
Zhao 60
```

```answer 运行结果与追踪
**输出**

```text
Wang 95
Li 90
Zhang 78
Zhao 60
```

**初始**：a[0]=Li 90，a[1]=Zhang 78，a[2]=Wang 95，a[3]=Zhao 60

| 外层 i | 内层 j | 比较 | 是否交换 | 交换后的数组顺序 |
|:---:|:---:|------|:---:|------|
| 0 | 0 | 90 < 78？ | 否 | Li90, Zhang78, Wang95, Zhao60 |
| 0 | 1 | 78 < 95？ | **是** | Li90, **Wang95, Zhang78**, Zhao60 |
| 0 | 2 | 78 < 60？ | 否 | Li90, Wang95, Zhang78, Zhao60 |
| 1 | 0 | 90 < 95？ | **是** | **Wang95, Li90**, Zhang78, Zhao60 |
| 1 | 1 | 90 < 78？ | 否 | Wang95, Li90, Zhang78, Zhao60 |
| 2 | 0 | 95 < 90？ | 否 | Wang95, Li90, Zhang78, Zhao60 |

**最终顺序**：Wang 95 → Li 90 → Zhang 78 → Zhao 60（按成绩从高到低）。

**三个考点**

1. **交换的是整个结构体**：`t = a[j]; a[j] = a[j+1]; a[j+1] = t;`，t 的类型必须是 `struct stu`（不是 `int`）。这就是结构体能整体赋值的用处 —— 如果用两个数组存姓名和成绩，交换起来要写两遍。
2. 排序的**依据是成员**：`a[j].score < a[j+1].score`。
3. 冒泡排序的内层次数是 `3 - i`（n 个元素排 n-1 轮），写错了会越界或漏排。
```

**第 3 题 · 结构体指针遍历**

```c-run
#include <stdio.h>

struct point {
    int x, y;
};

int main(void) {
    struct point a[3] = {{1, 2}, {3, 4}, {5, 6}};
    struct point *p = a;
    int i;
    for (i = 0; i < 3; i++) printf("%d,%d\n", (p + i)->x, (p + i)->y);
    p++;
    printf("%d %d\n", p->x, (*p).y);
    printf("%d\n", (int)(p - a));
    return 0;
}
```

```text
1,2
3,4
5,6
3 4
1
```

```answer 运行结果与追踪
**输出**

```text
1,2
3,4
5,6
3 4
1
```

| 语句 | p 指向 | `p->x` | `p->y` | 输出 |
|------|:---:|:---:|:---:|:---:|
| `struct point *p = a;` | a[0] | 1 | 2 | — |
| `(p+0)->x, (p+0)->y` | a[0] | 1 | 2 | `1,2` |
| `(p+1)->x, (p+1)->y` | a[0] | 3 | 4 | `3,4` |
| `(p+2)->x, (p+2)->y` | a[0] | 5 | 6 | `5,6` |
| `p++;` | a[0] → **a[1]** | 3 | 4 | — |
| `p->x, (*p).y` | a[1] | 3 | 4 | `3 4` |
| `p - a` | a[1] | 3 | 4 | **1**（下标）|

**三个考点**

1. `(p + i)->x` 与 `a[i].x` 等价；`->` 的优先级高于 `+`，所以 `p + i` 必须加括号，写成 `p + i->x` 就完全错了。
2. `p->x` 与 `(*p).y` 是两种等价写法（`->` 和 `(*p).` 是一回事）。
3. 结构体指针 `p++` 跳过的是**一整个结构体**（这里 8 字节），`p - a` 得到下标 1。

**第 4 题 · 共用体输出**

```c-run
#include <stdio.h>

union data {
    int i;
    char c;
    float f;

int main(void) {
    union data d;
    d.i = 66;
    printf("%c\n", d.c);
    printf("%d\n", (int)sizeof(union data));
    d.f = 1.5f;
    printf("%.1f\n", d.f);
    return 0;
}
```

```text
B
4
1.5
```

```answer 运行结果与追踪
**输出**

```text
B
4
1.5
```

| 语句 | `d.i` | `d.c` | `d.f` | 说明 |
|------|:---:|:---:|:---:|------|
| `d.i = 66;` | 66 | 66（低字节）| 被覆盖 | 4 个字节都写成 66 的编码 |
| `printf("%c\n", d.c);` | 66 | `'B'` | — | 66 是 `'B'` 的 ASCII 码 → 输出 **B** |
| `printf("%d\n", sizeof(...))` | — | — | — | 成员 4、1、4 → 取最长 = **4** |
| `d.f = 1.5f;` | 被覆盖 | 被覆盖 | **1.5** | 新写入的成员覆盖了前 4 个字节 |
| `printf("%.1f\n", d.f);` | — | — | 1.5 | 输出 **1.5** |

1. **共用内存**：`d.c` 读到的是 `d.i` 的低字节，66 → `'B'`。
2. **长度取最长成员**：`int`、`float` 都是 4 字节，所以 `sizeof(union data)` = 4（如果三个成员之和，那就是 9 了，那是 struct 的算法）。
3. **后写覆盖先写**：`d.f = 1.5f` 之后，`d.i` 和 `d.c` 的内容就被覆盖了，再读它们没有意义 —— 这就是"同一时刻只有一个成员有效"。

**第 5 题 · typedef 用法**

```c-run
#include <stdio.h>

typedef struct node {
    int data;
    struct node *next;
} NODE;

typedef struct {
    int x, y;
} POINT;

int main(void) {
    NODE a, b;
    POINT p = {3, 4};
    a.data = 1;
    b.data = 2;
    a.next = &b;
    b.next = NULL;
    printf("%d %d\n", a.data, a.next->data);
    printf("%d %d\n", p.x, p.y);
    printf("%d\n", (int)sizeof(POINT));
    return 0;
}
```

```text
1 2
3 4
8
```

```answer 运行结果与追踪
**输出**

```text
1 2
3 4
8
```

| 语句 | a | b | 说明 |
|------|------|------|------|
| `NODE a, b;` | 未赋值 | 未赋值 | `NODE` 就是 `struct node` |
| `a.data = 1; b.data = 2;` | data=1 | data=2 | — |
| `a.next = &b;` | next 指向 b | — | 用指针把两个结点串起来 |
| `b.next = NULL;` | — | next = NULL | b 是最后一个结点 |

| 表达式 | 值 |
|------|:---:|
| `a.data` | 1 |
| `a.next->data` | 2（先 `a.next` 找到 b，再 `->data`）|
| `p.x`、`p.y` | 3、4 |
| `sizeof(POINT)` | **8**（两个 int，2 × 4）|

**四个考点**

1. `typedef struct node { ... } NODE;` 之后，`NODE` 与 `struct node` 完全等价，声明变量时可以省掉 `struct`。
2. 结构体内部的 `struct node *next;` **仍然要写全 `struct node`**（此时 typedef 还没生效，别名 NODE 是在这一行之后才定义的）。
3. `a.next->data` 是"链式"访问：先取 a 的 next（得到 b 的地址），再用 `->` 取成员。
4. 这个结构就是**链表结点**：数据域 data + 指针域 next，`b.next = NULL` 表示链表结束。

**第 6 题 · 程序填空（输入并输出 3 个学生信息）**

★ 题目：下面的程序先输入 3 个学生的学号、姓名、成绩，再用结构体指针遍历输出。请补全程序中 ① ② ③ 三处。

| 空 | 所在语句 | 应填什么 |
|:---:|------|------|
| ① | `for (i = 0; i < 3; i++) scanf("%d %s %d", ①, a[i].name, ②);` | ？ |
| ② | 同上 | ？ |
| ③ | `for (p = a; p < a + 3; p++) printf("%d %s %d\n", ③, p->name, p->score);` | ？ |

**三个空**

| 空 | 答案 | 为什么 |
|:---:|------|------|
| ① | `&a[i].num` | num 是 int 型成员，`scanf` 必须给地址 |

| ③ | `p->num` | p 是结构体指针，取成员用 `->`；输出成员值不需要 `&` |

**最容易丢分的点**：`a[i].name` 是**字符数组**，它本身就是地址，**不能加 `&`**。三个空里只要有一个写成 `&a[i].name`，这一空就没分。

**7. 结构体与自定义类型 · 速查表**

| 关键词 | 定义形式 | 长度 | 访问成员 | 备注 |
|------|------|------|:---:|------|
| 结构体 | `struct 名 { 成员表 };` | 各成员之和（+对齐）| `.` / `->` | 可整体赋值，不能整体输入输出 |
| 共用体 | `union 名 { 成员表 };` | **最长成员** | `.` / `->` | 成员共用内存，同时只有一个有效 |
| 枚举 | `enum 名 { 元素表 };` | 本质是 int | 直接用元素名 | 元素是常量，默认从 0 开始 |
| 类型别名 | `typedef 类型 新名;` | 与原类型相同 | — | 不产生新类型，末尾要分号 |

**8. 本章易错清单（考前最后一遍看这里）**

⚠ 结构体定义末尾**分号不能丢**：`};`。

⚠ 类型名要带 `struct` 关键字（除非用 typedef 起了别名）；类型不占内存，变量才占。

⚠ 成员访问：变量用 `.`，指针用 `->`；`(*p).成员` 的括号不能省。

⚠ 同类型结构体变量可以**整体赋值**，但**不能整体输入输出**，要逐个成员。

⚠ `scanf` 里字符数组成员**不加 `&`**，其他成员必须加 `&`；`s.name = "Li";` 是错的，要用 `strcpy`。

⚠ `union` 的长度是**最长成员**（不是各成员之和）；成员互相覆盖，同一时刻只有一个有效。

⚠ 枚举元素是**常量**，默认从 0 开始、依次 +1；指定初值后，后面的元素接着 +1。

⚠ `typedef` 末尾要分号；结构体自引用只能用指针 `struct node *next;`。

💡 本章总口诀：**struct 定义末尾分号别丢；类型不占空间、变量才占；变量用点、指针用箭头；结构体能整体赋值、不能整体输入输出；union 挤一块取最长，枚举从 0 数，typedef 起别名。**
