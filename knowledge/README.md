📌 从 2025 真题看出的命题规律：

1. **爱考边界**（`while(i)` 初值 0 → 0 次；循环边界差一位）；

3. **程序阅读只考三件事**：函数功能、递归展开、指针/下标移动；
4. **编程题逻辑简单但要求完整**：分段计费、数组统计、结构体查找。

## 三、如何判断是否真正学会

💡 关键认知：**"听懂 ≠ 学会"**。判断标准只有两条——

| 你觉得 | 真正的检验 | 学会的标志 |
|------|------|------|
| "这段代码我看得懂" | 合上代码，纸笔追踪变量变化 | 追踪结果和实际输出一致 |
| "这道编程题我会做" | 关掉答案，从空白文件重敲 | 能编译通过、能跑出正确结果 |

## 八、五条学习原则 ★★★

1. **程序阅读必须纸笔追踪**，不许心算、不许跳步。
2. **代码必须编译运行**。敲完就跑，跑出来才算会；"看着对"不算。
3. **每个程序题先自己写答案，再点开折叠答案**。直接看答案等于没做。
4. **错题回到章节**：做错的题，回到本资料对应小节，把那里的例题再做一遍。
5. **每天不断线**：哪怕只有 20 分钟，也要完成"1 道追踪 + 1 道编程"的最小动作。
