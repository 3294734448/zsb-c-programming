## 1.1 C程序的结构与执行过程 ★★★

★ 考点：①函数构成、`main` 的地位；②从编辑到运行的四个阶段与各阶段产物；③注释写法。三道题常年轮考。

**1. 规则**

**（1）C 程序由函数构成，有且只有一个 `main` 函数**

| 结论 | 说明 |
|------|------|
| 一个 C 程序可以由多个函数组成 | 但**有且只有一个** `main` 函数 |
| 程序从 `main` 开始执行，到 `main` 结束 | 其他函数只有被调用才执行 |
| `main` 可以放在任意位置 | 放最后、放最前都不影响执行顺序 |
| `main` 不能被其他函数调用 | 它是入口，不是普通函数 |

**（2）四个阶段与产物（高频填空）**

| 阶段 | 做什么 | 产物扩展名 |
|:---:|------|:---:|
| 编辑 | 用编辑器写源代码 | `.c`（源程序） |
| 编译 | 把源程序翻译成机器指令（查语法错） | `.obj`（目标文件） |
| 连接 | 把目标文件与库函数等拼成完整程序 | `.exe`（可执行文件） |
| 运行 | 执行可执行文件，得到结果 | — |

⚠ 编译阶段只查**语法错误**，查不出逻辑错误（比如 `a-b` 写成 `a+b`）。逻辑错要靠「运行 + 看结果」发现。

**（3）注释：两种写法**

- `/* ... */`：可跨多行，**不能嵌套**。
- `// ...`：从 `//` 到本行末，只能单行。
- 注释不参与编译，被替换成一个空格。

**（4）预处理命令**

以 `#` 开头，写在源程序最前面，**末尾不加分号**。常见：`#include <stdio.h>`、`#define PI 3.14`。

**2. 例题**

**例 1.1.1（程序阅读 · 写出运行结果）**

```c-run
#include <stdio.h>
void line(void) {
    printf("B\n");
}
int main(void) {
    printf("A\n");
    line();
    printf("C\n");
    return 0;
}
```

```text
A
B
C
```

```answer 运行结果与追踪
输出三行：`A`、`B`、`C`。

追踪（程序的执行路线）：

1. 程序从 `main` 的第一条语句开始，先执行 `printf("A\n")` → 屏幕输出 `A`。
2. 遇到 `line();`，**转去执行 `line` 函数体**：输出 `B`，然后返回 `main` 的下一句。
3. 继续执行 `printf("C\n")` → 输出 `C`。
4. `return 0;` → `main` 结束，**程序结束**。

关键结论：`line` 函数虽然在 `main` 前面，但它**不是**先执行的；C 程序永远从 `main` 的第一条语句起步。把 `line` 函数挪到 `main` 后面（并在前面加 `void line(void);` 声明），输出仍然是 `A B C`。
```

**例 1.1.2（单项选择 · 2025 山西真题风格）**

> 以下关于 C 程序的叙述中，正确的是（　　）
> A. 一个 C 程序可以从任意函数开始执行，到任意函数结束
> B. 一个 C 程序从 `main` 函数开始执行，到 `main` 函数结束
> C. 一个 C 程序中可以有多个 `main` 函数
> D. `main` 函数必须放在程序的最前面

```answer 参考答案
**选 B。**

逐项判定：

| 选项 | 判定 | 理由 |
|:---:|:---:|------|
| A | ✘ | C 程序的入口**唯一**，只能是 `main` |
| B | ✔ | 从 `main` 开始、到 `main` 结束，是 C 的硬规定 |
| C | ✘ | 一个程序**有且只有一个** `main`；写两个会在连接阶段报「重复定义」 |
| D | ✘ | `main` 的位置随意，放最后也能正常跑 |

⚠ 与本题配套的另一个高频选项：「C 程序总是从第一个函数开始执行」——错。第一个函数不一定是 `main`。
```

**3. 易错清单**

⚠ 混淆「编译」与「连接」：源文件 `.c` **编译**成目标文件 `.obj`，目标文件再**连接**成可执行文件 `.exe`。填空常问「编译后生成的文件扩展名」，答案是 `.obj`，不是 `.exe`。

⚠ 把 `/* */` 嵌套写：`/* a /* b */ c */` 会报错，因为第一个 `*/` 就把注释结束了。

⚠ 预处理命令末尾加分号：`#define PI 3.14;` 会把分号也当成宏内容，之后 `PI*2` 展开成 `3.14;*2` → 语法错误。

✔ 正确：`#include <stdio.h>`、`#define PI 3.14`，行尾什么都不加。

💡 口诀：**「一主到底，编连运行；井号命令，分号不跟」**（一个 main 贯穿始终；编译→连接→运行；`#` 开头的命令不加分号）。

## 1.2 标识符与关键字 ★★★

★ 考点：①给一个名字，判断是不是合法标识符（选择题必考）；②32 个关键字里哪几个没见过（`register`、`volatile`、`union`）；③`define` 到底是不是关键字。

**1. 规则**

**（1）标识符的命名规则（三条硬规则 + 一条惯例）**

| 规则 | 内容 | 例子 |
|:---:|------|------|
| ① | 只能由**字母、数字、下划线**三种字符组成 | `sum2`、`_count` ✔ |
| ② | **不能以数字开头** | `2nd` ✘ |
| ③ | **区分大小写** | `sum` 与 `Sum`、`SUM` 是三个不同变量 |
| ④ | **不能是关键字** | `int`、`float`、`do`、`while` ✘ |

**（2）32 个关键字（必须能一眼认出）**

| 类别 | 关键字 | 个数 |
|------|------|:---:|
| 类型 | `char` `short` `int` `long` `float` `double` `void` `signed` `unsigned` | 9 |
| 类型定义 | `struct` `union` `enum` `typedef` | 4 |
| 存储类别 | `auto` `static` `extern` `register` | 4 |
| 流程控制 | `if` `else` `switch` `case` `default` `for` `while` `do` `break` `continue` `goto` `return` | 12 |
| 其他 | `const` `sizeof` `volatile` | 3 |
| **合计** | | **32** |

⚠ `sizeof` 是**关键字**，不是函数；`define` 是**预处理命令**，不是关键字；`include` 也不是关键字。这三个是选择题最爱设的坑。

**（3）预定义标识符**

`printf`、`scanf`、`main`、`define`、`include` 这类由系统预先定义的标识符，**不是关键字**。你可以重定义它们（语法允许），但会覆盖原义，考试里算**合法但不建议**。

**2. 例题**

**例 1.2.1（程序阅读 · 合法标识符的三种写法）**

```c-run
#include <stdio.h>
int main(void) {
    int sum = 1, _count = 2, Max2 = 3, INT = 4, _123 = 5;
    printf("%d %d %d %d %d\n", sum, _count, Max2, INT, _123);
    return 0;
}
```

```text
1 2 3 4 5
```

```answer 运行结果与追踪
输出 `1 2 3 4 5`。

逐个验证合法性（对照三条硬规则）：

| 标识符 | 字符合法 | 不以数字开头 | 非关键字 | 结论 |
|:---:|:---:|:---:|:---:|:---:|
| `sum` | ✔ | ✔ | ✔ | 合法 |
| `_count` | ✔（下划线开头） | ✔ | ✔ | 合法 |
| `Max2` | ✔ | ✔ | ✔ | 合法 |
| `INT` | ✔ | ✔ | ✔ | **合法**——因为 C 区分大小写，`INT` 与关键字 `int` 不是同一个东西 |
| `_123` | ✔ | ✔（**下划线**开头，不是数字开头） | ✔ | 合法 |

⚠ 最容易判错的两个：`INT`（合法）和 `_123`（合法）。判断口诀是「先看首字符是不是数字，再看有没有非法字符，最后查关键字表」。
```

**例 1.2.2（单项选择 · 2025 山西真题同类题）**

> 下列各组用户标识符中，**全部合法**的一组是（　　）
> A. `2sum`、`_num`、`total`
> B. `sum`、`a-b`、`_total`
> C. `sum`、`_123`、`tump`
> D. `total`、`float`、`Sum`

```answer 参考答案
**选 C。**

逐项判定（这是本节的核心技能，必须形成条件反射）：

| 选项 | 标识符 | 判定 | 违反哪条规则 |
|:---:|:---:|:---:|------|
| A | `2sum` | ✘ | 以**数字**开头 |
| A | `_num` `total` | ✔ | — |
| B | `a-b` | ✘ | 含**减号**，不是字母/数字/下划线 |
| B | `sum` `_total` | ✔ | — |
| **C** | `sum` `_123` `tump` | **全 ✔** | 三者均合法 |
| D | `float` | ✘ | 是**关键字** |
| D | `total` `Sum` | ✔ | — |

⚠ 原始真题的常见变体：一组里同时出现 `do`、`float`、`while` 三个**关键字**（如「`do`、`float`、`while`」），这一组同样是**全不合法**，因为它一个合法标识符都没有。关键字不能当变量名，这一点要和「大小写不同就合法」（`INT` ✔ / `int` ✘）分开记。
```

**3. 易错清单**

⚠ `a-b` 不算「用减号连接两个字母」，它就是非法字符组合。同理 `a.b`、`a b`、`a$b` 全非法。

⚠ 关键字**不能**当变量名，但**可以**当字符串或注释内容：`printf("int")` 完全合法。

⚠ `define` 不是关键字。真题原题：「以下不属于 C 语言关键字的是：A. `int` B. `define` C. `return` D. `while`」→ 选 **B**。

✔ 变量命名建议：全小写 + 下划线（`stu_score`），或小驼峰 `stuScore`；**不要**用 `l`（小写 L）、`O`（大写 o）、`I`（大写 i）当变量名，极易与 `1`、`0` 混淆。

💡 口诀：**「字母数字下划线，首位不排数字站；大小写要分开算，关键字里没 define」**。

## 1.3 数据类型总览与 sizeof ★★★

★ 考点：①各类型占几个字节；②`sizeof` 是运算符不是函数、加不加括号的规则；③`sizeof('a')` 与 `sizeof("a")` 的差别——这一项是「送命题」。

**1. 规则**

**（1）常用类型与长度（32 位 / 64 位 Windows 下一致）**

| 类型 | 字节数 | 取值范围（有符号） | 打印格式 |
|------|:---:|------|:---:|
| `char` | 1 | -128 ~ 127 | `%c` / `%d` |
| `short` | 2 | -32768 ~ 32767 | `%d` |
| `int` | 4 | -2147483648 ~ 2147483647 | `%d` |
| `long` | 4 | 同 `int`（Windows 下 4 字节，Linux 64 位才是 8） | `%ld` |
| `float` | 4 | 约 ±3.4×10³⁸，有效位 6—7 位 | `%f` |
| `double` | 8 | 约 ±1.7×10³⁰⁸，有效位 15—16 位 | `%lf` |
| `unsigned int` | 4 | 0 ~ 4294967295 | `%u` |
| `unsigned char` | 1 | 0 ~ 255 | `%c` / `%d` |

📌 记忆方向：**`char` 1、`short` 2、`int`/`long`/`float` 4、`double` 8**。除 `double` 外都是 2 的幂次递进，只有 `long` 在 Windows 下「和 `int` 一样大」需要特别记。

**（2）`sizeof` 的三条规则**

1. `sizeof` 是**运算符**（关键字），不是函数，优先级与 `++`、`!` 同级。
2. `sizeof` 后面跟**类型名**：**必须加括号** → `sizeof(int)`。
3. `sizeof` 后面跟**变量名或表达式**：括号可省 → `sizeof a`、`sizeof(a)` 都行。

**（3）三个必背结论**

| 表达式 | 值 | 说明 |
|:---:|:---:|------|
| `sizeof(char)` | 1 | 长度运算符 |
| `sizeof('a')` | **4** | `'a'` 是**字符常量**，在 C 中按 `int` 处理，占 4 字节 |
| `sizeof("a")` | **2** | `"a"` 是**字符串**，含 `'a'` 和结尾的 `'\0'` |
| `sizeof("abc")` | **4** | 3 个字符 + 1 个 `'\0'` |

⚠ `sizeof('a')` 与 `sizeof("a")` 是本节最大的陷阱：**前者 4，后者 2**。`'a'` 是整型，`"a"` 是字符串（多一个 `'\0'`）。

**2. 例题**

**例 1.3.1（程序阅读 · 写出运行结果）**

```c-run
#include <stdio.h>
int main(void) {
    int a = 10;
    printf("%d\n", (int)sizeof(int));
    printf("%d\n", (int)sizeof(a));
    printf("%d\n", (int)sizeof a);
    printf("%d\n", (int)sizeof('a'));
    printf("%d\n", (int)sizeof("a"));
    printf("%d\n", (int)sizeof("abc"));
    printf("%d\n", (int)sizeof(1.5));
    return 0;
}
```

```text
4
4
4
4
2
4
8
```

```answer 运行结果与追踪
逐行追踪（每题都要能在 10 秒内说出理由）：

| 输出行 | 表达式 | 值 | 依据 |
|:---:|:---:|:---:|------|
| 1 | `sizeof(int)` | 4 | `int` 占 4 字节 |
| 2 | `sizeof(a)` | 4 | `a` 是 `int` 变量 |
| 3 | `sizeof a` | 4 | 跟变量时**括号可省**，值不变 |
| 4 | `sizeof('a')` | **4** | `'a'` 是字符常量，C 中按 `int` 算 |
| 5 | `sizeof("a")` | **2** | 字符串 `"a"` = `'a'` + `'\0'` |
| 6 | `sizeof("abc")` | **4** | 3 个字符 + 1 个 `'\0'` |
| 7 | `sizeof(1.5)` | **8** | 小数常量 `1.5` 默认是 `double`；写成 `1.5f` 才是 4 |

⚠ 表达式 `sizeof a`（不带括号）也**完全合法**——因为 `a` 是变量名，不是类型名。写成 `sizeof int` 就错了。
```

**例 1.3.2（单项选择 · 数组中的 sizeof）**

```c-run
#include <stdio.h>
int main(void) {
    int a[5] = {1, 2, 3, 4, 5};
    char s[] = "abc";
    printf("%d %d\n", (int)sizeof(a), (int)(sizeof(a) / sizeof(a[0])));
    printf("%d %d\n", (int)sizeof(s), (int)(sizeof(s) / sizeof(s[0])));
    return 0;
}
```

```text
20 5
4 4
```

```answer 运行结果与追踪
输出两行：`20 5` 和 `4 4`。

**第一行**（`int a[5]`）：

- `sizeof(a)` = 5 个元素 × 4 字节 = **20**（注意：是**整个数组**的字节数，不是元素个数）。
- `sizeof(a) / sizeof(a[0])` = 20 / 4 = **5** → 这就是**求数组元素个数**的标准写法，务必背下来。

**第二行**（`char s[] = "abc"`）：

- 字符数组存 `"abc"` 会自动在末尾补 `'\0'`，所以数组实际是 `{'a','b','c','\0'}` → 4 个元素。
- `sizeof(s)` = 4 × 1 = **4**。
- `sizeof(s) / sizeof(s[0])` = 4 / 1 = **4**。

⚠ 对比记忆：**`sizeof(s)` 得 4（含 `'\0'`），`strlen(s)` 得 3（不含 `'\0'`）**。这两个数不一样，是填空题的常客。
```

**3. 易错清单**

⚠ `sizeof` 是运算符不是函数，所以 `sizeof int` 是错的、`sizeof(int)` 才对；而 `sizeof a` 和 `sizeof(a)` 都对。

⚠ 求数组元素个数**不能**写 `sizeof(a) / 4`（硬编码字节数），要写 `sizeof(a) / sizeof(a[0])`，这样换类型也不会错。

⚠ `sizeof` 的结果是**无符号整数**，直接参与 `printf("%d", ...)` 在部分编译器下会告警；考试里写 `(int)sizeof(x)` 最稳妥。

💡 口诀：**「类型必须带括号，变量随便；字符常量算四个，字符串多一个」**。

## 1.4 常量与变量 ★★

★ 考点：①整型常量的三种进制（八进制、十六进制）；②实型常量的指数形式；③字符常量与转义字符；④字符串常量末尾的 `'\0'`；⑤`#define` 与 `const` 的区别。

**1. 规则**

**（1）整型常量：三种进制**

| 进制 | 写法 | 例子 | 对应的十进制 |
|:---:|------|------|:---:|
| 十进制 | 普通数字，**不能以 0 开头** | `123`、`-45` | 123、-45 |
| 八进制 | **以 `0` 开头**，只含 0—7 | `012`、`017` | 10、15 |
| 十六进制 | **以 `0x` 或 `0X` 开头**，含 0—9、A—F | `0x12`、`0X1F` | 18、31 |

⚠ `018` 是**错误**的整型常量——八进制里没有数字 8。`0` 单独写是十进制 0，不是八进制。

**（2）实型常量：两种形式**

| 形式 | 写法 | 例子 |
|:---:|------|------|
| 小数形式 | 必须有小数点 | `1.5`、`-0.25`、`3.`（合法）、`.5`（合法） |
| 指数形式 | `尾数e指数`，e 前必须有数字、e 后必须是整数 | `1.5e-3`、`2E5`、`1e-3` |

⚠ 指数形式三个非法例子：`e3`（e 前没数字）、`1.2e2.5`（指数不是整数）、`1.2e`（没写指数）。

**（3）字符常量与转义字符**

字符常量用**单引号**括起**一个**字符：`'a'`、`'A'`、`'1'`、`' '`。转义字符表：

| 转义字符 | 含义 | ASCII 值 |
|:---:|------|:---:|
| `\n` | 换行 | 10 |
| `\t` | 横向制表（Tab） | 9 |
| `\r` | 回车 | 13 |
| `\b` | 退格 | 8 |
| `\\` | 反斜杠本身 | 92 |
| `\'` | 单引号 | 39 |
| `\"` | 双引号 | 34 |
| `\0` | 空字符（字符串结束标志） | 0 |
| `\ddd` | 1—3 位**八进制**数对应的字符 | `\101` = `'A'` = 65 |
| `\xhh` | 1—2 位**十六进制**数对应的字符 | `\x41` = `'A'` = 65 |

**（4）字符串常量**

用**双引号**括起一串字符：`"a"`、`"hello"`、`""`（空串，仍占 1 字节）。

⚠ **字符串末尾自动加 `'\0'`**，所以 `"a"` 占 **2** 字节，而 `'a'` 占 1 个字符（按 `int` 计 4 字节）。

**（5）符号常量**

| 方式 | 写法 | 特点 |
|------|------|------|
| 宏定义 | `#define PI 3.14` | 预处理阶段**文本替换**；末尾不加分号；无类型 |
| `const` 常量 | `const double pi = 3.14;` | 有类型；**末尾要加分号**；运行期不可改 |

**（6）变量：先定义后使用**

变量必须先声明类型，才能使用。定义时给初值叫**初始化**（`int a = 5;`），没给初值时局部变量的值是**随机垃圾值**。

**2. 例题**

**例 1.4.1（程序阅读 · 字符量与字符串长度）**

```c-run
#include <stdio.h>
#include <string.h>
int main(void) {
    char s[] = "a\nb";
    printf("%s", s);
    printf("\n");
    printf("%d %d\n", (int)sizeof(s), (int)strlen(s));
    printf("%d %d\n", 'A', 'a');
    printf("%d %d %d\n", '\101', '\x41', 'A');
    return 0;
}
```

```text
a
b
4 3
65 97
65 65 65
```

```answer 运行结果与追踪
输出 5 行（第 1、2 行是 `a` 和 `b` 分两行）：

| 语句 | 输出 | 追踪 |
|:---:|:---:|------|
| `printf("%s", s)` | `a` 换行 `b` | 数组内容是 `'a'`、`'\n'`、`'b'`、`'\0'`，`\n` 让它换行 |
| `printf("%d %d", sizeof(s), strlen(s))` | `4 3` | `sizeof` 数**字节数** = 4；`strlen` 数字符个数 = 3 |
| `printf("%d %d", 'A', 'a')` | `65 97` | 字符以 ASCII 码参与运算 |
| `printf("%d %d %d", '\101', '\x41', 'A')` | `65 65 65` | 八进制 101 = 十进制 65；十六进制 41 = 十进制 65 |

**`sizeof(s)` 为什么是 4 而不是 5**：关键是 `'\n'` 算**一个**字符，不是两个。

| 数法 | 内容 | 个数 |
|:---:|------|:---:|
| 字面量 `"a\nb"` 的字符 | `a`、`\n`、`b` | 3 |
| 末尾自动追加的结束标志 | `'\0'` | 1 |
| 数组总长度 `sizeof(s)` | 3 + 1 | **4** |
| `strlen(s)` 数到 `'\0'` 为止 | `a`、`\n`、`b` | **3** |

⚠ 转义字符**整体只占 1 个字节**：`'\n'` 是 1 字节，`'\101'` 也是 1 字节，`"\\"` 还是 1 字节。不要把 `\` 和 `n` 数成两个字符。

📌 本节要背死的对照表（比上面这个例子更常考）：

| 声明 | `sizeof` | `strlen` |
|------|:---:|:---:|
| `char s[] = "abc";` | 4 | 3 |
| `char s[10] = "abc";` | 10 | 3 |

**`sizeof` 看数组容量，`strlen` 数字符个数（到 `'\0'` 为止，不含 `'\0'`）。**
```

**3. 易错清单**

⚠ `'a'` 与 `"a"` 完全不同：`'a'` 是字符常量（1 个字符，按 `int` 算 4 字节）；`"a"` 是字符串常量（2 字节，含 `'\0'`）。**不能**把 `"a"` 赋给 `char c`。

✘ 错误写法：`char c = "a";` → 编译错误（把字符串赋给字符变量）。
✔ 正确写法：`char c = 'a';`

⚠ `#define` 行末**不能加分号**：`#define N 5;` 会让 `N*2` 展开成 `5;*2`，编译报错。

⚠ 局部变量不初始化就是**垃圾值**，不要假设它是 0：`int a; printf("%d", a);` 输出不确定。

💡 口诀：**「零头八进制，零叉十六进；单引字符双引串，串尾藏个 `\0`」**。

## 1.5 整数的存储与取值范围 ★★

★ 考点：本节重点解释——「4 个字节共多少 bit」「能表示多少个不同值」「有符号取值范围」。本节把这三问一次讲透，并补上补码与溢出的求法。

**1. 规则**

**（1）字节、位与取值个数（核心三问）**

| 问题 | 推算过程 | 答案 |
|------|------|:---:|
| 4 个字节共多少 **bit**？ | 1 字节 = 8 位，4 × 8 = | **32 位** |
| 32 位能表示多少个**不同值**？ | 每位 2 种状态，2³² = | **4294967296 个**（约 43 亿） |
| 其中**有符号** `int` 的**正数**个数 | 最高位当符号位（0 正 1 负），剩 31 位 | 0 ~ 2147483647，共 2³¹ 个非负数 |
| 有符号 `int` 的**取值范围** | 负数比正数多一个（`-0` 被占用） | **-2147483648 ~ 2147483647** |
| `unsigned int` 的取值范围 | 32 位全用来表示数值 | **0 ~ 4294967295** |

✔ 记住这组对称关系：**有符号范围 = -2³¹ ~ 2³¹-1；无符号范围 = 0 ~ 2³²-1**。两个范围里的**不同值个数相同，都是 2³² 个**——只是切分方式不同。

**（2）补码：负数的存储方式**

计算机用**补码**存整数，规则分三步：

1. 正数的补码 = 它自己的二进制（如 `5` → `00000000 00000000 00000000 00000101`）。
2. 负数的补码 = **取绝对值 → 转二进制 → 全部按位取反 → 末位加 1**。
3. 由补码还原真值：最高位是 1 就是负数，**整体取反加一**得到绝对值，再添负号。

**（3）负数的补码速算法（应试版）**

> `-n` 的补码 = `2³² - n`。

例：`-1` 的补码 = 4294967296 - 1 = 4294967295 = `0xFFFFFFFF`（32 位全 1）。
`-5` 的补码 = 4294967296 - 5 = 4294967291 = `0xFFFFFFFB`。

**（4）溢出**

当运算结果超出该类型的表示范围时，会**回绕（wrap）**到另一端：

- `int` 的最大值 2147483647 再 `+1` → 变成 **-2147483648**。
- `unsigned int` 的 4294967295 再 `+1` → 回到 **0**。

⚠ 考试范围内**只要求你算出回绕后的值**，不要求解释「未定义行为」。按「加减 2³² 取模」算就与主流编译器一致。

**2. 例题**

**例 1.5.1（程序阅读 · 由长度推范围）**

```c-run
#include <stdio.h>
int main(void) {
    printf("%d\n", (int)sizeof(int));
    printf("%d\n", (int)(sizeof(int) * 8));
    printf("%u\n", 2147483647u + 1u);
    printf("%d\n", 2147483647);
    printf("%u\n", 4294967295u);
    return 0;
}
```

```text
4
32
2147483648
2147483647
4294967295
```

```answer 运行结果与追踪
| 行 | 表达式 | 输出 | 追踪 |
|:---:|:---:|:---:|------|
| 1 | `sizeof(int)` | 4 | `int` 占 4 字节 |
| 2 | `sizeof(int) * 8` | **32** | 4 字节 × 8 位/字节 = 32 位（**第一问的答案**） |
| 3 | `2147483647u + 1u` | 2147483648 | 加 `u` 后缀变**无符号**，可以正常表示 2³¹ |
| 4 | `2147483647` | 2147483647 | 有符号 `int` 的**最大值** INT_MAX |
| 5 | `4294967295u` | 4294967295 | 无符号 `int` 的**最大值** UINT_MAX = 2³²-1 |

把这一节的三问连起来回答：

- **4 个字节 = 32 bit**（4 × 8）。
- **32 位能表示 2³² = 4294967296 个不同值**（不是 42 亿「左右」，就是 2³²）。
- **有符号 `int` 范围 -2147483648 ~ 2147483647**；**无符号 0 ~ 4294967295**。

⚠ 第 3 行和第 4 行对比着看：同一个数 2147483647，加 `u` 后缀后 `+1` 得到 2147483648；不加后缀时 `+1` 会**溢出**成 -2147483648（见例 1.5.2）。
```

**例 1.5.2（程序阅读 · 溢出与补码）**

```c-run
#include <stdio.h>
int main(void) {
    int max = 2147483647;
    int min = -2147483648;
    printf("%d\n", max + 1);
    printf("%d\n", min - 1);
    printf("%d\n", -5);
    printf("%u\n", (unsigned)-5);
    return 0;
}
```

```text
-2147483648
2147483647
-5
4294967291
```

```answer 运行结果与追踪
| 行 | 表达式 | 输出 | 追踪过程 |
|:---:|:---:|:---:|------|
| 1 | `max + 1` | **-2147483648** | 2147483647 已是最大值，再加 1 **回绕**到最小值（溢出） |
| 2 | `min - 1` | **2147483647** | -2147483648 减 1 回绕到最大值（反向溢出） |
| 3 | `-5` | -5 | 正常输出 |
| 4 | `(unsigned)-5` | **4294967291** | 同一个位模式按**无符号**解释 |

**第 4 行的完整推导**（补码速算法）：

1. 求 `-5` 的补码：`2³² - 5 = 4294967296 - 5 = 4294967291`。
2. 写成 16 进制：`4294967291 = 0xFFFFFFFB`。
3. 二进制：`11111111 11111111 11111111 11111011`。
4. 同一串位，按 `int` 解释 → 最高位是 1，是负数，取反加一得绝对值 5 → `-5`。
5. 按 `unsigned` 解释 → 没有符号位，直接算数值 → `4294967291`。

**用「取反加一」验证 -5**：

| 步骤 | 内容 |
|:---:|------|
| ① 绝对值 5 | `00000000 00000000 00000000 00000101` |
| ② 按位取反 | `11111111 11111111 11111111 11111010` |
| ③ 末位加 1 | `11111111 11111111 11111111 11111011` = `0xFFFFFFFB` |

⚠ 溢出题在山西卷里以**选择/填空**出现，问法通常是「执行后 i 的值是」。答案就是回绕值，**不用纠结**编译器差异。
```

**3. 易错清单**

⚠ 把「能表示多少个不同值」答成 2147483647。正解是 **2³² = 4294967296 个**（有符号、无符号都一样多）。

⚠ 把有符号范围的负端写成 -2147483647。正解是 **-2147483648**（负数多一个，因为 `0000...0` 被 0 占用了）。

⚠ 用「原码」算负数：`-5` 不是 `10000101`，那是原码，计算机**不用**。必须用**补码**：`0xFFFFFFFB`。

⚠ 忘记 `unsigned` 与 `%u` 配对：打印无符号数要用 `%u`，用 `%d` 会得到负数。

💡 口诀：**「四字节三十二位，二的三十二次方个值；有符号负多一个，负数补码取反加一」**。

## 1.6 类型转换 ★★★

★ 考点：①自动转换的「由低到高」方向；②赋值时的截断（`int x = 3.9` 得 3）；③`1/2` 与 `1.0/2` 的区别——**这是程序阅读题失分率最高的一个点**。

**1. 规则**

**（1）自动类型转换：由低到高**

| 方向 | 类型顺序（低 → 高） |
|:---:|------|
| 纵向提升 | `char` / `short` → `int` → `unsigned` → `long` → `float` → `double` |
| 一句话 | 短 → 长、整型 → 浮点型。**两个不同类型运算时，先把低的转成高的，再运算** |

典型表现：`1 + 1.5` → `1` 先变成 `1.0` → 结果是 `2.5`（`double`）。

**（2）赋值时的转换：以左边类型为准（可能截断）**

| 语句 | 过程 | 结果 |
|------|------|:---:|
| `int x = 3.9;` | 浮点转整型：**直接舍去小数部分**（不是四舍五入） | `x = 3` |
| `int y = -3.9;` | 舍去小数部分（向零取整） | `y = -3` |
| `double d = 5;` | 整型转浮点：安全提升 | `d = 5.0` |
| `char c = 65;` | 整数按 ASCII 转字符 | `c = 'A'` |

**（3）强制类型转换**

写法：`(类型名)(表达式)`，例如 `(int)3.9` 得 `3`、`(double)5/2` 得 `2.5`。

⚠ 强制转换**只在本表达式中生效**，不改变原变量的类型和值：`double d = 3.9; int n = (int)d;` 之后 `d` 仍然是 `3.9`。

**（4）整除：程序阅读题的头号杀手**

| 表达式 | 值 | 原因 |
|:---:|:---:|------|
| `5 / 2` | **2** | 两边都是整型 → **整除**，舍去小数 |
| `5 % 2` | **1** | 取余数 |
| `5.0 / 2` | **2.5** | 一边是浮点 → 按浮点除法 |
| `(double)5 / 2` | **2.5** | 强制转换把 5 变成 5.0 |
| `1 / 2 * 2.0` | **0.0** | **先算 `1/2` 得 0**，再 `0 * 2.0` = 0.0 |

📌 最后一行是「顺序陷阱」：`1/2*2.0` **不等于** `1.0`，因为整除先发生。要写成 `1.0/2*2` 或 `1/(2.0)*2`。

**2. 例题**

**例 1.6.1（程序阅读 · 整除与类型提升）**

```c-run
#include <stdio.h>
int main(void) {
    int a = 5, b = 2;
    printf("%d\n", a / b);
    printf("%d\n", a % b);
    printf("%.1f\n", 5.0 / 2);
    printf("%.1f\n", (double)a / b);
    printf("%.1f\n", 1 / 2 * 2.0);
    return 0;
}
```

```text
2
1
2.5
2.5
0.0
```

```answer 运行结果与追踪
| 行 | 表达式 | 输出 | 追踪（关键在**运算两边是什么类型**） |
|:---:|:---:|:---:|------|
| 1 | `a / b` | **2** | `a`、`b` 都是 `int` → 整除，5÷2 = 2.5 → **舍去小数得 2** |
| 2 | `a % b` | **1** | 5 ÷ 2 余 1 |
| 3 | `5.0 / 2` | **2.5** | 一边是 `double` → `2` 被提升为 `2.0` → 浮点除法 |
| 4 | `(double)a / b` | **2.5** | 强制转换把 `a` 变成 `5.0`，再除以 2 |
| 5 | `1 / 2 * 2.0` | **0.0** | ⚠ **先算 `1/2` = 0**，再算 `0 * 2.0` = `0.0` |

⚠ 第 5 行是本书最想让你记住的一行。虽然整个表达式里有 `2.0`（浮点），但 `*` 和 `/` **同级、左结合**，所以 `1/2` 先算，而它是**整除**，结果 0，再怎么乘都是 0。

正确写法对照：

```c
double x = 1.0 / 2 * 2;   /* 0.5 * 2 = 1.0 */
double y = 1 / (2.0) * 2; /* 0.5 * 2 = 1.0 */
double z = 1.0 * 1 / 2 * 2; /* 左边先变浮点，全程浮点 = 1.0 */
```

**例 1.6.2（程序阅读 · 赋值截断与强制转换）**

```c-run
#include <stdio.h>
int main(void) {
    int x = 3.9;
    int y = -3.9;
    double d = 5;
    int n = (int)3.9 + (int)2.9;
    printf("%d\n", x);
    printf("%d\n", y);
    printf("%.1f\n", d);
    printf("%d\n", n);
    printf("%.2f\n", (double)(7 / 2));
    return 0;
}
```

```text
3
-3
5.0
5
3.00
```

```answer 运行结果与追踪
| 行 | 语句 | 输出 | 追踪 |
|:---:|:---:|:---:|------|
| 1 | `int x = 3.9;` | **3** | 浮点赋给整型 → **舍去小数**（不四舍五入） |
| 2 | `int y = -3.9;` | **-3** | 向零取整，不是 -4 |
| 3 | `double d = 5;` | **5.0** | 整型提升为浮点，安全 |
| 4 | `(int)3.9 + (int)2.9` | **5** | 3 + 2 = 5（**先各自转换再相加**，不是 `(int)6.8`） |
| 5 | `(double)(7 / 2)` | **3.00** | ⚠ **括号在里层：先整除 `7/2` = 3**，再转成 `3.00` |

⚠ 第 5 行和 `(double)7 / 2`（结果是 3.50）**完全不同**，区别只在括号位置：

| 写法 | 先算什么 | 结果 |
|:---:|:---:|:---:|
| `(double)(7 / 2)` | **里面**先整除 → 3 → 再转 double | `3.00` |
| `(double)7 / 2` | 7 先转 `7.0` → 再浮点除 | `3.50` |

📌 应试判据一句话：**强制转换的括号管到哪，就先算到哪；括号外面的事后算。**
```

**3. 易错清单**

⚠ 认为 `int x = 3.9` 会四舍五入成 4。**C 一律截断**，得 3。想四舍五入要写 `(int)(3.9 + 0.5)`。

⚠ 忘记 `1/2 == 0`。凡是「求平均数、求比例」的题，只要两边都是整型，结果就被砍掉小数——这是程序阅读题最常见的坑。

⚠ 以为强制转换能改原变量：`(int)d` 之后 `d` 还是 `double`、值还是 `3.9`。

⚠ `(double)(7/2)` 与 `(double)7/2` 混为一谈。记法：**括号是「圈地」的，圈里的人先算完再出来**。

💡 口诀：**「低到高自动升，浮点赋值砍尾巴；整除只看两边型，一个浮点就是真除」**。
